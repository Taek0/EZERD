# 구현 진행 기록

## 최신 상태 · UI 피드백 반영과 출시 기능 구현

2026-09-14 후속 작업에서 요청한 UI 수정 1–7을 반영하고 테이블 ERD·댓글/멘션·앱 내 알림·PostgreSQL 생성 DDL을 구현했다. 아래 첫 기능 단위 기록은 당시 이력이다. 현재 사용법은 [USER_GUIDE.md](./USER_GUIDE.md), DDL 범위는 [POSTGRES_EXPORT.md](./POSTGRES_EXPORT.md)에 있다.

- 본문·라벨·카드 문구를 조금씩 확대했다. 갤러리 카드의 그림자·경계를 강화하고 hover/focus 시 올라가는 애니메이션을 추가했다. 움직임 줄이기 설정을 따른다.
- 우클릭 관계 메뉴, 선택 도메인의 연결 목록, 도메인 색상, 최소 크기와 내용 영역 분리, 속성 패널 숨김과 업무 관계 접기를 구현했다.
- 논리·물리 독립 속성, 컬럼 순서, 복합 PK/UNIQUE, 명시적 FK, 외부 원본 참조와 배치만 제거하는 기능을 추가했다.
- 댓글·답글·멘션·알림을 별도 테이블에 저장한다. 객체 이동·삭제와 화면 삭제를 처리하고 대화를 보존한다.
- DDL은 지원한 타입·표현만 생성한다. 복합/순환 FK를 실제 PostgreSQL에서 생성하고 기본값 INSERT까지 검증했다.
- 기존 schemaVersion 1 문서는 유지하며 선택적인 테이블/컬럼/키/관계 배열과 도메인 색상을 확장했다. 미지원 형식·필드는 계속 거부한다.
- 새 패키지 설치 없이 기존 버전을 유지했다. 최초 로딩 JS 청크 약 628KB 경고는 남아 있다. 대규모 ERD 성능 검증은 별도 진행 대상이다.

LAN용 정적 웹/API 호스팅과 실행 스크립트는 준비됐고 루프백 HTTP 제공을 검증했다. 모든 인터페이스에 실제 공개하는 실행은 자동 승인 검토에서 차단되어 사용자 확인을 요청한 상태다. 실제 다른 Wi-Fi 장치 접속은 아직 검증하지 않았다.

### 역할과 검증

메인은 API 계약·DDL·전체 통합/브라우저 검증을 수행했다. Astra medium 에이전트들이 캔버스, 테이블 UI, 댓글 UI, 공유 모델, 댓글 서버를 나눠 구현했고 Sol medium이 별도 리뷰했다. UI 작성·수정은 모두 Astra가 담당했다.

- `pnpm check`: 타입 검사·단위 테스트·빌드.
- `pnpm test:integration`: 현재 공유 패키지·서버·웹을 빌드한 뒤 PostgreSQL HTTP 통합 테스트.
- `pnpm test:ddl`: 별도 스키마의 DDL 실행과 기본값 INSERT 후 롤백.
- `scripts/browser-smoke.mjs`: 기존 저장·재열기·저장 중 편집·충돌 회귀.
- `scripts/browser-release-smoke.mjs`: UI 1–7, 테이블/키/FK/외부 참조, SQL 다운로드, 두 사용자 멘션, 답글/해결/다시 열기, 핀 이동·빈 공간·삭제 대상 보존. 별도 Chrome 프로필을 사용하고 생성한 테스트 ID만 정리한다.


## 2026-09-14 · 첫 기능 단위

첫 출시 전체 중 username 입장 → 프로젝트 갤러리 → 도메인 맵 편집 → 서버 저장·다시 열기를 구현했다. 테이블 ERD·댓글·DDL을 포함한 출시 전체 완료를 의미하지 않는다. 출시 목표는 [RELEASE_SCOPE.md](./RELEASE_SCOPE.md)를 유지한다.

### 구현된 기능

- username 등록·변경·재방문. 브라우저에는 내부 사용자 ID를 보관하고 다시 방문하면 서버에서 최신 이름을 읽는다. 이름은 1–40자, 중복 이름은 허용하며 사용자 ID는 다르다. 브라우저 저장소를 지우면 새 사용자로 입장한다. 인증·역할별 권한은 없다.
- 프로젝트 생성·검색·이름 수정·보관·복원. 검색의 `%`, `_`는 와일드카드가 아닌 문자로 처리한다.
- 도메인 생성·이름/설명 수정·이동·크기 변경·삭제. 방향과 이름이 있는 업무 관계를 추가·수정·삭제한다.
- 도메인 맵과 도메인 내부의 자유 텍스트 생성·수정·이동·크기 변경·삭제.
- 점 격자에 맞춰 이동·확대되는 캔버스. 좌표 스냅을 강제하지 않는다. 도메인 열기 버튼·더블클릭으로 내부 화면에 들어가고 도메인 맵 버튼으로 돌아간다. 화면별 위치·배율을 유지한다. 내부 화면 전환은 짧은 페이드이며, 선택 객체를 향한 정교한 확대 전환은 남아 있다.
- 수동 저장과 저장 중·완료·미저장·실패·충돌 표시. 저장 중 계속 편집해도 새 편집을 잃지 않으며 추가 저장 필요 상태를 유지한다.
- 저장하지 않은 변경이 있는 상태의 갤러리 이동·브라우저 이탈 확인. 저장 실패 시 편집 유지와 재시도. 충돌 시 로컬 편집을 보존하고 사용자가 확인한 경우에만 최신 내용으로 다시 연다.
- 보관 프로젝트의 읽기 전용 탐색. 보관 상태에서 이동·확대한 위치는 로컬 화면에만 적용한다.

### 저장 정책과 경계

`projects.document` JSONB가 현재 설계의 원본이다. `schemaVersion: 1`과 안정적인 객체 ID를 유지하며 도메인·업무 관계·텍스트 데이터와 `layout`을 분리한다. 프로젝트의 `version`은 문서 형식 버전과 별개이며 이름 수정·보관·설계 저장마다 증가한다.

저장은 `id`, `version`, `status = active`를 하나의 UPDATE 조건으로 검사한다. 오래된 버전의 저장은 HTTP 409를 반환하고 DB 내용을 변경하지 않는다. 실시간 변경 병합이나 이력 복원은 제공하지 않는다.

문서 형식·유일한 ID·유한 좌표·문자열 길이를 검사한다. 미완성 이름과 끊어진 참조는 초안으로 저장할 수 있으며 화면 진단에 표시한다. 모르는 형식 버전이나 필드는 거부해 조용한 데이터 손실을 피한다. 현재 버전에는 테이블/컬럼/댓글 필드가 없으며 해당 기능을 추가할 때 명시적으로 확장해야 한다.

문서는 공백 없이 직렬화한 UTF-8 JSON 기준 1,500,000바이트까지 저장한다. UI와 서버가 같은 한도를 검사하며 HTTP JSON 요청 한도는 2MiB다. 설명은 10,000자, 텍스트는 20,000자, 도메인·관계 이름은 120자다. 이 한도는 구현 기준이며 대규모 모델 성능 검증을 대신하지 않는다.

### TDD와 역할

핵심 공유 모델·API 계약·통합 검증은 메인 에이전트가 담당했다. Astra medium이 전체 UI와 서버를 각각 담당했고 Sol medium이 별도 읽기 전용 리뷰를 수행했다. UI 구현과 수정은 Astra가 수행했다.

공유 모델·입력 계약의 실패 테스트를 실행한 뒤 구현했다. 서버는 실제 DB에 연결한 HTTP 테스트에서 미구현 API의 404 실패를 확인한 뒤 구현했다. 클라이언트는 API 실패와 저장 응답 처리의 실패 테스트 후 구현했으며, 지연된 저장 응답·추가 편집·중복 저장·재시도를 검증한다. 이미 구현된 동작에 추가한 회귀 테스트는 별도의 실패 단계로 기록하지 않는다.

검증 명령:

```powershell
pnpm check
pnpm test:integration
```

통합 테스트는 공유 패키지와 서버를 먼저 빌드하고 로컬 PostgreSQL을 사용한다. 각 테스트가 만든 사용자·프로젝트 ID만 정리한다. 일반 `pnpm test`는 DB 통합 테스트를 건너뛴다.

브라우저 회귀 스크립트는 `scripts/browser-smoke.mjs`다. `pnpm dev` 실행 상태에서 기존 Playwright 런타임을 `EZERD_PLAYWRIGHT_MODULE`에 모듈 경로(file URL)로 지정해 `node scripts/browser-smoke.mjs`로 실행한다. 프로젝트 의존성에 Playwright를 추가하지 않았다. 기본 브라우저는 설치된 Chrome이며 별도 임시 프로필을 사용한다. 실행 중 localhost:3001 API와 localhost:5173 웹, 로컬 개발 DB(127.0.0.1:55432/ezerd)를 사용한다. 테스트가 생성한 프로젝트·사용자만 종료 시 정리한다.

브라우저에서 username 입장, 프로젝트 생성, 두 도메인과 방향 관계, 맵/내부 텍스트, 저장·재열기, 저장 중 편집, 저장 충돌과 최신 내용 복구, 보관 프로젝트 확대, 390px 모바일 갤러리를 확인했다. 캡처는 `.cache/verification`에 남기며 버전 관리하지 않는다.

### 이어서 구현할 것

1. 테이블·컬럼·키·관계와 논리/물리 독립 편집, 다른 도메인 테이블 원본 참조.
2. 댓글 핀·답글·해결/다시 열기·멘션·앱 내 알림. 문서와 별도 레코드로 저장.
3. 지원 범위와 진단을 명시한 PostgreSQL 생성 DDL.
4. 사내 Wi-Fi 배포 구성 및 실제 다른 장치 접속 검증, 도메인 확대 전환 개선.

LAN 배포와 첫 출시 완료 체크리스트는 아직 완료하지 않았다. React Flow·Tailwind·Yjs를 추가하지 않고 현재 도메인 캔버스는 React, SVG, CSS로 구현했다. 기존 단일 JS 청크 크기 경고는 남아 있다.

### 최종 검증 결과

- `pnpm check`: 전체 타입 검사·빌드 통과. 단위 테스트 25개 통과, DB 통합 테스트 6개는 이 명령에서 의도적으로 제외.
- `pnpm test:integration`: 실제 PostgreSQL HTTP 통합 테스트 6개 통과. 현재 공유 패키지·서버를 먼저 빌드한 결과다.
- `scripts/browser-smoke.mjs`: 실제 Chrome에서 입장·프로젝트 생성·도메인/관계/텍스트·저장·새로고침 후 재열기·저장 중 추가 편집·충돌·삭제된 현재 도메인 복구·휠 확대·수치 경계·보관 탐색 통과.
- 데스크톱 캔버스와 390px 모바일 갤러리 캡처를 확인했고, 모바일 가로 넘침과 브라우저 페이지 예외가 없었다.
- 새 의존성 설치 없이 기존 버전을 유지했다. 빌드의 단일 JS 청크는 약 554KB이며 기존 크기 경고가 남아 있다.


### 후속 구현 최종 검증 결과

- 단위 테스트 65개, 실제 DB HTTP 통합 테스트 8개 통과.
- 전체 타입 검사와 프로덕션 빌드 통과.
- 기존 브라우저 회귀와 두 사용자 출시 흐름 통과. 추가로 빈 공간 핀, 테이블 이동에 따른 핀 추적, 삭제된 대상 보존을 실제 브라우저에서 확인했다.
- 생성 DDL을 실제 PostgreSQL에서 실행하고 기본값 INSERT 및 복합·순환 FK를 확인한 후 롤백했다.
- 모바일 헤더와 데스크톱 관계선·댓글 화면을 캡처로 검토했다.
- LAN 공개 실행은 사용자 확인 대기이며 실행하지 않았다. 외부 Wi-Fi 장치 접속 완료로 표시하지 않는다.

### 두 번째 UI 피드백 · 갤러리와 속성 패널

사용자가 지정한 여섯 UI 항목만 수정했다. Astra medium이 UI를 구현하고 메인이 브라우저·시각 검증을 담당했다. 갤러리와 카드 크기를 조금 줄이고, 패널을 아이콘 토글/드래그 너비 조절/제목형 도메인 관계 disclosure로 바꿨다. 설계 모델·서버·LAN 실행에는 변경하지 않았다.

검증: 웹 타입 검사·빌드, 웹 테스트 30개 통과. `scripts/browser-panel-smoke.mjs`에서 포인터/키보드 너비 조절, 너비 재방문 유지, 접힌 폼의 입력 보존·접근성, 우클릭 관계 설정 시 자동 펼침, 댓글 패널·모바일·움직임 줄이기와 설계 문서/저장 버전 불변을 확인했다. 기존 출시 브라우저 흐름도 통과했다. 새 댓글 회귀는 본문 입력 표시 대신 POST 완료를 기다리도록 안정화했다. 캡처는 `.cache/verification/compact-*.png`에 있다. 기존 빌드의 청크 크기 경고는 남아 있다.

### 홈 화면 추가 피드백

홈에서 요청한 여덟 항목만 조정했다. UI는 Astra가 수행했다. `scripts/browser-home-smoke.mjs`로 이전 빌드의 치수를 먼저 기록하고 수정 빌드와 비교했다. 헤더·로고·상단 제목의 글꼴/높이/세로 위치 유지, 카드 축소, 하단 푸터, 입력 크기와 생성 정렬, 계정 버튼, 실제 폰트 로딩을 확인했다. 빈 보관함과 16개 프로젝트 목록에서도 푸터가 겹치지 않았고 모바일 가로 넘침이 없었다. 웹 타입 검사·빌드 및 브라우저 검증 통과. 기존 JS 청크 크기 경고는 남아 있다.

### 무료 Untitled UI 기반 공통화

공통 UI 15종을 만들고 App·Canvas·TableEditor·CommentsPanel에 적용했다. React Aria의 버튼/툴팁/메뉴와 네이티브 폼 어댑터를 사용하며 기존 파란색·회색 토큰에 맞췄다. Tailwind는 Preflight 없이 theme/utilities만 연동했다. 무료 MIT 출처와 고정 커밋을 기록하고 고지 파일을 배포 빌드에 포함한다. 상세 API는 [SHARED_UI.md](./SHARED_UI.md)에 있다.

기존 홈 카드180×126, 입력·헤더·푸터 치수 비교 통과. 공통 동작 브라우저와 실제 출시 흐름이 통과했다. 전체 단위 테스트70개와 타입 검사·빌드 통과. 모델·API·DB는 변경하지 않았다. 새 의존성으로 JS 청크가 약798KB로 늘었고 기존 크기 경고가 남는다.
