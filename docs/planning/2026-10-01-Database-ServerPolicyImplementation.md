# C3 DB 문맥 검증·서버 보호 구현

- 기준: [전체 명세](2026-10-01-Database-CapabilitySpecification.md). 선행 C1~C2b 완료, 기준 HEAD `f1d459c`, 시작 시 작업 트리 깨끗함.
- C3a: native 문서의 순수 DB 정책 검증과 legacy 원인별 복구 쓰기 검증을 모델에 추가한다. 빈 이름/빈 테이블 등 초안과 지원하지 않는 타입·옵션을 구분하고 key/FK/generated/check/index의 문맥·참조를 검사한다.
- C2c/C3b: 프로젝트 profile/revision 저장 및 기존 v1 경로의 DB 변경·동기화 문맥 보호를 추가한다. 데이터는 자동 변환하지 않고 실제 v2 소비 경로 준비 전에는 v2 저장을 열지 않는다.
- 서버는 잠근 행의 DB 설정으로 최종 후보를 검사한다. 과거 accepted 작업 재생은 유지하고 오래된 신규 쓰기는 거부한다.
- 마이그레이션은 추가 열/기본값/무결성 제약을 제공하며 기존 설계 JSON과 개인 기록을 유지한다. 실제 DB 검증은 격리된 로컬 테스트 DB에서 수행한다.
- 단위마다 의미 있는 테스트·포맷·타입 검사 후 독립 커밋한다. 기존 사용자 파일과 다른 작업은 건드리지 않는다.
