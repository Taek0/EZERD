# Prettier 도입 및 코드 포맷 정리

작성일: 2026-09-15

루트 개발 의존성에 Prettier를 정확한 버전으로 추가하고 2칸 들여쓰기, LF, 작은따옴표, 세미콜론, 100자 기준 줄바꿈을 통일한다. pnpm format / format:check 명령과 check 연동, VS Code의 언어별 저장 시 포맷 설정을 제공한다.

대상은 직접 관리하는 소스·테스트·스크립트·설정이다. DB 마이그레이션과 스냅샷, lockfile, 빌드·캐시·DB·공개 폰트 자산·문서·산출물은 제외한다. 기존 문서 재분류 변경은 포함하지 않는다. scripts/document-versions.mjs의 기존 경로 변경은 작업 트리에 보존하고 해당 파일은 HEAD 기준 포맷 변경만 커밋한다.

설정 도입과 실제 코드 포맷을 분리해 커밋한다. 적용 후 format:check, 타입 검사, 단위 테스트와 빌드를 실행한다. 포맷 작업용 테스트를 새로 만들지 않으며 기존 검증을 사용한다.
