# 많은 테이블 보기와 도메인 뷰 개선

카드의 불필요한 여백·최소 크기를 줄이고 콘텐츠 계산과 스타일을 일치시킨다. 기존에 사용자가 지정한 크기와 좌표를 임의로 재저장하지 않는다. 축소 범위를 25%에서 10%로 확장한다.

도메인 구성 문구를 도메인 뷰로 통일하고 테이블 고정 배치/키 관계 및 선 이동 허용을 안내한다. 나가기 시 진입한 도메인으로 돌아가며 해당 도메인이 없으면 구성에 남은 도메인 또는 도메인 맵으로 복귀한다.

목록 탭에 많은 테이블이 있는 fixture로 스크롤을 재현하고 하단 항목 접근을 검증한다. MCP에는 콘텐츠에 맞는 카드 크기와 구조적 계층 표현, 좌표 기반 간격 검증 지침을 보완한다. 429 시 현재 워크스페이스 포크로 인계한다.
