# 편집 기능 구현 계획

작성일: 2026-09-14

확정된 EDITOR_WORKFLOW_DECISIONS.md의 편집 개선 전체를 구현한다. 기존 홈 화면과 파란색 공통 테마, 댓글, 저장 흐름을 유지한다.

## 작업 단위
1. 프로젝트 공통 ENUM 저장·계약·DDL 및 이전 문서 호환 검증.
2. 순환과 독립 노드를 처리하는 관계 흐름 자동 배치. 현재 뷰의 카드 배치만 변경한다.
3. 도메인 패널 접힘, 맥락 메뉴, 직접 연결, 복수 관계 분리, 관련 항목 강조.
4. 테이블 셀 직접 편집, 5열 표시, 신규 NOT NULL, 복합 UNIQUE, ENUM 관리, FK 대상 키·컬럼 대응 확인, 까마귀발 및 관계 삭제.
5. 통합 검사와 실제 브라우저 및 PostgreSQL DDL 검증.

## 상세 구현 기준
- 셀 더블클릭으로 편집하고 Enter/Tab/blur 확정, Escape 취소한다.
- ENUM은 안정적인 ID로 참조하며 기본 스키마 public, 값 순서 보존, 사용 중 삭제 차단한다. 새 DDL을 생성하며 외부 DB 변경 SQL은 만들지 않는다.
- 관계 양 끝 선택성은 논리 정보이며 UNIQUE, NOT NULL, 연결 테이블을 자동 생성하지 않는다.
- 자동 배치는 빈 캔버스 우클릭 명령으로만 실행하고 외부 참조 소유권과 다른 화면 배치를 보존한다.
- 직접 연결은 Escape로 취소하며 생성 명령은 해당 패널을 연다.
- UI 구현은 Astra 에이전트가 담당한다. 핵심 모델과 통합 검증은 주 에이전트가 담당한다.
- 각 단위의 결과와 검증을 work-log에 기록하고 해당 변경만 개별 커밋한다. 기존 문서 분류 변경은 이번 기능 커밋에 섞지 않는다.
