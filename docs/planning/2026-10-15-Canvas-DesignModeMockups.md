# 물리·논리 설계 전환 목업

- 더보기 메뉴의 논리 모드 토글을 외부의 명시적인 물리/논리 두 선택지로 옮기는 디자인 3개를 비교한다.
- A: 부드러운 세그먼트 선택 배경, B: 연결된 윤곽 버튼, C: 밑줄 탭. 기존 상단바와 폰트 크기·색상·간격을 맞춘 독립 HTML 목업으로 제공한다.
- 사용자가 디자인을 선택하기 전에는 실제 앱의 UI·모드 기본값·팝업 문구를 변경하지 않는다.
- 선택 후 generic 프로젝트는 논리 설계를 기본으로 하고, 생성 안내에 논리 설계 기본값과 DDL 제한을 함께 표시할 예정이다.
- 목업만 렌더링해 이미지와 인터랙티브 미리보기를 제공한다. 실제 프로젝트 데이터는 변경하지 않는다.
