# 소프트 세그먼트 설계 모드 적용

- 사용자가 선택한 A안에 따라 상단바에 물리/논리 두 모드를 동시에 표시한다. 선택 배경이 이동하는 소프트 세그먼트와 키보드·reduced-motion을 지원한다.
- 더보기 내부의 논리 설계 켜기/끄기는 제거한다. 모드 변경은 표시·편집 문맥을 바꾸되 기존 설계 데이터를 변환하거나 삭제하지 않는다.
- RDBMS 선택안함(generic)은 프로젝트 진입 시 논리 설계를 기본으로 한다. 기존 generic 프로젝트에도 동일하게 적용하며 다른 DB 프로젝트는 물리를 기본으로 유지한다.
- 서버 동기화 응답이나 재렌더링은 사용자의 선택 모드를 초기화하지 않는다. 프로젝트/DB 문맥이 실제로 바뀔 때만 기본값을 재설정한다.
- 선택안함 생성 팝업에 논리 설계가 기본임을 명시하며 DDL 제한 안내를 유지한다.
- 기본값·토글·메뉴 제거·팝업·동기화 이후 상태 유지 회귀와 타입·빌드 검증 후 커밋한다.
