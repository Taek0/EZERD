# Native 편집기 원래 UI 이식 계획

2026-10-06. 사용자 요청에 따라 기존 Canvas의 전체 화면 구성과 도구 UI를 Native 데이터/저장 경로에 이식한다. 넓은 캔버스, 상단 생성/보기 도구막대, 오른쪽 속성/목록/도메인/도구 패널, 하단 커서/손/확대·축소를 복원한다.

- 기존 Native 폼/복구/권한·개인 상태는 재사용하고 패널 탭 전환은 unmount 대신 숨김으로 입력을 유지한다. Native의 카드/보조 UI memo 경계를 보존한다.
- 생성 버튼은 기존 Native 생성 폼으로 연결하고 손 도구·Space/중간 버튼 드래그는 화면만 이동한다. 도메인/개인 화면 선택과 논리/물리 모드를 유지한다.
- 기존 v1 문서로 투영하지 않는다. 기존 v1의 다중 선택·일괄 이동 등 Native에 없는 동작을 구현된 것으로 표시하지 않는다.
- 모바일에서 패널을 아래에 쌓아 폼 접근성을 유지한다. keyboard/focus/read-only/복구와 브라우저 레이아웃·pan 회귀를 검증한다.
- 제품 코드를 현재 PR #2 브랜치에도 선별 반영하고 검증 후 push한다. main merge/운영 데이터 변경은 하지 않는다.
