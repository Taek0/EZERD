- 현재 MCP 호출과 서버 감사 이벤트를 대조한 소유자 ID cebce815-6ff4-42fe-a55f-997d1b6aabc0를 사용한다. 실행 시 해당 계정 및 확인한 토큰 레코드의 활성 상태/소유자를 재검증한다. 원문 자격은 출력하지 않는다.
- Edusync 공간 UUID는 611dca01-381d-4d45-9b6e-a2a47b2177d9, TY 공간 UUID는 3c57cfc8-e6e6-4ec5-8cbd-8c5538a67182다. UUID와 migrationKey를 고정해 재실행을 지원한다. 공간 이름 중복은 일반 정책대로 허용한다.
- 대상은 klassboard-backend 56a7ccd0-ffb8-462c-a253-6ae6f266c4a8, ezerd 903ec4ff-2ca4-4724-8d8a-3ec98765a68b, monya bbae7fcb-72ba-4395-add3-a9e4ff13a546다. 이름/ID를 모두 검사하고, 다른 공간에 이미 배정된 프로젝트는 이동하지 않는다.
- 0011 마이그레이션은 공간/멤버/초대/감사 테이블과 nullable 프로젝트 FK를 준비한다. 이관 스크립트는 단일 REPEATABLE READ 트랜잭션에서 projects ACCESS EXCLUSIVE 잠금, 계정/토큰 확인, 공간+owner 생성, 소속 변경, 감사 기록, NOT NULL 확정을 실행한다.
- 설계와 모든 자식 테이블은 수정하지 않는다. projects는 workspace_id를 제외한 모든 컬럼, 리뷰 메시지/핀/알림·개인 상태/작업·동기화 작업/필드 버전/기준/삭제 스냅샷은 정렬된 행 JSON의 SHA-256과 건수를 전후 대조한다. 불일치 시 롤백한다.
- 미소속 추가 프로젝트, 잘못된 이름/ID, 다른 소속, 충돌한 기존 공간/owner를 발견하면 중단한다. 사용자 추측 배정, DB 초기화 및 전체 사용자 삭제는 없다.
- 스크립트 dry run은 롤백하며, --apply만 커밋한다. 이후 0012 NOT NULL 마이그레이션을 생성/적용해 일반 설치 스키마와도 일치시킨다.
- 구현/테스트 완료 후 서버 현상태를 확인하고 운영 스키마/데이터/빌드를 함께 적용한다. 원격 git push는 하지 않는다.
