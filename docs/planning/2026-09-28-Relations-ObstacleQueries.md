# 관계 경로 장애물 검사 최적화

작성일: 2026-09-28
기준: `b889777`, `feat/performance-measurement`.

- 후보 경로마다 전체 장애물을 반복 검사하는 clear 경로를 조사한다. 경로 후보·탐색 순서·점수는 유지하고, 수평/수직 선분의 고정 좌표별 장애물 구간을 재사용한다.
- 장애물을 공간적으로 제거하거나 탐색 범위를 임의 제한하지 않는다. 접촉은 통과, 내부 교차는 차단하는 기존 부등식과 zero-length/diagonal 의미를 보존한다.
- raw/expanded 장애물 배열마다 관계 계산 한 번 안에서만 인덱스를 사용한다. 글로벌 캐시·문서 간 무효화는 도입하지 않는다.
- 기존 경로 알고리즘을 테스트 전용으로 고정해 기본·수동·self·밀집·중첩·랜덤 사례에서 전체 결과를 비교한다. 선분 검사 자체도 선형 기준과 비교한다.
- bounded scale runner로50/100/300을 재측정한다. 300개 first1초 이하이면 같은30초 제한 내 warm 반복을 허용한다. UI는100개 회귀부터 확인하고300개는 계산·안정성 결과에 따라 결정한다.
