# MCP 전체 도구·v2 계약 점검 계획

- 실제 tools/list와 서버 등록 목록을 기준으로 전체 도구의 입력·출력·설명·annotations를 대조한다.
- 프로젝트 생성·파일 전송·공유/개인 변경·DB capabilities/DDL·Native 이력/취소·공간/리뷰/알림의 v2 경로와 인증·권한·CAS·operation replay 경계를 확인한다.
- 원문 보존이 필요한 문서·ACK·취소 요청에서 SDK/계약 파싱이 값을 바꾸거나 상세 구조를 숨기는지 조사한다. 문서 및 명령 payload의 누락된 설명·검증 오류도 점검한다.
- 확인된 문제는 독립적인 단위로 수정하고 관련 회귀 테스트와 결과 문서를 함께 커밋한다. 단위가 완료되면 다음 수정으로 넘어간다.
- 기존 MCP 테스트 전체 및 관련 Native·개인 상태 통합 테스트를 격리 QA DB에서 실행하고 전체 포맷·타입·테스트·빌드를 확인한다.
- 실제 사용자 프로젝트·DB·서버 실행 상태·배포·docs/EZERD.txt는 변경하지 않는다. 전수 정적 대조와 실제 실행 검증의 범위를 결과 문서에 구분해 기록한다.
