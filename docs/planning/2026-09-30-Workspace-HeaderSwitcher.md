# 상단 워크스페이스 선택 A안 적용

- 승인된 A안의 로고 옆 이름 드롭다운을 실제 앱 상단에 배치한다. 갤러리와 프로젝트에서 현재 공간을 표시하고 프로필은 오른쪽에 유지한다.
- 기존 공간 생성, 설정/멤버 관리, 받은 초대 기능을 드롭다운에 연결한다. 권한과 보관 상태 및 한국어/영어를 유지한다.
- 시안보다 글자를 소폭 키우되 현재 앱의 크기 체계를 따른다. 공간 이름과 설명/역할의 위계를 유지한다.
- 전환 시 편집 중 자동 저장 처리를 수행하고 프로젝트를 닫은 뒤 대상 공간 갤러리로 이동한다. 실패나 중복 요청으로 다른 공간에 변경을 적용하지 않도록 한다.
- 변경된 화면과 실제 가상 API 기반 전환을 확인하고 관련 테스트·타입·포맷 검사를 수행한다.
