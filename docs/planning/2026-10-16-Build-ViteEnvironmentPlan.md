# Vite 빌드 환경 변수 격리 계획

- 작성일: 2026-10-16
- 대상: `apps/web/vite.config.ts`

## 문제와 변경

개발 서버 프록시의 `PORT`를 읽기 위해 저장소 루트 `.env`를 항상 `loadEnv`로 읽으면, 서버의 `NODE_ENV=development`가 Vite 내부 환경 변수에 기록되어 제품 빌드까지 React 개발 모드가 된다. `command === 'serve'`일 때만 서버 환경을 읽도록 제한한다. 명시적인 셸 `NODE_ENV`와 웹 앱 자체 환경 파일을 통한 개발 빌드 의도는 Vite의 기존 처리에 맡긴다.

## 검증

별도 임시 프로젝트에 실제 Vite 설정 파일을 복사하고, 서버 루트 `.env`에 개발 모드와 프록시 포트를 지정한다. 새 Node 프로세스의 `resolveConfig`로 기본 빌드의 프로덕션 분류, 명시적 개발 빌드, 개발 서버 프록시 포트와 셸 포트 우선순위를 확인한다. 실제 빌드 및 주 checkout의 환경 파일은 수정하지 않는다.
