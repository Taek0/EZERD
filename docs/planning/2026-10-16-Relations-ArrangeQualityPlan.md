# 관계선 자동 정리 품질과 계산량 개선 계획

- 작성일: 2026-10-16
- 기준: [자동 정리 구현 계획](2026-10-15-Relations-AutoArrangeImplementationPlan.md)
- 격리 위치: codex/performance-lab 성능 워크트리. 일반 이동·팬·줌 경로는 변경하지 않는다.

사용자가 명시적으로 관계선 자동 정리를 실행할 때만 추가 품질 계산을 수행한다. 카드의 가로 또는 세로 유효 범위가 겹치고 직선 통로가 비어 있으면 양쪽 연결점 좌표를 먼저 일치시킨다. 균등 간격보다 직선 연결을 우선하되 같은 면의 연결점 순서와 가능한 최소 12 단위 간격을 지킨다. 대각 배치에서는 중심 간 거리가 아니라 카드 경계와 짧은 출발·도착 구간을 고려하여 자연스러운 면을 고른다.

첫·마지막 직선 구간은 보통 28 world 단위를 보장하고 공간이 좁을 때만 줄인다. 불필요한 짧은 우회는 검증된 저비용 후보로 제거한다. 깨끗한 직선/L/Z 후보를 먼저 검사하고 복잡한 경로만 기존 장애물 탐색기로 보낸다. 실행 내부 캐시를 재사용하고 문제가 없는 경로는 재탐색하지 않는다.

기존 FK source / PK target 규칙, 입력·탐색 상한, all-or-nothing 검증, 저장된 경로의 renderer 재현 규칙을 보존한다. 같은 합성 fixture와 실제 snapshot으로 전후 시간·교차·겹침·꺾임을 비교하고 장애물 및 renderer replay를 검증한다. 결과는 work-log에 기록한다.
