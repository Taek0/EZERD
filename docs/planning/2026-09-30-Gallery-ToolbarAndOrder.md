# 갤러리 메뉴와 생성순 정렬 보완

- 공간 선택 팝오버의 열림·닫힘 애니메이션을 실제 렌더링 구조에 맞춰 적용한다.
- 검색 포커스의 테두리를 제거하고 정렬 오른쪽의 불필요한 여백을 줄이면서 레이블 변경에 따른 위치 흔들림은 방지한다.
- + 버튼을 작은 더보기 메뉴로 바꿔 새 프로젝트 생성과 가져오기를 제공하고 하단 가져오기 버튼은 제거한다.
- 사용자가 다른 정렬을 선택하기 전까지 createdAt 오름차순으로 유지하고 새 카드/초안은 기존 카드 오른쪽에 배치한다. 동률은 일관된 기준으로 정렬한다.
- 기존 자동 이름 저장·생성·가져오기 권한과 한영 UI, 키보드 조작을 유지한다. 관련 정렬 테스트와 브라우저 UI 검증을 수행한다.

## 추가 요청

- 워크스페이스 관리 팝업의 기본 정보·멤버·초대·위험 작업을 정리하고 작은 화면에서 스크롤과 버튼 배치를 개선한다.
- 공간 생성·관리·받은 초대 및 하위 선택 메뉴의 열림/닫힘 애니메이션을 확인하고 reduced-motion, Escape, 포커스 복귀를 유지한다.
