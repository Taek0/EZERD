# ERD 즉시 편집 UX 개선 계획

- 모든 저장 요청·입력 초기화 버튼과 해당 수동 흐름을 제거하고 입력 후 별도 동작 없이 자동 저장한다. 입력 중 상태, 실패 초안, 동시성 보호는 유지한다.
- 사이드바 컬럼 속성의 미검증 기능 차단 원인을 분석하고 지원되는 속성 편집이 잘못 차단되지 않게 한다.
- 테이블 소속 이동 동작은 소속 도메인 드롭다운으로 바꾸고 일반 필드와 글자 크기를 맞춘다.
- 카드 타입 검색 입력을 수정하고 DB 접두사를 표시에서 제거한다. 카드 +는 빈 컬럼을 즉시 추가한다.
- 고급 인덱스 식은 식 종류와 대상 항목 선택을 계층화한다.
- 컬럼 편집 순서를 이름, 타입, 설명으로 정리한다. 추가 옵션은 기본 접힘으로 NULL, 기본값, 배열 차원 순서로 배치한다.
- UI 작업은 사용자 추가 지시에 따라 gpt-6-astra/low 워커에 파일 소유권과 검증 범위를 명시하여 위임한다. 처음 호출한 sol/high 워커는 코드 수정 전에 중지했다. UI 외 독립 작업에만 필요 시 sol/high를 사용한다. 세션 오너가 통합 및 회귀 검증을 맡는다.
- 각 단위별 결과를 기록하고 커밋한다. 실제 사용 흐름과 입력 연속성, 저장 실패 및 권한 보호를 검증한다.
