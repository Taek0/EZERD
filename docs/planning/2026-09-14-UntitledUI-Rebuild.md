# Untitled UI 실제 컴포넌트 재구성 계획

작성일: 2026-09-14

기존 구현은 네이티브 컨트롤과 EZERD 스타일을 유지해 제공된 Untitled UI의 외형과 상호작용을 충분히 반영하지 못했다. 이번에는 공개 MIT 소스를 고정 버전으로 확보하고 실제 실행되는 컴포넌트에 반영한다.

- 선택박스는 React Aria 기반 트리거·팝오버·목록·선택 표시·키보드 동작을 갖춘 Select로 교체한다.
- 체크박스는 상태별 시각 요소와 포커스 처리, 입력창·텍스트 영역은 원본의 테두리·그림자·간격·상태 디자인을 적용한다.
- 드롭다운·우클릭 메뉴·툴팁·버튼은 같은 스타일과 원본 상태별 전환을 사용한다. 열기/닫기 애니메이션과 모션 감소 설정을 함께 검증한다.
- 원본 구성에 필요한 수정은 파란색 테마, 기존 한국어 폰트, 로컬 import, 독립 SVG 및 앱 이벤트 연결로 명시한다. PRO 소스와 아이콘 패키지는 가져오지 않는다.
- 기존 전역 CSS가 공통 컨트롤의 새 스타일을 덮지 않도록 화면 스타일을 정리한다. 갤러리와 편집기 레이아웃·저장 모델은 유지한다.
- UI 구현은 Astra가 담당한다. 출처·라이선스·원본 대비 수정 범위를 기록하고 실제 화면에서 마우스·키보드·읽기 전용·포커스·저장 회귀를 확인한다.

이전처럼 일부 참조만 하고 전체를 적용했다고 설명하지 않는다. 실제 적용 파일과 별도 구현 영역을 최종 기록에 구분한다.
