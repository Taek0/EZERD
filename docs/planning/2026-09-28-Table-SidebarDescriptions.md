# 테이블 캔버스 속성 설명 입력 개선

- 테이블 기본 정보의 테이블명 아래에 설명을 추가하고 기존 `physical.comment`에 저장한다.
- 관계 설명은 고급 설정에서 관계명 바로 아래로 이동하고 기존 `logical.description`을 유지한다.
- 두 설명 입력란은 공통 컴포넌트를 사용한다. 작은 글자(13px)로 표시하고 내용에 따라 64~180px 높이로 늘어나며 최대 높이 이후 내부 스크롤을 제공한다.
- 값 변경과 사이드바 너비 변경 시 높이를 다시 계산한다. 기존 읽기 전용 및 변경 저장 흐름을 유지한다.
- 웹 타입 검사, 관련 기존 테스트, 프로젝트 포맷 검사를 수행하고 결과를 작업 기록에 남긴다.
