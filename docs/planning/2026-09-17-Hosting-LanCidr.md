# LAN 호스팅 설정 수정 계획

- `pnpm host:start`의 `LAN_ALLOWED_CIDRS` 검증 오류를 해결한다.
- 현재 값 `127.0.0.1`은 CIDR 형식이 아니며 허용 대상 사설 IPv4 대역에도 해당하지 않는다.
- 현재 en0 주소 `192.168.35.101`, 넷마스크 `255.255.255.0`을 기준으로 `.env`의 허용 대역을 `192.168.35.0/24`로 변경한다.
- 프로덕션 및 전체 인터페이스 바인딩 조건에서 설정 검증과 허용 대역 파싱을 확인한다.
- 기존 서버 프로세스 및 데이터베이스는 변경하지 않는다.
