# 작업 중심 UI 구성 목업 계획

- 이전 상세 목업을 보존하고 DesktopMockupRefined HTML을 별도 제작한다.
- apple-design 기준의 명확한 위계·공간 일관성·피드백을 유지한다.
- 컴포넌트 구성을 개선한다: 탐색 목록, 문서 헤더, 그룹화된 작업 도구, 읽기 쉬운 캔버스 카드, 문맥별 속성 필드와 관계 매핑, 일관된 협업 패널.
- 데스크톱 전용이다. 논리 설계와 검증 메뉴 위치는 유지한다.
- 탐색·검색·선택·패널 전환·컬럼 입력·관계·핀·갤러리의 실제 목업 동작을 브라우저에서 확인한다.
- 제품 코드는 변경하지 않고 계획·목업·결과만 커밋한다.
