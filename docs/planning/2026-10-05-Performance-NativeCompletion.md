# Native 캔버스 잔여 작업 완료 계획

2026-10-05. 사용자가 남은 작업 전체 진행을 요청했다. 성능 lab b908b3f에서 계속하며 main/운영 DB를 직접 변경하지 않는다.

1. 인라인 편집: 이름/설명은 NativeEditorForm 기반의 보존되는 단일 필드 편집, 타입/NULL은 기존 NativeFormatEditor 정책·폼을 화면 위에서 재사용한다. 권한/busy/버전 충돌을 기존 저장 경로에 전달한다. 클릭 선택은 유지하고 더블클릭 또는 F2로 연다.
2. 관계선: 선택·hover·키보드, 경로 및 연결점 drag/폼을 Native의 shared/personal canvas 저장 경로에 연결한다. 불완전 초안/실패 시 원문을 보존하고 명시 저장·초기화를 제공한다.
3. PNG: 색상 헤더, 도메인 배지, 컬럼 제목, 키 강조, 관계선 endpoint와 라벨 배경을 현재 화면과 일치시킨다. escape/크기/권한·저장본 제한을 유지한다.
4. 통합: 입력 이후 pan/zoom, 선택, draft/권한/버전, 개인·공유 저장과 PNG의 의미 있는 회귀 및 브라우저 실험을 진행한다. 이동 p95는 50/100테이블에서 반복 비교하며 카메라 재계산0회를 유지한다. 필요할 때만 화면 밖 렌더링 제외를 추가한다.
5. 문서·커밋: 제품 단위별 계획/결과를 기록하고 커밋한다. 운영 데이터에 쓰지 않는 테스트 환경을 사용한다.
6. 제품 전용 PR: 최신 원격 main 기반의 별도 브랜치에 제품 코드·회귀 테스트와 필요한 제품 문서만 선별한다. 측정 도구·raw·lab Git 기록은 제외한다. 원격 이력을 확인하고 충돌/회귀를 해결한 뒤 draft PR을 생성한다. merge/배포하지 않는다.

최종 UI 완성도와 실제 저장 검증의 한계를 명시한다. 캐시 때문에 최신 입력·권한을 누락하거나 callback 비교를 생략하지 않는다.
