# 승인된 데스크톱 디자인 구현 계획

- 기준 제품 커밋: d5e46e1. 기존 검토 워크트리 codex/apple-ui-review에서 구현한다.
- 승인 범위: 좌측 독립 탐색 영역, 그라데이션 없는 역할별 버튼. 기존 UX는 가능한 한 유지한다.
- 유지 사항: 논리 설계/검증 항목의 더 보기 위치, 갤러리와 생성/공유 메뉴, 편집 권한, 자동 저장·복구, 단축키, 캔버스 직접 편집, 속성 폼·키·관계·고급 설정·히스토리·핀.
- 목업의 예시 SQL/데이터나 축약한 폼을 제품에 이식하지 않는다. 핀과 속성의 강제 상호 배타 전환, 새로운 SQL 탭 등 승인된 시각 변경에 필수 아닌 UX 변경은 이번에 적용하지 않는다.
- 단위 1: 공통 버튼 토큰과 CSS를 역할별 단색으로 정리한다. 상태와 크기/아이콘/접근성 API는 유지한다. 포맷·관련 테스트·브라우저 확인 후 기록 및 커밋.
- 단위 2: 기존 탐색 목록과 필터/선택 처리를 좌측으로 옮기고, 우측은 현재 편집 폼을 그대로 유지한다. 목록 항목·도메인·관계·필터가 누락되지 않는지 검증한다. 필요한 최소한의 탐색 접기 동작과 공간 배분을 적용한다.
- 최종: format:check, 타입 검사, 관련 이벤트·폼·선택 회귀 테스트와 빌드, 실제 컴포넌트 격리 화면 검증. 원본 main 작업 디렉터리의 기존 미커밋 파일은 건드리지 않는다.
