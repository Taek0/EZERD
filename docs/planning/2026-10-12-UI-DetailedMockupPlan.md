# 상세 디자인 목업 확장 계획

- 기존 수정안은 보존하고 2026-10-12-UI-DesktopMockupDetailed.html을 별도로 만든다.
- 상세 ERD: 컬럼 설명·NULL·기본값, PK/FK, 관계 선택, 미니맵과 줌, 노트와 핀 위치를 보강한다.
- 속성: 테이블/컬럼/관계 선택에 맞는 필드, 키·인덱스, 변경 상태를 표시한다.
- 협업: 핀 위치 이동, 답글 추가, 해결됨 상태를 목업 메모리 안에서 체험할 수 있게 한다.
- ENUM·검증·내보내기·히스토리에는 실제 형태에 가까운 상세 다이얼로그를 제공한다. 논리 설계와 검증 항목의 더 보기 위치를 유지한다.
- 제품 코드·데이터를 변경하지 않는다. 목업 밖에 데이터를 저장하거나 전송하지 않는다.
- 스크립트 검사와 가능하면 브라우저 렌더링·클릭 검증 후 결과를 기록하고 커밋한다.
