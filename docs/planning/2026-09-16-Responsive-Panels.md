# 반응형 패널 계획

- 저장된 속성/핀 패널 너비는 유지하고 실제 작업 공간에서 표시 너비만 제한한다.
- 속성 패널은 캔버스에 최소 420 CSS px를 남기고, 이 조건과 최소 패널 너비 280 px를 동시에 만족하지 못하면 아래로 배치한다.
- 핀 패널은 가로 배치 시 작업 공간에 최소 840 px를 남긴다. 작업 영역이 1120 px 이하이면 아래 행으로 이동해 속성 패널을 가리지 않는다.
- 좁은 화면에서 각 패널 본문을 독립적으로 스크롤하고 너비 조절기는 감춘다. DPR 또는 테이블 카드 글꼴은 변경하지 않는다.
- 패널 계산 단위 테스트와 포맷 검사로 확인한다. 전체 화면 검증은 상위 통합 작업에서 수행한다.
