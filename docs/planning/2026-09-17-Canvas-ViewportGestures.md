# 화면 높이와 트랙패드 입력 개선 계획

편집기를 실제 100dvh 높이에 맞추고 캔버스의 고정 최소 높이 때문에 페이지가 늘어나는 제약을 제거한다. 속성·핀은 배정된 영역 안에서 스크롤하며 좁은 창의 하단 패널도 같은 높이 예산을 사용한다. 기존 더티 responsive-shell.css는 보존한다.

일반 wheel의 deltaX/deltaY는 캔버스 이동, Ctrl/Meta wheel은 포인터 위치를 유지하는 연속 배율 변경으로 처리한다. 작은 핀치 이벤트마다 10%씩 확대하던 처리를 완화하고 배율 제한을 유지한다. deltaMode 정규화 및 입력창 스크롤 보호, 연속 이벤트 누적을 검증한다. 카메라만 변경하며 공유 문서는 수정하지 않는다.
