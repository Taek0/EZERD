# 탐색 계층 및 패널 상호작용 계획

- 2026-10-12. 사용자 요청에 따라 3002 호스팅을 중단했다.
- 좌측 도메인 → 테이블 → 컬럼 계층을 구현한다. 미소속, 검색, 선택 동기화, 관계 탐색을 유지한다.
- 좌측 너비를 200–420px 범위에서 포인터 캡처로 즉시 조절하며 키보드와 로컬 저장을 지원한다.
- 계층 펼침/접힘 애니메이션은 중단 가능하고 reduced-motion에서는 정적으로 동작한다.
- 우측의 중복 목록 전환을 제거한다. 상단 도구 위치는 사용자 확인 후 확정한다.
- 테이블명은 PNG 포함 흰색 고정, 기본 헤더는 짙은 슬레이트로 변경한다. 사용자 지정 배경은 유지한다.
- 관련 회귀 테스트, 타입 검사, 포맷, 빌드를 수행한다. 검토용 호스팅은 자동 재시작하지 않는다.

## 확정 사항
- 상단 도구 모음은 기존 상단 행에서 오른쪽 정렬한다(사용자 확인).
