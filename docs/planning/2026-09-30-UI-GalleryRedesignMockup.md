# 갤러리 UI 재설계 목업

- 작성일: 2026-09-30
- 상태: 목업 검토 대기. 사용자 승인 전 실제 서비스 구현 금지.
- 기준: 기존 `workspace-switcher-prototypes.html`의 A안 전체 화면. 헤더, 여백, 블루 그레이 색상, ERD 미리보기 카드와 프로젝트 갤러리를 유지한다.
- 가독성: 본문·컨트롤 14~15px, 워크스페이스명 16px, 카드 제목 18px, 페이지 제목 32px.
- 목업 경로: `apps/web/gallery-redesign-preview.html`. 프로덕션 소스 및 백엔드를 변경하지 않는다.
- 상호작용: Edusync/TY 전환, 검색, 보관함, 프로젝트 생성·이름 변경·보관을 메모리에서만 시연한다.
- 드롭다운: 실제 버튼으로 구성하고 버튼 텍스트 선택을 방지한다. 입력 필드의 정상 텍스트 선택은 유지한다. 바깥 클릭, Escape, 방향키 및 Tab 이동을 지원한다.
- 모션: 드롭다운 열림·닫힘 170ms, 카드 호버와 워크스페이스 전환의 절제된 모션. reduced-motion 설정 준수.
- 검토 기준: 이전 A안과 전체적인 형태가 일치하는지, 폰트 크기가 적절한지, 메뉴 클릭 시 주변 텍스트가 선택되지 않는지, 열기·닫기 및 키보드 조작이 자연스러운지 확인한다.

## 2026-09-30 피드백 반영

- 로고는 서비스의 `EZERD.` 타이포그래피와 포인트 점을 유지한다.
- 좌우 폭 조절은 상단 헤더에 한정하며, 로고·공간 선택기와 프로필 영역의 여백을 균형 있게 맞춘다.
- 공간 드롭다운을 축소하고 하단 설명을 제거하며, 하단 세 메뉴의 글자와 아이콘 두께를 강화한다.
- 프로젝트 생성 시 PostgreSQL·MySQL·SQLite를 선택하고 카드 배지에 반영하는 메모리 기반 목업을 제공한다.
- 생성 타일, 생성 버튼, 카드 하단을 간결하게 조정한다. 프로젝트 더보기와 정렬은 작은 앵커형 메뉴로 제공한다.
- 모든 변경은 기존 목업 파일에만 적용하고 실제 서비스 반영은 승인 후 진행한다.
