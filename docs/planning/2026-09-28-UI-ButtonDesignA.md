# 버튼 디자인 A 적용 계획

- 사용자가 선택한 A안(홈 그대로)을 공통 버튼과 프로젝트 편집 화면에 적용한다.
- 기본/주요 버튼은 청회색 그라데이션, 8px 모서리, 부드러운 양방향 그림자를 공유한다.
- 호버, 눌림, 선택, 펼침, 키보드 포커스, 비활성 및 위험 작업 상태를 공통화한다.
- 화면별 크기와 간격은 유지하고 버튼 색상·그림자 재정의만 정리한다. 프로젝트 카드 제목, 목록 탐색, 색상 견본과 핀의 형태 등 기능 표현은 유지한다.
- 포맷 검사, 타입 검사, 기존 UI 테스트와 브라우저 확인 후 작업 기록을 작성한다.
