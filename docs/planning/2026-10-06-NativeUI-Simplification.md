# 네이티브 편집 UI 정리 및 신규 설계 정책

- ENUM 팝업은 현행 공통 에셋을 사용해 목록·검색·편집·닫기 영역과 작은 화면 스크롤을 정돈한다.
- 사이드바 도구 탭을 없애고 필요한 선택 속성과 명시적인 복구 경로는 유지한다.
- 새 도메인 관계 생성은 도메인 맵에서만 제공한다. 목록의 도메인·테이블은 기본 확장, 관계 그룹은 기본 접힘으로 설정한다.
- 상단의 반복적인 미저장·미확인 상태 문구는 숨기되 저장 보호와 실제 오류·복구 기능은 유지한다. 보관된 입력 복구를 더보기로 옮기고 다시 불러오기 버튼을 제거한다.
- DB 종류·목표 버전·편집 상태를 하나의 메타데이터 행으로 정리한다.
- 신규 프로젝트는 네이티브 문서만 생성한다. 기존 프로젝트·가져오기 원문을 일괄 전환하지 않는다. 생성 UI·API·MCP 정책과 기본값을 검증한다.
- UI를 Astra 에이전트에 분담하고 타입·정책 회귀 테스트와 전체 검사를 수행한다. 운영 데이터 삭제는 하지 않는다.
