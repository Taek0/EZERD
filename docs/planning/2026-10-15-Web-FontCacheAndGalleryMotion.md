# 폰트 캐시 및 갤러리 모션 개선

- 폰트 콘텐츠 해시 URL과 1년 immutable 캐시를 사용한다. 변경 없는 배포는 URL을 유지하며 HTML과 고정 CSS에는 재검증 정책을 적용한다.
- 기존 프로젝트 카드의 3px hover 상승 효과를 재사용하고 덮어쓰는 스타일 및 transform 전환을 정리한다. 편집 중 카드 고정과 reduced-motion을 유지한다.
- 보이지 않거나 덮어쓰인 불필요한 모션을 관련 전역/갤러리 스타일에서 점검한다. 기능에 필요한 모션을 임의로 제거하지 않는다.
- 실제 사용자 서버/DB를 변경하지 않고 코드·헤더·파일 참조 테스트로 검증한다.
