# 캔버스 주변 UI 정리

- 히스토리 내역의 실행 취소 버튼을 제거하고 더보기는 본문 크기의 박스 없는 텍스트 토글로 표시한다. 필터를 정리하고 불러온 이력 안내 문구를 제거한다.
- 설계 확인 항목을 상단 더보기 메뉴에서 열도록 이동하고 사이드바 목록의 도메인 선택 항목에 색상 점을 추가한다.
- ENUM 추가 선택 시 생성 폼이 바로 나타나게 한다.
- 상단 더보기 메뉴에서 추가·붙여넣기·관계 경로 초기화 명령과 상단 핀 추가 버튼을 제거한다. 캔버스 문맥 메뉴 등 별도 진입점은 유지한다.
- 상단 테이블·메모·전체 테이블·도메인 맵·도메인 필터·ENUM 버튼 크기를 통일한다.
- 보관된 입력 복구 화면은 기존 안전한 복구 동작을 유지하면서 공통 컴포넌트에 맞춰 읽기 쉬운 구성으로 정리한다.
- 관련 회귀 테스트와 타입·포맷·빌드를 확인하고 논리 단위로 커밋한다.
