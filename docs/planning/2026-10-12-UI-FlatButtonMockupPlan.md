# 단색 버튼 컴포넌트 목업 계획

- 사용자 결정: 좌측 독립 탐색 영역은 유지한다. 버튼의 그라데이션을 제거한다.
- 기존 목업을 보존하고 FlatButtonMockup HTML을 별도로 만든다.
- 버튼 역할: 단색 주요 동작, 중립 보조 동작, 텍스트/아이콘 보조 동작, 지속 선택 상태, 위험 동작.
- 기본/hover/pressed/focus/disabled/loading 상태를 제품 화면과 컴포넌트 예시에서 비교할 수 있게 한다.
- 제품 코드는 변경하지 않는다. 기존 논리 설계·검증 메뉴 위치는 유지한다.
- 브라우저에서 렌더링과 버튼 상태 및 기존 탐색 흐름을 확인하고 커밋한다.
