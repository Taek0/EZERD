# v1 서버 API·MCP 폐기

- v1 전용 REST 문서/동기화 경로는 인증 후 410 Gone으로 종료를 알리고, v1 MCP 조회·편집·이력 도구는 등록에서 제거한다.
- Native API/MCP, 공통 WebSocket Gateway, 파일 import/export/upgrade 및 원본 document-state 조회는 보존한다. 삭제/복구/취소 이력의 공통 보존 정책도 유지한다.
- 단위 1: 외부 v1 경로를 차단하고 도구 목록·안내·테스트를 갱신한다. 공통 personal-state 변경 경계에서도 v1 원본 편집을 거부한다.
- 단위 2: SyncService의 정리 스케줄을 별도 공통 서비스로 옮기고 미사용 v1 서비스·MCP 구현·전용 테스트를 제거한다. 혼합 테스트와 Native 회귀는 유지·갱신한다.
- 타입 검사·관련 테스트 후 각 단위를 커밋하고 최종 포맷·전체 테스트·빌드를 수행한다. 실제 사용자 DB 데이터나 마이그레이션 스키마는 변경하지 않는다.
