# 기본값 및 도메인 배치 개선 계획

컬럼 타입별 기본값 선택을 추가한다. 자동 증가(시퀀스 시작1)와 고정 DEFAULT1을 구분하며 기존 defaultExpression 계약과 DDL 검증을 사용한다.

도메인 뷰는 overview의 도메인 카드 중심 위치를 기준으로 각 도메인의 테이블 묶음을 배치한다. 묶음 내부 테이블 간 상대 거리는 유지하고, 묶음 크기를 고려한 공통 배율로 간격을 확보한다. 위치가 같은/누락된 도메인은 결정적인 대체 위치를 사용한다. 전체 선택 체크박스는 부분 선택 상태를 표시한다.

도메인 관계 이름은 좌표·예상 텍스트 경계로 충돌을 피하고 필요시 연결 보조선을 표시한다. 관계선 접점 자체는 유지한다. 실제 데이터 변경 없이 계산 테스트와 별도 UI fixture로 검증한다. 429 발생 시 현재 워크스페이스 포크로 인계한다.
