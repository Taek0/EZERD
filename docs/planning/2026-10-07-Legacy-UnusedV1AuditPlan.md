# 미사용 v1 코드 우선 조사

- 앞으로 v1 프로젝트를 열거나 편집하지 않는다는 사용자 방침을 기준으로 점진적 제거 후보를 조사한다.
- 이번 작업은 조사이며 제품 코드를 삭제하지 않는다. 현재 실행 경로에서 사용 중인 코드와 Native에서 재사용하는 코드는 우선 삭제 후보에서 제외한다.
- TypeScript 소스의 import/export 연결, 앱 진입점, 서버 모듈 등록, 테스트·스크립트 참조를 확인한다. 미참조 파일과 미사용 export를 구분하고 정적 분석의 한계를 명시한다.
- 결과와 근거는 docs/work-log/2026-10-07-Legacy-UnusedV1AuditResult.md에 기록한다.
