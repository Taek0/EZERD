# ERD 작성 흐름과 비동기 동기화 개선 계획

- 모든 UI 구현은 사용자 지정 astra/low로 진행한다. 비 UI 동기화 분석·구현은 필요 시 sol/high에 위임한다. 파일 소유권을 나누고 Git 작업은 오너가 순차 수행한다.
- 입력과 이동은 로컬에서 즉시 반영하며 서버 전송은 유효한 마지막 변경을 모아 비동기로 처리한다. 이미 전송한 요청·ACK·권한·DB 문맥·초안 보존 계약은 유지한다.
- 사이드바: 검색 가능한 타입, 설명 아래 PK 체크, 불필요한 작은 제목·현재 타입 안내·카드 표시 제거, 새 테이블 기본 접힘, 컬럼 위아래/편집 닫기 제거와 삭제 버튼 우측 정렬, 도메인 선택의 색상 점, 상세 정보 UI 개선.
- 상단: 도메인 필터 레이아웃 복구, 사이드바/핀 버튼 순서 교환, 물리·논리 버튼 제거. 더보기의 논리 설계 토글은 기본 OFF이며 꺼져 있을 때 관련 UI를 숨긴다. 기존 데이터는 삭제하지 않는다.
- 테이블 생성: 상단 생성 버튼 한 번으로 빈 카드 생성·선택, 카드 또는 사이드바에서 바로 편집한다.
- ENUM 팝업과 고급 인덱스·식 편집은 공통 UI와 결정 순서에 맞춰 재구성한다.
- 히스토리는 최신순으로 표시하고 높이를 제한한다. 사이드바 리사이즈 hover, 배율 폭, 카드 우클릭, 손/커서 단축키를 개선한다.
- 단위 검증 후 전체 pnpm check 및 필요 범위 DB 회귀, 임시 DB 브라우저 QA를 수행하고 결과를 기록한다.
