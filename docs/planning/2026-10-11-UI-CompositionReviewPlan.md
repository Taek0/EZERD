# UI 전체 구성 검토 계획

- 날짜: 2026-10-11
- 기존 apple-design UI 검토 워크트리와 브랜치를 사용한다.
- 범위: 갤러리의 진입·생성 흐름, 편집기 상단의 정보 위계, 캔버스와 속성·댓글 패널의 공간 배분, 선택·탐색 동선, 좁은 화면의 배치.
