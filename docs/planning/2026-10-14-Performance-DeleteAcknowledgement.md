# 삭제 저장 확인 단계 개선 계획

- 로컬 삭제 표시와 서버 ACK 이후 저장 확인 표시를 별도 단계로 측정한다. 실제 원본을 수정하지 않고 최신 실제 문서 복제본과 지연 ACK fixture를 사용한다.
- ACK 적용의 문서 변경, 정규화, 개인 화면 병합, 검증 및 React 비용을 분해한다. sequence/revision 검사와 실패 시 재조회, 서버 저장 완료의 의미는 유지한다.
- 확인된 중복 복사/계산만 줄이고 기존 전체 ACK·경량 ACK·개인 화면·삭제 연쇄·순서 누락 회귀를 확인한다.
- 제품 변경은 검증 후 로컬 main에 통합한다. 최초 요청한 기존 변경 push는 0b5547f로 완료했다. 새 개선의 원격 반영 여부는 결과에 명시한다.
