# 히스토리 및 캔버스 선택 회귀 조사

- klassboard-backend 호스팅의 최신 히스토리 누락과 최초 로딩 지연을 읽기 전용으로 조사한다. 오래된 항목부터 페이지를 가져오는 경로, 중복 문서 페이로드, 실시간 갱신을 점검한다.
- 히스토리 UI는 최신 페이지를 우선 표시하고 더보기는 과거 페이지를 추가한다. 실행취소의 기존 안전 검사와 오름차순 소비자는 보존한다.
- 히스토리 내부 중첩 스크롤과 이벤트 차단을 수정하고 히스토리/이전·다음 버튼 간격을 조정한다.
- 사라진 드래그 선택 영역의 CSS/이벤트/렌더링 회귀를 조사하고 원인을 기록한다.
- 테이블 사이드바 PK/UNIQUE·관계 숫자는 현재 모드에서 실제 표시되는 목록과 동일하게 집계한다.
- 기능별 실패 재현·검증과 실제 렌더링을 수행한다. 실제 사용자 프로젝트를 수정하거나 테스트 계정을 생성하지 않는다.
