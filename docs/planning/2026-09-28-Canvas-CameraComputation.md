# 카메라 변경과 문서 계산 분리 실험

작성일: 2026-09-28
기준: `feat/performance-measurement`, `5944f09`, 깨끗한 작업 트리.

- 첫 기준에서 50개 테이블 팬 한 번에 치수 5,150회·관계 경로 100회가 계산됐다. 문서 불변인 카메라 갱신에서 이 계산을 재사용한다.
- Canvas의 뷰 노드·도메인 경로와 카드 콘텐츠 치수, 테이블 관계의 순수 geometry 준비를 memo화한다. 관계 렌더 이벤트·상태·callback은 최신 상태를 유지하며 컴포넌트 전체를 부정확한 비교 함수로 memo하지 않는다.
- 첫 실험은 문서 객체 전체를 무효화 기준으로 사용한다. 편집·이동·동기화·undo 등 새 문서가 오면 다시 계산한다. 세부 필드별 캐시나 공유 경로 캐시는 다음 작업으로 남긴다.
- 선택된 뷰·scope·visible node 목록도 의존성에 포함한다. 장애물·수동 경로·label 의미는 변경하지 않는다.
- 단위·타입·일반 빌드·측정 빌드를 확인하고 같은 50/10 wheel PAN으로 재측정한다. MOVE·EDIT도 확인하여 오래된 경계·경로가 남지 않는지 검사한다.
- 원시 시간에는 계측 오버헤드가 있으므로 호출 수를 1차 지표로 사용하고 시간 변화는 참고값으로 구분한다. 현재 turn은 구현과 로컬 검증이며 원격 push는 별도 요청 시 수행한다.
