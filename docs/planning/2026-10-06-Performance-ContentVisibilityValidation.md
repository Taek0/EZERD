# 카드 표시 생략 후보의 회귀 검증

- 제품 소스는 최신 main 기준을 유지하고 lab 전용 CSS/메모리 예제에서 적용 여부를 전환한다.
- 테이블 카드에만 content-visibility:auto를 적용한다. 선택/포커스/활성 입력/드래그 관련 카드는 visible로 유지하는 보수적 후보를 검증한다.
- 같은 문서·카메라에서 전후 화면과 카드 치수/관계/PNG를 비교한다. 화면 밖 이동 후 재진입, 줌, 인라인 저장/실패/취소, 타입 popup/Tooltip, 키보드 포커스, 카드 이동/크기, 기존 모션을 확인한다.
- 실제 제품의 저장 서버 대신 메모리 ACK만 사용한다. 제품 저장 경로의 정확성 전체를 이 예제로 대체하지 않는다.
- 후보의 이동 성능을 다시 측정한다. 시각/기능 회귀가 있으면 수정하거나 적용 보류를 명시한다. main/원격 push는 하지 않는다.
