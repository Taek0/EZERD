# 워크스페이스 전환 프로토타입

- 작성일: 2026-09-30
- 목적: 실제 서비스 적용 전에 전환 UI 세 가지의 위치와 사용 흐름을 비교한다.
- 범위: 독립 HTML에서 A 이름 드롭다운, B 왼쪽 레일, C 검색 모달을 구현한다.
- 공통 예시: Edusync에는 klassboard-backend, TY에는 ezerd와 monya를 표시하며 소유자 역할과 대기 초대 예시를 제공한다.
- 실제 API, 저장소, 운영 화면은 연결하지 않는다. 선택과 생성은 페이지 메모리에서만 처리한다.
- 기존 Apple SD Gothic Neo와 청회색 버튼 토큰을 참고하고 목록 항목은 평면으로 표현한다.
- 검증: 세 변형의 직접 URL, 워크스페이스 전환, 검색, Escape와 외부 클릭 닫기를 확인한다.
