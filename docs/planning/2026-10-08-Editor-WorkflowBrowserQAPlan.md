# 편집 워크플로 브라우저 QA 계획

- 단독 CUA 소유자로 Chrome의 http://127.0.0.1:5174 임시 DB QA 서버를 UI로 검증한다. native-sync POST 지연은 800ms이다.
- QA 전용 새 사용자, 워크스페이스, PostgreSQL 프로젝트를 생성한다.
- 우선: 사이드바 검색 타입/PK/설명/옵션, ENUM 생성·편집·삭제, 히스토리 최신순·높이, 고급식과 상세정보, 도메인 필터, 논리설계 OFF/ON.
- MAIN/Godel 완료 통지 후: 빈 테이블 즉시 생성, 이동 지연, 키보드, 우클릭.
- 결함은 발견 즉시 지정 결과 문서에 재현 절차와 화면 증거를 기록한다. 코드 수정과 Git add/commit은 하지 않는다.
