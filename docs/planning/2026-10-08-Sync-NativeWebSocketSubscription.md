# Native WebSocket 수신 구현

- 로그인 세션과 활성 Native 프로젝트에 묶인 WebSocket 구독을 구성한다.
- operation/subscribed/head의 최신 sequence와 DB revision을 확인하고 원격 변경만 기존 백그라운드 문서 갱신으로 반영한다.
- 자기 저장 ACK의 중복 조회를 방지하며 연속 이벤트를 합친다. 재연결·온라인 복귀·탭 복귀 및 주기적 누락 확인을 지원한다.
- 이전 프로젝트/세션 이벤트와 권한 회수를 처리하고 카메라·선택·미저장 입력·드래그를 보존한다.
- 서버 발행과 Native 클라이언트 수신을 함께 검증한다. DB 마이그레이션이나 v1 런타임 복원은 하지 않는다.
