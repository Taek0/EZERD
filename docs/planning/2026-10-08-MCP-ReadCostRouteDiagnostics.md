# MCP 조회 비용과 관계선 검증 개선

- 우선순위 1인 반복 조회 비용 절감과 관계선 배치 검증부터 구현한다.
- 공유 조회에 불필요한 개인 상태·preview·전체 DB 진단 계산을 분리한다. 권한은 매 호출 재확인하고 개인 데이터는 공용 캐시에 넣지 않는다.
- 캐시는 버전·동기화 순서·DB 컨텍스트로 구분하고 크기를 제한하며 변경된 문서와 오류를 잘못 재사용하지 않는다.
- 카드 관통·선분 겹침·교차를 실제 좌표로 진단한다. 검증하지 못한 자동 경로는 명확히 표시한다.
- 배치 알고리즘이나 운영 설계 좌표를 자동 변경하지 않는다. 일괄 상세 조회·페이지 버전 고정·변경분 조회는 별도 후속 범위다.
