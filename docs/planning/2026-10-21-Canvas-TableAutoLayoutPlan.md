# 테이블 자동 배치 개선 계획

기준: origin/main 880f9bc를 performance-lab에 병합한 상태. 기존 도메인 배치와 일반 이동은 유지한다.

## 구현 범위

- 테이블 배치 전용 순수 계산 경로를 추가한다. PK/참조 대상이 위, FK/참조하는 테이블이 아래인 계층을 기본으로 한다.
- 연결 그룹을 분리하고 순환 참조는 SCC로 묶는다. 같은 계층은 목표 폭에 맞춰 여러 행에 배치하며 독립 그룹은 공간에 맞춰 포장한다.
- 실제 표시 카드 크기를 사용하고 테이블 경계 사이 기본 간격 200을 적용한다. 기존 좌우 순서를 tie-break로 활용하며 소수의 고정 폭 후보와 고정 횟수 순서 조정으로 계산량을 제한한다.
- 메모와 다른 화면·숨겨진 테이블은 이동하지 않는다. 메모 충돌 회피는 기존의 메모 아래 영역을 사용하는 보수적 정책을 유지한다.
- UI에서는 명시적 테이블 배치에서만 Worker를 실행한다. 계산 중 변경이 감지되면 오래된 결과를 저장하지 않는다. 기존 일괄 저장과 한 번의 실행 취소를 유지한다. 관계선의 고비용 자동 정리는 별도 명시적 실행으로 유지한다.
- 긴 단일 연결의 접기, 위치 고정 UI, 미사용 코드 정리는 이번 범위 밖이다.

## 검증

분기·고립·순환·긴 연결·불균일 카드 크기·입력 순서·반복 실행의 안정성, 겹침과 계층 보존, Worker 결과 반영과 실행 취소를 확인한다. 합성 문서 측정과 전체 format/check를 수행하고 결과를 work-log에 기록한다. 원본 문서와 main 서버는 변경하지 않는다.
