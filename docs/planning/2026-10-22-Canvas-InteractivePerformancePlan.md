# 캔버스 반복 작업 축소 구현 계획

[조사](../work-log/2026-10-22-Canvas-OptimizationAuditResult.md)의 1~4번을 codex/performance-lab에 구현한다. 일반 라우팅 부분 갱신과 DOM 가상화는 제외한다.

1. 팬 pointermove를 프레임당 마지막 좌표로 병합한다. release/cancel/capture 해제의 최종 위치, 줌 앵커 및 scope 변경/StrictMode 정리를 검증한다.
2. 관계선 SVG를 안정된 memo 경계로 분리하고 표·컬럼 이름 조회와 tooltip을 콘텐츠별로 재사용한다. 선택·hover·언어·이름 변경은 정상 반영한다.
3. 인라인 셀의 같은 table/column/input 반복 조회를 줄인다. 편집 초안·IME·포커스·권한·최신 저장 기준은 유지한다.
4. 탐색/속성 패널의 문서 기반 파생값과 검색을 분리해 memo한다. 인덱스는 입력 변경 시 갱신하고 선택/모드/범위/검색/라벨 변경을 검사한다.

각 영역 파일 소유권을 분리해 병렬 작업하고 루트에서 리뷰·단위별 커밋한다. 불필요한 UI 훅 모킹 신규 도입은 피하고 실제 React/DOM 또는 순수 데이터 동등성 및 작업 횟수 회귀 검사를 활용한다. 전체 format/check와 변경 전후 작업 횟수 검증을 수행한다. 실제 브라우저 FPS를 측정하지 않으면 개선율로 주장하지 않는다. 실제 문서·main·실행 서버는 수정하지 않는다.
