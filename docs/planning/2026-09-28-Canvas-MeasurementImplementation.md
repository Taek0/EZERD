# 최소 성능 측정 도구 구현

작성일: 2026-09-28
기준: `feat/performance-measurement`, `293ff60`, 깨끗한 작업 트리.

- 사용자 승인에 따라 최소 fixture·계측·측정 화면을 구현하고 작은 데이터에서 첫 검증을 진행한다.
- 일반 배포와 분리된 Vite 성능 빌드에서만 계산 함수를 계측한다. 실제 모델 카드 치수·관계 경로·도메인 관계 함수를 사용하고 제품 알고리즘은 변경하지 않는다.
- collector는 bounded raw 표본, 호출 수·누적 시간, 시작/종료·reset·오류·손실 상태를 제공한다. 중첩 시간은 inclusive로 명시한다.
- 실제 Canvas에 합성 문서를 연결하는 독립 화면을 만든다. DB/API 연결 없이 크기 선택·초기화·측정·JSON 결과 및 내보내기를 제공한다.
- 우선 10개 fixture로 안정성 확인 후 50개에서 팬·이동·편집을 측정한다. 규모 확장은 작은 fixture의 실제 비용과 안정성을 확인한 뒤 결정한다.
- collector·fixture·계측 변환의 의미 있는 테스트와 타입·빌드를 검증한다. 브라우저는 제공된 Browser 스킬의 지원 API만 사용하고 안정성 문제 시 중단한다.
- 구현과 검증 기록을 독립 커밋으로 남긴다. 일반 빌드에 측정 화면·계측이 포함되지 않는지도 확인한다.
