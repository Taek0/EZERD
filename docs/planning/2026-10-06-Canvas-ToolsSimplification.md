# 캔버스 도구 메뉴 정리 계획

- 상단바의 보기 선택과 자동 배치 항목을 기본 버튼 및 더 보기 메뉴에서 제거한다.
- 도메인 필터와 전체 테이블·도메인 맵 이동은 유지한다.
- 사이드바 도구 탭의 카메라 저장·초기화, 테이블 복사·붙여넣기, 공유 캔버스 / 개인 화면 패널을 제거한다.
- 기존 개인 화면 데이터, 저장된 카메라, 단축키 복사·붙여넣기 및 입력 복구 경로는 보존한다. 일반 도구 패널을 제거해도 기존 보관 입력은 별도 복구 편집기로 열 수 있게 한다.
- 관련 렌더링 회귀 테스트, 웹 타입 검사, 포맷 검사를 수행한 뒤 결과를 기록하고 커밋한다.
