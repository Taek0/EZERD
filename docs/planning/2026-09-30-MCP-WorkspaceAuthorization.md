# MCP 워크스페이스 권한 적용 계획

- 모든 프로젝트 조회·변경 도구에 인증된 사용자 ID를 전달한다. 문서 탐색과 진단은 권한 검사가 수행된 서비스 스냅샷으로만 처리한다.
- SpaceService의 사용자 우선 API로 공간·멤버·초대 생명주기 도구를 제공한다. 입력에서 actor를 받지 않는다.
- whoami는 인증된 사용자 ID·이름·색상만 반환한다. 모든 도구 호출 직전에 현재 토큰의 소유자·만료·폐기 상태를 확인한다.
- 프로젝트 생성/검색/가져오기 계약에 workspaceId를 반영하고 내보내기 문서는 이름과 공유 설계만 포함한다.
- 도구 등록, 권한 전달, 멤버십 취소 후 재호출, 폐기 토큰 및 입력 위조를 테스트하고 관련 기존 테스트를 갱신한다.
