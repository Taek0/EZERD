# 편집기 탐색과 패널 접근성

- 도메인 뷰 구성은 테이블 캔버스에서만 제공한다.
- 갤러리 이동은 기존 확인 대화상자로 확인한 뒤 기존 자동 저장 flush와 프로젝트 종료 순서를 유지한다.
- 갤러리 버튼과 프로젝트 경로를 구분선으로 분리하고 경로 글자 크기를 통일한다.
- 캔버스의 남은 높이를 grid/flex로 제한하여 사이드바의 모든 내용에 스크롤로 접근하게 한다.
- 핀치 확대 계수를 0.0015에서 0.002로 조정하고 포인터 고정과 범위 제한을 검증한다.
- 사용자 선택 A안을 반영해 탐색은 왼쪽에 두고 편집·보기·협업 및 변경 기록을 그룹과 구분선으로 나눈다. 기존 UI 컴포넌트와 디자인을 재사용한다.
- 변경 후 포맷, 웹 타입 검사, 관련 테스트 및 가능한 화면 검증을 수행한다.
