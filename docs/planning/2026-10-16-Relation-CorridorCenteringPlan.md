# 관계선 통로 중앙 정렬 계획

작성일: 2026-10-16

- 명시적 관계선 자동 정렬의 마지막 단계에만 통로 중앙 정렬을 적용한다.
- 카드와 메모의 18px 확장 경계를 한 번 계산하고, 긴 내부 평행 구간의 전체 길이에 공통으로 열린 통로를 구한다.
- 같은 통로의 선을 16px 간격의 묶음으로 배치하고 묶음 중심을 통로 중심에 맞춘다. 각 선의 끝점, 앵커, 방향 및 최대 28px의 기존 출발·도착 보호 구간을 보존한다.
- 기존 꺾임 수와 구간 진행 방향을 유지한다. 장애물 침범, 자기 중첩 및 관계선 쌍별 교차·중첩·좁은 간격 증가를 거부한다.
- 통로 그룹과 후보 수에 명시적 상한을 두고 추가 그래프 탐색 없이 가장 중앙에 가까운 유효 후보를 선택한다.
- 수평·수직, 두 평행선, 폭이 다른 카드, 전체 구간을 제약하는 장애물, 좁은 통로와 직접 연결을 검증한다.
- HWP DTO와 2026-10-14 실제 스냅샷에서 현재 소스와 변경 소스의 시간·품질·저장 경로 재생을 비교한다.
