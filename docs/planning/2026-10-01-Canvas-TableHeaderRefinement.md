# 테이블 헤더 편집 개선과 뷰 통합 검토

## 구현 범위

- 전체 테이블 캔버스의 헤더에서 도메인 이름을 오른쪽에 표시한다. 배지의 `소유 도메인` 접두어는 제거하고 글자를 11px에서 13px로 조금 키운다. 제목도 일반 도메인 화면과 같은 26px로 맞춘다.
- 테이블 제목을 편집할 때 제목과 같은 위치·글자 크기로 투명한 입력 필드를 표시한다. 큰 일반 입력창의 배경·테두리·윤곽·여백을 사용하지 않는다.
- 제목의 검정 글자는 배경과 흑백 중 최대 대비를 선택하는 기존 코드의 결과임을 설명했다. 후속 요청에 따라 대비 계산을 제거하고 테이블 이름은 모두 흰색으로 통일한다.
- 컬럼 편집과 읽기 전용 동작은 유지하고, 제목의 더블클릭·키보드 진입·저장·취소를 확인한다.

## 뷰 통합 의견 범위

도메인 테이블 화면 및 개인 함께 보기와 전체 캔버스의 현재 차이를 확인하고 통합 방향의 장점·배치·필터·권한 정책을 제안한다. 사용자가 구현 전 의견을 요청했으므로 이번에는 뷰 통합을 구현하지 않는다. 도메인 맵과 테이블 화면을 같은 화면으로 합치는 것과도 구분한다.

후속 요청에서 전체 테이블 기본 화면·도메인 필터·공유 화면 방향을 채택했다. 실제 통합 작업은 별도 계획과 작업 단위로 진행한다.

## 통합 제안

- 전체 테이블 캔버스를 기본 편집 화면으로 하고 `전체 / 도메인 선택` 필터와 저장된 보기를 같은 화면에서 제공한다. 도메인 맵은 업무 영역·흐름을 다루는 별도 화면으로 유지한다.
- 도메인 하나를 선택한 상태에서 테이블을 생성하면 그 도메인에 자동 소속시킨다. 전체 또는 여러 도메인 선택에서는 미지정 생성이 기본이며 필요하면 명시적으로 소속을 지정한다.
- 필터 전환은 같은 테이블과 위치를 사용하는 방향을 권장한다. 현재 전체/소속/개인 뷰 좌표가 독립적이므로 기존 좌표를 바로 삭제하거나 전체 좌표로 덮어쓰지 않고 이관·되돌리기 정책을 먼저 정한다.
- 기존 개인 도메인 뷰는 저장된 도메인 필터와 개인 메모·관계선 상태로 연결할 수 있다. viewer가 개인 보기에서 할 수 있는 작업과 공유 캔버스 수정 권한의 차이는 유지해야 한다.
- 관계는 양쪽 테이블이 현재 필터에 보일 때 표시한다. 도메인 밖 FK 상대를 보고 싶을 때는 별도 외부 관계 표시 선택을 제공한다.
- 첫 통합은 화면 진입과 필터·저장된 보기 선택을 정리하는 단계로 잡고, 좌표 정책은 기존 사용자 배치를 보존하는 원칙으로 별도 구현한다. 테이블 모델을 복제하거나 도메인 관계를 FK로 변환할 필요는 없다.

## 검증

기존 웹 회귀 테스트, 웹 타입 검사·빌드·포맷과 실제 브라우저의 헤더 배치 및 입력 상태를 확인한다. 구현 결과는 work-log에 기록하고 이번 변경만 커밋한다.
