# 관계 준비의 카드 경계·조회 인덱스 재사용

작성일: 2026-09-28
기준: `4b7e4ae`, `feat/performance-measurement`, 작업 트리 깨끗함.

- 관계마다 반복하는 table/node/route/column 조회와 관계 쌍 검색을 한 준비 호출 내 Map/Set으로 대체한다.
- 카드 경계는 노드 객체별로 지연 계산하고 같은 준비 호출의 다른 관계·장애물에서 재사용한다. 문서 간 전역 캐시는 추가하지 않는다.
- 기존 first-match, 관계 쌍의 원래 순서, self relation, 수동 경로, visibleNodeIds 및 obstacle 의미를 보존한다. 입력 문서를 변경하지 않는다.
- 기존 준비 함수와 새 함수를 다양한 합성 문서에 실행해 결과 동등성을 확인하고, 치수 계산이 eligible node당 최대 한 번인지 테스트한다.
- 변경 전 `5f6479a` 브라우저 기준과 동일한 EDIT/MOVE 반복을 수행해 SVG path·문서 fingerprint·입력 이벤트를 비교한다. 카메라 재계산0회도 유지되어야 한다.
- 코드·검증은 로컬 성능 브랜치에 독립 커밋한다. 세밀한 관계별 무효화, Worker, 렌더러 교체는 이번 범위가 아니다.
