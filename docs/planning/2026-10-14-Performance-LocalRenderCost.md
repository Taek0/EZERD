# 로컬 편집 표시 비용 축소 계획

- 실제 문서 복제본의 이름/NULL/삭제를 동일 조건으로 측정하며 문서 투영, 카드 metrics, inline 조회 및 React subtree 비용을 구분한다.
- 반복 계산의 재사용은 브라우저 표시 경계에서만 적용하고, 서버 검증/원본 모델 함수의 가변 입력 의미는 유지한다.
- 확인된 병목 하나를 독립적으로 개선하고 이름/속성/삭제/ACK/권한/DB 문맥 회귀를 검사한다. 실제 입력의 최신 context를 무시하는 memo 비교는 사용하지 않는다.
- UI와 애니메이션, world 합성 설정을 유지하며 검증 결과와 한계를 work-log에 기록한다. 실측 도구와 원본 자료는 lab에 남긴다.
