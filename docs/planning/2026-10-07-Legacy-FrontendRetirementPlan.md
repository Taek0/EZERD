# v1 프런트엔드 구현과 QA 정리

- 웹 Native 진입 전환 이후 남은 v1 Canvas/TableEditor 및 클라이언트 동기화·히스토리의 전용 구현·테스트·QA를 정리한다.
- 먼저 main.tsx의 import 그래프와 전체 레포 소비자를 대조한다. Native에서 사용하는 모듈·스타일·공통 함수·파일 가져오기·서버 API는 삭제하지 않는다.
- 단위 1: v1 편집기 및 해당 편집기만 사용하는 QA를 제거한다. 혼합 테스트는 유지 또는 필요한 검증을 공통/Native 경로로 옮긴다.
- 단위 2: v1 클라이언트 동기화·히스토리와 전용 QA를 정리한다. 개인 상태 병합 등 공통 동작의 검증은 남긴다.
- 단위별 참조 검색·타입 검사·관련 테스트 후 커밋한다. 최종 포맷·전체 단위 테스트·빌드로 Native 회귀를 확인한다.
- README·자동 실행 설정에 삭제되는 스크립트 참조가 있으면 갱신한다. 과거 작업 기록은 당시 사실로 보존하고 이번 기록으로 폐기 범위를 명시한다. docs/EZERD.txt는 수정하지 않는다.
