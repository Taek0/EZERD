# 테이블 카드 밀도 개선 계획

- 제목 24px, 본문 18px로 조정하고 행·헤더·푸터 여백을 줄인다.
- `table-geometry.ts`의 내용 크기 계산과 카드 CSS를 함께 조정한다. 긴 타입과 설명의 줄바꿈 및 높이 확장을 유지한다.
- 저장된 노드 크기는 그대로 존중한다. 내용 때문에 추가되던 최소 크기만 줄이며 저장된 레이아웃을 자동 변경하지 않는다.
- 카드 크기·긴 텍스트 회귀 테스트와 웹 타입 검사를 수행한다.

## 추가 요청: 카드 대비 글자 확대

- 제목 26px, 본문 20px로 키우되 행의 세로 여백을 줄여 한 줄 행 높이 37px와 헤더 높이 50px를 유지한다.
- 텍스트 폭 추정과 여러 줄 행 높이를 실제 글자 크기 및 줄 높이에 맞춰 조정한다.
