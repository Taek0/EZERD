# 워크스페이스 선택 및 순서 저장

- 마우스로 선택창을 클릭할 때 발생하는 텍스트 선택과 선택 후 남는 포커스 장식을 조사한다. 마우스 포커스 장식을 정리하되 키보드 focus-visible 접근성은 유지한다.
- 선택 목록을 드래그하여 순서를 바꾸고 이동 중 인접 항목이 자연스럽게 자리를 바꾸도록 한다. 드래그 종료를 워크스페이스 선택 클릭으로 처리하지 않는다.
- 순서는 로그인 사용자별 서버 설정으로 저장해 새로고침·재로그인·다른 기기에서도 유지한다. 다른 사용자의 목록 순서는 바꾸지 않는다.
- 서버는 본인 멤버십의 중복 없는 유효한 목록만 원자적으로 변경한다. 새로 참여한 공간은 기존 정렬 뒤에 표시하고 탈퇴한 공간은 제외한다. 다른 탭에는 기존 사용자 변경 이벤트로 반영한다.
- 저장 실패는 안내하고 마지막 확인된 순서로 복구한다. 키보드 순서 변경과 reduced-motion을 지원한다.
- 실제 사용자 DB에는 마이그레이션을 적용하지 않고 계약·권한·저장·드래그/클릭 구분 회귀와 타입·빌드로 검증한다.
- 추가 요청: 메모와 물리/논리 그룹 사이에 구분선을 넣고 세그먼트 텍스트를 가로·세로 중앙 정렬한다.
