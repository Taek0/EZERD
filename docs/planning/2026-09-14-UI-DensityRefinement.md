# UI 밀도와 디자인 톤 조정 계획

작성일: 2026-09-14

최신 피드백을 우선하여 전체 글꼴·핀·팝업은 축소하고 테이블 카드 내부 글자는 확대한다. 진행 중/보관함의 추가 윤곽을 제거하고 프로젝트 카드 윤곽을 완화한다. 버튼은 기존 회색 바탕·부드러운 양각/음각과 절제된 파란 강조의 뉴모피즘/스위스 톤으로 맞춘다. 접근성·검색·키보드 등 공통 컨트롤 동작은 유지한다.

핀은 이전의 작은 마커 형태로 복원하고 첨부처럼 작성자·본문·답글 입력을 촘촘하게 배치한다. 사이드바 열기/닫기에 애니메이션을 적용한다. 컬럼 편집은 짧은 라벨과 격자 배치로 축소한다. 도메인 함께 보기는 도메인 뷰로 이름을 바꾸고 툴바 버튼 아래 드롭다운 메뉴에서 선택한다.

UI는 Astra가 담당한다. 실제 화면에서 글꼴 크기/팝업/핀 입력 높이/마커/카드 넘침/메뉴·저장 동작과 모션 감소를 검증한다. 데이터 모델과 삭제 정책을 변경하지 않는다. 이전 문서 분류 변경은 이번 커밋에 포함하지 않는다.

추가 요청: 관계선 조절 버튼은 클릭마다 이동하는 방식에서 누른 채2차원 드래그하는 방식으로 변경한다. 직각 선을 유지하고 뷰별 bend 좌표를 선택 필드로 저장한다. 기존 offset 경로와 문서 호환을 유지하며 좌표 검증·복제·저장 왕복과 확대된 캔버스의 드래그 동작을 검증한다.
