# 편집 흐름 개선 계획

- 도메인 뷰는 선택 후 적용 시 즉시 활성화하고 선택 창을 닫는다.
- 핀 삭제와 입력란 뒤 회색 한 줄 콜아웃을 추가한다. Enter는 전송, Shift+Enter는 줄바꿈이며 IME 조합 중에는 전송하지 않는다.
- 테이블 카드 사이드바의 속성명을 속성으로 정리한다.
- 설계 변경에 Ctrl+Z 실행 취소를 제공한다. 서버 핀 상태와 설계 이력은 구분한다.
- 테이블 관계 패널은 PK 출발, FK 대상 순서로 표현하고 관계 추가 폼을 기존 관계 아래 배치한다. 저장 모델의 FK→PK 의미는 유지한다.
- 다른 도메인 테이블은 저장된 도메인 뷰의 참조 관계에 포함된 테이블만 표시하며 행 클릭이나 테이블 추가를 제공하지 않는다.
- 타입 검사와 관련 테스트 및 브라우저에서 즉시 적용, 관계 순서, 비상호작용 목록을 검증한다.
