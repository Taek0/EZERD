# 동시 편집과 전체 편집 잠금 제거

- 사용자 결정: 겹치지 않는 속성 변경은 함께 반영하고 같은 속성은 서버에서 후속 처리한 편집을 우선한다.
- 저장 요청 대기 상태를 이유로 프로젝트 전체 입력을 잠그지 않는다. 후속 입력을 보존하며 전송은 직렬 처리한다.
- 이미 보낸 요청의 operationId와 본문은 변경하지 않는다. 응답 미확인은 결과 조회·동일 요청 재시도로 복구한다.
- 삭제된 객체, 권한 상실, DB 컨텍스트 변경 및 구조 제약 오류는 자동 덮어쓰기로 무시하지 않는다.
- 서버 충돌 정책과 클라이언트 입력 보존·복구를 분리해 구현하고 회귀 테스트 후 검증한다.
