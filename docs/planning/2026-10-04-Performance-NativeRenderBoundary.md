# Native 카메라와 문서 렌더 경계 분리 계획

2026-10-04. 중복 장면 계산 제거 eb16762 이후 카드·관계선 React 트리를 memo 컴포넌트로 분리한다. 카메라 transform은 외부에서만 변경한다. 문서/장면/선택/표시 모드는 정상 props 비교로 갱신하고, 이벤트는 layout effect에서 갱신한 최신 동작 참조를 사용하여 현재 zoom·권한·문서·저장 콜백을 읽는다. 콜백을 무시하는 custom comparator는 사용하지 않는다.

기존 JSX/CSS와 조작은 유지한다. 회귀 테스트와 일반 빌드/타입/포맷을 실행하고 브라우저 pan/zoom에서 nativeColumnTypeDisplay 및 geometry 호출 0회를 확인한다. 선택·뷰 전환이 정상 반영되고 새 문서/콜백이 캐시에 가려지지 않는지 검증한다. API/운영 문서는 수정하지 않는다. 결과를 기록하고 독립 커밋한다.
