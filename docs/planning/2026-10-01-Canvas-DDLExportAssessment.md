# 공유 메뉴 DDL 내보내기 사전 조사

## 요청과 범위

- 프로젝트 상단바 공유 드롭다운에 DDL 내보내기를 추가하기 전에 현재 코드의 재사용 범위와 추가 작업량을 확인한다.
- 이번 작업에서는 제품 코드를 변경하지 않는다.
- 공유 메뉴, DDL 생성기, API 계약, 권한, 진단 및 기존 테스트를 살펴보고 구현 범위와 검증 항목을 제안한다.
- 조사 완료 결과는 `docs/work-log/2026-10-01-Canvas-DDLExportAssessment.md`에 기록한다.
- 시작 시 존재한 미커밋 제품 코드와 테스트 변경은 조사 참고용으로만 읽고 이번 커밋에 포함하지 않는다. `docs/EZERD.txt`는 변경하지 않는다.

## 조사 순서

1. 공유 메뉴와 현재 내보내기 동작을 추적한다.
2. DDL 생성 및 내려받기 경로와 기존 테스트를 확인한다.
3. 재사용 가능한 기능, 누락된 연결, 선택해야 할 UX를 정리한다.
4. 필요한 경우 관련 기존 테스트를 실행하고 결과 문서만 커밋한다.
