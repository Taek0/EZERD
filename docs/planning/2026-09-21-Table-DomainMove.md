# 테이블 도메인 이동

- 속성 사이드바의 기본 정보에 도메인 선택을 추가한다. 읽기 전용에서는 변경할 수 없다.
- 실제 소유 도메인이 바뀌면 새 소유 도메인 외의 일반 도메인 배치를 제거한다. 새 소유 배치가 이미 있으면 위치를 유지하고, 없으면 기존 소유 위치를 사용한다.
- 테이블 ID, 컬럼, 키, FK 정의는 유지하고 양 끝 테이블 배치가 없는 관계 경로만 정리한다. 함께 보기 화면은 선택 도메인에 따라 갱신한다.
- 동일 도메인의 이름 등 속성 변경은 사용자가 추가한 외부 참조를 유지한다. 기존 저장 데이터의 일괄 변경이나 초기화는 하지 않는다.
- 모델 회귀 테스트와 속성 화면 렌더링 검증을 수행한다.
