# 도메인 이동과 캔버스 도구 계획

테이블 기본정보에서 소유 도메인을 변경한다. 실제 소유권 변경 시 이전 일반 도메인 배치/참조를 제거하고 새 소유 배치를 유지하며, 의도적으로 선택한 도메인 뷰는 구성에 따라 재계산한다. 컬럼·키·FK는 보존한다. 기존 데이터는 자동 일괄 정리하지 않는다.

캔버스 우측 하단 배율 왼쪽에 커서/손 도구를 둔다. 커서의 빈 공간 드래그는 사각형 다중 선택, 손 도구는 카드 편집 없이 카메라 이동만 처리한다. 선택된 여러 카드는 함께 이동하고 Delete는 자체 확인창 후 처리한다. 카메라는 로컬 상태로 유지한다. 트랙패드 핀치 계수는 현재0.002에서0.003으로 증가한다.

사각형/좌표 변환과 모델 정합성은 계산 테스트로 검증한다. 실제 운영 프로젝트는 수정하지 않는다. 429 발생 시 현재 워크스페이스 포크로 인계한다.
