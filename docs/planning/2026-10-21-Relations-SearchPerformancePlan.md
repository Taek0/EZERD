# 관계선 자동 정리 탐색 비용 개선 계획

version 407 klassboard-backend 스냅샷(D:/ChatGPT/ERD/.data/klass-route.json)을 고정 복제하여 비교한다. 현재 입력은 nativeCanvasScene 물리 보기의 실제 크기·라벨 폭으로 준비한다. 실제 프로젝트는 읽거나 변경하지 않는다.

1. 현행 기본/확대 예산의 시간·실패·탐색 횟수를 기록한다.
2. 자동 정리 전용 저비용 후보와 공유 장애물 인덱스를 적용한다. 일반 relationGeometry 호출의 기본 동작은 보존한다.
3. 전체 장애물로 검증하면서 작은 탐색 좌표 집합부터 점진적으로 확대한다.
4. 관계별 초기 예산, 보류 후 잔여 예산 재배분, 전체 경과 시간 한도를 적용한다. 먼저 유효 경로를 확보하고 남은 예산으로 미관을 개선한다.
5. 카드 비관통·직교·연결점·출발 직선·재생 일치·완료 관계 수를 필수 검증한다. 교차·겹침·꺾임·길이는 품질 지표로 비교한다. 실패한 기존 실행은 완성된 품질 결과로 취급하지 않는다.

일반 드래그 경로에는 신규 탐색 정책을 적용하지 않는다. 저장/ACK 프로토콜은 유지한다. 구현은 독립 단위 커밋하며 측정 자료는 artifacts/performance/2026-10-21-relation-search에 보관한다.
