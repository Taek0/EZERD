# 설계 확인 항목 토글과 이력 작업 필터

- 설계 확인 항목은 기본 펼침을 유지하고 공통 DisclosureButton/Collapse로 접기와 펼치기를 제공한다. 제목에 건수를 표시하고 기존 문제 이동 기능을 유지한다.
- 이력은 서버가 반환한 변경 경로와 존재 여부로 추가, 수정, 이동, 크기 변경, 순서 변경, 삭제, 관계, 데이터베이스 변경을 분류한다. 여러 작업을 포함한 이력은 관련 필터 모두에서 전체 변경 내용과 함께 표시한다.
- 페이지 단위로 불러온 이력만 필터링한다는 안내와 결과 건수, 빈 결과 안내를 제공한다. 전체 선택은 알 수 없는 형식과 거부된 이력도 보존한다.
- 보상 요청, 실행 취소, 삭제 복원, 사용자와 시간 표시, 추가 페이지 로딩은 기존 동작을 유지한다.
- 분류 단위 테스트, 렌더링 회귀 테스트, 웹 타입 검사 및 포맷 검사를 수행한다.
