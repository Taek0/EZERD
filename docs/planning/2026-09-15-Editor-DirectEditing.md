# 히스토리 필터와 테이블 직접 편집·관계 조절

작성일: 2026-09-15

히스토리를 동작별로 필터하고 실제 값이 변하지 않은 키 컬럼 기록의 생성 원인을 수정한다. 과거 기록의 무변경 항목도 표시에서 제외한다. 테이블 캔버스 우클릭의 새 테이블, 카드 타입·NULL 선택, 컬럼 키 지정 및 사이드바 PK 체크박스를 추가한다. 관계 편집은 요약과 상세 영역으로 정리하고 새 FK 컬럼 이름을 기본값 유지 상태에서 수정할 수 있게 한다.

까마귀발은 카드 테두리의 위치로 이동하고 관계선은 직각 선분을 직접 드래그한다. 접점과 수동 경로를 문서·동기화 계약에 저장하며 드래그 미리보기와 확정 저장을 구분한다. 기존 단일 bend 문서는 호환한다. 직선 구간 이동시 직각 꺾임 구조를 유지하고 필요하면 인접 꼭짓점을 함께 조절한다.

대응관계 선택박스의 참조 이미지가 메시지에 없어 재첨부와 의미 확인을 요청했다. 해당 세부 선택 방식은 답변 또는 명시한 합리적 기본안으로 확정한다. UI는 Astra, 모델 변경 비교 회귀는 Sol, 관계 경로와 통합 정합성은 주 에이전트가 담당한다. 테스트 먼저 작성, Prettier 적용, 단위별 검증·작업 기록·커밋을 수행한다.
