# 편집기 뷰포트 반응형 셸

- 편집기에서만 CSS 뷰포트 너비와 높이에 따라 헤더, 프로젝트 행, 캔버스 도구 모음의 여백과 컨트롤 크기를 조절한다.
- 기준 화면은 1512×827 CSS 픽셀이다. OS, DPR, 디스플레이 물리 해상도 판별 또는 전체 화면 확대/축소는 사용하지 않는다.
- 갤러리 브랜딩과 캔버스 카드 글자 크기 및 문서 줌은 유지한다. 조작 글자는 최소 13px, 보조 정보는 최소 12px을 사용한다.
- 좁은 화면에서는 제목과 도구를 줄바꿈하며 기존 고정 캔버스 최소 높이를 줄여 사용 가능한 높이를 확보한다.
- 별도 CSS 파일과 App import만 변경한다. 패널 폭 정책은 별도 작업에 맡긴다.
- Prettier와 웹 빌드로 검증하고 부모 작업에서 실제 뷰포트별 시각 검증을 수행한다.
