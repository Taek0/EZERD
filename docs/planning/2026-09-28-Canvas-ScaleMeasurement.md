# 100·300개 규모 측정

작성일: 2026-09-28
기준: `ee6e533`, `feat/performance-measurement`.

- 먼저 관계 준비 전체를 별도 Node 프로세스에서 측정한다. 각 fixture는 30초 wall timeout, 첫 계산이 1초를 넘으면 30회 반복을 생략하고 단일 표본으로 기록한다.
- 50·100·300개, 컬럼10개, 관계1배를 우선 비교한다. 데이터 생성·검증은 측정 구간 밖에서 수행하고 프로세스 시작 비용과 순수 준비 시간을 구분한다.
- 1차 계산이 1초 이하인 크기만 브라우저 준비/조작을 검토한다. 100개부터 시작하고 안정성 확인 후300개로 확장한다. 브라우저가 멎으면 반복하지 않고 실패·미측정으로 기록한다.
- 브라우저는 기존 PANEL/fixture와 EDIT/MOVE/PAN helper를 사용한다. 먼저 각1회로 입력·결과를 확인하고 안전하면 반복3회로 확장한다. node 지표를 UI 지연으로 표현하지 않는다.
- 이번에는 제품 최적화 없이 측정 도구와 조사 결과만 추가한다. 30컬럼·관계3배 및 상세 메모리는 후속 범위다.
