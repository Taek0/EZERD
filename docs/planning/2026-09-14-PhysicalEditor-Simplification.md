# 물리 모델 중심 편집 UI 변경 계획

작성일: 2026-09-14

## 요청 범위
- 점 격자 확대, DDL 내보내기 UI 제거, 프로젝트 상단 높이 및 갤러리·검토 대화·저장·알림 버튼 축소.
- 레퍼런스처럼 테이블 제목과 컬럼 목록 자체를 하나의 카드로 구성한다.
- 물리 모델만 편집하도록 논리/물리 선택과 적용 범위, 스키마, 테이블 주석, 메타데이터, 설계 확인 UI를 제거한다.
- 컬럼 편집은 물리 컬럼명, 선택형 타입, ENUM, 관련 타입에서만 활성화되는 길이/정밀도/소수 자릿수, NULL 여부, comment를 제공한다. 논리 항목·기본값 SQL 입력·PostgreSQL 문구는 제거한다.
- 빈 키·선택 컬럼 없는 관계의 반복 생성을 막는다. 확인한 컬럼을 기반으로 생성한다.
- 도메인 맵으로 돌아가는 버튼을 강조한다.

## 구현 및 검증
기존 논리 정보·스키마·기본값·메타데이터는 저장 문서에서 삭제하지 않고 UI에서만 제외한다. DDL 엔진은 유지하되 내보내기 사용자 경로를 제거한다. 새 객체는 물리 모델로 생성한다.

UI는 Astra가 담당한다. 생성 가드와 타입 매개변수는 회귀 테스트, 카드 구조·상단 높이·입력 제거·키/FK 흐름은 실제 브라우저로 검증한다. 작업 결과를 별도 work-log에 기록하고 논리 단위별로 커밋한다. 기존 docs 분류 변경은 포함하지 않는다.
