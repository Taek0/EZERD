# 사용자 PIN 복합 유일성과 색상

작성일: 2026-09-15

사용자 요청에 따라 이름 단독 UNIQUE를 이름 + 숫자 네 자리 PIN의 복합 UNIQUE로 전환한다. PIN은 앞자리 0을 보존하는 문자열이며 등록시 필수다. 동일 이름은 다른 PIN으로 등록할 수 있으며 같은 조합은 409로 거절한다. 이름 변경은 기존 PIN을 유지한다. PIN 원문은 응답·로그에 노출하지 않고 서버에서 결정적 해시로 바꿔 저장한다. 기존 사용자 ID에 기반한 사용 흐름을 유지하며 인증 체계를 새로 도입하지 않는다.

사용자 색상은 DB에 저장하고 상단 아바타 및 핀/메시지 표시에 반영한다. 핀 패널 너비는 범위를 제한한 슬라이더와 브라우저 선호값으로 저장한다.

현재 사용자 전체 초기화가 승인됐다. 기존과 같이 관련 핀·메시지·알림을 포함해 백업 후 초기화하며 프로젝트와 설계는 유지한다. API 중지와 테이블 잠금 후 단일 트랜잭션에서 백업, 사용자/리뷰 데이터 삭제, 새 마이그레이션 적용 및 프로젝트 전체 행 불변을 검증한다. 테스트는 이름+PIN 충돌/다른 조합 허용/앞자리 0/색상 변경/응답 비노출을 포함한다.

DB 기동 확인 중 Docker 4.83.0의 dockerInference 잔존 소켓 오류가 재발했다. 프로세스 종료와 대상 경로를 확인한 후 Docker/run 및 docker-secrets-engine 런타임 폴더만 백업 이름으로 변경하여 복구한다. 기존 .data/postgres 및 컨테이너 데이터는 그대로 사용한다.

현재 개발 서버는 자동 재시작 감시기로 실행 중이다. API 감시기 중지 대신 관련 테이블과 프로젝트·마이그레이션 저널을 ACCESS EXCLUSIVE로 잠근 단일 SERIALIZABLE 트랜잭션을 사용해 신규 쓰기와 경합을 막는다. 초기화는 미적용 0004가 정확히 하나 있을 때만 허용해 재실행을 방지한다.
