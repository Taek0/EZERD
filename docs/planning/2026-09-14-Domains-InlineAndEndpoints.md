# 도메인 설명 직접 편집과 관계 끝점 분산

작성일: 2026-09-14

업무 설명의 Enter 줄바꿈을 저장·표시하고 도메인 카드에서 설명을 더블클릭하여 편집한다. Enter는 줄바꿈, Ctrl/Cmd+Enter 또는 포커스 이동은 적용, Escape는 취소다. 카드의 명시적 열기 버튼을 유지하고 설명 편집 더블클릭이 도메인 이동으로 전달되지 않도록 한다.

관계 곡선만 벌리는 기존 방식 대신 카드의 각 면에 연결된 모든 관계 끝점을 모아 고유한 위치로 분산한다. 같은 두 도메인의 여러 관계, 반대 방향·양방향·여러 목적지·자기 관계를 처리하고 카드 이동/크기 변경에도 경계를 따르도록 한다.

기존 도메인 정보·관계 ID를 보존한다. 모델/기하 회귀와 실제 브라우저에서 편집·줄바꿈·취소·undo·끝점 구분을 검증하고 작업 결과를 work-log에 기록한다.
