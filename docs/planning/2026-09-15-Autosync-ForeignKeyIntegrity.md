# 자동 동기화 외래 키 무결성 회귀 수정 계획

작성일: 2026-09-15

## 문제

구조적으로 같은 primitive 배열을 변경 목록에서 제외한 뒤, 오래된 online 기준에서 생성한 FK bundle이 그 사이 삭제된 참조 키를 감지하지 못하고 수락된다. 이 수락으로 잘못된 FK가 통합 테스트의 공유 프로젝트에 남아, 다음 복원 테스트도 복원 관계 외의 동일 이름 관계를 발견해 실패한다.

## 변경 범위

- online 작업은 직접 쓰기 경로의 최신 값 우선 정책을 유지하되, 서버가 후보 문서에서 계산한 구조 의존성 경로에는 기준 시퀀스 이후 변경이 없는지 검사한다.
- reconnect 작업은 기존처럼 직접 쓰기 경로와 구조 의존성 경로를 모두 검사한다.
- 동등한 배열을 실제 변경으로 되돌리지 않으며 기존 통합 테스트 assertion도 유지한다.

## 검증

- 모델 단위 테스트에 online 직접 쓰기와 구조 의존성의 서로 다른 충돌 정책을 명시한다.
- 모델 테스트와 타입 검사를 실행한다.
- 격리 PostgreSQL 스크립트로 autosync 통합 테스트 전체를 실행해 FK bundle 거부와 후속 restore 제외를 함께 확인한다.
- 실제 개발 데이터베이스는 사용하거나 삭제하지 않는다.
