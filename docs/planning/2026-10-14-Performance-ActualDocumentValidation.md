# 실제 문서 ACK 및 편집 지연 검증 계획

- localhost:3001 실제 문서의 화면/번들/서버 상태를 확인한다.
- 로컬 DB에서 현재 klassboard-backend 원본을 읽어 최신 snapshot을 로컬 artifacts에 저장한다. 원본 프로젝트에는 편집 명령을 보내지 않는다.
- 실제 실행 서버에 임시 계정/워크스페이스/복제 프로젝트를 만들어 경량 ACK와 전체 문서 일치, 연속 편집을 검증하고 생성 데이터만 정리한다.
- 동일 원본 snapshot을 격리 브라우저 fixture로 표시해 지연 ACK 편집과 우측 패널 resize를 계측한다. 실제 탭에서는 패널 너비 조절을 확인하고 원래 너비로 되돌린다.
- rAF 타임아웃은 실패로 기록하며 프레임 성능 수치를 추정하지 않는다. 결과와 제한을 work-log에 기록하고 독립 커밋한다.
