# 캔버스·핀·프로젝트 피드백 구현 계획

작성일: 2026-09-14

## 확정 변경
- 테이블·도메인 카드 글꼴 확대, 테이블 내용에 맞는 최소 크기로 내부 스크롤 방지, 컬럼 추가와 크기 조절 손잡이 분리.
- PK에서 관계 연결을 시작하고 FK 대상에 대응 컬럼을 자동 생성한다. 복합 PK 순서를 보존하며 이름 충돌은 안전하게 구분한다. 기존 관계·컬럼은 일괄 변환하지 않는다.
- 직각 관계선, 경로 조절, 연결 중 점선 미리보기, 이름은 출발테이블.속성:도착테이블만 표시.
- 선택한 여러 도메인의 테이블을 함께 보고 해당 집합 안의 관계만 표시한다. 원본 객체·소유권은 유지한다.
- 현재 캔버스를 고해상도 이미지로 내려받는다. 화면 배경·카드·관계·글꼴을 포함한다.
- 대화 기능을 핀으로 표시하고 빈 공간 핀을 기본으로 한다. 우클릭 위치에서 핀 작성, 프로젝트 전체 핀과 답글 스레드를 제공한다.
- 보관함 삭제 API/버튼, 오른쪽 보관·삭제 액션, 공통 확인 대화상자, 대시보드 윤곽 강화.
- 공통 토글의 열기/닫기 애니메이션과 빠른 클릭 시 텍스트 선택 방지. 검색 가능한 대문자 타입 선택 및 공개 UI 기반 색상 선택.

## 데이터·검증 원칙
기존 숨김 데이터·소유권·다른 뷰 배치를 보존한다. FK 자동 컬럼 생성은 이번 사용자 요청으로 기존 수동 매핑 원칙을 변경한다. 프로젝트 삭제는 보관된 프로젝트에만 제공하고 예상 버전 검사와 사용자 정의 확인 대화상자를 거친다. 실제 테스트 데이터만 삭제한다.

기능별 계획 아래 작은 단위로 구현하고 모델/API 회귀, 실제 브라우저 키보드·마우스·저장 검증과 내보낸 이미지 확인을 수행한다. UI는 Astra, 가장 중요한 삭제 API와 최종 통합은 주 에이전트가 담당한다. 기존 docs 분류 변경은 이번 커밋에 섞지 않는다.
