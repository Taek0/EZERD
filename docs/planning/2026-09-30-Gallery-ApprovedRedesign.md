# 승인된 갤러리 목업 구현

- 최종 gallery-redesign-preview.html의 전체 갤러리 디자인을 실제 서비스에 적용한다. 현행 로고·프로필·기본 UI 에셋과 편집기는 유지한다.
- 공간 선택기, 이름과 파란 점 제목, 검색/정렬/+ 도구 줄, 미리보기 카드, 카드 내 이름/DB 편집 및 생성 흐름을 연결한다. 탭·새 카드·커서 애니메이션과 접근성을 유지한다.
- 새 카드의 빈 이름은 다른 작업으로 이동할 때 서버에서 새 프로젝트로 자동 저장한다. 같은 워크스페이스의 활성/보관 프로젝트를 포함해 중복되면 새 프로젝트 1, 2 순서로 번호를 부여한다. 동시 생성은 트랜잭션으로 직렬화한다. 명시적 수동 이름 전체에 새 고유성 규칙을 추가하지 않는다.
- DB 종류는 postgresql/mysql/sqlite 프로젝트 메타데이터로 저장하고 기본값은 postgresql이다. 이번 갤러리 변경은 다른 엔진의 타입·DDL 생성기를 구현하는 작업이 아니다. 가져오기/내보내기와 기존 파일 호환성을 유지한다.
- 생성·수정 대기 중 공간 전환/검색/정렬/탭 변경에서 변경 유실과 중복 요청을 방지한다. 저장 실패 시 오류와 편집 상태를 보존한다.
- 서버/계약과 UI를 병렬 구현하며 루트가 통합·실제 데이터 미리보기·검증을 맡는다. 운영 데이터 삭제나 초기화는 하지 않는다.
