# 고스트 카드 드래그 검증 계획

현재 performance-lab에서 제품 동작 변경 없이 비교한다. 현행은 pointermove마다 preserve가 draft를 만들고 장면을 재계산하는 경로다. 고스트 후보는 이동 중 별도 미리보기 transform만 RAF로 갱신하고 drop 시 최종 배치를 한 번 계산한다.

- 기존 보관된 43테이블 복제 문서와 Klassboard version 407 원본을 사용해 단일/다중 이동의 장면 계산 시간을 측정한다. 캔버스 UI·실제 서버에는 쓰지 않는다.
- lab 전용 최소 고스트 프로토타입으로 pointer offset/zoom/최종 release/취소/그룹 상대 좌표와 장면 갱신 횟수를 검증한다. 제품에 바로 연결하지 않는다.
- 드래그 중 계산 절감과 drop의 남는 동기 계산 비용을 구분한다. 실제 브라우저 FPS를 측정하지 않으면 해당 개선율은 주장하지 않는다.
- 결과를 바탕으로 제품 적용 범위와 필요한 drop 비동기 처리 여부를 권고한다. 원격 push·서버 재시작은 하지 않는다.
