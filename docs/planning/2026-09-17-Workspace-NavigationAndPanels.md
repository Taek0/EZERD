# 이동·편집·협업 도구 및 패널 개선

사용자 선택 A안: 상단을 이동/편집/협업 그룹으로 분리한다. 도메인 뷰는 테이블 캔버스에만 표시하고 갤러리 이동은 자체 확인창을 거친다. 브레드크럼 글꼴과 공통 버튼 스타일을 통일하며 사이드바 긴 콘텐츠의 스크롤 제약을 해결한다. 핀치 감도는 소폭 올린다.

알림/MCP 패널의 크기와 애니메이션을 공통 디자인에 맞춘다. MCP 밖 클릭·Escape로 닫으며, 본인 소유의 폐기된 토큰만 별도 삭제 API로 제거할 수 있게 한다. 활성/다른 사용자 토큰은 삭제하지 않는다. 429 오류가 발생하면 사용자가 요청한 현재 워크스페이스 포크로 작업을 인계한다.
