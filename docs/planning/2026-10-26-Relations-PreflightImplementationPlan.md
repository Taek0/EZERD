# 관계 자동 정리 사전 검증·무변경 저장 개선 계획

검토 결과에 따라 1) 기존 서버의 current 기준 재생성/retired identity 보호 검증, 2) 공통 클라이언트 preflight 및 시작/결과/저장 직전 차단, 3) 경로 필드 의미 비교와 변경분만 저장을 순서대로 진행한다. 각 단계를 검사 후 커밋한다.

표시용 생성 배치를 저장 배치로 보완하는 기존 처리는 유지한다. 클라이언트 사전 확인이 서버 권한·현재 문서·충돌 검증을 대체하지 않는다. 좌표 반올림 없이 연결면/비율/꺾임점 순서를 비교하며 충돌 감지와 무변경 판정의 목적을 구분한다. 실제 문서·main 서버·저장 프로토콜은 변경하지 않는다.
