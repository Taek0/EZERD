# MCP Native v2 전환과 v1 전용 경로 정리

- MCP부터 도구 등록·조회·변경 경로의 v1 의존성을 조사한다.
- 현재 필요한 프로젝트 요약·테이블·화면·관계 조회를 native v2로 제공한다. v1 모델로 축소 변환하지 않는다.
- v2 대체 기능이 있는 기존 편집기 전용 MCP 도구와 사용되지 않는 MCP 코드는 제거한다. REST·웹·저장 문서 마이그레이션에서 사용하는 공통 코드는 이 범위에서 무작정 삭제하지 않는다.
- 접근 권한·개인 상태 분리·페이지 조회·동시성·재전송 안전을 유지한다.
- 기존 미추적 artifacts/layout-refinement-2026-10-07/는 변경하지 않는다.
- 조회·등록 회귀 테스트와 가능한 격리 DB 통합 검증 후 문서 및 커밋으로 기록한다.
