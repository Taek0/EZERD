# Native 전용 편집 진입과 미사용 UI 제거

- 사용자 방침에 따라 웹 앱에서 v1 프로젝트를 열거나 편집하지 않도록 한다.
- 단위 1: 공통 projectEntry 경계에서 source schemaVersion 1을 거부하고 Native 미리보기가 있어도 편집기로 진입하지 않게 한다. 갤러리·알림의 공통 로더와 Native 정상 경로를 검증한다.
- 단위 2: App의 v1 화면·autosave·동기화 연결을 제거하고 새로 미사용이 되는 UI를 조사해 외부 참조가 없는 코드를 정리한다. 세션 등 공통 요소는 유지한다.
- 서버 API/MCP, 파일 import/export, v1→Native 변환 및 Native legacy 원문 보존은 별도 소비자가 있으므로 이번 웹 진입 제거만으로 삭제하지 않는다. DB 데이터는 변경하지 않는다.
- 각 단위는 타입 검사·관련 테스트 후 커밋한다. 최종 포맷 검사·빌드를 수행한다. scripts/테스트가 여전히 쓰는 구현은 미사용으로 간주하지 않는다.
