# 승인 목업의 시각 디자인 제품 적용 계획

- 기준: 단색 버튼 목업 FlatButtonMockup, 현재 제품 c1c992a. 작업 브랜치 codex/apple-ui-review.
- 목표: 기능만 재배치한 상태를 넘어 실제 화면의 색상·타이포그래피·여백·배치·메뉴·입력 상태·애니메이션을 승인 목업에 맞춘다.
- 전역 헤더/문서 헤더/툴바, 좌측 탐색, 우측 속성·핀, 갤러리, 모달·popover·context menu·검색형 입력·inline editor를 대응표로 점검한다.
- 기존 저장·권한·단축키·필드·메뉴 항목은 유지한다. 논리 설계/검증 메뉴 위치 유지, 모바일 신규 설계 제외.
- 캔버스의 글자·행 높이 변경은 공유 geometry와 관계 포트·PNG 출력까지 함께 맞춘다. 사용자가 지정한 색상·좌표·크기는 보존한다.
- 모션은 입력을 막지 않는 짧은 전환으로 정리하고 reduced-motion을 검증한다. 기존 애니메이션 재입력 문제는 별도 독립 단위로 보완한다.
- 실제 제품 컴포넌트에 목업과 유사한 풍부한 테스트 데이터를 제공해 화면·우클릭·키보드·입력·상태를 확인한다. 목업 이미지를 구현 결과로 제시하지 않는다.
- 단위별 기록과 커밋 후 format/typecheck/test/build를 완료한다.
