# 편집기 통합 도구 헤더

- 프로젝트 제목, 캔버스 도구, 저장 상태를 하나의 반응형 헤더에 배치한다.
- Canvas 상태를 유지하며 React portal로 도구를 헤더에 표시한다. 호스트가 없는 기존 단독 Canvas는 원래 위치에 도구를 표시한다.
- 넓은 화면은 한 행을 우선하고 좁은 화면에서는 그룹 단위로 줄바꿈한다. 버튼은 최소 30px 높이, 13px 글자와 600 이상 굵기로 유지하며 파란 뉴모피즘과 명확한 경계·포커스를 적용한다.
- 포털 도구의 Delete 입력이 선택된 캔버스 객체 삭제로 전파되지 않도록 방어한다.
- 포맷 및 타입 검사를 수행하고 브라우저 확인은 상위 작업에서 수행한다.
