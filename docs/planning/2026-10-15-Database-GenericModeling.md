# RDBMS 미지정 모델링 모드

## 목적

특정 DB가 정해지지 않은 프로그램도 테이블·컬럼·관계를 시각화한다. 프로젝트 DB 선택에 `선택안함`을 추가하고 기존 DB 프로젝트의 규칙은 유지한다.

## 결정

- 내부 식별자는 `generic`, 프로필은 `generic-v1`로 분리한다. PostgreSQL 등으로 위장하지 않는다.
- 일반적인 SQL 타입을 제공하고 `(직접 입력)` 선택 시 사용자 지정 타입명을 입력·저장·표시한다. 직접 입력 문자열은 실행할 SQL로 취급하지 않는다.
- 미지정 모드에서는 실행 가능한 DDL 내보내기를 차단하고 선택 시 기존 팝업으로 제한을 설명하고 DDL 내보내기 버튼은 비활성화한다. 프로젝트 파일 가져오기·내보내기는 유지한다.
- 테이블·컬럼·키·관계·배치 편집과 동기화, API·MCP 저장 경계를 함께 지원한다.
- 기존 DB로의 자동 타입 변환은 제공하지 않는다. 기존 프로젝트의 DB 변경 보호 정책을 유지한다.

## 검증

- 모델/계약: 생성, 공통 타입, 사용자 지정 타입, 잘못된 타입과 DB 조합, DDL 차단, 파일 왕복.
- 서버: 프로젝트 프로필 저장 제약과 마이그레이션, API/MCP 경계.
- UI: 프로젝트 선택과 안내, 타입 선택/직접 입력 및 표시, 비활성화된 내보내기 안내.
- 전체 포맷·타입·테스트·빌드 검사 후 작업 기록과 커밋을 남긴다.
