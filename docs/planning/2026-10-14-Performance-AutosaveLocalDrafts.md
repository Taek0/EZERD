# 자동저장 대기와 로컬 이름 표시 분리 계획

- 테이블/컬럼 이름의 현재 탭 초안을 저장 큐보다 위에 투영한다. 기존 초안 보관/복구와 750ms 서버 전송 quiet window는 유지한다.
- 전송 중 후속 입력은 로컬 초안 최신값으로 표시한다. 같은 폼의 기존 autosave 조율이 다음 전송을 최신값 하나로 묶으며 이미 전송한 요청은 변경하지 않는다.
- 초안 이름 필드별 변경 순서를 보존하여 여러 입력 경로가 같은 이름을 편집할 때 최신 로컬 필드를 선택한다. 서버 ACK나 before 재기준화는 이 순서를 올리지 않는다.
- 속성 폼 ACK rebase는 투영된 props가 아니라 확인된 snapshot 문서를 기준으로 한다. pristine 폼의 표시 동기화와 dirty 초안 보존은 구분한다.
- 현재 탭에 로드된 초안만 자동 투영하고 다른 writer의 보관 초안을 무단 복구하지 않는다. 미지원 타입/관계/삭제의 낙관적 처리는 후속 범위로 둔다.
- 실제 입력/IME/취소/지연 ACK/750ms 전송/최신값 묶음 회귀 및 브라우저 검증 후 제품 커밋만 로컬 main에 반영한다. push는 별도 요청 전까지 하지 않는다.
