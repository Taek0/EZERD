# 고화질 PNG 테이블 타입 보존 계획

- PNG 내보내기는 복제 DOM에서 버튼을 일괄 제거하므로, 편집 가능한 테이블의 타입 버튼에 포함된 데이터도 함께 사라진다.
- 기존 타입 셀에 저장된 모델의 전체 타입 표시 문자열을 내보내기용 속성으로 지정한다.
- 계산된 스타일을 복사한 뒤 해당 셀의 자식을 정적 텍스트로 바꾸고 조작 버튼을 제거한다. 편집 중인 검색어나 선택 목록 대신 확정된 길이·정밀도·ENUM·배열 표시를 사용한다.
- SSR 검증으로 타입 셀의 모델 표시 문자열을 확인하고, DOM 대역 검증으로 복제본의 정적 변환 및 버튼 제거를 확인한다. 포맷과 타입 검사를 수행하고 결과를 작업 기록에 남긴다.
