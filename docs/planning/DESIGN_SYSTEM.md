# EZERD 디자인 방향

Neumorphism + Swiss Design. 부드러운 깊이감과 명확한 타이포그래피·격자·정보 위계를 결합한다.

## 시각 규칙

- 바탕과 카드: 밝은 중성 회색 `#e9ecef`.
- 본문: 차콜 `#202327`, 보조 문구 `#59616b`.
- 강조: 파랑 `#305be7`. 주요 행동·선택·포커스에 제한적으로 사용한다.
- 상태: 연결 성공과 확인 필요는 색상에 더해 기호와 텍스트로 구분한다.
- 레이아웃: 일정한 좌측 정렬, 숫자 섹션 표기, 얇은 구분선, 충분한 여백.
- 글꼴: 사용자가 제공한 Apple SD Gothic Neo를 프로젝트에서 직접 제공한다. 제목·본문·버튼·숫자 표기를 같은 폰트 계열로 통일하고 실제 굵기 파일로 위계를 만든다.
- 표면: 주요 카드와 조작 버튼에 얕은 양방향 그림자. 눌린 버튼·아이콘 영역에는 안쪽 그림자.
- 테이블 본문과 관계선처럼 정보 밀도가 높은 영역은 선명하고 평평하게 유지한다.

## 캔버스 점 격자

- 사용자 제공 이미지처럼 밝은 배경 위에 작고 균일한 점을 배치한다. 도메인 맵과 내부 테이블 ERD에 공통 적용한다.
- 기본값: 배경 `#fafbfc`, 점 색상 `#818894`, 100% 확대율에서 점 간격 `40px`, 점 지름 `1.5px`.
- 위 수치는 구현 시작값이며 실제 테이블·관계선과 함께 확인하며 조정한다.
- 격자는 캔버스 좌표에 연결해 화면 이동과 확대·축소를 따라간다. 화면 픽셀에 고정하여 노드와 따로 움직이지 않도록 한다.
- 점은 관계선·텍스트·댓글 핀보다 시각적으로 약하게 표시한다. 매우 축소했을 때는 점 밀도를 조절하거나 숨겨 무늬가 뭉치지 않게 한다.
- 점 격자는 캔버스 전용이다. 갤러리와 속성·댓글 패널은 기존 뉴모피즘 표면을 유지한다.
- 배경은 반복 가능한 CSS 또는 SVG 패턴으로 구현하며 참고 이미지 자체를 늘려 사용하지 않는다.
- 점 격자 표시가 배치 스냅을 강제하지 않는다. 도메인·테이블·자유 텍스트는 자유롭게 배치한다.
- 토큰은 `apps/web/src/tokens.css`의 `--erd-*`에 준비했다. 도메인 맵과 내부 텍스트 캔버스에 적용했다. 테이블 ERD에도 적용했다.

## 조작 규칙

- 그림자만으로 조작 가능 여부를 전달하지 않는다. 버튼에는 텍스트, 외곽선, 키보드 포커스를 제공한다.
- 일반 버튼의 최소 높이는 44px로 한다.
- 선택 상태는 인셋 효과에 강조색·테두리를 함께 사용하는 방향으로 구성한다.
- 단순 조작 전환은 짧게 유지하고 움직임 줄이기 설정을 따른다.
- 모바일에서는 다열 카드를 단일 열로 바꾼다.

## 구현 위치

- 색상·그림자·곡률·글꼴: `apps/web/src/tokens.css`
- 화면 레이아웃과 상태: `apps/web/src/styles.css`
- 현재 적용 화면: 입장, 프로젝트 갤러리, 도메인 맵, 테이블 ERD와 댓글 패널.

## 폰트와 굵기

| 용도 | 굵기 | 파일 계열 | 토큰 |
| --- | --- | --- | --- |
| 본문·설명 | 400 | Regular | `--font-weight-body` |
| 보조 강조·섹션 번호·숫자 | 500 | Medium | `--font-weight-medium` |
| 버튼·섹션 제목·카드 제목·상태 | 600 | SemiBold | `--font-weight-label` |
| 페이지의 큰 제목 | 700 | Bold | `--font-weight-title` |
| EZERD 워드마크 | 800 | ExtraBold | `--font-weight-brand` |

- 기본 계열: `'Apple SD Gothic Neo', 'Malgun Gothic', sans-serif`.
- 고정폭 토큰은 향후 SQL·코드 영역용으로 유지하고 현재 UI에는 사용하지 않는다.
- 제공된 CSS의 굵기 대응을 따르며 650과 같은 중간 굵기를 실제 파일의 600으로 정리했다.
- `font-synthesis: none`으로 임의 굵기 합성을 억제하고 `font-display: swap`으로 폰트를 기다리는 동안에도 텍스트를 표시한다.
- 5개 굵기의 문자별 서브셋 600개를 보관한다. `unicode-range`로 화면에 필요한 문자에 해당하는 파일만 요청한다.
- 파일 위치: `apps/web/public/fonts/apple-sd-gothic-neo/`. 스타일시트는 `fonts.css`, 파일별 크기·SHA-256은 `manifest.json`에 있다.
- 원본: 사용자 지정 `D:/AppleSDGothicNeo`. 해당 폴더는 읽기만 했으며, 앱 실행 시에는 프로젝트 내부 복사본을 사용한다.
- 원본 서브셋의 확장자는 `.woff2`였지만 내부 형식이 WOFF였으므로 복사본의 확장자와 CSS `format()`을 WOFF에 맞췄다. 글리프 데이터는 변환하지 않았다.
- 다시 가져오기: 저장소 루트에서 `node scripts/import-fonts.mjs D:/AppleSDGothicNeo`를 실행한다. 외부 CDN이나 OS 폰트 설치가 필요하지 않다.

이 문서는 첫 스타일 기준이며, 프로젝트 갤러리·도메인 맵·테이블 ERD·댓글 패널을 구현할 때 같은 토큰과 규칙을 확장한다.

## 적용 확인

- 2026-09-14: 웹 타입 검사·빌드 통과.
- 데스크톱 및 390px 모바일 viewport에서 레이아웃을 확인하고 모바일 가로 넘침이 없음을 확인했다.
- 다시 확인 버튼으로 API·DB 상태가 갱신되는 것을 확인했다.
- 새 디자인 라이브러리는 설치하지 않았으며 개발 환경 버전과 lockfile을 유지했다.
- Apple SD Gothic Neo 적용 후 다섯 굵기의 CSS 설정, 각 굵기의 폰트 HTTP 응답, 데스크톱·모바일 화면을 확인했다. 브라우저 오류·경고 로그가 없고 모바일 가로 넘침이 없었다.


## 2026-09-14 사용자 피드백 반영

본문·폼·보조 문구의 작은 크기를 약 1–2px 높였다. 도메인 제목은 24px이며 폼·캔버스 내용은 주로 14–15px다. 갤러리 카드는 그림자와 밝은 테두리를 강화하고 hover/focus에서 7px 올라가는 전환을 제공한다. 움직임 줄이기 설정에서는 이동 애니메이션을 사용하지 않는다. 도메인 색상은 상단 테두리와 약한 배경 색에 적용한다. 도메인 최소 크기 240×210에서 제목·설명·열기 버튼을 분리해 겹침을 막는다. 모바일 헤더의 알림은 줄바꿈하지 않고 긴 사용자명은 말줄임표로 표시한다.


## 갤러리·사이드바 두 번째 피드백

- 갤러리 최대 폭 1360→1240px, 카드 패딩 24→20px와 카드 제목 24→22px로 조정했다. 본문·메타데이터의 14–15px 가독성과 기존 입체감·호버를 유지한다.
- 속성 패널의 긴 텍스트 버튼을 34px 아이콘 버튼으로 바꿨다. 얇은 외곽선과 우측 분할을 사용하며 상태·hover·focus에 짧은 전환을 제공한다.
- 패널 경계는 드래그와 키보드로 조절한다. 기본 320px, 최소 280px, 최대 520px이며 남은 캔버스 공간에 맞춰 제한한다. 좁은 작업 영역에서는 아래로 배치한다.
- 관계 섹션은 위의 ‘도메인 관계’ 제목 자체를 disclosure로 사용한다. 별도 큰 펼치기 버튼을 제거하고 화살표 회전·높이 전환을 넣었다.
- 출발·도착 필드를 묶고 폼 간격과 설명 영역을 줄였다. 숨긴 콘텐츠는 키보드와 접근성 트리에서도 제외하며 움직임 줄이기 설정을 따른다.

## 홈 화면 세부 조정

로고·상단 소개 영역의 글꼴과 높이는 유지하고, 홈 갤러리 최대 폭을 1360px로 확장했다. 카드는 최대 280px 폭으로 제한하고 여백을 줄였다. 한 줄 제목 기준 1920×1080 검증에서 약 335×233px였던 카드가 280×188px로 줄었다.

푸터는 짧은 목록에서 화면 하단에 배치하고 긴 목록에서는 카드 뒤로 자연스럽게 이어진다. 글자 크기는 12→13px다. 검색 입력은 210×40px, 새 이름 입력은 280×40px이며 이름 입력 글자는 17→16px로 조정했다. 생성 버튼은 아이콘과 문구를 중앙 정렬했다. 홈의 알림·사용자 버튼은 높이 40px와 글자 15px로 줄였다. 카드 상태 문구는 기존 Apple SD Gothic Neo를 유지하면서 14px·보통 자간·20px 줄 높이로 명시했다.

추가로 제공된 축소 참고 이미지에 맞춰 프로젝트 카드 최대 폭을 180px, 한 줄 제목 기준 높이를 약 126px로 줄였다. 카드 간격은 16px이며 제목은 한 줄 말줄임표와 전체 이름 툴팁으로 표시한다. 이미지 배율을 적용하지 않고 실제 CSS 치수와 글자 크기를 조절했다. 상단·입력창·푸터 크기는 유지했다.
