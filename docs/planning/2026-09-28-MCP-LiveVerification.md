# MCP 재시작 후 실제 연결 검증 계획

## 범위

재시작된 MCP 서버에 실제 도구 호출로 접속해 등록 도구 28개와 기본 조회를 확인한다. 기존 프로젝트는 변경하지 않고 새 검증 프로젝트에만 공유 문서·개인 화면·리뷰 데이터를 만든다.

## 검증 순서

1. 도구 등록 수와 `list_projects` 응답으로 연결·인증 상태를 확인한다.
2. 고유 이름의 검증 프로젝트를 만들고 요약·화면·테이블·관계·이력 조회를 확인한다.
3. 공유 문서에서 도메인·ENUM·테이블·컬럼·키·관계·메모의 생성, 부분 수정, 배치·관계 경로, 진단, 실행 취소·삭제 복원을 확인한다.
4. 사용자별 결합 화면에서 뷰포트·테이블 참조·메모·관계 경로의 생성·부분 수정·삭제와 재조회를 확인한다.
5. 리뷰 핀 생성·답글·해결·조회·삭제, 프로젝트 전송, 페이지 커서와 알림 목록을 확인한다. 자기 소유 알림이 없으면 알림 읽음 변경은 존재하지 않는 ID에 대한 거부 경계만 확인하고, 긍정 경로는 이미 통과한 격리 통합 테스트 결과와 구분해 기록한다.
6. 가져오기 검증으로 생긴 임시 프로젝트는 보관 후 삭제한다. 메인 검증 프로젝트는 사용자 확인용으로 남긴다.

## 기록

각 도구의 성공·실패 및 서버 응답을 `docs/work-log/`의 같은 날짜 문서에 기록한다. 민감한 토큰·인증 헤더는 기록하지 않는다.
