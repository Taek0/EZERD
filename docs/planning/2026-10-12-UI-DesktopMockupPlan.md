# 데스크톱 디자인 수정안 HTML 목업 계획

- 기존 apple-design 검토 결과를 바탕으로 독립 실행 HTML 목업을 만든다.
- 제품 갤러리와 편집기의 주요 배치, 논리 설계·검증 항목의 더 보기 메뉴 위치를 유지한다. 모바일은 범위 밖이다.
- 시각 변경: 버튼 강조, 패널 표면·정렬, 글자 대비, 격자 강도와 카드 여백.
- 목업에서 갤러리/편집기 전환, 테이블 선택, 패널 토글, 메뉴와 시각 비교를 직접 확인할 수 있게 한다.
- 원본 제품 컴포넌트는 변경하지 않는다. 결과물은 docs/planning/2026-10-12-UI-DesktopMockup.html에 저장한다.
- 코드 문법과 실제 렌더링을 가능한 도구로 검증하고 결과를 work-log에 기록한 뒤 커밋한다.
