# 고급 편집기 평가 및 ACK 표시 갱신 축소 계획

- 고급 편집기는 최초 펼침/복구 전에는 폼을 생성하지 않는다. 한 번 열린 폼은 접어도 유지해 초안·자동저장·복구를 보존하고, 접힌 미편집 초기값에 대한 후보 평가만 생략한다.
- 동일 렌더 안의 고급 후보 평가 결과를 재사용한다. dirty 값은 접혀도 기존 검증/저장 경로를 유지한다.
- ACK는 최신 문서·snapshot·권한을 모든 편집 상태에 계속 전달한다. 대신 편집하지 않는 셀의 타입 옵션 생성과 변경 없는 표시 subtree 갱신을 줄인다. 이벤트는 최신 committed handler를 사용하고 편집 중 셀은 캐시하지 않는다.
- 단계별 회귀, 전체 검사, 서버 쓰기 없는 ACK 재생을 수행한다. 제품 변경만 로컬 main에 선별 반영하고 원격 push는 별도 요청 전까지 하지 않는다.
