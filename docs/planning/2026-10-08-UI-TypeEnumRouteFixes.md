# 타입 검색·ENUM 팝업·관계선 드래그 개선

- 컬럼 속성의 타입 검색 아이콘과 입력창 크기 불균형을 CSS 및 공통 컴포넌트 기준으로 수정한다.
- ENUM 생성 팝업의 색상·배치·상태를 기존 파란색 디자인과 일관되게 정리한다.
- 관계선 경로 드래그의 이벤트·입력 상태·저장 경로를 조사하고 실제 핸들러 회귀 테스트로 재현·수정한다.
- 관련 검증 후 논리 단위로 커밋한다. 운영 데이터나 DB 스키마는 변경하지 않는다.
- 추가 요청: 컬럼 삭제 사이드바의 영향 확인 단계·체크박스를 제거한다. 서버 참조·제약 검증은 유지하며 다른 객체의 삭제 정책을 임의로 확대하지 않는다.
