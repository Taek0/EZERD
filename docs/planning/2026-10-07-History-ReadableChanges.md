# 히스토리 가독성과 충돌 안내 검토

- 변경 이력의 내부 경로를 사용자에게 의미 있는 객체명·동작·필드 변화로 표시한다. 변경자·일시·상태와 실행 취소/복원 및 필터 기능은 유지한다.
- 긴 값·변경 목록은 요약과 더보기 토글로 제공하고 원문 데이터는 변경하지 않는다. 삭제된 객체는 이전 값으로 이름을 복구한다.
- 확인 필요 상태가 프로젝트 전체를 막는 원인을 읽기 전용으로 검토하고, 데이터 보존을 전제로 개선 방향을 제안한다. 사용자가 요청하지 않은 자동 충돌 해결이나 대기 요청 폐기는 수행하지 않는다.
- 빈 공간 클릭 흰 화면 수정은 별도 계획에 따라 동시에 진행한다.
