# 워크스페이스 정렬 마이그레이션 누락 복구

- 0018 journal.when이 0017보다 작아, 0017까지 이미 적용한 DB에서 Drizzle이 0018을 건너뛰는 문제를 확인했다. 빈 DB 전체 적용에서는 드러나지 않았던 업그레이드 경로 오류다.
- 공개된 기존 SQL/이력은 바꾸지 않고 0019 복구 마이그레이션을 추가한다. sort_order가 있거나 없는 DB 모두에서 안전하게 컬럼·CHECK를 보장한다.
- 운영 DB는 먼저 컬럼 및 migration ledger를 읽고 누락을 확인한 뒤 정상 migrator로 복구한다. 테이블·사용자 데이터 초기화는 하지 않는다.
- 0017까지 적용 후 업그레이드하는 경로와 전체 적용 경로를 임시 DB에서 검증하고, 이후 마이그레이션의 시간 역전을 방지하는 검사도 추가한다.
