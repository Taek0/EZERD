# Native 장면 중복 계산 제거 계획

2026-10-04. 원격 main 8390e9e 반영 후 NativeERDCanvas를 대상으로 한다.

- 사용자 목표: 기존 UI의 시각적 품질과 조작성을 유지하며 화면 이동을 부드럽게 한다.
- 이번 범위: 기본 문서 병합과 기본 장면을 입력 기준으로 memoize한다. 배치 초안이 없거나 현재 화면에 적용되지 않으면 기본 장면을 재사용한다. 실제 초안 좌표가 달라질 때만 미리보기 장면을 재계산한다.
- 기존 JSX, CSS, 입력·저장·개인 상태·PNG 동작은 유지한다. 콜백 비교를 생략하는 실험용 캐시를 제품 코드에 사용하지 않는다.
- 원본 장면/초안 장면의 기하 동등성, 비활성 초안, 문서 불변성을 회귀 검증한다. 기존 Native 캔버스·개인 배치·PNG 테스트와 타입·포맷·빌드를 확인한다.
- 측정 가능 시 현재 instrumented fixture에서 pan/zoom의 nativeCanvasScene 및 relationGeometry 호출 0회를 확인한다. 이전 main의 속도 수치와 직접 비교하지 않는다.
- 기록과 구현을 작업 단위별로 커밋한다. 원격 main이나 운영 프로젝트는 변경하지 않는다.
