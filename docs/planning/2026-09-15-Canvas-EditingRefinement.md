# 캔버스 편집과 관계선 개선 계획

작성일: 2026-09-15

관계선은 테이블 경계 밖에서 직각으로 연결하고 까마귀발 방향을 마지막 선분과 일치시킨다. 선 자체의 선택 영역과 경로 조절을 유지하며 불필요한 꺾임과 테이블 관통을 줄인다. 도메인 뷰는 체크박스와 적용으로 구성하고 각 도메인 원본 테이블의 상대 위치를 보존하여 도메인별로 간격을 두고 배치한다.

테이블 타입에 길이·정밀도·소수 자릿수를 표시한다. 카드 편집 Tab 이동, 컬럼 삭제와 NULL/comment 숨김 메뉴, 도메인 색상 헤더를 제공한다. 사이드바 컬럼은 드래그 정렬 및 선택 애니메이션을 제공하고 컬럼 추가 영역을 압축한다. ENUM은 생성 스타일을 정돈하고 검색 가능한 목록으로 개선한다.

사용자 메뉴에 색상 변경을 추가하고 사용자 표시 색상에 반영한다. 핀 사이드바에는 너비 조절 슬라이더를 추가한다. UI는 Astra가 담당한다. 독립 영역별로 회귀 테스트를 먼저 추가하고 구현·검증·작업 기록·커밋을 완료한다. 기존 미커밋 문서 재배치 작업은 포함하지 않는다.
