# 고급 생성 자동저장 연속 편집 계획

- 날짜: 2026-10-08
- 범위: `NativeAdvancedEditor.tsx`와 고급 편집 전용 테스트. ACK 후 보관 초안 복구를 위해 사전 알림 후 `native-draft-recovery-target.ts` 및 전용 테스트도 포함한다. 공통 폼 및 구조 편집은 다른 담당자의 영역으로 수정하지 않는다.
- 신규 인덱스·CHECK의 생성 ID를 복구 초안과 함께 유지하고 ACK 이후 현재 문서의 같은 ID를 대상으로 patch한다.
- version/sequence 변경만으로 폼을 재마운트하지 않는다. 사용자·프로젝트·테이블·선택·DB revision·명시 복구 변경은 기존 격리 기준을 유지한다.
- 기존 고급 편집 draftKey를 보존하고, ACK 뒤 문서가 갱신되기 전에는 후속 저장을 차단한다.
- 마운트·복구로 자동생성하지 않는 공통 폼 계약을 유지한다. ACK 이전 후속 입력, ACK/문서 도착 순서, 이후 patch, 미완성 초안 보존 및 삭제된 대상의 재생성 방지를 검증한다.
- 담당 파일만 포맷하고 2026-10-08 결과를 기록한다. 공유 Git index 경합에 대한 사용자 추가 지시에 따라 add/commit은 중지하고 오너가 파일별로 커밋한다.
