# 컬럼 기본값 선택

- 기존 컬럼 편집과 새 컬럼 생성에 타입별 기본값 선택을 제공한다.
- 날짜·시간 함수, 숫자 상수, boolean, 빈 문자열, UUID, JSON, ENUM 값을 안전한 목록으로 제공하고 임의 SQL 입력은 추가하지 않는다.
- 정수의 자동 증가는 SERIAL 계열로 표현한다. DEFAULT 1과 구분하며 배열에는 제공하지 않는다.
- 타입 변경은 기존 기본값을 초기화하고 NULL 불허 전환은 NULL 기본값을 제거한다.
- helper 동작, UI 정적 렌더링, PostgreSQL 생성 및 타입 검사를 검증한다.
