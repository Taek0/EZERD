# 데스크톱 시각 디자인 검토 계획

- 날짜: 2026-10-12
- 사용자 결정: 모바일은 사용 플랫폼에서 제외한다. 논리 설계와 검증 항목의 기존 메뉴 위치를 유지한다. 두 항목을 개선 우선순위에서 제거한다.
- apple-design 기준을 적용하되 데스크톱의 시각적 위계, 색과 대비, 글자 크기, 여백, 소재와 컴포넌트 일관성을 우선 검토한다.
- 기존 데스크톱 검토 스크린샷과 실제 스타일 정의를 대조한다. 기능 이동이나 새로운 탐색 패널 도입은 이번 디자인 우선 검토의 핵심 제안으로 삼지 않는다.
- 기존 구성 검토 문서를 날짜 규칙에 맞춰 갱신하고 참조 경로를 점검한다. 새 디자인 결과 문서와 함께 한 검토 단위로 커밋한다.
- 제품 UI 코드는 변경하지 않는다.
