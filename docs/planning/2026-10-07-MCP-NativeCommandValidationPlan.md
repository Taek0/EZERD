# Native MCP 명령 입력·오류 진단 점검

- 전달받은 SQLite v2 add_table 요청을 현재 서버 계약과 대조하고 실패 경계를 재현한다.
- MCP에 노출하는 명령별 입력 구조와 실제 검증 계약을 일치시키고 검증 실패의 필드 경로·원인을 반환한다.
- 기존 legacy 진단이 관계없는 신규 객체 추가를 막는지 격리된 fixture로 확인한다. 실제 사용자 프로젝트는 변경하지 않는다.
- 관련 MCP·명령 테스트, 포맷·타입·빌드를 검증한 뒤 work-log에 결과와 정상 요청 예제를 기록하고 변경 파일만 커밋한다.
- 진행 중인 v1 미사용 호환 코드 정리 변경은 이번 커밋에서 제외한다.
