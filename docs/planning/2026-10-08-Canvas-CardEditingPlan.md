# 카드 인라인 편집 개선 계획

- 범위: NativeERDCanvas, 카드 인라인 셀, SearchType 및 관련 회귀테스트.
- 검색어를 선택된 DB 타입 ID와 분리하고 재렌더링 및 복구 시 입력을 유지한다.
- 카드 +는 DB 기본 타입 계약으로 빈 컬럼을 즉시 저장하고 생성된 카드 이름 셀에 포커스를 연결한다.
- 카드 타입 표시에서만 엔진 prefix를 제거하고 저장 ID와 파라미터는 보존한다.
- 배치 입력 초기화 버튼과 해당 처리기를 제거한다.
- 금지된 편집기 파일 및 공유 native-editor-policy.ts는 수정하지 않는다.
- 시작 상태: 다른 작업의 미추적 Editor-ImmediateEditingPlan 문서만 존재, 코드 수정 없음.
- 관련 회귀테스트와 web 타입 검사를 실행하고 변경 파일만 포맷·커밋한다.
- 추가 요청: 공유 use-native-autosave hook으로 카드 이름·설명도 300ms debounce 저장한다. 편집 포커스를 유지하고 IME 중에는 지연한다. 검색 문자열은 타입 선택 전 저장 명령으로 보내지 않는다.
