# 고급 인덱스·식 편집 계층화 계획

- 날짜: 2026-10-08
- 범위: `NativeAdvancedEditor.tsx`, `native-expression-tree.tsx`, `native-editor-expression.tsx` 및 관련 전용 테스트.
- 항목 선택과 식 종류 선택을 각각 `생성하려는 항목 선택`, `생성하려는 식 선택`으로 구분한다.
- 선택 항목의 편집, 재귀 하위 식, 기존 식 묶기 작업을 토글 내부에서 계층화한다. 접힌 내용도 마운트하여 초안을 유지한다.
- AST 변환, 정책 검증, 저장 조건, 복구 키는 유지한다. 손상 초안 안내에서 입력 초기화 요구를 제거한다.
- 금지된 공통 폼·포맷·속성·프로젝트·캔버스 파일 및 다른 작업자의 변경은 수정하거나 커밋하지 않는다.
- 전체 포맷 대신 담당 파일만 Prettier로 확인한다. 관련 UI·정책·메모 테스트 및 웹 타입 검사를 실행한 후 결과를 기록하고 담당 파일만 커밋한다.
