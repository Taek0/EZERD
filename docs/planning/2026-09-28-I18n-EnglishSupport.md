# 한국어·영어 지원 계획

- 프로필 메뉴에서 한국어와 영어를 선택하고 현재 브라우저의 `ezerd.locale`에 저장한다. 재접속 시 복원하며 기본 언어는 한국어다.
- 공통 번역 API, 문자열 보간, 언어 변경 구독을 제공한다. 앱 문서의 lang도 동기화한다.
- 홈·인증·프로필, 캔버스·도메인·관계, 테이블·컬럼·ENUM, 핀·히스토리·MCP·프로젝트 전송과 공통 팝업을 번역한다.
- 사용자가 입력한 프로젝트명·테이블명·설명과 SQL 타입 및 데이터는 번역하지 않는다. 기존 문서와 DB 스키마는 유지한다.
- UI 작업을 Astra 에이전트에 기능별 분담하고 루트에서 공통 컨트롤, 통합 검증, 누락 확인을 수행한다.
- 한국어 기존 테스트와 언어 선택·보간·기본값 테스트, 전체 타입 검사 및 브라우저 언어 변경을 확인한다.
