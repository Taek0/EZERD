# 버튼 디자인 비교 시안

- 목적: 홈 화면과 프로젝트 편집 화면의 버튼 인상을 통일하기 전에 사용자가 세 시안을 비교하고 선택한다.
- 기준: `apps/web/src/components/ui/untitled.css`의 EZERD 테마. 홈의 기본 버튼은 회색 그라데이션과 양방향의 부드러운 그림자, 주요 버튼은 청회색 그라데이션과 짙은 파란 글자를 사용한다. 현재 공통 버튼의 모서리는 8px다.
- A: 홈의 현재 입체감과 8px 모서리를 가장 가깝게 유지한다.
- B: 같은 색상에 얇은 경계선과 작은 그림자를 적용해 편집 화면의 버튼이 밀집된 곳에서 구분하기 쉽게 한다.
- C: 같은 색상에 12px 모서리와 더 부드러운 깊이감을 적용한다.
- 비교 조건: 세 시안 모두 같은 홈 프로젝트 액션, 편집 도구, 속성 패널, 기본·호버·누름·포커스·선택·비활성·위험 버튼을 보여준다.
- 산출물: 앱 UI와 분리한 `apps/web/button-design-proposals.html`. 기존 자체 호스팅 글꼴을 사용하며 웹 브라우저로 렌더링하고 캡처한다.
- 선택 전에는 실제 앱 버튼을 수정하지 않는다. 사용자가 선택한 뒤 해당 규칙을 공통 버튼 및 화면별 재정의에 적용한다.
- 검증: 브라우저 캡처, 반응형 가로 넘침 확인, 버튼 상호작용과 키보드 포커스 확인, 저장소 포맷 검사. 작업 결과와 실제 검증은 work-log에 기록한다.
