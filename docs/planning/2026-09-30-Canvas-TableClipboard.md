# 다중 테이블 클립보드

- 커서 도구의 다중 테이블 선택을 우클릭할 때 선택을 유지하고 오려두기·복사하기를 제공한다. 도메인 화면의 빈 공간에는 붙여넣기를 제공한다.
- 표준 copy/cut/paste 이벤트로 Ctrl/Cmd+X/C/V를 지원한다. 입력창, 대화상자, 메뉴에서는 텍스트 편집을 가로채지 않는다.
- 컬럼·키·ENUM 및 선택 내부 관계와 상대 배치를 복제한다. 붙여넣기는 새 ID와 중복을 피한 이름을 사용하며 소유 도메인에 생성한다. 통합 뷰에서는 붙여넣기를 제한한다.
- 오려두기는 클립보드에 보관한 다음 기존 삭제 모델을 사용한다. 선택 외부 테이블과 연결된 관계는 삭제되며 붙여넣기로 복구하지 않는다. 기존 실행 취소로 원본 삭제를 되돌릴 수 있다.
- 시스템 클립보드와 탭 내 메모리 fallback을 사용한다. 외부 입력은 형식·문서 스키마·참조를 검증한다.
- 모델 복제·삭제·잘못된 클립보드 회귀 테스트와 웹 타입·빌드·포맷 검사 및 브라우저 동작 검증을 수행한다.
