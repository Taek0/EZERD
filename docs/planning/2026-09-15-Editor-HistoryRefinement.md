# 관계 라벨·히스토리·반응형 사이드바 개선

작성일: 2026-09-15

관계선 라벨을 PK 출발 컬럼명:FK 참조 컬럼명으로 변경한다. 복합 관계는 각 대응 목록을 같은 순서로 표시한다. 이력 명칭을 히스토리로 변경하고 변경자·일시 포맷은 유지한다. 원시 UUID/경로/JSON 대신 객체 이름과 동작·속성을 설명하는 요약을 제공한다. 히스토리 트리거를 주변 공통 버튼과 맞추고 메뉴 애니메이션을 추가한다.

작은 화면에서 사이드바 토글·드롭다운이 잘리는 원인을 재현해 레이아웃/스크롤/팝오버 배치를 보완한다. UI는 Astra가 담당하며, 이름 해석과 히스토리 요약 로직·검증은 주 에이전트가 직접 수행한다. Prettier 및 관련 단위·브라우저 검증 후 작업 단위로 커밋한다. 기존 문서 재분류 변경은 포함하지 않는다.
