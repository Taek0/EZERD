# 컬럼 타입 별칭 중복 제거

- PostgreSQL 내보내기의 기존 별칭 매핑을 공용 타입 모듈로 옮겨 선택 목록과 표시에도 적용한다.
- TIMESTAMPTZ, TIMETZ, TIMESTAMP, TIME, NUMERIC 등 대표 타입을 하나씩 제공한다.
- 저장된 별칭은 표시만 정규화하고 동일한 대표 타입 재선택 시 길이·정밀도·배열 및 기본값을 유지한다.
- ENUM과 사용자 정의 타입은 별도로 유지한다. 타입 매개변수와 기본값 검사도 공용 정규화를 사용한다.
- 별칭, 사용자 타입, ENUM, 저장 데이터 보존 회귀 테스트와 타입 검사 및 포맷 검사를 수행한다.
