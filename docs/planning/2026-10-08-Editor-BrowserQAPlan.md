# 최종 브라우저 QA 계획

- 임시 DB 서버 http://127.0.0.1:5174 에서 CUA 단독 세션으로 실제 UI만 조작한다.
- 테이블명 blur 없는 자동저장·reload, 카드 컬럼 추가·빈 값·포커스, 타입 var 연속 입력·varchar 선택·prefix 제거를 확인한다.
- 사이드바 이름·타입·설명 순서와 옵션 기본 접힘, 컬럼명·설명 저장·reload, 도메인 생성·소속 Select 저장, 고급식 계층화를 확인한다.
- 실패는 수정하지 않고 재현·스크린샷·콘솔 증거를 기록한다. 소스 및 Git index를 수정하지 않는다. 커밋은 오너가 담당한다.
