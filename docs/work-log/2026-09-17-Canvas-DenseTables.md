# 많은 테이블 탐색과 사이드바 스크롤

## 변경

- 카드 여백과 내용 최소 크기는 별도 카드 커밋에서 줄였고, 추가 피드백에 따라 제목26px/본문20px로 카드 대비 글자를 키웠다. 저장된 수동 크기·좌표는 임의 변경하지 않는다.
- 버튼·핀치 축소 최솟값을 공통 상수 10%로 통일했다. 모델/API의 기존 0.1 범위와 일치한다.
- 도메인 구성 문구를 도메인 뷰로 통일했다. 테이블 고정 배치, 키 관계 설정·관계선 이동 허용을 팝업과 사이드바에 안내한다.
- 도메인 뷰 나가기 버튼은 원래 도메인으로 돌아간다. 원래 도메인이 구성에서 빠지거나 삭제됐으면 남은 도메인/도메인 맵으로 안전하게 이동한다.
- 속성·목록 모두 고정 헤더/탭 아래의 높이가 확정된 본문을 스크롤하도록 통일했다. 핀 패널도 같은 높이 제한 안에서 스크롤한다.

## 검증

pnpm check 통과: 단위 테스트317개, 전체 타입 검사, 포맷, 빌드. DB 테스트23개는 이번에 실행하지 않았다.

Chromium 메모리 fixture에 테이블42개와 핀35개를 생성해 실제 wheel 스크롤을 확인했다. 목록은 scrollTop1946으로 마지막 table_40 접근, 컬럼 속성은 scrollTop423에서 맨 아래 삭제 버튼이 화면 안에 표시됨, 핀은 scrollTop4714에서 마지막 핀 접근을 확인했다. 목록/속성 스크롤 중 헤더 위치는 유지된다.

도메인 뷰 안내 문구와 나가기 버튼, 원래 주문 도메인으로 복귀, UI 배율10%까지 축소를 확인했다. 원래 도메인 삭제/구성 변경시 복귀 예외는 단위 테스트로 검증했다. 실제 데이터 변경은 없으며 임시 HTML/QA 서버/브라우저 탭은 정리한다. 실제 macOS Safari는 별도 하드웨어 확인 대상이다.

이번 작업에서 429 오류는 발생하지 않아 포크하지 않았다.
