# 버튼 디자인 비교 시안

- 실제 홈 화면 버튼의 청회색 그라데이션, 양방향 그림자, 글꼴을 기준으로 독립 시안 `apps/web/button-design-proposals.html`을 작성했다.
- A: 홈의 8px 모서리와 입체감 유지. B: 7px 모서리와 얇은 테두리·낮은 그림자. C: 12px 모서리와 더 부드러운 입체감.
- 각 시안에 동일한 프로젝트 관리, 편집 도구, 속성 패널과 기본·오버·누름·포커스·선택·비활성·삭제 상태를 배치했다.
- localhost:5188에서 브라우저로 렌더링하고 전체 비교 스크린샷을 저장했다. 선택 버튼 클릭 시 aria-pressed 변경도 확인했다.
- 시안 HTML의 Prettier 검사를 통과했다. 실제 앱 UI 및 데이터는 변경하지 않았다.
- 사용자가 A/B/C 중 선택한 후 실제 서비스의 공통 버튼과 화면별 예외 스타일을 정리한다. 현재 시안은 기본 배포 진입점에 포함되지 않는다.
