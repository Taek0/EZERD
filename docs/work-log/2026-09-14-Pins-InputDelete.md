# 핀 입력 및 삭제 변경 기록

- 핀과 답글 입력란에서 Enter로 전송하고 Shift+Enter는 줄바꿈한다. IME 조합 상태 및 키 코드 229는 전송하지 않으며 빈 입력, 처리 중, 중복 제출을 방지한다.
- 기존 공통 Textarea를 사용하면서 회색 배경과 공통 모서리/포커스를 적용했다. 기본 28px 및 작성 중 64px 높이, 아바타와 핀 모양, 패널 애니메이션을 유지했다.
- 모든 핀에 삭제 버튼을 제공하고 공통 확인 대화상자로 핀 및 모든 답글 삭제를 안내한다. 취소는 서버 요청을 발생시키지 않는다.
- 삭제에는 조회 당시 updatedAt을 전달한다. 성공 시 해당 핀만 제거하고 목록을 갱신한다. 실패 시 최신 핀을 다시 불러오고 오류를 유지한다. 다른 핀과 새 핀/답글 초안은 유지된다.
- `pnpm --filter @ezerd/web typecheck` 통과.
- `node scripts/browser-pin-editing-smoke.mjs` 실제 앱 검증 통과: 공백 전송 방지, Shift+Enter 줄바꿈, IME 조합/네이티브 isComposing Enter 무전송, 핀/답글 Enter 전송, 삭제 취소/확정, 다른 핀 및 두 종류의 초안 보존, 회색 28px/64px 입력창, 네이티브 대화상자 및 브라우저 오류 0건.
- `.cache/verification/pin-editing-flow.png`를 육안 확인했다. 회색 한 줄 답글 입력창과 활성 새 핀 입력창, 아바타, 핀 모양, 삭제 버튼이 정상 배치된다.
- 브라우저 검증은 임시 사용자와 프로젝트를 만들고 종료 시 정리한다.
