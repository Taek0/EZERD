# 자동 관계선 정리 실패 재탐색

- 최초 탐색 실패 시 네 연결 면의 여유 구간에서 대체 연결점을 구하고, 가까운 조합부터 최대 16개 방향 조합을 재탐색한다.
- 아직 처리하지 않은 관계의 연결점도 고려한다. 성공할 때만 연결점을 갱신하며 기존 카드 좌표와 입력은 변경하지 않는다.
- 기존 장애물 우회 탐색과 직각 경로 검증을 재사용한다. 전역 탐색 예산을 유지하며 남은 관계의 최초 탐색 횟수를 확보한다.
- 실제 Hwp 데이터에서 이름과 설명을 제거한 71개 카드·114개 관계의 좌표 fixture를 추가했다. 기존 코드에서 회귀 테스트 실패, 수정 후 전체 114개 경로 생성 성공을 확인했다.
- 테스트는 경로의 직각 여부, 모든 카드 침범 방지, 입력 불변성을 확인한다. 자동 정리 15개, 경로 통로 정리와 클라이언트 컨트롤러 21개 테스트 통과. 모델 TypeScript 빌드 및 변경 파일 Prettier 검사 통과.
- 실제 Hwp 프로젝트에는 저장하지 않았다. 새 빌드 적용 후 사용자가 자동 정리를 실행해야 반영된다.
- 탐색 한도와 원자적 실패 정책은 유지한다. 실제로 경로가 불가능하면 전체 저장을 하지 않으며, 복잡한 그래프의 선 교차가 전부 없어지는 것은 보장하지 않는다.
