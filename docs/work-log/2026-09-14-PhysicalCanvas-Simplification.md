# 물리 전용 캔버스와 상단바 간소화

- App에서 PostgreSQL DDL 버튼, 다운로드 핸들러, 결과 패널을 제거했다. 모델의 내보내기 엔진과 기존 문서 필드는 유지했다.
- 캔버스를 물리 전용 보기로 고정하고 논리/물리 선택 및 설계 확인 UI를 제거했다. 테이블 선택 접근성 이름은 물리명을 우선한다.
- 목록과 외부 참조 선택에서 논리 전용 테이블을 제외했다. 새 테이블은 물리 범위로 생성한다.
- 자동 배치는 물리 테이블과 관계를 대상으로 계산한 레이아웃만 원본 문서에 반영한다. 숨긴 논리 전용 노드의 위치와 기존 테이블·컬럼·메타데이터는 변경하지 않는다.
- 점 격자 반지름을 0.75px에서 1.05px로 키웠다. 프로젝트 상단바의 세로 여백과 갤러리·검토 대화·저장·알림 버튼을 줄이고 도메인 맵 복귀 버튼을 파란 배경과 화살표로 강조했다.
- 테이블 바깥 카드 여백을 0으로 제거하고 헤더·행을 하나의 카드로 연결했다. 사용자 지정 크기와 연결선·댓글 기준점을 유지하기 위해 기존 노드 치수는 보존했다.

## 검증

- `pnpm --filter @ezerd/web typecheck` 통과.
- 기본 브라우저 런타임 연결이 커널 종료로 실패하여 격리된 headless Chrome과 API 응답 모킹으로 실제 App UI를 확인했다. 실제 프로젝트나 사용자 데이터를 쓰지 않았다.
- 1440×1000, 390×844 화면 캡처 및 시각 검토. 프로젝트 상단바 높이 약 68px, 주요 버튼 높이 33px/글자 13px, 테이블 바깥 padding 0px, 헤더 배경 rgb(49,110,159)를 확인했다.
- DDL 버튼·표시 모드 그룹·설계 확인이 없는 것, 도메인 맵 복귀 버튼 노출, 모바일 문서 폭 390px로 가로 넘침 없음, 브라우저 오류 없음 확인.
- 검증 캡처: `.cache/verification/physical-ui-desktop.png`, `.cache/verification/physical-ui-mobile.png`.
