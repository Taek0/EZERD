# 캔버스 도구 단축키 작업 기록

- 도메인 맵과 테이블 캔버스의 공통 Canvas에서 V/커서, H/손 도구 전환을 연결했다. 대문자와 한글 자판의 해당 물리 키도 지원한다.
- 기존 도구 버튼과 동일한 전환 함수를 사용한다. 손 도구 선택 시 선택을 해제하고, 두 도구 모두 연결 진행 상태를 초기화한다.
- 입력·편집 요소, IME 조합, Ctrl/Meta/Alt 조합, 반복 키 입력, 이미 처리된 이벤트, 열린 대화상자·팝오버·메뉴와 드래그 중에는 무시한다.
- 도구 버튼 툴팁에 (V)/(H)를 추가했다. React Aria 버튼이 SSR에서 title/aria-keyshortcuts를 걸러내므로 기존 tooltip 속성으로 안내를 제공한다.
- 검증: Canvas 렌더링 및 단축키 판별 테스트 22개 통과, 웹 TypeScript 검사 통과. 실제 브라우저 조작은 수행하지 않았다.
- 루트 Prettier 실행 파일로 변경 코드 포맷을 적용하고 검사했다. 문서는 저장소 prettierignore에 따라 포맷 대상에서 제외된다.
