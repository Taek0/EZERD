# 비동기 편집 및 저장 경량화 검증

## 반영 범위

- 이름 초안은 기존 자동저장 타이머와 분리하고, 유효한 컬럼/테이블 속성·삭제·FK 생성/수정·키 명령은 영속 큐 등록 직후 로컬 문서에 투영한다.
- 원본 확인 문서, 미확인 명령, 이름 초안을 구분한다. 거절된 명령은 표시에서 제거하되 복구 기록을 보존한다. 오프라인 요청은 원본 그대로 유지하고 기존 순차 전송·재조회·취소 fence를 사용한다.
- 연속 ACK는 변경 집합으로 확인하며 gap/version/DB 문맥 불일치는 재조회한다. 구형 클라이언트/과거 ACK에는 전체 문서 응답을 유지한다.
- 변경 버전 SQL을 한 배치로 저장한다. 삭제/재정렬 ACK에서 생존 객체는 ID로 구조 공유한다.
- 기존 애니메이션, 스타일, canvas world의 will-change:auto 설정은 변경하지 않았다.

## 검증 결과

- main `pnpm check`: 2,926 passed, 499 skipped; format/type/build 통과.
- 격리 PostgreSQL DB의 replay 권한, 취소, 기능 통합 테스트: 160 passed. 테스트 DB 삭제 완료.
- 별도 로컬 테스트 프로젝트에서 전체/경량 ACK 각각 48회, 총 96회 저장 승인. 경량 ACK 조회 replay와 서버 전체 원본 문서의 일치 검증. 테스트 데이터 정리 완료.
- Chrome 50테이블×10컬럼 지연 ACK 검증: 이름 로컬 표시 180.5ms, 속성 표시 97.6ms, 삭제 표시 100.3ms. 모두 ACK 이전에 표시되고 이전 응답 이후 최신 입력 유지, 추가 중복 없음, 삭제 유지, 최종 큐 비움 확인. 이름 전송 시작은 약 1,238ms로 로컬 표시와 분리됐다.
- 위 시간은 계측 fixture에서 DOM을 주기적으로 확인한 값이며 실제 INP/화면 paint 시간이 아니다. 실제 이름 입력/컬럼 추가 버튼을 사용하고 속성·삭제는 동일 영속 큐에 명령을 등록했다. 브라우저 검증은 mock ACK만 사용해 사용자 문서를 수정하지 않았다.
- 메뉴·패널 버튼 워밍업 제외 React 합산 중앙값: 메뉴 2.0ms, 핀 15.5ms, 속성 패널 14.6ms, 컬럼 펼침 21.3ms. 서버 지연과 분리된 결과다.

## 전체/경량 ACK 비교

동일한 최종 코드로 순차 실행, 워밍업 1회 제외 3회 중앙값. 본문 크기는 압축 전 JSON bytes다.

| 100테이블 동작 | 전체 ACK bytes | 경량 ACK bytes | 전체 schema ms | 경량 schema ms |
| --- | ---: | ---: | ---: | ---: |
| 이름 | 526574 | 723 | 9.82 | 0.07 |
| 컬럼 추가 | 527052 | 1221 | 11.90 | 0.06 |
| 컬럼 삭제 | 526651 | 1369 | 9.65 | 0.07 |
| 10개 속성 | 526889 | 1759 | 11.21 | 0.08 |

경량 ACK의 100테이블 HTTP 중앙값은 약 366~383ms다. 전체 문서 검증·원장/베이스라인 기록은 여전히 필요하며 서버 저장 자체가 즉시 완료되는 구조는 아니다. 순차 실행/워밍업/환경 차이가 있어 전체와 경량의 HTTP 차이를 모두 응답 형식의 효과로 해석하지 않는다.

## 적용과 한계

- DB schema migration은 없다. 서버 프로세스를 재시작하고 브라우저를 새로고침해야 새 서버/클라이언트 조합을 사용한다. 구형 서버와 새 클라이언트도 전체 ACK fallback으로 동작한다.
- 이름 이외의 미완성 자유 입력은 기존 검증/자동저장 타이머를 유지한다. 큐에 들어간 유효 명령부터 서버 응답 대기를 분리한다.
- 모든 편집 명령을 낙관적으로 적용하는 범용 엔진은 아니다. 도메인/메모/클립보드/재정렬 등 기존 별도 경로는 유지한다.
- 원시 로그/측정 도구는 performance-lab의 `artifacts/performance/2026-10-14-async-*` 및 `apps/server/scripts/performance-save-ack.mts`, `apps/web/performance/panels.tsx`에 보관한다. main에는 제품 변경·테스트·문서만 반영한다.
