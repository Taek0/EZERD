# 개인 상태 API 및 개인 조합 뷰 제거

- 사용자가 카메라·마지막 화면·도메인 필터를 서버에 보관하지 않기로 결정했다. personal-state GET/PUT 컨트롤러·서비스·계약과 MCP 개인 조회/편집 도구를 제거했다. 카메라는 React 상태로만 유지된다.
- 프로젝트 진입은 document-state만 조회한다. 별도 개인 상태 병합, 캔버스 초기화 조회, 개인 저장·PNG·복구 경로를 제거했다.
- 개인 상태와 개인 작업 기록 테이블을 삭제하는 `0017_retire_personal_state.sql`을 작성했다. 이 작업에서 운영 DB에는 실행하지 않았다. 이전 0016을 적용한 환경도 0017 적용이 추가로 필요하다.
- 공유 테이블·관계·메모·배치와 공유 명령의 durable queue/복구는 유지한다. viewer의 핀 권한은 review 권한으로 유지한다.
- 구 파일의 원문 읽기·가져오기 무손실 호환을 위해 CombinedView 구조 일부는 남아 있으나 새 개인 화면 생성/수정이나 개인 경로 조회는 제공하지 않는다. 기존 개인 화면 ID를 UI에서 요청하면 공유 테이블 화면으로 처리한다.
- 브라우저에 남은 개인 저장 키는 사용자 데이터를 임의 삭제하지 않고 무시한다. 공유 편집/히스토리/DDL을 영구 차단하던 세 군데의 검사를 제거하고 회귀 테스트를 추가했다.

## 검증

- 전체 회귀 검사 2,909개 통과, DB 환경 의존 495개 건너뜀. 이후 개인 로컬 저장 키 차단 제거는 관련 42개 테스트로 추가 확인했다.
- 모델·계약·서버·서버 도구·웹 타입 검사, 서버/공유 패키지 빌드 및 웹 Vite 빌드 성공. Prettier 검사 통과.
- 개인 HTTP API 404, MCP 등록 제거, 공유 작업 인증·권한·복구·PNG·도메인 변경 회귀를 검사했다. 테스트에서 제거된 개인 기능 기대값을 정리했으며 공유 기능 검증은 보존했다.
- 실제 PostgreSQL에서 DROP 마이그레이션 실행 및 브라우저 수동 검증은 수행하지 않았다. 기존 대형 JS 번들 경고는 남아 있다.
