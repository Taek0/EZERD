# 테이블 카드 편집 사용성 개선 결과

- 컬럼 편집의 타입을 왼쪽, ENUM을 오른쪽에 배치했다.
- 카드 타입에 키보드 포커스가 오면 검색을 바로 열고 검색 입력 기존 값을 선택한다. Escape/선택 후 포커스 복귀가 다시 편집을 열지 않도록 처리했다.
- 테이블명 28px, 컬럼 본문 20px로 확대하고 측정 행 간격(30px), 헤더(62px), 컬럼 헤더(42px)를 동기화했다.
- 숨긴 NULL/설명 열을 제외한 최소 너비가 480px 제한에 막히지 않도록 변경했다. 사용자가 저장한 크기는 보존한다.
- ENUM 대화상자와 배경에 180ms 진입 효과를 적용하고 prefers-reduced-motion을 지원한다.
- ON DELETE/ON UPDATE를 FK 관계 기본 영역에 배치했다. PK/UNIQUE는 참조 키이고 동작은 FK에 저장된다.
- 검증: TableEditor 및 table-geometry 단위 테스트 19개 통과, 웹 tsc --noEmit 통과.
- pnpm format 적용. 브라우저 통합 확인은 상위 작업에서 진행한다. 기존 타입 편집 버튼은 포커스 시 검색 입력으로 전환되며 aria-label은 유지한다.
