# 저장 후 문서만 갱신

- Native 편집기의 저장 후 갱신이 프로젝트 열기 경로를 다시 호출하던 연결을 제거했다.
- 백그라운드 갱신은 현재 편집기를 유지한 채 최신 entry만 반영한다. 전역 busy·화면 이동·핀 초기화·편집기 교체 절차를 실행하지 않는다.
- 연속 갱신 요청을 합치고 이전 사용자·이동 세대의 응답 및 더 오래된 버전은 무시한다. 실패해도 현재 문서를 유지한다.
- 지연 응답 중 현재 문서 유지, 반복 요청 병합, 이전 화면 응답 무시, 버전 역행 방지, 화면 이탈 후 오류 무시 테스트 5개 통과.
- 카메라 초기화와 진행 중 배치 표시는 별도 캔버스 수정으로 함께 검증한다.
