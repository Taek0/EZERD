## 반영한 수정안

- 회색·블루의 제품 방향과 은은한 입체 버튼 스타일을 유지하면서 일반 동작, 주요 생성, 선택 상태의 강도를 구분했다.
- 속성·핀 패널에 공통 헤더 높이와 패딩을 적용하고 선택 객체를 별도로 강조했다.
- 캔버스 점 격자와 비선택 카드 그림자를 약하게 하고, 카드 제목은 20px 기준으로 구성했다. 이는 목업의 비교 후보이며 제품 사양 확정이 아니다.
- 갤러리 hero와 미리보기 높이를 줄이고 메타데이터 대비를 보강했다.
- 논리 설계·설계 확인 항목·보관된 입력 복구는 더 보기 메뉴 안에 유지했다. 모바일은 제작 범위 밖이며 목업의 최소 너비는 1120px이다.

## 조작 가능한 범위

- EZERD 로고 또는 갤러리 버튼으로 갤러리 이동, 프로젝트 카드로 편집기 이동.
- 테이블 선택과 속성 표시, 목록/속성 전환, 설명의 메모리 내 수정.
- 속성·핀 패널 토글, 핀의 해결됨 포함 상태, 캔버스 배율 조절.
- 전체 테이블/도메인 맵 전환, 논리 이름 표시 전환.
- 갤러리 검색, 정렬, 보관함 전환.
- 수정안/기존 분위기 비교 및 디자인 포인트 표시.

기존 분위기는 검토에서 확인한 스타일 특성을 단순화한 재구성이며 실제 제품 화면의 정확한 복제가 아니다. 추가·내보내기·히스토리 등 백엔드 기능은 안내를 표시한다. 드래그 이동은 구현하지 않았다. 모든 데이터는 예시이고 제품 서버 연결·저장은 없다. 외부 라이브러리·폰트·네트워크 의존성 없이 HTML 한 파일로 실행한다.

## 검증

- Node vm.Script로 내장 JavaScript 문법 확인: 통과.
- 정적 HTML ID 중복 및 스크립트의 정적 ID 참조 누락 검사: 없음.
- 로컬 단일 파일 서버 HTTP 200과 HTML 본문 확인: 통과.
- 앱 브라우저에 `http://127.0.0.1:5188/` 미리보기 열기를 요청했다. 도구 결과는 queued이며 실제 화면이 열렸다는 확인은 아니다.
- 현재 컴퓨터 제어 도구에 연결된 브라우저가 없어 실제 렌더링·클릭 검증과 스크린샷은 수행하지 못했다. 정적 검사 결과를 시각 QA나 상호작용 성공으로 해석하지 않는다.
- 문서·목업은 루트 .prettierignore의 docs 제외 대상이다. 제품 구현 변경이 없으므로 기존 제품 테스트를 재실행하지 않았다.
- diff 공백 및 산출물 상대 링크를 확인하고, 계획·목업·결과만 커밋한다.

## 열기

미리보기 서버가 실행 중이면 위 localhost 주소를 사용한다. 서버가 종료돼도 HTML 파일을 브라우저에서 직접 열어 사용할 수 있다. 미리보기는 고정된 목업 파일만 제공하며 저장소 전체를 노출하지 않는다.
