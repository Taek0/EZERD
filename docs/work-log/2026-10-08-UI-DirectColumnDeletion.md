# 컬럼 삭제 확인 단계 제거

- 컬럼의 사이드바·캔버스 삭제 진입점에서 영향 확인 사이드바를 여는 대신 기존 delete_objects 명령을 바로 요청한다.
- 삭제 계획의 참조·표현식 차단 검사를 유지하고 생성 컬럼 연쇄 삭제는 자동으로 켜지 않는다. 다른 객체의 확인 흐름은 변경하지 않는다.
- 서버 승인 후 해당 컬럼 선택만 해제하며 다른 프로젝트로 이동한 뒤 이전 응답이 선택 상태를 변경하지 않도록 기존 컨텍스트 검사를 사용한다.
- 직접 삭제 요청과 종속 표현식 차단 회귀 테스트를 추가했다. 관련 요청 테스트 15개와 전체 `pnpm check`(2,792개 테스트, 타입·포맷·빌드)를 통과했다.
