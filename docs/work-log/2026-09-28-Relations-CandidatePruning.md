# 자동 경로 후보 조기 제외

작성일: 2026-09-28
기준: `1b41dbc`, `feat/performance-measurement`.

## 변경과 안전 조건

- 자동 후보를 simplify한 뒤 기존과 동일한 점수를 먼저 계산한다. 현재 최선 점수 이상이면 선택될 수 없으므로 장애물/재추적 검사를 생략한다.
- 후보 순서·동점 처리·점수식은 바꾸지 않는다. 경로를 근사하거나 장애물을 줄이는 방식이 아니다.
- 수동 bend에서는 consider의 true/false가 fallback 실행 여부에 사용되므로 조기 제외를 적용하지 않는다. 수동 waypoint와 A* 순서도 유지한다.
- 기존 reference와300개 fixture 전체 경로, 수동·self·중첩 사례를 비교했다. 추가60개 고정 난수 장면에서도 전체 결과가 같아야 한다.

## 사전 측정

변경 전 고정 빌드 계산 결과는 `artifacts/performance/scale-1790594109065/`에 저장했다.300개 warm 중앙값200.36ms, p95223.28ms였다. 미커밋 개선 실험의300개 중앙값은93.07ms였으며 채택 여부는 최종 고정 커밋 반복으로 확인한다.

전체 검사와 고정 커밋·브라우저 결과는 아래에 후속 기록한다. 제품 전체 입력 지연이나 FPS 개선율을 의미하지 않는다.

검토 중 수동 bend의 검사 순서도 그대로 유지하도록 보완했다. 수동 후보는 기존처럼 expanded 충돌 검사→simplify→raw/재추적/필수점 확인→점수 계산 순서를 유지하며, 자동 후보에만 점수 선검사를 적용한다. 관련5개 테스트를 통과했다. 초기 전체 `pnpm check`는391개 통과·DB 관련25개 skip·타입·포맷·빌드 통과였다.

호출 수는 유지되고 각 후보 검사 비용이 줄었다. 시간은 계측 함수 inclusive 누적값이다. 실제 input-to-present, React commit, GPU나 총 렌더 시간을 나타내지 않는다.

- 100개6회는 이전 raf 빌드 `44fef72`와 입력·최종 문서·SVG paths가 정확히 일치했다. 해당 이전 시간은 변동이 컸으므로 이 표만으로 정확한 체감 개선율을 산출하지 않는다.
- 300개6회 모두 기존 `f775bf4`의 최종 문서·SVG paths와 일치했다. 이전 EDIT-300-2에는 input5개가 있었고 현재는1개여서 엄격한 입력 동일 시간 비교에서는 그 한 쌍을 제외했다. 비교 실패를 숨기거나 원시 기록을 덮어쓰지 않았다.
- PAN300의 문서 geometry0회와 wheel burst120개→카메라 반영1회도 회귀 검증했다. 브라우저 error 로그 없음.

## 남은 범위

- 후보 자체는 계속 생성하고 관계마다 탐색한다. 문서 변경의 영향 범위·계산 공유, 화면 밖 상세 UI·목록 가상화, 렌더링 비용 측정은 남아 있다.
- 수동 경로에는 이 조기 제외를 적용하지 않으므로 동일한 성능 향상을 기대하지 않는다.
- 프레임 병합의 paced drag 속도 판정 보류는 이번 계산 개선과 별개다. 입력 병합 때문에 빨라졌다고 해석하지 않는다.
- 로컬 성능 브랜치에 구현·검증을 커밋하며 push·main 병합은 수행하지 않는다. 이번 서버와 테스트 탭은 종료한다.

최종 `pnpm check`에서391개 통과·DB 관련25개 skip·타입·포맷·일반 빌드 통과. 성능 전용 빌드와100개 비교 스크립트도 통과했다. 기존 큰 청크 경고는 유지된다.
