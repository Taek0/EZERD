# 관계선 자동 정렬 구현 계획 작성 기록

- 사용자와 합의한 Worker 계산, 실행 조건, 포트 배치, 이동 보정, 진행 알림, 일괄 저장, 단일 실행 취소, 서버 충돌 처리 정책을 [구현 계획](../planning/2026-10-15-Relations-AutoArrangeImplementationPlan.md)에 정리했다.
- 명시적 클릭만 전체 최적화, 도메인/필터 제한, 구조 변경 시 중단, 충돌 보정 1회, 응답 유실 시 동일 작업 확인을 명시했다.
- 미정 수치(용량·탐색·성능 예산)는 검증 단계로 남겼다. 현재 모드 대상 관계 및 모드 간 공유 경로는 기존 코드 구조를 전제로 명세했다.
- 이번 작업은 문서 작성만 수행했다. 제품 코드·DB·서버를 변경하지 않았고 테스트/성능 실측/원격 push도 실행하지 않았다.
