# 탐색·속성 패널 파생 데이터 재사용 결과

[계획](../planning/2026-10-22-Canvas-InteractivePerformancePlan.md)의 4번을 구현했다.

- `useNativePanelDerived`에서 문서별 표·컬럼·도메인 인덱스를 만들고 이름 조회에 사용한다.
- 문서·모드·논리 이름 설정별 탐색 컬럼, 문서·선택 표·모드별 속성 행/키/관계, 범위별 outline을 memo한다. 검색과 도메인 필터는 별도 계산이며 입력 변화가 없는 패널 렌더는 기존 결과를 재사용한다.
- 번역된 이름 없는 표 라벨이 변경되면 이름 함수와 관계 검색을 갱신한다. 논리 이름 사용 설정과 기존 이름 fallback 순서를 유지한다.
- 검색 결과를 도메인별로 한 번 그룹화하여 각 도메인에서 전체 표 배열을 반복 필터링하지 않는다. 기존 문서 순서와 도메인 표시 조건을 유지한다.
- null 문서에서도 훅 호출 순서는 동일하다. 복구 문서의 노트 선택과 저장/ACK/권한 흐름은 변경하지 않았다.

## 검증

- 실제 React DOM(jsdom)으로 파생 훅을 반복 렌더했다. 같은 문서의 무관한 렌더와 검색 변경에서 속성 행 및 outline 생성 호출은 최초 1회로 유지된다. 모드 및 문서 변경은 재계산하며, 동일 visibleObjectIds 참조를 가진 선택 정보 변경은 outline을 재계산하지 않는다.
- 문서 이름, 키, null 문서 복귀, 논리 이름 설정, 번역 라벨, 도메인 필터/검색을 검증했다. 키 변경은 표 객체가 같아도 속성 행을 갱신한다.
- 기존 수동 React mock 테스트 한 곳에 useMemo 지원만 추가했다. 새 memo 검증은 실제 React를 사용한다.
- 관련 테스트 7개 파일, 72개 테스트 통과. `pnpm --filter @ezerd/web typecheck` 통과.
- 실제 브라우저 FPS/시간 개선율은 측정하지 않았다. visibleObjectIds 참조 안정성은 캔버스 생산자에서 유지해야 하며, 이 결과는 계산 호출과 참조 재사용 검증이다.
