# Native 원격 변경 자동 반영

- 활성 사용자·세션·프로젝트에 WebSocket 구독을 연결했다. 프로젝트 이동·로그아웃·만료 시 이전 연결과 응답을 정리한다.
- 원격 변경은 기존 NativeBackgroundRefresh를 사용해 화면을 다시 열지 않고 반영한다. 동일 문서의 fallback 응답은 다시 렌더링하지 않고 변경하지 않은 객체 참조를 재사용한다.
- HTTP 조회는 해당 actor 세션에 고정한다. 권한 변경 시 멤버십을 재확인하고 확인 중 쓰기를 중지하며, 접근 상실 시 프로젝트를 닫는다. 로컬 초안은 삭제하지 않는다.
- 실제 전송한 작업 ID를 이 탭의 제한된 메모리에 기록해 자신의 정상 ACK에 대한 중복 조회를 줄인다.
- 원격 갱신 중 복구 편집기 key를 version/sequence로 재생성하지 않는다. 작성 중 인라인 입력·배치 초안·드래그·카메라 보존을 회귀 테스트했다.

## 검증

- 전체 pnpm check: 테스트 2,856개 통과(499개 조건부 건너뜀), 타입·포맷·빌드 통과. 기존 번들 크기 경고는 남아 있다.
- 실제 서버·WebSocket·MCP를 사용하는 격리 DB에서 클라이언트 자동 반영과 DB 전환 관련 5개 테스트 통과. MCP 후속 조회 통합 8개도 통과했다.
- 통합 검증은 수신 후 애플리케이션 문서 상태 반영을 확인한 것이며 실제 브라우저 화면 수동 검증은 수행하지 않았다.
- 서버 재시작과 새 웹 번들 로드 후 적용된다. DB 마이그레이션 변경은 없다.
