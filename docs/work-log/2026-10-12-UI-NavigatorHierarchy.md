# 탐색 계층 및 패널 상호작용 결과

- 날짜: 2026-10-12
- 브랜치: codex/apple-ui-review
- [계획](../planning/2026-10-12-UI-NavigatorHierarchyPlan.md)

## 구현
- 좌측 도메인 → 테이블 → 컬럼 계층. 미소속, 빈 도메인, 이름/컬럼/도메인 검색, 도메인 열기 및 관계 탐색을 유지한다.
- 도메인 맵에서 테이블을 선택하면 전체 테이블 뷰로 이동한다. 선택된 테이블/컬럼의 부모 계층이 펼쳐진다.
- 좌측 너비 200–420px, 기본 240px. Pointer Capture를 사용해 드래그를 즉시 반영하며 취소/캡처 해제를 처리한다.
- 방향키 10px, Shift+방향키 40px, Home/End 최소/최대, 더블클릭 기본값 복원. localStorage에 너비를 저장하며 저장 불가 시에도 동작한다.
- 계층 펼침/접힘 180ms, 회전 160ms. 접힌 자식은 inert/aria-hidden으로 포커스에서 제외한다. reduced-motion에서는 전환을 제거한다.
- 우측 중복 목록과 단일 속성 탭을 제거하고 편집 항목을 직접 노출한다.
- 도구 모음을 기존 상단 행 오른쪽에 정렬한다. 논리 설계/검증 항목의 메뉴 위치는 유지한다.
- 테이블명 흰색 고정, 기본 배경 #435975. 사용자 지정 배경은 유지한다. PNG도 같은 색상 함수를 사용한다.

## 검증
- pnpm check: 포맷, 전체 타입 검사, 전체 테스트 및 전체 빌드 통과. DB 통합 검사는 EZERD_DB_TEST=0으로 제외했다.
- 회귀 검증: 너비 제한/다른 포인터 무시/취소/키보드/너비 저장/저장 차단, 중첩 계층, 흰색 제목, PNG.
- 실제 브라우저의 1600×1000 테스트 데이터 화면: 키보드 240→280px, 포인터 드래그 280→320px, 새로고침 후 320px 유지.
- 컬럼 status 검색 후 선택하면 orders의 컬럼 속성 편집이 열린다. 도메인 접힘 높이 0 및 inert 확인.
- 세 테이블명 computed color는 모두 rgb(255,255,255). 도구 모음 justify-content:flex-end와 마지막 컨트롤의 우측 경계 일치 확인.
- Vite 500kB 초과 청크 경고는 기존과 동일하다. OS 모션 설정 변경이나 실제 DB 편집 저장은 이번 검증에서 수행하지 않았다.
