# 브라우저 동기화 기준 문서 정규화

작성일: 2026-09-15

## 문제와 변경

실제 브라우저의 첫 자동 저장에서 기준 ID·시각·순서가 같은데도 요청이 거부됐다. 서버는 개인 overview viewport와 생략된 배열을 포함한 원본 문서를 기준으로 저장했지만, 브라우저는 sharedDocument로 개인 정보를 제거하고 빈 공유 배열을 채워 문서 지문이 달랐다.

서버가 발급·저장하는 기준 문서를 공통 공유 형태로 정규화하고, 기존 저장 기준을 비교할 때도 같은 정규화를 적용했다. 제출된 공유 내용의 정확한 지문 비교와 사용자·클라이언트·프로젝트·순서·시각·만료 검증은 유지한다. 프로젝트 원본 저장 형태는 변경하지 않는다.

## 검증

Sol medium 담당자가 추가한 회귀 테스트는 수정 전 accepted 대신 rejected로 실패했고, 수정 후 통과했다. 공유 기준 내용을 변조한 요청의 거부도 확인했다. 서버 빌드 및 실제 PostgreSQL 통합 테스트 2개 파일/19개 통과, git diff --check 통과. Astra low 읽기 전용 검토에서 해당 수정 범위를 승인했다. 실제 5개 브라우저 시나리오는 별도 재실행 중이다.
