# 관계선 경로 드래그 수정

- world 영역으로 portal된 경로 핸들을 캔버스 pointer capture가 빈 공간으로 판단해 선택을 해제하던 문제를 수정했다.
- 경로 핸들은 선택 사각형·손/스페이스 화면 이동·핀 생성보다 자신의 포인터 이벤트를 우선 처리한다.
- 드래그 중 경로 폼의 자동 저장을 일시 정지하고 pointer-up에서 최종 입력을 제출한다. 수동 제출이 같은 예약 리비전을 소비해 중복 저장하지 않는다.
- 긴 드래그와 중단된 입력 보존, 선택/손/스페이스/핀 모드 및 기존 경로 계산 테스트를 확인했다. 일반 텍스트 편집의 debounce/maxWait는 유지한다.
- 관련 테스트 71개 통과. 전체 `pnpm check`에서 2,792개 통과(498개 조건부 건너뜀), 타입·포맷·빌드 통과. 기존 번들 크기 경고는 남아 있다.
- 브라우저 수동 조작은 수행하지 않았으며 컴포넌트의 실제 이벤트 핸들러 회귀 테스트로 검증했다.
