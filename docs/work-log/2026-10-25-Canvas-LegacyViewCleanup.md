# 캔버스 용어 및 개인 조합 뷰 정리 결과

## 제거·변경

- MCP instructions와 도구 설명의 공유 문서/배치/화면 표현을 프로젝트 문서·테이블 캔버스·동일한 배치로 정리했다. 도메인 필터는 별도 저장 화면이 아니며 사용자별 조합 뷰 API가 없음을 명시했다.
- UI의 내보내기 안내는 도메인 맵 또는 테이블 캔버스로 변경했다. 개인 화면 저장 관련 미사용 번역을 제거하고 과거 보기의 삭제 영향은 이전 형식의 보기로 표시한다.
- public upsertCombinedView/removeCombinedView와 테이블 추가·도메인 변경 시 개인 조합 뷰 배치를 자동 생성하는 코드를 제거했다. 테스트는 생성 API 대신 과거 문서 fixture로 구성한다.
- 서버의 미지원 화면 오류 코드는 canvas.shared-view-required에서 canvas.unsupported-view로 변경했다. 과거 뷰 편집 금지는 유지한다.

## 유지한 호환 처리

- CombinedView/views 저장 스키마는 기존 원본·이력·가져오기 문서 해석에 필요하여 유지하고 legacy 읽기용임을 명시했다.
- sharedDocument의 과거 views 및 해당 노드·메모·경로 제외 처리는 동기화/내보내기에 과거 개인 데이터가 섞이는 것을 막으므로 유지했다.
- 과거 뷰가 포함된 문서에서 도메인 삭제·테이블 소유권 변경으로 잘못된 참조가 남지 않도록 정리하는 처리는 유지한다. 신규 개인 배치는 생성하지 않는다.
- 실제 DB 자료 삭제, 마이그레이션 및 과거 이력 재작성은 하지 않았다. 기존 작업 기록/artifacts는 역사적 자료이므로 변경하지 않았다.

## 검증

- 모델 전체 44개 파일 1,212개 테스트 통과. 마지막 보정 후 관련 11개 테스트 재검증.
- MCP·서버 명령·뷰 조회·UI·comments·계약의 관련 10개 파일 120개 테스트 통과.
- model/contracts/server 빌드 및 web 타입 검사 통과. 변경 코드 포맷 검사 및 diff 검사를 진행했다.
- 브라우저 수동 검증은 하지 않았다. 재빌드·재시작 및 MCP 재연결 후 새 지침이 반영된다.
