# 노션 커버 제작 결과

- 기존 웹 폰트와 로고, 슬로건을 HTML/CSS로 렌더링한 3000×1200 PNG를 artifacts/brand에 저장했다.
- 배경색 rgb(233,236,239), 폰트 로드, 3000×1200 뷰포트 및 캡처 결과를 확인했다.
- 중앙 가로 배치와 여백, 파란 마침표, 두 줄 슬로건을 시각 검증했다.
- 재현용 HTML과 커버/공개 폰트만 제공하는 로컬 미리보기 서버를 함께 보관한다. 실행: node artifacts/brand/serve-cover.mjs, 주소: http://127.0.0.1:5189/.
- 이미지 생성 도구는 사용하지 않았다.
