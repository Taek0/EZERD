# 워크스페이스 선택 A안 적용 결과

- 로고 옆 상단에 이름·이니셜 드롭다운을 배치하고 갤러리와 편집기에서 공통 사용한다. 기존 갤러리 선택 영역은 제거했다.
- 선택 버튼 15px, 목록 이름 16px, 역할·보조 문구 13px로 시안보다 가독성을 높였다. 기존 권한·보관 상태, 한국어/영어, 생성·관리·초대 대화상자를 유지했다.
- React Aria 메뉴로 키보드·Escape·외부 클릭과 선택 후 포커스 복귀를 처리한다. 목록은 API가 제공하는 역할·보관 상태를 표시하며 없는 프로젝트 개수는 만들지 않는다.
- 전환 전 자동 저장과 진행 중 로컬 편집 보관·개인 상태 저장을 기다린다. 안전하게 보관하지 못한 변경이 있으면 오류와 함께 기존 공간을 유지한다. 영구 저장된 공유 대기열은 서버 응답을 기다리지 않고 이후 복원할 수 있다.
- 전환 중 편집기 입력을 잠시 막고 중복 전환을 방지한다. 실제 데이터나 DB는 변경하지 않았다.

## 검증

- `pnpm check` 통과: 포맷·전체 타입·전체 빌드, 테스트 541개 통과(38개 제외). 기존 번들 크기 경고는 유지된다.
- 대기 중 편집·개인 상태 저장·실패·메모리 전용 대기열의 이탈 차단을 결정적 테스트로 확인했다. 실패한 공유 편집의 저장 여부를 확인할 수 없으면 계속 전환을 막는 보수적 정책이다.
- 가상 API 기반 실제 App에서 갤러리 전환, 편집기에서 TY 갤러리로 이동, 받은 초대 창 연결, 확대된 글씨와 선택 메뉴를 확인하고 스크린샷을 저장했다. 임시 QA 파일은 제거했다.
