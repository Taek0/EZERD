# 동기화 중 카메라와 편집 유지

- 개인 화면 상태를 다시 가져올 때 기존 상태를 지우지 않아 화면이 임시 기본 보기로 바뀌는 경로를 제거했다.
- 카메라 초기화는 실제 사용자·프로젝트·보기 전환 시에만 실행한다. 저장 ACK·문서 버전·개인 상태 버전 변화는 카메라 위치와 확대율을 초기화하지 않는다.
- 저장 대기 중인 오브젝트 위치를 표시한 채 다음 오브젝트 이동을 허용한다. 이전 ACK는 새 이동 초안과 진행 중 제스처를 지우지 않는다.
- 승인된 위치 표시는 다음 서버 문서 갱신에서 해제해 나중 작성자의 위치가 가려지지 않도록 한다. 거부·삭제·DB 컨텍스트 변경 시에도 남아 있지 않도록 정리한다.
- 기존 개인 화면 저장의 동시 요청 보호는 유지했다. 공유 캔버스 연속 편집과 개인 화면 카메라 보존이 이번 수정 범위다.

## 검증

- 실제 컴포넌트 핸들러로 카메라·확대율 유지, 개인 버전 갱신, 지연 ACK 중 두 번째 이동, 후속 서버 위치 반영을 검증했다.
- 전체 `pnpm check` 통과: 테스트 2,817개 통과(506개 조건부 건너뜀), 포맷·타입 검사와 빌드 성공. 기존 번들 크기 경고는 남아 있다.
- 브라우저 수동 시각 검증은 수행하지 않았다.
