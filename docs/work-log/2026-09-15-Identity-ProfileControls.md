# 사용자 PIN 입력·색상과 핀 패널 너비

작성일: 2026-09-15

Astra 담당자가 작성한 UI 코드를 주 에이전트가 적용·검증했다. 사용자 등록 폼에 숫자 네 자리 PIN 입력을 추가하고 3자리 등 잘못된 입력은 제출하지 못하게 했다. 이름 변경에서는 기존 PIN을 유지한다. 사용자 메뉴의 이름 변경 아래에 색상 변경을 추가했다. 공통 색상 선택기와 미리보기·저장·취소 폼을 사용하며 서버 저장 성공 후 적용한다.

사용자 색상은 상단 아바타, 내가 작성한 핀, 메시지 및 입력 아바타에 반영된다. 밝기에 따라 글자 색을 조절한다. 현재 사용자의 변경은 즉시 반영하고 기존 회원 목록 조회 흐름도 유지한다. 사용자 색상은 DB 저장값이며 PIN과 그 해시는 응답에 노출하지 않는다.

핀 사이드탭에는 280~560px 범위, 20px 단위 슬라이더를 추가했다. 기본 너비는 340px이고 키보드 이동 및 브라우저 선호값 저장을 지원한다. 잘못된 저장값은 기본값 또는 범위 내 값으로 보정하고 모바일은 화면 너비를 넘지 않도록 제한했다.

검증:

- 전체 pnpm check: 타입 검사, 단위 테스트 149개, 프로덕션 빌드 통과. 기존 Vite 대형 번들 경고는 유지된다.
- 실제 DB API 통합 테스트 12개 통과.
- scripts/browser-user-pin-profile-smoke.mjs: 4자리 PIN 등록, 사용자 메뉴 순서, 색상 저장/새로고침 유지, 아바타와 핀의 색상 반영, 키보드 너비 조절, 새로고침 후 너비 유지, 390px 화면 내 패널 배치 통과.
- 테이블 편집, 관계선, 도메인 뷰의 별도 브라우저 회귀도 통과. 임시 HTML 생성/삭제로 Vite가 다른 검사 화면을 새로고침할 수 있어 최종 검증은 충돌한 검사를 순차 재실행했다.
- 브라우저 검증이 만든 사용자·프로젝트만 정리했고 기존 프로젝트 2개의 전체 행 해시는 초기화 전 백업과 동일하다.
