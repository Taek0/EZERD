# ENUM 여러 줄 입력 복원

- ENUM 생성·편집의 기본 값을 한 줄당 하나씩 입력하는 textarea로 복원했다. 여러 줄을 한 번에 붙여넣을 수 있다.
- LF·CRLF·CR 줄바꿈과 빈 구분 줄을 처리한다. 비어 있지 않은 값의 공백·순서·중복은 그대로 보존해 기존 검증에 맡긴다.
- 실제 빈 문자열 또는 개행을 포함한 기존 값은 값별 편집으로 보존하며 명시적 빈 문자열 추가도 가능하다. 기존 보관 초안을 자동 재해석하지 않는다.
- JSON 초안 형식을 유지하면서 입력 중 마지막 줄바꿈이 사라지지 않도록 표시 텍스트를 보존한다. 생성 ACK 중 다음 줄 입력과 동일 ENUM 수정도 검증했다.
- 공통 입력기를 사용하는 MySQL SET의 최대 개수도 일괄 입력에서 검증하며 기존 초과 초안은 잘라내지 않는다.
- 전체 `pnpm check` 통과: 테스트 2,796개 통과(498개 조건부 건너뜀), 타입·포맷·빌드 성공. 기존 번들 크기 경고는 남아 있다.
