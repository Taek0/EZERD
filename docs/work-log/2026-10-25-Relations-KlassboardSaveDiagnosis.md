# Klassboard 자동 관계선 저장 거부 진단

- 현재 version 454 / sequence 464, 테이블 140개·관계 247개로 로컬 재현했다.
- 원본/표시 문서 UTF-8 JSON 크기 1,442,486바이트. 자동 정리는 관계 247개 계산에 성공한다.
- 후보 문서는 1,506,456바이트로 MAX_DOCUMENT_BYTES=1,500,000을 6,456바이트 초과한다. nativeEditorCandidate 최종 검증에서 document.size-limit이 발생한다.
- DB 최근 취소 기록: 2026-10-25 00:44:21 및 00:47:13 KST, operation.cancelled. 마지막 모델 검증 거부는 10월21일의 별도 FK 오류다.
- 크기 검증은 sync 결과 저장 전 HTTP 400으로 거부된다. 클라이언트는 해당 오류에서 보류 요청을 취소·보관하고 일반 저장 거부 문구를 표시한다. 실제 실패 HTTP 응답은 캡처하지 않았지만 현재 데이터로 같은 저장 검증 실패를 재현했다.
- 문서 여유 57,514바이트 대비 자동 정리 증가량 63,970바이트다. 요청을 분할해도 최종 문서 크기 제한은 남는다.
- 후속 개선: 문서 한도의 적정 상향 검토 및 document.size-limit 전용 안내. 실제 프로젝트 변경·데이터 삭제는 하지 않았다.
- 읽기 전용 DB 조회 및 임시 로컬 테스트를 수행했다. 테스트 파일은 진단 후 제거한다.
