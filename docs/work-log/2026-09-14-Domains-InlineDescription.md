# 도메인 설명 직접 편집 및 줄바꿈

작성일: 2026-09-14

카드의 업무 설명을 더블클릭하면 공통 Textarea에서 직접 편집한다. Enter는 줄바꿈, Ctrl/Cmd+Enter 또는 포커스 이동은 적용, Escape는 취소다. 설명은 pre-wrap으로 줄바꿈을 보존하며 길어지면 설명 영역만 스크롤하여 하단 열기 버튼을 가리지 않는다. 읽기 전용에서는 변경하지 않는다.

편집 중 포인터 이벤트와 더블클릭이 카드 이동·도메인 열기로 전달되지 않도록 했다. 내용 적용은 한 번의 변경 이벤트로 전달한다. 도메인 관계는 새 끝점 배치 도우미를 사용한다.

검증: scripts/browser-domain-inline-smoke.mjs 실제 Chrome 통과. Enter 줄바꿈·Ctrl/Cmd+Enter·Escape·blur·읽기 전용·최대 길이·인스펙터 줄바꿈·하단 버튼 겹침 방지·카드 크기 변경 후 끝점 구분을 확인했다. pnpm check의 전체125개 테스트·타입 검사·프로덕션 빌드 통과. DB 통합 전용12개는 이번 UI/기하 변경에서 재실행하지 않았다.
