# 관계선 속성 사이드바 구성 개선

- 테이블 관계선 경로 편집을 캔버스 floating aside에서 사이드바 속성 탭 전용 portal로 이동했다.
- 공통 접이식 패널을 사용하며 폼을 유지한 채 접거나 펼칠 수 있다. 접힘·속성 탭 비활성 상태에서는 world 드래그 핸들을 숨기고 dragging 상태를 해제한다.
- Escape 선택 해제와 경로 자동 저장·입력 보존을 유지했다.
- 원본 속성·고급 설정을 ON UPDATE 아래에 배치하고 원본 스크롤·패널 간격을 정리했다. 물리 관계가 없는 경우에도 고급 매핑 설정은 접근 가능하다.
- 관련 회귀 테스트 62개 및 전체 pnpm check 통과: 2,858개 테스트 통과(499개 조건부 건너뜀), 타입·포맷·빌드 성공. 기존 번들 크기 경고는 남아 있다.
- 브라우저 수동 시각 검증은 수행하지 않았다. DB 스키마나 운영 데이터 변경은 없다.
