# 원본 편집 동작을 Native 명령에 연결

- 컬럼 목록에 드래그 핸들과 위/아래 방향키 재정렬을 연결했다. 전체 소유 컬럼 ID를 전송하며 숨겨진 scope 컬럼을 누락하지 않는다.
- 서버의 reorder_columns 명령은 중복/누락/다른 테이블 ID를 거부한다. 다른 테이블의 배열 위치와 컬럼 원문은 보존한다. 기존 Native 변경 diff/동기화/이력 경로를 사용한다.
- 기본 정보, 컬럼, 키·PK/UNIQUE, 테이블 관계, 상세 DB 정보 그룹을 원본 PanelSection으로 구분했다. 컬럼 추가는 기존 가드가 있는 생성 폼으로 연결한다.
- 도메인 관계 생성과 구조 편집에도 원본 아코디언을 적용한다.
- 상단 undo/redo는 Native baseline과 durable queue를 통해 실행한다. 다른 사용자의 작업, 이미 보상된 작업, 형식 전환은 제외한다. redo는 해당 undo의 보상 연산이며 외부 revision 변경 시 local redo를 비운다. 오래된 작업은 히스토리에서 확인한다.
- 검증: 전체 타입 검사 통과, Native 서버 명령 테스트 10개 통과. 최종 통합 검사 결과는 UI 검증 로그에 기록한다.
