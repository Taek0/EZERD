# 상단 통합 도구 모음 QA

작성일: 2026-09-16

프로젝트 제목과 캔버스 도구를 같은 상단 행에 배치한 결과를 실제 App 메모리 fixture로 확인했다. 1512×827에서 캔버스 시작점이 약 176.5px에서 125px로 올라가 세로 작업 공간을 약 52px 확보했다. 테이블 뷰에서도 도구는 하나만 렌더링된다. 1280px에서 한 줄을 유지하고 1024px에서는 도구가 다음 행으로, 390px에서는 넘침 없이 줄바꿈된다.

기존 CSS 우선순위 때문에 일부 버튼이 14px/약 34px로 표시되는 것을 발견해 보정했다. 최종 도구 버튼은 13px/30px, 굵기 650이고 기본 텍스트 #244b7b와 가장 어두운 배경 #dce5f1의 대비는 약 6.98:1이다. 포커스 테두리 표시, ENUM/도메인 뷰 팝업, 선택된 테이블이 있는 상태에서 상단 버튼에 Delete를 눌러도 카드가 삭제되지 않음을 확인했다.

프로젝트 제목 공간은 창 너비에 따라 280~400px로 조절해 1512px에서 fixture의 긴 이름이 잘리지 않도록 보완했다. 관련 테스트 8개, 웹 타입 검사, 수정 파일 Prettier, 웹 프로덕션 빌드 통과. 브라우저 오류 없음. 실제 DB 데이터는 변경하지 않았다.
