# 다중 테이블 클립보드 구현 결과

## 변경

- 다중 선택한 테이블의 어느 컬럼을 우클릭해도 테이블 메뉴의 오려두기·복사하기가 우선 표시되며 선택이 유지된다.
- 도메인 캔버스 빈 공간의 우클릭 메뉴에 붙여넣기를 추가했다. 메뉴 붙여넣기는 클릭 위치, 단축키 붙여넣기는 현재 화면의 좌상단에서 일정 간격을 두고 배치한다.
- Ctrl/Cmd+C/X/V를 표준 클립보드 이벤트로 연결했다. 텍스트 입력·대화상자·메뉴·드래그 중에는 테이블 단축키를 가로채지 않는다.
- 테이블·컬럼·키·참조 ENUM·선택 내부 관계를 복사하고, 붙여넣을 때 ID와 참조를 재매핑한다. 테이블·키·ENUM 이름 충돌과 반복 붙여넣기를 처리한다.
- 오려두기는 완전한 클립보드 스냅샷을 먼저 보관한 뒤 테이블을 기존 모델 함수로 삭제한다. 선택 밖 테이블과의 연결은 삭제되며 붙여넣기에 포함되지 않는다.
- 소유 도메인에 붙여넣을 수 있고 도메인 맵·통합 뷰에서는 붙여넣기를 허용하지 않는다. 읽기 전용에서는 복사만 가능하다.
- 시스템 클립보드가 제한되면 탭 내 복사본으로 메뉴 및 Ctrl/Cmd+V를 지원한다. 시스템 복사 성공 시 fallback을 해제한다.
- 외부 클립보드의 형식·크기·스키마·소유 참조를 검증하며, 문서 제한 초과는 변경 적용 전에 차단한다. 비동기 붙여넣기 중 프로젝트·문서·뷰가 바뀌거나 컴포넌트가 해제되면 변경하지 않는다.

## 검증

- `table-clipboard`, `Canvas`, `canvas-selection`, `canvas-tool-shortcuts`: 4개 테스트 파일, 32개 테스트 통과.
- 테스트 범위: 내부 관계 선택, ID·컬럼·키 재매핑, ENUM 재사용과 충돌, 다른 도메인 붙여넣기, 잘못된 참조 거부, 반복 붙여넣기, 좌표 제한, 클립보드 fallback.
- 실제 Browser fixture에서 다중 선택 유지와 우클릭 메뉴를 확인했다.
- Ctrl+C/V: 테이블 2→4, 컬럼 10→20, 관계 1→2를 확인했다.
- Ctrl+X/V: 테이블 4→2→4, 오려두기 메뉴 후 Ctrl+V: 2→0→2를 확인했다.
- 빈 영역의 붙여넣기 메뉴로 2→4 복제를 확인했다.
- 읽기 전용에서는 Ctrl+X/V가 테이블 수를 바꾸지 않고 오려두기 메뉴가 비활성화된다.
- 텍스트 입력의 Ctrl+A/X/V 후 원본 텍스트가 유지되고 테이블 수가 변하지 않음을 확인했다.
- 웹 타입 검사·프로덕션 빌드 통과. 기존 번들 크기 경고가 남아 있다.
- `pnpm format`, `pnpm format:check`, `git diff --check` 수행. 임시 fixture는 제거했다.
- 실제 서버 동기화 및 실행 취소의 브라우저 종단 간 검증은 수행하지 않았다. 문서 변경은 기존 `onChange` 흐름으로 한 번에 전달한다.
