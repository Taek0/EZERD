# 설계 실행 취소·다시 실행

작성일: 2026-09-14

프로젝트별 최대100개의 설계 스냅샷 이력을 추가했다. 도메인·테이블·컬럼·키·관계·배치와 뷰 변경을 되돌린다. 동일 객체의 연속 입력·드래그는 UI 제스처 경계로 묶고, 새로운 편집은 redo 분기를 지운다. 입력 객체는 복제해 이후 변경과 분리한다.

Ctrl/Cmd+Z 실행 취소, Ctrl/Cmd+Shift+Z 또는 Ctrl+Y 다시 실행을 제공한다. 입력창·편집 가능한 텍스트 안에서는 브라우저 텍스트 실행 취소를 유지한다. 화면 이동/확대만 바뀐 경우에는 이력을 추가하지 않으며 설계 복원 시 현재 카메라를 보존한다.

일반 저장 후 이력은 유지하고 프로젝트 전환·최신 내용 다시 열기·브라우저 재시작에서는 새 이력으로 시작한다. 저장 응답이 늦게 돌아와도 undo/redo의 최신 문서를 덮어쓰지 않도록 revision을 단조 증가시킨다.

공유 핀·답글과 프로젝트 자체 삭제는 설계 문서 이력에 포함하지 않는다.

검증: 미구현 모듈 RED 후 이력 단위4개 GREEN. 실제 browser-undo-smoke에서 생성/undo/redo, 저장 후 이력, 지연 저장 응답,12단계 드래그1회 복구, 입력 native undo와 그룹 복구, 저장/재열기 초기화 통과.
