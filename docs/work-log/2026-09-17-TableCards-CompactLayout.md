# 테이블 카드 밀도 개선 결과

- 제목을 28px에서 24px로, 본문을 20px에서 18px로 조정했다. 한 줄 행 높이는 47px에서 37px로 줄였다.
- 헤더·컬럼 제목·푸터 여백과 컬럼 최소 폭을 줄이고, 내용 크기 계산과 CSS를 일치시켰다.
- 일반적인 짧은 이름의 5개 컬럼 카드 내용 크기는 442×309px이다. 긴 타입·설명은 계속 줄바꿈하고 카드 높이를 확장한다.
- 기존 저장 크기는 보존한다. 저장된 노드의 폭·높이를 자동 변경하지 않으며 내용에 의한 최소 크기만 줄였다.
- 검증: 카드 geometry, TableEditor, table-refinement, domain-view의 4개 테스트 파일 30개 테스트 통과. 웹 TypeScript 검사 통과.
- 환경의 `pnpm exec vitest` 경로 해석이 실패하여 같은 설치본 `node_modules/.bin/vitest.CMD`를 직접 실행했다.
