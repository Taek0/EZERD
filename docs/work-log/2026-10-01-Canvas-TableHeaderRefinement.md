# 테이블 헤더 배치·직접 입력 개선

- [계획과 통합 의견](../planning/2026-10-01-Canvas-TableHeaderRefinement.md)에 따라 전체 캔버스의 도메인 이름을 헤더 오른쪽으로 옮겼다. 접두어를 제거하고 도메인 이름은 13px, 제목은 26px로 표시한다.
- 제목 편집은 큰 공통 입력창 대신 제목과 같은 위치·크기의 투명한 native input을 사용한다. 배경·테두리·윤곽·그림자·추가 여백을 제거하고 길이는 기존 계약의 120자로 제한한다.
- 기존 검정 글자는 자동 대비 코드의 결과였다. 후속 요청에 따라 해당 계산을 제거하고 모든 테이블 이름을 흰색으로 통일했다.
- IME 조합 중 Enter가 편집을 조기에 확정하지 않도록 처리했다. 기존 컬럼 입력 방식은 유지한다.

## 검증

- 기존 TableEditor·table-appearance·Canvas 테스트 34개 통과.
- 웹 타입 검사와 빌드 통과. 마지막 색상 정책 수정은 기존 테스트에서 모든 배경의 흰색 제목을 검증했다.
- 브라우저에서 오른쪽 정렬·도메인 13px·제목 26px, 입력 배경 transparent·border 0·outline none·shadow none 및 높이 34px를 확인했다.
- Enter 저장, Escape 취소, 한국어 이름 입력 후 blur 저장을 확인했다. 초록 배경의 실제 헤더 글자색이 `rgb(255, 255, 255)`로 적용됨도 확인했다.
- 채택된 전체 캔버스·도메인 필터 통합은 다음 구현 단위에서 진행한다.
