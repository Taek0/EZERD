# 컬럼 타입 별칭 중복 제거 결과

- PostgreSQL 타입 목록과 별칭 정규화를 모델 공용 모듈로 추출했다. 내보내기와 편집 화면이 같은 대표 이름을 사용한다.
- 컬럼 생성, 상세 편집, 테이블 인라인 편집 목록에서 DECIMAL을 NUMERIC으로 통합하고 저장된 긴 시간 타입 별칭도 TIMESTAMPTZ, TIMETZ, TIMESTAMP, TIME으로 표시한다.
- 별칭이 저장된 컬럼의 현재 선택값과 목록을 함께 정규화하여 중복 항목과 잘못된 선택 표시를 없앴다. 같은 대표 타입을 재선택하면 저장된 이름, 매개변수, 배열 및 기본값을 그대로 유지한다.
- ENUM은 별도 식별자로 제공하고 알려지지 않은 사용자 타입은 보존한다. 길이·정밀도 입력과 기본값 선택도 동일한 별칭 처리를 적용한다.
- `pnpm typecheck` 통과.
- `pnpm test` 통과: 79개 파일, 409개 테스트 성공, 3개 파일 및 25개 테스트 건너뜀.
- 렌더링 회귀 테스트 2건 추가 후 관련 테스트 재실행: 5개 파일, 73개 테스트 성공. 실행 전 공용 패키지를 다시 빌드했다.
- `pnpm format` 및 `pnpm format:check`로 루트 포맷 확인.
- 사용자 관리 파일 `docs/EZERD.txt`는 수정하지 않았다.
