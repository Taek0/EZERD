# 새 테이블 도메인 선택 색상 표시

- 우측 새 테이블 생성 폼의 도메인 선택 목록과 선택값 앞에 각 도메인 색상 점을 표시한다.
- 기존 공통 Select의 renderOptionLeading 및 native-domain-option-dot를 재사용한다. 미소속·색상 미설정은 중립색 #8993a3를 사용한다.
- 기존 선택/생성 로직과 데이터 형식은 변경하지 않는다.
- 관련 기존 테스트 28개, 웹 타입 검사, 변경 파일 Prettier 검사 통과. 브라우저 시각 검증은 수행하지 않았다.
- pnpm 다운로드 DNS 제한으로 로컬 Node 도구를 직접 실행했다.
