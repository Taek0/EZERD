# MCP 워크스페이스 권한 적용 결과

- MCP 도구를 28개에서 44개로 확장했다. whoami와 공간 생성·목록·상세·변경·삭제, 멤버 목록·역할 변경·제거·탈퇴, 초대 생성·목록·받은 초대·수락·거절·취소를 추가했다.
- 공간 도구는 입력의 대상 ID와 별개로 MCP 토큰의 사용자 ID를 SpaceService에 전달한다. whoami는 사용자 ID·이름·색상만 반환한다.
- 모든 도구 실행 직전에 토큰 소유자·만료·폐기와 사용자 존재를 재검사한다. HTTP 요청별 인증과 서비스의 현재 멤버십 검사를 함께 사용한다.
- 프로젝트 생성·가져오기·변경·삭제·내보내기, 프로젝트 목록과 공유 스냅샷, 리뷰 목록·상세, 설계 이력 조회의 사용자 인자를 갱신했다. 문서 요약·뷰·테이블·관계·진단 도구는 권한이 확인된 스냅샷만 사용한다.
- 프로젝트 생성/가져오기에는 workspaceId가 필요하다. 조회 출력은 공유 프로젝트 계약의 workspaceId를 포함하고, 전송 문서의 project는 이름만 포함한다.
- 실제 MCP 통합 테스트에 공간 전체 생명주기, 외부 사용자 접근 거부, viewer 설계 변경 거부와 리뷰·개인 상태 허용, 보관 공간 리뷰 쓰기 거부, 멤버 제거 후 기존 토큰 조회 거부를 추가했다. 기존 테스트의 공간과 멤버 fixture 및 정리 순서를 갱신했다.

## 검증

- 서버 TypeScript 빌드 및 noEmit 타입 검사 통과.
- MCP 서버·문서·읽기·토큰·보안 단위 테스트: 5개 파일, 23개 테스트 통과.
- 새로 생성한 격리 PostgreSQL 데이터베이스에서 MCP HTTP 통합 테스트: 5개 테스트 통과. `node apps/server/scripts/test-workspaces.mjs apps/server/test/mcp.integration.test.ts`로 확인했고 운영 DB에는 이 테스트 데이터를 기록하지 않았다.
- 변경한 파일은 루트 Prettier 설정으로 포맷했다. 전체 저장소 검증과 논리적 단위 커밋은 통합 담당자가 수행한다.
- docs/EZERD.txt와 credential 원문은 읽거나 수정하지 않았다. git push는 수행하지 않았다.
