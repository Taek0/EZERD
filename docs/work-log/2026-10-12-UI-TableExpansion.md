# 테이블 확장 및 기본 접힘 결과

- 2026-10-12, codex/apple-ui-review.
- [계획](../planning/2026-10-12-UI-TableExpansionPlan.md)
- 데이터 모델 섹션, 도메인, 테이블의 기본 상태를 접힘으로 변경했다. 초기 선택으로 자동 펼치던 효과를 제거했다.
- 테이블 펼침 상태를 행 내부에서 프로젝트 탐색기의 ID별 상태로 이동했다. 선택/캔버스 범위 갱신과 행 재마운트 시에도 사용자가 펼친 상태가 유지된다.
- 이름 버튼에도 aria-expanded/aria-controls를 연결했다. 테이블 이름 클릭 시 확장과 선택을 수행하고 화살표로 접을 수 있다.
- 이전 코드의 실패는 테스트 데이터에서는 재현되지 않았다. 이번에는 키보드뿐 아니라 실제 마우스 클릭으로 검증했다.
- 새로고침 후 모델 open=false, 도메인 및 모든 테이블 aria-expanded=false 확인. 데이터 모델 → 주문 관리 → orders 이름을 차례로 마우스 클릭하면 aria-expanded=true 및 status 컬럼 버튼 visible=true 확인.
- 화면 전환 뒤 확장 유지 및 다시 접기 회귀 테스트 추가. 관련 3파일 27테스트 통과. 웹 타입 검사, 포맷 검사, 웹 빌드 통과. Vite 청크 크기 경고는 기존과 동일하다.
- 3002 최신 HTML/JS/CSS HTTP 200 확인. 검증용 5187 서버는 종료했다. 실제 DB 데이터 변경 없음.
