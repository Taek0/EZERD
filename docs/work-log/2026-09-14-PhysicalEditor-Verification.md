# 물리 전용 편집 UI 검증 결과

작성일: 2026-09-14

## 반영 사항
- 점 격자 크기를 키우고 프로젝트 상단과 갤러리·검토 대화·저장·알림 버튼을 축소했다.
- DDL 내보내기 UI, 논리/물리 선택, 적용 범위, 스키마, 테이블 주석, 메타데이터, 설계 확인을 화면에서 제거했다.
- 테이블 카드의 외부 여백을 제거하고 파란 제목 영역과 컬럼 행을 하나의 카드로 구성했다. 저장된 카드 크기·리사이즈 동작은 유지한다.
- comment 표기, 선택형 타입, 타입별 매개변수 활성화와 입력 범위 검증을 적용했다.
- 키는 작성 초안에서 컬럼을 선택한 뒤 확정한다. 작성 중 반복 추가를 차단한다. FK 관계는 출발 컬럼 선택 후 대상 키와 컬럼 대응을 확인한다.
- 도메인 맵 복귀 버튼을 강조했다.

## 검증
- pnpm check: 단위 테스트 98개, 타입 검사, 프로덕션 빌드 통과. DB 통합 전용 9개는 일반 실행에서 제외된다.
- 테이블 브라우저 검사: 빈 키/작성 중 반복 추가 차단, 복합 키 확정, 선택 없는 관계 추가 차단, 타입 드롭다운·조건부 매개변수·입력 범위 통과.
- 실제 앱 저장 검사: 더블클릭 편집·저장·재열기 및 숨긴 기존 논리 정보·스키마·기본값·메타데이터·배치 보존 통과.
- 데스크톱과 390px 모바일 화면 검토: 페이지 가로 넘침 없음. 프로젝트 제목 영역 68px, 주요 버튼 약 33px/13px.
- 기존 대형 청크 빌드 안내는 남아 있으며 빌드는 성공했다.

사용 안내: [물리 전용 편집 UI](./2026-09-14-PhysicalEditor-Usage.md).

## 최종 회귀 보완
- 제목 텍스트 드래그는 5px 이동 이후 시작하며 더블클릭 편집과 공존한다. 작은 이동·Enter/Escape·입력 선택·읽기 전용 회귀 검사를 실제 Chrome에서 통과했다.
- 전체 실제 앱 회귀 검사에서 물리 테이블 생성, 키/FK 가드, 외부 참조, 두 사용자 댓글·멘션·알림, 답글·해결·다시 열기, 대상 삭제 후 대화 보존을 확인했다. 페이지 오류 없음.
- 최종 제목 드래그 수정 후 웹 타입 검사와 프로덕션 빌드도 통과했다.
