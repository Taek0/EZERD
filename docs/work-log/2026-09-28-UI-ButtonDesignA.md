# 버튼 디자인 A 적용 기록

## 변경

- A안의 기본/주요 청회색 그라데이션, 8px 모서리와 부드러운 양방향 그림자를 공통 버튼 토큰과 스타일로 적용했다.
- 주요/보조/아이콘/탭 버튼의 호버, 눌림, 선택·펼침, 포커스와 비활성 상태를 공통화하고 위험 작업에는 옅은 붉은색을 유지했다.
- 프로젝트 툴바, 경로 이동, 사이드 패널, 홈 탭·카드 작업 및 줌 도구의 개별 색상·그림자 재정의를 제거했다. 기존 크기와 배치는 유지했다.
- 댓글 핀은 위치 표시 형태를 유지하면서 청회색 표면을 공유한다. 프로젝트 카드 제목과 목록 행 및 색상 견본은 기능별 표현을 유지한다.

## 검증

- `pnpm format`: 통과.
- `pnpm format:check`: 통과.
- `pnpm --filter @ezerd/web typecheck`: 통과.
- `node node_modules/vitest/vitest.mjs run apps/web/src/components/ui/ui.test.ts`: 5개 테스트 통과.
- `pnpm exec vitest`는 현재 실행 환경에서 실행 파일을 찾지 못해 설치된 Vitest의 Node 진입점으로 같은 테스트를 실행했다.
- 운영 DB를 쓰지 않는 가상 API 기반 실제 App 화면을 브라우저로 확인했다. 좁은 화면의 도메인 캔버스, 1280px 데스크톱의 테이블·사이드바·상단바를 검토하고 적용 이미지를 저장했다.
- ENUM 팝업을 열고 닫았으며 보조 버튼의 공통 그라데이션·8px 모서리·그림자가 적용됐음을 확인했다. 임시 화면 너비는 검증 후 복원했다.
