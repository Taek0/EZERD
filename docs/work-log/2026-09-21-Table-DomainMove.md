# 테이블 도메인 이동 결과

- 속성 사이드바 기본 정보에 소유 도메인 선택을 추가했다. 읽기 전용에서는 선택 컨트롤도 비활성화된다.
- 소유 도메인을 실제로 변경할 때 이전 도메인과 다른 일반 도메인의 테이블 배치를 제거한다. 대상 도메인의 기존 배치는 위치와 크기를 유지하며, 배치가 없으면 이전 소유 위치에 생성한다.
- 컬럼, 키, FK 정의와 테이블 ID는 보존한다. 양 끝 테이블이 없는 관계 경로를 제거하고 함께 보기 화면은 선택 도메인에 맞게 갱신한다.
- 동일 도메인에서 이름 등을 편집하면 외부 참조 배치를 유지한다. 저장 데이터 초기화나 기존 참조 일괄 수정은 수행하지 않았다.
- 검증: `pnpm test packages/model/src/relational.test.ts apps/web/src/TableEditor.test.ts` 통과(2개 파일, 23개 테스트). 이동 후 FK 보존, 기존/외부 배치 제거, 대상 배치 유지, 함께 보기 갱신, 삭제된 테이블 재생성 방지, 읽기 전용 도메인 컨트롤을 확인했다.
- `pnpm format` 적용 및 `pnpm format:check` 통과. 전체 통합 검증은 상위 작업에서 수행한다.
