# 브라우저 자동화 성능 측정 계획 문서화

작성일: 2026-09-28

- Browser 스킬의 실행 경로와 지원 API 확인 의무를 읽고 자동화 계획을 작성했다. 실제 브라우저 연결·테스트는 수행하지 않았다.
- 메모리 fixture, production 기반 테스트 진입점, 계측 어댑터·제어 패널 상태 계약, 작은 fixture의 안정성 점검, UI 시나리오, A/B 비교 및 중단·복구 절차를 구체화했다.
- browser 입력과 내부 재생, 앱 내부 시간과 도구 왕복 시간, 선택적 trace 및 수동 검증을 구분했다. 아직 구현하지 않은 도구·API는 예정 계약으로 표시했다.
- 7단계 조사 문서에 자동화 확장 경로를 연결하고 문서 안내에 링크를 추가했다. 기존 기본 경로와 새 자동화 경로의 관계를 명시했다.
- 시작 HEAD는 `0fd0a81`이며 다국어 지원 관련 별도 변경이 진행 중이었다. 해당 소스·스크립트 변경은 수정하거나 이번 커밋에 포함하지 않았다.
- 문서 diff 공백 검사와 로컬 링크 확인을 수행했다. Markdown은 Prettier 제외 대상이다. 전체 `pnpm format:check`는 동시 작업의 `apps/web/__language-qa.html`, `scripts/prepare-language-qa.mjs` 포맷 경고로 실패했다. 다른 작업을 변경하지 않기 위해 전체 `pnpm format`은 실행하지 않았다.
- 계측 구현·성능 측정·기능 테스트는 미실행이다. `docs/EZERD.txt`는 수정하지 않았다.
