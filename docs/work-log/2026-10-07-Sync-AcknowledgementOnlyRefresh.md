# 내 저장의 중복 문서 조회 제거

- 순서가 이어지는 정상 ACK에 포함된 authoritative 문서를 직접 사용한다. 동일 문서를 다시 GET하지 않는다.
- 중간 순서가 누락되거나 DB 컨텍스트가 달라 프로젝트 버전을 안전하게 판단할 수 없을 때만 백그라운드 전체 조회로 복구한다. 재전송된 과거 ACK는 현재 문서를 되돌리지 않는다.
- 동일한 테이블·컬럼 등 하위 데이터 참조를 유지하고, 위치·크기만 변경한 ACK는 DB 설계 검사를 다시 실행하지 않는다.
- 백그라운드 문서 반영은 React transition으로 처리한다. 최신 확정 문서 참조는 지연된 화면 렌더와 별도로 유지한다.
- 입력 이벤트에서는 후속 입력을 보관한 뒤 전송 처리를 다음 작업으로 예약한다. 빈 대기열의 주기 확인은 불필요한 저장 상태 토글을 만들지 않는다.
- 서버 API나 DB 스키마를 변경하지 않았다. 로컬 표시를 서버 승인으로 취급하거나 미확인 입력을 삭제하지 않는다.

## 검증

- 전체 `pnpm check`: 테스트 2,826개 통과, 506개 조건부 건너뜀. 타입·포맷·빌드 통과. 기존 번들 크기 경고는 남아 있다.
- 정상 ACK 시 재조회하지 않는 핸들러, 이벤트 이후 전송 예약, 참조 재사용, 중복 ACK·순서 누락·DB 컨텍스트 방어를 테스트했다.
- 브라우저 실측은 수행하지 않았다. 순수 장면 계산 성능 비교는 [별도 기록](2026-10-07-Canvas-SceneMeasurementReuse.md)에 기술했다.
