# 자동저장 대기와 로컬 이름 표시 분리 구현

- 현재 탭의 테이블/컬럼 이름 초안을 저장 intent보다 위에 투영한다. 초안 보관 알림으로 로컬 표시를 예약하므로 750ms 서버 quiet window와 ACK를 기다리지 않는다.
- 입력창은 기존 즉시 상태 갱신을 사용하고 문서 표시 갱신은 React transition으로 예약한다. 이미 보낸 요청은 변경하지 않으며 같은 폼의 기존 autosave가 전송 대기 동안 최신값을 유지한다.
- 이름 필드별 순서를 메모리 metadata로 추적한다. 다른 필드 수정/ACK before 재기준화가 오래된 이름의 우선순위를 올리지 않는다. 다른 writer 보관 초안을 자동 복구하지 않는다.
- 이름 전용 순수 투영은 구조/타입/legacy 값을 변경하지 않고 참조를 보존한다. 전송 큐 이름 투영도 테이블 이름까지 확장했다. 서버 검증은 기존대로 유지한다.
- 속성/인라인 ACK rebase는 확인된 snapshot을 사용한다. 로컬 표시값을 before로 채택해 후속 입력을 clean으로 오인하지 않는다. pristine 속성 폼은 표시를 따라가되 dirty 입력은 보존한다.
- 초기 전체 검사 성공(2,926 passed / 499 skipped) 후 ACK 추가 회귀를 보강했다. 인라인/속성 집중 51개 통과: 750ms 이전 표시, 최신값 한 번 전송, 전송 중 후속 입력, 이미 보낸 요청 불변, 실제 서버 baseline 유지.
- 삭제/관계/타입 등의 선반영은 아직 확대하지 않았다. 다른 편집기/탭의 전송 순서 정책과 기존 복구 정책도 변경하지 않았다. 최종 main 전체 검사 및 실제 입력 브라우저 검증을 이어서 수행한다.
