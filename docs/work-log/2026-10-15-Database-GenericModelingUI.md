# RDBMS 미지정 구조 모델링 — UI

- 프로젝트 DB 메뉴에 `선택안함`을 추가했다. 기존 확인 팝업으로 구조 모델링 용도와 DDL 제한을 안내하며 취소하면 이전 선택을 유지한다.
- 공통 타입과 `(직접 입력)`을 제공한다. 캔버스·사이드바에서 사용자 타입을 편집하고 공통 타입으로 되돌릴 수 있다.
- 직접 입력은 Enter로 저장하며 Tab은 다음 필드로 이동하며 저장한다. IME 조합 중 Enter는 저장하지 않는다.
- 사용자 타입과 공통 타입 모두 같은 문서 검증 경로를 사용하여 참조 PK/FK 타입 불일치 등의 오류를 저장 전에 확인한다.
- DDL 메뉴를 비활성화하고 이유를 표시한다. 프로젝트 JSON과 PNG 내보내기는 유지한다. 미지정 모드에서 DB 버전 및 엔진 전용 옵션은 숨긴다.
- 기존 공통 컴포넌트와 한·영 번역을 사용한다.

## 검증

- 갤러리 선택·팝업 취소, 사용자 타입 저장/수정, 비활성 DDL, SSR, Enter/Tab/IME 및 FK 불일치 회귀 테스트 통과.
- 전체 회귀 테스트 2,985개 통과 후 직접 입력 경로 추가 수정과 관련 테스트를 재검증했다. 웹 TypeScript 검사 및 Vite 빌드 성공.
- 기존 대형 번들 경고는 남아 있다. 브라우저를 실행한 수동 검증은 수행하지 않았다.
- 워크스페이스/초대/알림 폴링 최적화는 사용자 요청에 따라 논의만 했으며 코드 변경에 포함하지 않았다.
