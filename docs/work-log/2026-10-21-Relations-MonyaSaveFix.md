# Monya 관계선 저장 거부 수정

- 전체 테이블 화면의 단일·일괄 관계선 저장 전에 누락된 공유 테이블 배치를 구체화한다. 조회 보정과 같은 노드 ID 및 배치 규칙을 사용한다.
- 기존 배치와 메모·도메인별 경로는 수정하지 않는다. 추가 노드와 관계선은 동일 후보 문서로 원자적으로 저장되며 역변경으로 함께 복구된다.
- 수정 전 회귀 테스트에서 양쪽 테이블 부재 오류 재현, 수정 후 관련 21개 테스트 및 서버 TypeScript 빌드 통과.
- Monya version 10 원본과 실제 계산 명령을 로컬에서 재실행: 전체 테이블 노드 6개, 관계선 6개, DB 모델 검증 오류 0개.
- 실제 Monya 프로젝트에 쓰거나 호스팅 서버를 재시작하지 않았다. 재빌드·재시작 후 자동 관계선 정리를 다시 실행하면 적용된다. DB 마이그레이션은 없다.
