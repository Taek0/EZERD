# 한 페이지 PDF 내보내기

- 내보내기 메뉴에 PDF 내보내기 · 한 페이지를 추가했다. 현재 뷰·도메인 필터·논리/물리 모드의 전체 범위를 브라우저에서 벡터 PDF로 만든다.
- 기존 SVG 생성기를 재사용하고 PNG 픽셀 제한과 PDF 크기 계산을 분리했다. PDF 최대 변 14,400pt 내에서 비율을 유지한다. 화면용 정규화 문서를 사용해 원본의 누락 배치도 표시 범위와 일치시킨다.
- jsPDF 4.2.1 및 svg2pdf.js 2.8.1은 동적 import한다. PDF용 Nanum Gothic Regular/Bold TTF는 같은 서버의 로컬 정적 파일로 제공하고 PDF에 필요한 글리프를 포함한다. OFL 및 라이브러리 고지를 포함했다.
- 생성 도중 프로젝트·뷰·필터 등 문맥이 바뀌면 다운로드하지 않는다. 서버 이미지 렌더링은 추가하지 않았다. PNG 동작은 유지한다.
- 관련 테스트 43개, 웹 TypeScript 및 프로덕션 빌드 통과. 빌드의 기존 큰 청크 경고는 남는다. frozen-lockfile 설치 성공. core-js 설치 후 스크립트는 불필요하여 명시적으로 비활성화했다.
- 분리된 headless Chromium으로 실제 PDF를 생성해 Poppler 이미지로 시각 확인했다. 한글 컬럼 헤더가 깨지는 font-weight 600을 PDF용 700으로 보정 후 재검증했다.
- pypdf 검증: 페이지 1개, 한글 제목·컬럼·메모·관계명 추출 성공, 삽입된 래스터 이미지 0개. 관계선·까마귀발·메모 색상도 렌더링에서 확인했다. 테스트 파일은 .data에만 보관하고 임시 웹 페이지 및 QA 서버를 정리했다.
- 큰 범위는 페이지에 맞춰 축소하므로 PDF 뷰어에서 확대해 확인한다. 객체 수가 아주 많은 경우 브라우저의 처리 시간·메모리는 여전히 필요하다. 새 빌드 및 재시작 후 적용되며 DB 마이그레이션은 없다.
