# 전체 갤러리 UI 목업 재제작

- 사용자는 앞선 A안의 선택기뿐 아니라 전체 헤더·갤러리·카드·여백을 원한다고 명확히 했으며, 이번에는 목업 승인 후 실제 구현하도록 요청했다.
- `apps/web/gallery-redesign-preview.html`에 독립 목업을 작성했다. 기존 프로덕션 소스는 수정하지 않았다.
- 앞선 A안의 회청색 표면과 ERD 미리보기 카드, 전체 레이아웃을 유지하면서 제목·본문·보조 정보 글자 크기를 조정했다. 검색·보관·생성·관리 흐름은 메모리의 예시 데이터로 동작한다.
- 버튼과 메뉴 행에서 텍스트 선택을 방지하고 마우스 클릭에는 입력란 같은 포커스 테두리를 표시하지 않는다. 키보드 포커스는 유지한다. 메뉴 열기/닫기에 170ms 애니메이션 및 reduced-motion 대응을 추가했다.
- 브라우저에서 Edusync → TY 전환, 프로젝트 목록 갱신, 클릭/더블클릭 후 빈 텍스트 선택 상태와 BUTTON 포커스를 확인했다. 메뉴가 닫힌 전체 화면과 열린 상태를 이미지로 저장했다.
- 인라인 JS 구문 검사, 변경 HTML Prettier 검사, git diff 검사를 수행했다.
- 실제 서비스 UI 변경과 버그 수정 적용은 사용자 착수 승인 후 별도 구현한다.

## 후속 피드백 반영

- 현행 EZERD. 로고를 반영하고 사용자 확인에 따라 상단 헤더의 좌우 여백만 조정했다.
- 공간 메뉴 크기를 줄이고 하단 설명을 제거했다. 하단 세 메뉴의 글씨와 SVG 아이콘 두께를 높였다.
- 새 프로젝트 버튼과 카드 하단을 줄이고 생성 타일을 개선했다.
- 새 프로젝트 창의 DB 선택을 라디오 카드로 제공하고 선택된 DB가 예시 프로젝트 배지에 반영되는 것을 확인했다. 실제 다른 DB 엔진 지원은 구현하지 않았다.
- 프로젝트 더보기와 정렬을 브라우저 기본 메뉴·전체 화면 창 대신 앵커 팝오버로 구현했다. 메뉴 동작과 MySQL 선택 후 예시 카드 배지를 브라우저로 확인했다.
- 변경 HTML Prettier 및 인라인 JavaScript 구문 검사를 통과했다. 실제 서비스 소스는 변경하지 않았다.

## 비율 및 현행 에셋 재조정

- 헤더 공간 선택기를 높이 36px의 한 줄로 축소했다. 화살표는 단일 SVG의 0/180도 회전으로 수정했다. 하단 세 메뉴는 13px로 줄였다.
- 탭 표시줄을 텍스트 가까이 배치하고 현행 프로필 버튼과 상시 알림 벨을 넣었다.
- 본문 상단은 현행 gallery hero의 44px 제목과 여백을 기준으로 공간명 및 파란 점을 표시한다.
- 실제 tokens.css, ui.css, confirm.css를 참조해 기본 버튼·입력·팝업을 현행 에셋으로 맞췄다. 정렬은 자체 메뉴, DB 선택은 라디오 카드를 유지한다.
- 좁은 화면과 1280px 데스크톱 배치를 확인했다. 선택기 36px, 화살표 SVG 1개 및 180도 회전, 빈 텍스트 선택 상태를 브라우저에서 검증했다. 현행 confirmation-dialog 클래스와 팝업 제목 크기도 확인했다.
- 검증용 화면 크기를 복원했으며 여전히 목업만 변경했다.
