# 핀 패널 경계 드래그 적용

작성일: 2026-09-15

Astra가 작성한 PinPanelResizer를 핀 패널 왼쪽 경계에 추가하고 내부 슬라이더를 제거했다. 왼쪽으로 끌면 넓어지고 오른쪽으로 끌면 좁아진다. 기존 280~560px 제한과 브라우저 너비 저장을 유지하며 드래그 중 너비 전환 애니메이션은 해제했다.

포인터 캡처, 취소·캡처 상실·언마운트 정리를 지원한다. 경계선에 키보드 초점을 두고 좌우 화살표·Shift·Home·End로 조절할 수 있다. 모바일에서는 저장 너비 대신 실제 표시 너비를 드래그 시작값으로 사용한다. 패널 자체의 중복 z-index가 경계선을 덮는 문제를 브라우저에서 재현해 보정했다.

검증: 슬라이더가 남아 있으면 실패하는 브라우저 테스트를 먼저 작성했다. 타입 검사와 너비 보정 단위 테스트 통과. 실제 브라우저에서 280→420px 드래그, 키보드 최대 너비, 새로고침 복원, 모바일 경계선 히트와 실제 너비 기준 축소를 확인했다. 기존 이름/PIN 재접속·색상·핀 검증도 통과했다. 최종 웹 빌드 성공, 기존 대형 번들 경고만 남아 있다. 테스트에서 생성한 사용자·프로젝트만 정리했다.
