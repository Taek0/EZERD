# 핀 삭제 API와 충돌 방지

작성일: 2026-09-14

DELETE /threads/:id에 expectedUpdatedAt을 요구한다. 트랜잭션에서 핀을 잠그고 최신 시각을 비교하여 새 답글·상태 변경이 있는 경우409로 거부한다. 성공하면 해당 핀·답글·연관 알림만 삭제하고 다른 핀과 사용자 데이터는 유지한다.

핀 갱신 시각은 밀리초 단위로 단조 증가시켜 같은 시각의 연속 요청도 오래된 삭제 확인을 구분한다. API는 {id,deleted:true}를 반환한다.

미구현404 RED 후 상태 충돌·본문 검증·연관 답글/알림 정리·다른 핀 보존을 실제 PostgreSQL로 검증했다. HTTP 통합12개 통과, 테스트가 만든 레코드만 정리했다.
