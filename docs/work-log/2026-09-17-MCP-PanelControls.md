# MCP·알림 패널 조정

MCP 폭을 460px, 기본 글꼴을 13px로 축소했다. 알림 폭은 320px이며 화면 폭에 맞춰 제한한다. 두 패널에 진입/종료 애니메이션과 reduced-motion 대응을 적용하고 바깥 클릭/Escape로 닫는다.

폐기된 토큰 행에 삭제 버튼을 추가했다. DELETE /api/mcp-tokens/:id/record는 인증 세션의 사용자 ID·토큰 ID·revoked_at IS NOT NULL을 하나의 삭제 조건으로 검사한다. 활성 토큰, 다른 소유자 및 미인증 요청은 삭제하지 않는다. 기존 폐기 API는 유지하고 감사 로그는 남긴다.

검증: MCP 단위 테스트 6개, 전체 검사 313개 및 격리 PostgreSQL/API/WS 통합 테스트 23개 통과. 실제 DB 통합에서 활성/미인증/다른 소유자 삭제 거부와 본인 폐기 토큰 삭제를 확인했다. 브라우저 메모리 fixture에서 폭·폰트·애니메이션, 폐기 행 제거, 외부 클릭 닫기와 알림 토글을 확인했다. 실제 사용자 토큰은 변경하지 않았다.
