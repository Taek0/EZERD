# 도메인 캔버스 편집 개선 결과

작성일: 2026-09-14

- 도메인 생성, 관계 생성, 관계 검색, 관계 목록을 독립적으로 접을 수 있게 구성했다. 관계 생성 명령은 해당 편집 영역을 열고 출발 도메인을 채운다.
- 신규 도메인의 기본 색상을 회색으로 설정하고 제목을 27px로 키웠다. 기존 사용자 지정 색상은 보존한다.
- 빈 캔버스 우클릭에 도메인 생성·관계 생성·자동 배치를 추가했다. 테이블 화면에서는 현재 뷰 자동 배치를 제공한다.
- 카드 우클릭 직접 연결 후 대상 도메인을 클릭하면 관계를 생성하며 Escape로 취소한다. 출발 카드와 연결 미리보기를 표시한다.
- 같은 도메인 쌍의 복수 관계는 별도 곡선과 라벨 위치로 분리했다.
- 카드 선택 시 연결 관계 목록을 바로 펼쳐 보여준다. 연결 도메인 강조는 관련 없는 카드와 선만 흐리게 하며 문서는 변경하지 않는다.
- 테이블 FK 대상 클릭과 확인 대화상자, 관계 삭제 콜백을 통합하고 테이블 생성 도구를 선택 없는 속성 패널로 배치했다.

## 검증

- `pnpm --filter @ezerd/web typecheck` 통과.
- `scripts/browser-domain-workflow-smoke.mjs` 실제 Chrome 통과: 초기 접힘 상태, 복수 곡선, 직접 연결/Escape, 선택 후 관계 목록, 강조 시 문서 불변, 관계 폼 생성, 수동 자동 배치, 회색 도메인 생성.
- 테스트는 임시 Vite 페이지에 격리된 문서를 구성하며 데이터베이스나 사용자의 저장된 프로젝트를 변경하지 않는다. 임시 파일은 종료 시 제거한다.
- 브라우저 캡처에서 기본 카드 크기 보정과 자동 배치 간 높이 차이를 발견했다. 실제 렌더링된 카드의 사각형 충돌 검사를 추가해 RED를 재현하고, 배치 모듈의 최소 크기 반영 후 GREEN을 확인했다.
- 우클릭 생성 위치는 해당 생성 명령에만 적용한다. 이후 툴바 생성이 이전 우클릭 위치를 재사용하지 않는 회귀 검사도 통과했다.
- 선택 도메인의 연결 관계 목록을 위치·크기 입력보다 앞, 설명 바로 아래로 올려 쉽게 확인하도록 했다.
