# 메모 배경색 적용

- 메모의 선택 색상을 카드 전체 배경에 그대로 적용하고 상단 4px 강조줄을 제거했다.
- 배경의 상대휘도에 따라 검정·흰색 중 대비가 높은 글자색을 적용한다. 직접 편집 입력도 투명 배경과 동일 글자색을 사용한다.
- PNG 내보내기에도 같은 배경색과 글자색을 적용했다. 기존 저장 데이터 형식은 유지한다.
- Astra가 UI와 출력 코드를 수정했다. 관련 UI·PNG 테스트 30개, 공유 패키지 빌드, 웹 타입 검사 및 변경 코드 Prettier 검사 통과.
- pnpm 실행은 Corepack 다운로드 DNS 오류로 사용할 수 없어 설치된 로컬 도구를 직접 실행했다. 브라우저 시각 검증은 수행하지 않았다.
