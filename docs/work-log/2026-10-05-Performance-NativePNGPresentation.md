# Native PNG 표현 일치 결과

2026-10-05. 화면과 같은 색상 헤더·도메인/스키마 배지·컬럼 제목/폭·PK/FK 행 배경·NULL/comment 열, 관계선 카디널리티·라벨 배경을 SVG/PNG 출력에 적용했다. endpoint 메타데이터와 marker path 정의는 화면/PNG가 같은 helper를 사용한다. 텍스트/색상 XML escaping, 출력 범위/픽셀 한도, 저장본/권한/개인 상태 export guard는 유지했다. 카드/컬럼 clip으로 긴 텍스트가 다른 카드에 넘치지 않게 했다. 기본 light 출력이며 브라우저 테마·폰트 렌더링과 픽셀 단위 동일성을 보증하지 않는다.
