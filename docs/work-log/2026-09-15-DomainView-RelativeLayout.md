# 도메인 뷰 선택과 상대 배치

작성일: 2026-09-15

Astra 담당자가 설계·작성한 UI와 helper를 주 에이전트가 적용했다. 하위 에이전트의 승인 대기가 반복돼 코드 작성과 실행을 분리했다. 이름 입력·새 뷰·보기 삭제·저장뷰 목록을 제거하고 체크박스와 적용/닫기로 단순화했다. 현재 뷰 또는 기존 첫 뷰 ID를 재사용하여 반복 적용시 새 뷰가 늘어나지 않는다.

각 테이블의 소유 도메인 원본 좌표 차이를 보존하고 실제 카드 너비를 고려해 도메인 사이 180px 간격을 둔다. 원본·다른 저장뷰·노트는 보존하고 재배치되는 현재 뷰의 수동 관계 경로만 초기화한다. 먼저 실패 테스트를 작성한 뒤 구현했으며 상대 위치·뷰 재사용·기존뷰 보존·외부 참조 좌표 배제 테스트 4개와 web typecheck가 통과했다.

실제 브라우저에서도 체크박스만 있는 선택 UI, 즉시 적용, 원본 좌표 차이, 도메인 구역 간격, 반복 적용시 동일 뷰 ID 유지가 통과했다. 검증 스크립트는 scripts/browser-domain-view-refinement-smoke.mjs다. 임시 HTML을 생성하는 브라우저 스크립트들은 Vite 전체 새로고침 영향을 피하도록 순서대로 실행한다.
