# 관계선 중첩 재확인 결과

- 전체 도메인 결합 화면 all-tables를 MCP로 재조회했다.
- 이전 작업 완료 시 개인 버전 4에 관계선 경로 24개가 있었고 재조회 일치까지 확인했다.
- 이번 조회에서는 개인 버전 5, 관계 경로 0개였다. 테이블 17개의 좌표·크기는 이전 입력 스냅샷과 완전히 같았다.
- 따라서 현재 화면은 이전에 개선한 경로가 아닌 기본 자동 경로를 사용한다. 어떤 조작이나 저장이 경로를 제거했는지는 확인되지 않았으며 특정 사용자 동작이나 앱 결함으로 단정하지 않는다.
- 저장된 routing-result.json의 검증된 경로 24개를 개인 버전 5 기준으로 복구했다. 적용 후 개인 버전 6.
- MCP 결과 재조회: 경로 24개 값 일치, 테이블 배치 유지.
- 앞선 0건 지표는 정확한 공선 중첩에 한정된다. 점 교차 22건과 가까운 평행선·라벨·화살표의 시각적 중첩 가능성은 남는다. 이번에는 브라우저 화면을 직접 검사하지 않았다.
- 애플리케이션 코드 변경 없이 원격 상태 복구와 기록만 수행했다.
