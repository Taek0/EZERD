# 선택적 변경 집합 ACK

- 브라우저가 native commands/operations에 `x-ezerd-native-ack: delta-v1`을 보내면 서버가 확인한 변경 집합, 적용 전 sequence, 적용 후 projectVersion을 반환한다.
- 원본 요청/fingerprint는 유지한다. 서버 원장에는 전체 문서도 유지하여 구형 클라이언트·기존 replay·히스토리 호환성을 보존한다. 신규 필드는 기본 HTTP/이벤트/취소 응답에서 제거한다. 과거 ACK에 delta가 없으면 전체 응답을 사용한다.
- 브라우저는 연속 sequence와 정확한 version일 때만 변경 집합을 적용한다. 순서 누락·문맥 변경·적용 실패는 기존 재조회 경로로 복구한다.
- 구조 공유는 entity ID를 기준으로 이전 객체를 찾아 삭제/재정렬 이후 남은 카드의 참조를 보존한다. 일반 값 배열은 위치 기준을 유지한다.
- lab 전체 검사 통과: 2,936 tests, 499 skipped, 포맷·타입·빌드 정상. 경량/전체 결과 동등성, 구형 포맷, 순서/버전 누락, 중복 ACK, 객체 참조 회귀 포함.
- DB 원장/베이스라인의 전체 문서 저장 비용은 이 변경으로 제거되지 않는다. 네트워크/클라이언트 JSON 검증 비용을 줄이는 단계다.
