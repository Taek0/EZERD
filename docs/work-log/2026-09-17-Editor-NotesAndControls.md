# 편집 도구·메모·애니메이션 변경

## 구현

- 상단의 편집 도구 그룹을 우측에 배치하고 텍스트 도구를 메모로 표시한다. 기존 더티 responsive-shell.css는 수정하지 않고 별도 editor-feedback.css를 추가했다.
- 컬럼 속성의 별도 ENUM 선택 상자를 제거하고 전체 폭의 타입 검색에 ENUM 옵션을 통합했다. ENUM과 일반 타입 간 전환 시 배열 여부를 유지한다.
- 메모는 더블클릭 또는 키보드 Enter로 편집한다. Enter 줄바꿈, blur 또는 Ctrl/⌘+Enter 저장, Escape 취소를 지원한다. 사이드바의 공통 색상 선택기를 사용하며 옅은 배경과 색 띠로 가독성을 유지한다.
- 모델과 계약에 선택적 메모 색상을 추가했다. 기존 무색 메모는 호환된다. JSONB 문서 필드 추가로 DB 마이그레이션은 필요하지 않다.
- 공통 Accordion, 테이블 관계 고급 설정, ENUM 목록을 AnimatedDetails로 통합했다. 열기/닫기를 Web Animations API로 처리하고 빠른 반전 클릭과 reduced-motion을 처리한다. ENUM 항목 진입 및 편집 폼 전환 애니메이션도 추가했다.
- 긴 텍스트 히스토리는 제목을 짧게 유지하고 글자 수로 변경을 표시한다. 원본 operation 데이터는 보존한다.

## 검증

- 단위 테스트 283개 통과, DB 통합 테스트 20개는 실행하지 않았다.
- 웹/서버 TypeScript 검사, Vite 프로덕션 빌드, 변경 파일 Prettier 검사 통과.
- 날짜가 바뀌어 24시간 기준을 넘긴 sync-client 테스트 fixture는 Date만 고정하도록 보완했고 해당 테스트 19개도 통과했다. 실제 동기화의 유효기간은 변경하지 않았다.

## 이전 시도의 검증·커밋 차단

브라우저 스킬로 연결 후 실제 로컬 QA 페이지 열기를 요청했으나 자동 승인 검토의 429 호출 한도 오류로 거부되었다. 실제 열기/닫기 동작, 메모 편집/색상, 타입 검색 및 툴바 배치를 시각적으로 검증한 상태는 아니다. 다른 브라우저나 간접 실행으로 우회하지 않았다.

Git 커밋 명령도 같은 자동 승인 오류로 차단됐다. 수정은 작업 트리에 있고 커밋은 아직 없다. 재개 시 히스토리, 메모 모델/계약, 편집 UI/애니메이션, 날짜 독립 테스트 보완을 논리 단위로 커밋한다. 기존 responsive-shell.css 변경, __responsive-qa.html, 2026-09-16-Editor-MergedToolbarQA.md는 사용자 기존 변경으로 보존한다.

prepare-editor-feedback-qa.mjs는 메모리 API/WS만 사용하는 별도 QA fixture 생성기다. 실제 DB 쓰기는 없다. 생성한 임시 HTML, 브라우저 탭/뷰포트와 이번 QA 서버는 종료·정리한다.

## 재시도 완료

사용자 재시도 요청 후 브라우저와 Git 권한 검토가 정상 처리됐다. 실제 App과 메모리 API fixture에서 다음을 확인했다.

- 메모 더블클릭 편집, 줄바꿈 보존 및 Ctrl+Enter 저장, Escape 취소.
- 공통 색상 선택기로 #12B76A 선택 및 팝업 종료 후 값 유지.
- 사이드바 위치/크기 항목 열기·닫기 및 닫힌 입력 비표시. 테이블 사이드바의 기본 정보·컬럼·추가·키·관계·고급 설정 모두 공통 AnimatedDetails 사용 확인.
- ENUM 팝업 생성, 항목 펼치기, 편집 폼 전환. 타입 검색에서 ORDER_STATUS · ENUM을 선택한 뒤 VARCHAR로 전환하고 길이 입력 활성화 확인. 별도 ENUM 선택 상자는 없다.
- 1280px 및 MacBook 기준 1512×827 CSS 뷰포트에서 툴바 도구가 저장/핀 그룹 오른쪽에 배치되고 문서 가로 넘침이 없는 것을 DOM 좌표로 확인.

단위 테스트 283개, 웹/서버 타입 검사와 빌드의 기존 통과 결과를 유지한다. DB 테스트 20개는 제외됐고 실제 DB 쓰기는 수행하지 않았다. 검증은 Chromium 기반 브라우저에서 수행했으며 실제 macOS Safari 검증은 별도다. 히스토리, 메모 모델, 날짜 독립 테스트, 편집 UI를 독립 커밋으로 정리했다. 기존 더티 반응형 파일과 사용자 QA 문서는 포함하지 않는다.
