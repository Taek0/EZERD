# 히스토리 표시 개선

- 내부 경로 대신 객체 이름과 변경 종류, 가능한 경우 변경 전후 값을 표시한다.
- 삭제된 객체 이름을 이력에서 복구하고, 변경되지 않은 키 배열은 변경 내역에서 제외한다.
- 기본 표시는 최대 3개 항목·항목당 140자이며 더보기로 전체 표시 내용을 펼친다. 원본 이력 데이터는 변경하지 않는다.
- 기존 공통 펼침 컴포넌트로 애니메이션과 접근성 속성을 유지한다.
- 관련 회귀 테스트 7개와 웹 타입 검사를 통과했다.
- 전체 `pnpm check`도 통과했다. 테스트 2,774개 통과, 502개 건너뜀, 빌드 성공이며 번들 크기 경고는 남아 있다.
- 저장 충돌 정책은 변경하지 않았다. [개선안](../../docs/planning/2026-10-07-Sync-ConflictRecoveryUX.md)에 원인과 단계별 권장 방향을 기록했다.
