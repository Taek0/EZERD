# 관계선 자동 정렬 UI 구현

- 계획: [구현 계획](../planning/2026-10-15-Relations-AutoArrangeImplementationPlan.md).
- 캔버스 자동 배치 메뉴에 기존 테이블 배치와 관계선 배치 하위 메뉴를 추가했다. React Aria의 메뉴 포커스, 방향키, Escape, 좌우 공간 판정을 재사용한다.
- 전체 테이블/필터 없음에서만 관계선 정렬을 실행하며 Worker 컨트롤러와 실제 저장 접수 ID를 연결했다. 카메라 이동은 입력 검증을 재실행하지 않는다.
- 계산 중 보기·모드·필터·도메인 탐색 및 직접 경로 편집을 막고, 테이블 이동·팬·줌은 유지한다.
- 카메라 컨트롤 왼쪽에 지연 표시하는 단일 live-region 알림을 배치했다. 취소, 완료 후 실행 취소, 변경 유형별 안내, 확인된 혼잡 테이블 이름 및 reduced-motion을 지원한다.
- 관계선 호버·키보드 포커스·선택 시 실제 연결 컬럼을 강조한다.
- 검증: 실제 jsdom 하위 메뉴/알림 2개 테스트 통과. 기존 캔버스·테이블·프로젝트 화면 6개 파일 94개 테스트 통과. web TypeScript 검사 통과.
- 전체 포맷/제품 빌드 및 브라우저 검증은 통합 작업에서 함께 수행한다.
