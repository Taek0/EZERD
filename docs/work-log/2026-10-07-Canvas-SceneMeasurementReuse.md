# 캔버스 이동 계산 중복 제거

- 한 번의 장면 계산에서 테이블·도메인·메모·경로를 인덱싱하고 테이블별 치수와 컬럼 행 측정을 재사용한다.
- 관계마다 같은 테이블의 전체 컬럼·키·관계를 재탐색하던 계산을 줄였다. 문서 간 캐시를 사용하지 않아 데이터 변경이 즉시 반영된다.
- 장애물 기반 선 배치 알고리즘은 변경하지 않았다.
- 테이블당 컬럼 15개·체인 FK·10회 표본의 Vite SSR 순수 장면 계산 비교: 30개 테이블 중앙값 2.67→1.06ms, 100개 12.62→5.37ms, 200개 40.52→15.68ms. 실제 브라우저 프레임 시간 측정은 아니다.
- 중복 배열 탐색 횟수와 변경 문서 재측정 회귀 테스트를 추가했고 관련 캔버스 테스트 33개와 웹 타입 검사를 통과했다.
