# 개발 서버 WebSocket 프록시 수정

작성일: 2026-09-15

실제 5개 브라우저 검사에서 첫 변경은 초기 REST 조회로 보였지만 두 번째 변경은 실시간으로 전파되지 않았다. Vite의 /api 프록시에 ws 설정이 빠져 브라우저의 동일 출처 WebSocket 연결이 API 서버로 전달되지 않는 것이 원인이었다. Astra low가 읽기 전용으로 원인을 확인했고 Sol medium이 ws: true를 추가했다.

웹 타입 검사·프로덕션 빌드·git diff --check 통과. 변경 적용에는 개발 서버 재시작이 필요하다. 실제 WebSocket 프레임과 5개 세션 전파 확인은 브라우저 수용 검사에서 계속 진행한다.
