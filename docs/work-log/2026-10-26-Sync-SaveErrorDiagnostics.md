## 오류 전달 개선

- API 응답의 오류 코드·요청 ID·최대 3개 필드 진단을 보존한다. 요청 본문·서버 원문 메시지·중첩 상세는 노출하지 않는다.
- HTTP 거부 후 취소 ACK를 받더라도 최초 실패 원인을 저장 큐 반환값에 유지한다. 승인 또는 no-op 처리에는 오류를 붙이지 않는다.
- 화면에서 용량 초과·입력 검증·충돌·DB 문맥 변경·삭제 식별자 충돌을 구분하고 오류 코드와 가능한 요청 ID를 표시한다.
- 관련 5개 파일 67개 테스트, 웹 타입 검사 및 포맷 검사 통과. 호스팅 서버 재시작이나 실제 프로젝트 저장은 수행하지 않았다.
