# 상단바 버튼 기본 상태 대비 개선 기록

## 변경

- 프로젝트 편집기의 `.editor-heading` 범위에서만 공통 버튼 토큰을 재정의했다.
- 기본 버튼은 청회색 그라데이션, 주요 버튼은 조금 더 짙은 청회색으로 조정했다. 기존 부드러운 그림자에 얇은 안쪽 경계를 더해 마우스를 올리지 않아도 윤곽이 보이게 했다.
- 호버·선택·눌림 색상도 단계적으로 짙게 조정했다. 공통 비활성 투명도, 포커스 표시와 A안의 모서리·입체감을 유지했다.

## 검증

- 설치된 Prettier의 Node 진입점으로 변경 파일을 포맷하고 `--check`를 통과했다. `pnpm exec prettier`는 현재 셸에서 실행 파일을 찾지 못했다.
- `git diff --check` 통과. 변경 범위가 상단바 토큰과 작업 문서에 한정됨을 확인했다.
- CSS 색상만 변경하여 별도 동작 테스트를 추가하지 않았다. 실제 브라우저의 육안 확인은 수행하지 않았다.
