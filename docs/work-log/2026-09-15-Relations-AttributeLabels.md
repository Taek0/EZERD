# 테이블 관계 속성 라벨

작성일: 2026-09-15

관계선의 표시를 출발 PK 속성:참조 FK 속성으로 변경했다. 예시는 id:user_id이며 테이블명은 표시 라벨에서 제외한다. 복합 관계는 tenant_id:tenant_id · id:user_id처럼 정의된 대응 순서의 속성 쌍을 표시한다. 속성이 없으면 식별자 대신 ?를 사용한다. 기존 논리 관계명은 툴팁에 유지한다.

표시 함수의 회귀 테스트를 먼저 실패 확인한 뒤 구현했다. 단일/복합/누락 속성 테스트와 기존 관계 렌더링 테스트를 통과했다. 실제 브라우저에서 새 라벨로 관계 선택·경로 드래그·자동 정리·빈 영역 선택이 정상 동작함을 확인했다. 담당 파일에 Prettier를 적용했다.
