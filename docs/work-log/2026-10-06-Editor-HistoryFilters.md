# 이력 작업 종류 필터

- [계획](../planning/2026-10-06-Editor-IssuesHistoryFilters.md)에 따라 추가, 수정, 이동, 크기 변경, 순서 변경, 삭제, 관계, 데이터베이스 변경 필터를 추가했다.
- 서버 변경 경로와 존재 여부를 기준으로 분류한다. 여러 작업이 섞인 이력은 해당하는 모든 필터에 표시하며, 전체 변경 내용을 그대로 유지해 실행 취소와 삭제 복원의 작업 단위를 바꾸지 않는다.
- 전체 필터는 변경 목록이 없는 거부 이력이나 알 수 없는 형식도 유지한다.
- 불러온 이력만 필터링한다는 안내와 일치/불러온 건수, 빈 결과 안내를 한국어와 영어로 제공한다. 더 보기 버튼과 기존 사용자, 시간, 상태, 복구 동작은 유지한다.
- 혼합 작업의 중복 분류, 원본 변경 내용 유지, 위치/크기/순서/DB 경로, null 속성 값, 전체 필터 복원을 테스트했다.
- 관련 테스트 4개 파일, 16개 항목, 웹 TypeScript 검사, 변경 소스 Prettier 검사가 통과했다.
- 브라우저에서 실제 클릭 및 API 페이지 로딩 검증은 수행하지 않았다.
