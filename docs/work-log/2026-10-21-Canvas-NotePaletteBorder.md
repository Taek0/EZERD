# 메모 기본색 및 테두리 수정

- 고정 테두리색 #ded9bf를 제거하고 메모 배경과 같은 색상을 화면 및 PNG에 사용한다.
- 기본색 미지정 메모는 기존 #fff3c4 노란색을 유지한다. 생성 코드도 색상을 미지정하며 회색을 기본으로 저장하는 경로는 확인되지 않았다. 배포·캐시 상태는 검증하지 않았다.
- 선택 상태에서도 메모색 테두리를 유지하고 외부 선택 윤곽선으로 선택 여부를 표시한다.
- 기본 노랑·밝은 색·어두운 색의 UI/PNG 및 CSS 회귀 테스트 39개, 웹 타입 검사, 변경 파일 포맷 검사 통과.
- pnpm 다운로드 DNS 제한으로 설치된 로컬 도구를 직접 실행했다. 브라우저 시각 검증 및 기존 프로젝트 데이터 변경은 하지 않았다.
