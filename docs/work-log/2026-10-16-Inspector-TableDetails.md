# 테이블 헤더 색상 및 접히는 설명

- 선택된 테이블 헤더의 이름 앞에 소속 도메인 색상 점을 추가했다. 테이블 자체 색상은 사용하지 않으며 도메인 색상 미지정/미소속은 중립색으로 표시한다. 도메인명은 접근성 이름과 title에 제공한다.
- 메모·관계·도메인이 실제 선택 헤더를 차지할 때는 이전 테이블의 색상 점을 표시하지 않는다.
- 편집용 NativePropertyEditor의 테이블 comment/definition과 읽기 전용 기본 정보의 설명을 PanelSection으로 감싸 기본 닫힘으로 구성했다. 컬럼 설명은 변경하지 않았다.
- 필드는 닫힌 상태에서도 마운트를 유지하여 초안·자동 저장을 보존한다. 기존 텍스트 영역 ResizeObserver가 열릴 때 너비 변경을 감지해 높이를 계산한다. 읽기 전용 설명은 테이블 변경 시 기본 닫힘을 재적용한다.
- 관련 7개 파일 46개 테스트, 웹 TypeScript·전체 Prettier·Vite 빌드 통과. 기존 JS 번들 크기 경고는 남아 있다. 이번 작업은 실제 사용자 프로젝트나 DB를 변경하지 않았다.
