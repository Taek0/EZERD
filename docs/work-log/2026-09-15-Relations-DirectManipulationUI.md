# 관계 선 직접 조작 UI 작업 기록

- 별도 관계 선 조절 버튼을 제거하고 각 직선 구간에 14px 드래그 영역을 추가했다.
- FK/PK 끝점에 카드 테두리 재배치 조작과 선택 표시를 추가했다. 방향키 및 Shift 방향키 조절을 지원한다.
- SVG 화면 변환 행렬과 부모 그룹 포인터 캡처를 사용한다. 이동 중에는 미리보기만 적용하며 포인터 종료 시 최신 문서에 조작 의도를 한 번 저장한다.
- Escape, 포인터 취소, 캡처 상실, 읽기 전용 전환 및 해제 시 미리보기를 복원한다. 동시 변경된 도메인·반대쪽 접점·offset을 보존하며 원격 삭제한 관계를 복구하지 않는다.
- 검증: `node node_modules/vitest/vitest.mjs run apps/web/src/table-relations-sync.test.ts` 8개 통과. 담당 TSX/CSS/테스트에 루트 Prettier 적용. 최종 타입 검증은 병행 구현 중인 routing 유틸리티 통합 뒤 수행한다.
