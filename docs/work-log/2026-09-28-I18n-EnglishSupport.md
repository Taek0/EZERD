# 한국어·영어 UI 지원

## 변경

- 상단 프로필 메뉴에 언어 변경을 추가했다. 한국어/English 라디오 선택 즉시 UI를 전환하고 `ezerd.locale`에 저장한다. 기본값은 한국어이며 브라우저 저장소가 차단돼도 현재 세션 전환은 가능하다.
- 홈·인증·프로필, 캔버스·도메인·관계, 테이블·컬럼·ENUM, 핀·히스토리·MCP·프로젝트 전송과 공통 대화상자의 UI 문구를 번역했다. 날짜와 React Aria 접근성 기본 문구도 선택 언어에 맞춘다.
- 공통 번역 API와 기능별 영어 사전을 사용한다. 같은 한국어의 의미가 다른 문맥(수정/수정일, 속성/컬럼 속성)은 문맥 키로 구분하고 중복 번역은 통일했다.
- 사용자 데이터는 그대로 유지하며 기존 문서 및 DB 구조를 변경하지 않는다. 모델이 생성하는 기존 기본 이름과 사용자 작성 내용은 UI 번역 대상에서 제외한다.

## 검증

- 웹 타입 검사, 전체 빌드 및 Prettier 검사 통과. 기존 Vite 번들 크기 경고는 유지된다.
- 전체 단위 테스트 368개 통과, 25개 제외. 이후 문맥 번역 및 React Aria 언어 적용 보완 후 관련 테스트 29개와 웹 타입 검사를 재확인했다.
- 기존 한국어 회귀 테스트 및 영어 렌더링에서 사용자 이름·ENUM 값·SQL 표현·문서 불변성 검증.
- 실제 App과 가상 API를 사용하는 브라우저 화면에서 프로필 메뉴, 영어 선택, 새로고침 유지, 영어 도메인/테이블 화면, 한국어 복귀를 확인했다. 운영 API와 DB에는 쓰지 않았다.
- 언어 선택 모달의 영어 적용 스크린샷을 사용자에게 제공했다. 임시 QA 파일은 제거했다.

## 범위

- 설정은 브라우저별이며 다른 기기나 계정에 동기화되지 않는다.
- 사용자 작성 데이터 및 서버·모델이 제공하는 미등록 진단 원문은 자동 번역하지 않는다. 추가 언어는 같은 번역 사전을 확장하여 지원한다.
