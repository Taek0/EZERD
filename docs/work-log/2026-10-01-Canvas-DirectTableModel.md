# 전체 테이블 캔버스 모델·계약 구현

- [구현 계획](../planning/2026-10-01-Canvas-DirectTableImplementation.md)에 따라 `domainId: null`인 테이블과 예약 전체 뷰 `__tables__`, 선택적인 HEX `Table.color`를 지원한다.
- 직접 생성한 테이블은 전체 캔버스에 배치하고 도메인에서 생성한 테이블은 소속 화면과 전체 캔버스에 같은 ID로 배치한다. 기존 소속 화면만 있는 문서도 진단·계약에서 계속 수용한다.
- `ensureTableCanvasLayout`은 기존 위치를 보존하며 누락된 전체 배치를 결정적으로 추가한다. 반복 적용은 같은 객체를 반환한다.
- 소속 지정·변경·해제는 전체 위치와 테이블 색상·모델을 유지한다. 전체 배치는 참조 제거로 삭제할 수 없으며 테이블 삭제를 사용한다.
- 전체 뷰의 자동 배치, 메모, 관계선, 개인 viewport와 공유 설계 저장 경계를 지원한다. DDL은 미소속 테이블을 허용하되 잘못된 도메인 참조는 계속 진단한다.
- 명시적 색상 해제와 HEX 검증, 예약 ID 충돌 거부를 추가했다.

## 검증

- `pnpm build:shared`: 모델·계약 빌드 통과.
- `pnpm exec vitest run packages/model packages/contracts`: 23개 파일, 172개 테스트 통과.
- 도메인 0개인 두 테이블의 PK/FK와 PostgreSQL DDL, 소속 변경·해제, 위치·색상 유지, 기존 문서의 결정적 정규화, 공유 메모/개인 viewport, 파일 색상 왕복을 검증했다.
- 변경 파일에 루트 Prettier 설정을 적용했다. 서버·웹 통합과 전체 검증은 다음 작업 단위에서 진행한다.

## 기존 배치 정규화 보완

- 여러 도메인의 원점이 겹치면 누락된 전체 배치를 격자로 추가하여 캔버스가 한 줄로 길어지는 것을 방지했다. 소속 화면의 기존 좌표는 유지한다.
- 40개의 겹치는 소속 배치를 사용해 전체 화면의 결정적 격자와 기존 문서 진단을 검증했다.
