# 갤러리 요소 크기 조정 결과

- 상단 로고 31→34px, 모바일 로고 28→30px, 오른쪽 문구 12→13px로 확대했다.
- 진행 중/보관함 공통 카드 너비 180→200px, 내부 여백 10→14px로 확대했다.
- 좁은 화면에 대응하는 min(100%, 200px) 규칙을 유지했다.
- 검증: pnpm --filter @ezerd/web build 통과(TypeScript 검사 포함), git diff --check 통과.
- 빌드에서 500kB 초과 JavaScript 청크 경고가 발생했다. 브라우저 시각 검증은 수행하지 않았다.
- 기본 실행 환경의 샌드박스 초기화 실패로 승인된 외부 실행 경로를 사용했다.
- 기존 문서 재정리 변경은 이 작업 커밋에 포함하지 않는다.
