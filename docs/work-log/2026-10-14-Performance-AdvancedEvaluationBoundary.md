# 접힌 고급 편집기 평가 축소

- 최초 펼침 전 폼 마운트를 생략하고, 복구 대상이 있으면 즉시 열린 상태로 생성한다.
- 한 번 열린 폼은 접혀도 유지하여 초안과 자동저장 lifecycle을 보존한다. 접힌 상태에서 before와 같은 초기 값의 후보 평가는 생략하되 변경된 값은 기존 검증/저장을 수행한다.
- 인덱스 후보 평가의 동일 render 내 결과를 재사용한다. 권한/snapshot 변경 전달은 유지한다.
- 집중 회귀 21개: 기존 ACK/복구/자동저장, 접힌 dirty 인덱스·CHECK 저장, 최초 마운트 생략과 복구 표시 통과. 후속 ACK 표시 개선과 함께 전체 검사를 진행한다.
