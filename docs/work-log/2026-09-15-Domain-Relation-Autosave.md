# 도메인 관계 즉시 편집 결과

- 기존 관계의 출발·도착·이름·방향·설명은 변경 이벤트에서 해당 필드만 최신 문서에 패치한다. 관계 수정 버튼을 제거하고 신규 관계 연결 버튼은 유지했다.
- 동일 도메인 선택은 비활성화하고 빈/유효하지 않은 끝점은 저장하지 않는다. 빈 이름은 별도 초안과 안내를 표시하며 마지막 저장 이름을 유지한다.
- 원격 문서의 값을 직접 표시하며 원격 삭제된 관계를 재생성하지 않는다. 다른 필드 편집이 원격 변경이나 빈 이름 초안을 함께 전송하지 않는다.
- 프로젝트 전환 시 App의 Canvas `key={opened.project.id}`로 편집 상태가 초기화됨을 확인했다.
- 검증: domain-relation-edit 테스트 7개 통과, web typecheck 통과.
