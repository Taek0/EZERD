# 탐색 토글 피드백 수정 결과

- 2026-10-12, codex/apple-ui-review.
- [계획](../planning/2026-10-12-UI-NavigatorFeedbackPlan.md)
- 탐색기 화살표를 공통 SVG로 통일했다. 데이터 모델 섹션도 앞쪽에 배치하며 닫기 애니메이션의 목표 상태를 즉시 반영한다.
- 탐색기 aria-expanded에 공통 버튼 선택 배경이 적용되는 충돌을 제거했다. 선택된 테이블 행과 키보드 포커스 표시는 유지한다.
- 워크스페이스 트리거와 자식에 user-select:none을 적용했다. 입력 필드에는 적용하지 않는다.
- 테이블 이름 클릭 시 setExpanded(true)를 명시해 이미 선택된 테이블도 접힌 컬럼을 다시 펼친다.
- 브라우저: 선택된 orders 접기 false → 이름 재클릭 true. 펼친 도메인의 두 버튼 배경 및 테두리 투명 확인. 접힘 화살표 -90도, 펼침 0도. 워크스페이스 메뉴 열기/Escape 닫기와 트리거/텍스트 user-select:none 확인.
- 관련 4파일 21테스트, 포맷 검사, 웹 타입 검사 및 빌드 통과. 기존 청크 크기 경고 유지.
- 3002 최신 HTML/JS/CSS 응답 정상. 임시 5187 서버 종료. 실제 DB 데이터는 변경하지 않았다.
