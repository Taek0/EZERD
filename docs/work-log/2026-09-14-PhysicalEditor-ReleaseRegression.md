# 물리 모델 편집기 출시 회귀 검증

작성일: 2026-09-14

## 변경

- `scripts/browser-release-smoke.mjs`의 테이블 생성 흐름을 물리명과 물리 컬럼만 사용하는 UI에 맞췄다.
- 새 키 초안이 열린 동안 추가 버튼이 비활성화되고, 컬럼 선택 전에는 키를 생성할 수 없는지 검증한다.
- FK 출발 컬럼 선택 전에는 관계 추가 버튼이 비활성화되고, 선택 뒤에만 대상 테이블 연결을 시작하는지 검증한다.
- 테이블은 물리명으로 찾고, 외부 참조는 목록 탭의 다른 도메인 테이블 항목에서 추가한다.
- PostgreSQL DDL 내보내기와 논리/물리 표시 모드가 노출되지 않는지 검증한다.
- 오래된 도메인 속성 패널 검사는 제거하고, 이 회귀의 핵심인 테이블·댓글 흐름을 위해 두 임시 도메인을 모델 API로 시드한다.

## 검증

다음 명령으로 로컬 API(3001)와 Vite(5173)에 연결해 실제 Chrome 회귀를 실행했다.

```powershell
$env:EZERD_PLAYWRIGHT_MODULE='file:///C:/Users/nty43/AppData/Local/OpenAI/Codex/runtimes/cua_node/a708e72b10c27b59/bin/node_modules/playwright/index.mjs'
node scripts/browser-release-smoke.mjs
```

결과: 통과.

- 물리 전용 테이블 생성, PK 생성 가드, FK 생성 가드와 매핑, 외부 참조 추가·제거
- 저장 응답의 물리 테이블 범위와 관계 수
- 두 사용자 댓글, 멘션 알림과 읽음 처리, 답글, 해결·다시 열기
- 댓글 핀 이동, 테이블 삭제 뒤 대화 보존, 빈 공간 댓글, 도메인 삭제 뒤 안전한 개요 이동
- DDL 내보내기 버튼 및 표시 모드 선택 UI 부재
- 갤러리 카드 상호작용과 모바일 가로 넘침 부재
- 브라우저 페이지 오류 없음

종료 처리에서는 이번 실행이 생성한 프로젝트 ID 한 건과 사용자 ID 두 건만 삭제한다. 기존 프로젝트와 사용자 레코드는 수정하거나 삭제하지 않는다.
