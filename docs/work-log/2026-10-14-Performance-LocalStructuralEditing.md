# 저장 큐의 구조 편집 로컬 선반영

- 컬럼 전체 속성, 테이블 속성, 테이블/컬럼/관계 삭제, FK 생성·수정, 키 추가·수정을 영속 저장 큐에서 화면에 투영한다.
- 타입/DB 문맥은 모델 편집 함수를, 연쇄 삭제는 기존 삭제 계획 함수를 재사용한다. 관계/키 패치 처리는 contracts로 공유하여 서버와 브라우저의 null/deferrable 의미를 일치시킨다.
- 미지원 명령이 섞인 배치와 실패한 배치는 부분 표시하지 않는다. 실제 서버 승인 여부와 영속 요청을 변경하지 않는다.
- 삭제 후에는 투영 문서에서 선택 객체가 조회되지 않으므로 속성 UI가 사라지고, 거절 시 확인 문서로 돌아오며 원본 거절 기록은 보존된다.
- 26개 집중 회귀 및 웹 타입 검사 통과. 오프라인 이름, 새 저장소 reader 복구, 지연 ACK, 삭제 거절 복구, 리비전 변경, FK 생성/수정/연쇄 삭제를 포함한다.
- 자동저장 이전의 자유 입력 초안 투영은 기존 이름 범위다. 나머지 속성은 유효 명령이 저장 큐에 들어간 시점부터 선반영한다.
