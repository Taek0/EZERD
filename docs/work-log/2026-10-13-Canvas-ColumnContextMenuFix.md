# 컬럼 우클릭 메뉴 응답 및 실행 수정

## 원인과 변경

- 컬럼 우클릭으로 셀이 포커스되면서 인라인 편집과 속성 패널 선택 처리가 먼저 실행됐다. 비편집 셀의 보조 버튼 입력은 포커스를 이동하지 않도록 하고 메뉴 열기는 카드 내부 상태만 갱신하도록 변경했다.
- 메뉴를 열기 위한 유효성 검사에서 메뉴 정책을 중복 계산하던 경로를 제거했다. 마우스 입력은 포인터 좌표를 사용하고 키보드 입력에만 행 위치를 측정한다.
- React 포털 메뉴의 클릭이 캔버스 캡처 핸들러까지 전달되어 손 도구에서 차단됐다. 캔버스 DOM 외부의 클릭 및 키 입력은 캔버스가 처리하지 않도록 변경했다.
- 컬럼 속성·추가·삭제·PK·관계 작업은 기존 대상 식별자와 검증 경로를 유지한다. 기존 입력 필드의 우클릭 및 키보드 메뉴 열기를 유지한다.

## 검증

- 수정 전 포털 메뉴 클릭 차단과 키 입력 가로채기를 회귀 테스트로 재현했다.
- 관련 테스트 103개 및 웹 TypeScript 검사 통과.
- 최종 `pnpm check` 통과: Prettier, 전체 타입 검사, 테스트 2,887개 통과 / 499개 건너뜀, 서버·웹 빌드 성공.
- 빌드의 번들 크기 경고는 남아 있다. 실제 브라우저에서 메뉴 표시 시간은 측정하지 않았다.
