# MCP 수직 계층 및 권장 간격 반영

- 같은 도메인은 상위 테이블을 위, 종속 테이블을 아래에 배치하고 형제 테이블은 같은 행에 정렬하도록 지침을 구체화했다.
- 테이블 테두리 간 권장 간격은 캔버스 좌표 기준 200px 이상으로 변경하고 가로/세로 간격 계산식을 명시했다.
- 실제 관계 방향과 순환 관계 의미는 보존한다. 도메인 구역을 정한 뒤 크기/간격과 경로를 정리하는 기존 순서를 유지한다.
- diagnose_layout의 기존 40px 진단 임계값은 변경하지 않았다. 200px 정책 충족 여부는 별도 좌표 확인이 필요함을 명시했다.
- 기존 프로젝트 배치와 자동 배치 알고리즘은 수정하지 않았다. MCP 등록/지침 테스트 16개와 포맷/diff 검사 통과.
- 실행 중 MCP에 반영하려면 서버를 재빌드·재시작하고 클라이언트 연결을 갱신해야 한다.
