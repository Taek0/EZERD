# 프로젝트 설계 파일 내보내기·가져오기 구현

작성일: 2026-09-17

## 구현

- `GET /api/projects/:id/export`: 서버의 단일 최신 스냅샷에서 이름과 설계 문서만 반환한다. 인증·계정·대화·이력·동기화 메타데이터는 포함하지 않는다.
- `POST /api/projects/import`: 세션 인증 후 엄격한 파일 계약과 기존 모델 참조 진단으로 검증하고 단일 INSERT로 새 활성 프로젝트를 생성한다. 프로젝트 ID와 버전·동기화 기준은 새로 만들고 문서 내부 ID는 보존한다.
- 형식 `ezerd-project`, 버전 1, 파일 2 MB 제한, 문서 1.5 MB와 기존 객체 수 제한을 사용한다. 미래 버전과 알 수 없는 필드를 거부한다.
- 가져오기 버튼은 선택 파일 검증 후 이름과 도메인·테이블·컬럼·관계·ENUM·메모·저장된 뷰 수를 표시한다. 가져오기 중 중복 요청을 막고 오류를 표시한다. 내보내기는 서버 연결이 필요하며 브라우저의 미동기화 문서로 대체하지 않는다.
- App 연결은 상위 작업에서 담당한다. `ProjectImportButton`의 `onImported(project)`와 `exportProjectFile(projectId)`를 제공한다.

## 검증

- 신규 서버/웹 단위 테스트 9개 통과: 반복 가져오기, ID 보존, 개인정보 필드/미래버전/참조/좌표 거부, 저장 실패, 서버 스냅샷 범위, 인증 선행, UTF-8 파일 크기, 안전한 다운로드 파일명.
- 공유 패키지 빌드와 서버·웹 타입 검사 통과.
- 실제 PostgreSQL API 통합 테스트를 추가했다. ENUM·PK·FK·참조 동작·메모·레이아웃·저장 뷰를 왕복하고, 실패 시 행 미생성, 반복 가져오기 독립성, 가져온 설계의 새 동기화 편집을 확인한다. 전체 격리 DB 실행 결과는 상위 작업 기록에 남긴다.
- `pnpm format` 적용. 기존 사용자 프로젝트와 인증 데이터는 수정하지 않았다.
