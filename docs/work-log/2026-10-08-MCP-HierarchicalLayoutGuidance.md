# MCP 계층 배치 및 경로 검증 지침

- 핵심/상위와 종속/하위의 계층 및 도메인 구역을 먼저 정하고 카드 크기·간격을 확정한 다음 관계선을 정리하도록 명시했다.
- 기존 카드 간 최소 40px 간격에 더해 카드 중첩과 관계선의 비연결 카드 관통을 금지하고, 연결 카드도 올바른 연결 지점에서만 접촉하도록 했다.
- 선이 같은 구간에 포개지지 않도록 경로를 분리한다. 복잡한 그래프의 불가피한 교차는 최소화하고 남은 교차를 보고한다.
- 카드 사각형·선분 좌표로 확인하며 카드 전용 diagnose_layout 결과를 관계선까지 검증한 것으로 해석하지 않도록 구분했다.
- MCP 지침 전달 테스트를 포함한 등록 테스트 13개를 통과했다. 배치 알고리즘이나 운영 프로젝트 좌표를 변경한 작업은 아니다.
