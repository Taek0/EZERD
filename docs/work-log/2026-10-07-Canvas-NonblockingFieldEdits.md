# 응답 대기와 필드 편집 분리

- 동일 셀의 다시 편집·Tab 이동과 관계 경로 폼의 다음 제출이 서버 ACK를 기다리던 가드를 제거했다.
- 제출 리비전별로 중복 요청만 막고 새 리비전의 입력은 즉시 받는다. 저장 성공은 여전히 실제 서버 승인으로만 판단한다.
- 제출한 이름·타입은 로컬에 표시하고 이전 ACK·거부 응답이 이후 입력을 지우지 않도록 보호한다. ACK 전에 타입을 원래 값으로 되돌리는 경우도 실제 후속 변경으로 보낸다.
- 공유 편집의 문서 버전 진행은 자동 반영하되 DB 설정 변경·권한·개인 화면 CAS 보호는 유지한다.
- 관련 테스트 58개 및 웹 타입 검사를 통과했다. 지연 응답 중 동일 객체 두 번 이동, 같은 셀 반복 편집, 타입 되돌리기, 후속 입력 보존을 포함한다.
