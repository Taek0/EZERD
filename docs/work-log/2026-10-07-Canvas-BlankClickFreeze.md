# 빈 캔버스 클릭 흰 화면 수정

- HTTP 환경처럼 `crypto.randomUUID`가 없는 조건에서 선택 해제 후 새 테이블 폼을 렌더링하면 예외가 발생하는 경로를 재현했다.
- 새 객체와 FK 컬럼 ID 생성에 기존 호환 UUID 함수를 사용하도록 수정했다.
- 포인터 캡처가 해제될 때 해당 포인터의 선택 사각형과 이동 상태를 정리한다.
- 회귀 테스트는 실제 선택 해제 경로, UUID API 부재, 정상 재선택, 캡처 해제 및 다른 포인터의 간섭을 검증한다.
- 실제 Mac Chrome 기기에서의 재현·수정 확인은 수행하지 않았다. 사용자 증상과 일치할 수 있는 코드 경로를 모사 환경에서 확인했다.
- 전체 `pnpm check` 통과: 포맷·타입 검사, 테스트 2,774개 통과(502개 건너뜀), 빌드 성공. 번들 크기 경고는 남아 있다.
