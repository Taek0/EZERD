# DB 변경 테스트의 폐기된 개인 상태 기대값 정리

- 모드 전환 관련 회귀 검사 중 DB 변경 테스트가 이미 폐기된 개인 localStorage 키로 작업이 차단되기를 기대하고 있었다.
- 공유 작업 대기 검증에는 실제로 보호해야 하는 history 키를 사용하도록 수정했다.
- 별도 테스트로 옛 개인 키가 남아 있어도 DB 변경을 준비할 수 있고 해당 로컬 원문은 삭제하지 않음을 확인했다. 제품 동작 변경은 없다.
- DB 변경 테스트 54개를 포함한 관련 4개 파일 81개 테스트 통과.
