# 도메인 설명과 계층 배치 결과

- 프로젝트: 169ab1bb-b2e7-4db7-8112-f927ec4c3334.
- 도메인 5개에 역할, 구성 테이블, 다른 영역과의 연결, JSONB/FK 예외를 설명했다.
- 도메인별 화면은 내부 FK를 기준으로 깊이를 계산하고 부모를 자식 그룹의 중심에 정렬했다. 동기화 4개 테이블은 직접 FK가 없으므로 같은 깊이에 배치했다.
- 전체 화면은 17개 테이블을 실제 FK 계층별로 묶어 기존 도메인별 세로 누적 공백을 제거했다. 감사 테이블에는 가상의 부모 관계를 만들지 않았다.
- 같은 계층의 카드 폭은 맞추고 높이는 콘텐츠에 맞췄다. 관계 경로는 부모 우측/자식 좌측을 사용하며 계층을 건너뛰는 선에는 상단 우회 경로를 지정했다.
- Overview 카드 크기를 440×420으로 확장해 도메인 설명 공간을 확보했다.
- 최초 공유 배치 요청은 결합 화면의 개인 노드를 포함해 거부됐고 변경은 적용되지 않았다. 공유 화면과 개인 결합 화면을 분리하여 각각 정상 적용했다.
- 공유 변경 sequence 2, 전체 물리 ERD 개인 상태 version 1.
- 7개 화면 전체 재조회: 최소 40px 간격 위반 0건, 표시된 FK의 부모→자식 수평 계층 위반 0건.
