# 관계선 자동 정렬 구현 및 통합 검증

## 구현 결과

- 사용자 명시 실행 시에만 Web Worker에서 관계선 전체 정렬을 계산한다. 전체 테이블·필터 없음 조건에서만 활성화하고 도메인 화면에서는 비활성화한다.
- 네 면 균등 포트, 혼잡 면 분산, 카드/메모 회피, 이미 배치된 선의 점유 비용 및 제한 재탐색을 구현했다. 테이블 위치는 바꾸지 않는다.
- 기존 자동배치에 테이블 배치/관계선 배치 하위 메뉴를 추가했다. 계산 중 모드·필터 전환은 잠그고 팬·줌은 허용한다. 하단 도구 왼쪽의 진행·취소·완료·공간 부족 안내와 관계 컬럼 강조를 연결했다.
- 관계선 호버 강조는 테이블별로 분리해 무관한 테이블 행의 memo 참조를 유지한다.
- 경로 일괄 명령으로 100개 초과 관계도 한 operation/트랜잭션/히스토리 단위로 저장한다. 로컬 projection을 먼저 적용하며 ACK를 기다려 편집을 막지 않는다.
- 계산 중 이동은 최신 위치에서 기존 경로 처리로 보정한다. 구조·카드 크기 변경은 중단한다. 서버의 안전한 충돌은 전체 최적화를 재실행하지 않고 1회 보정 재시도한다.
- 전송 중 취소는 먼저 로컬 복구 표식을 기록한다. 서버가 이미 승인했으면 정확한 승인 시퀀스까지 화면 반영을 기다린 후 관계선만 되돌린다. 보상 히스토리 작업 ID도 저장해 ACK 유실/재시작 시 동일 작업을 확인한다.
- no-op의 취소 ACK를 실제 승인으로 오인해 Undo를 표시하지 않도록 확인한다. 다른 편집을 문서 전체 복원으로 덮어쓰지 않는다.

## 검증

- `pnpm check` 통과: 포맷·전체 타입 검사·2,983 tests passed / 499 skipped·제품 빌드. 266 test files passed / 28 skipped. 테스트 실행 19.56초.
- 기존 웹 테스트의 수동 scene 호출은 새 상태 훅에 맞춰 공용 driver로 전환했고 기존 단언을 보존했다. 전체 검사에서 발견된 온라인 이벤트 등록 문제는 React 렌더 중 등록하지 않고 커밋된 update에서만 연결하도록 수정했다.
- `EZERD_PANEL_INTERACTIONS=1 EZERD_PANEL_DETAIL=1 pnpm perf:build` 통과. 별도 Worker 번들은 약 28KB. 기존 메인 번들 청크 크기 경고는 남아 있다.
- 임시 `ezerd_qa_*` PostgreSQL DB를 생성·마이그레이션·제거한 실제 HTTP 검증 통과: 150개 경로 단일 저장, 동일 operation ACK 재전송, 잘못된 관계의 원자적 거절, 버전 충돌, 이후 노드 이동을 유지하는 경로만 undo.
- 순수 알고리즘 및 기존 routing parity 25개 검증 통과. 컨트롤러·저장·기존 canvas interaction 집중 검증 72개 통과. 전체 검사에 포함된 테스트와 중복 집계하지 않는다.
- 정적 빌드 Chrome fixture(실제 문서 복제, 서버 쓰기 차단) 검증: 하위 메뉴, 도메인/필터 활성 시 비활성, 계산 중 모드/필터 잠금, ACK 전 로컬 표시, 저장 대기 중 잠금 해제, 61개 경로 저장, 61개 경로 history undo 확인.
- 동일 fixture에서 응답을 보류하고 취소한 뒤 늦은 승인 ACK를 전달했다. `history undo confirmed · 292 · 61 paths`와 `관계선 정리를 되돌렸어요`를 확인해 전송 경합 보상 동작을 검증했다.
- 재시작/오프라인/공동 편집 경합은 단위 테스트와 코드 재검토로 확인했다. 모든 장애 조합을 실제 브라우저에서 재현했다는 뜻은 아니다.

## 성능·품질과 제한

- 물리 화면 43테이블·15메모·61관계 로컬 측정에서 기본 계산 약 1.8초. 순수 알고리즘 시간이며 UI 적용·서버 저장 시간은 제외한다.
- 최종 자동 결과: 교차 91, 중첩 길이 99(월드 좌표), 간격 위반 0. 기존 수동 저장 경로: 교차 53, 중첩 0, 간격 위반 24. 균등 간격을 얻었지만 정교한 수동 경로보다 교차가 많을 수 있으며 완전 무교차 최적해를 보장하지 않는다.
- 첫 버전 계산 제한: 테이블+메모 256개, 관계 1,000개, 경로 계산 시도 2,048회, 격자 탐색 노드 300,000개. 기본 개선 1회.
- 저장 제한: 한 배치 1,000경로, 전체 경유점 8,192개, JSON UTF-8 600,000 bytes. 기존 문서 전체 1.5MB 및 히스토리 1,000변경 제한은 유지한다.
- 관련 상세 기록: [알고리즘](2026-10-15-Relations-AutoArrangeAlgorithm.md), [저장](2026-10-15-Relations-BatchStorage.md), [Worker/복구](2026-10-15-Relations-AutoArrangeIntegration.md), [UI](2026-10-15-Relations-AutoArrangeUI.md), [QA](2026-10-15-Relations-AutoArrangeIntegrationQA.md).
