# 설계 확인 항목 접기와 펼치기

- [계획](../planning/2026-10-06-Editor-IssuesHistoryFilters.md)에 따라 설계 확인 항목에 공통 DisclosureButton/Collapse를 적용했다.
- 처음에는 목록을 펼쳐 기존 가시성을 유지한다. 제목에 항목 수를 표시하고 접힌 목록은 키보드 탐색과 접근성 트리에서 제외된다.
- 기존 안내 문구, 항목 클릭 시 문제 객체로 이동하는 동작을 유지한다.
- 렌더링 회귀 테스트에서 기본 펼침 상태, 연결된 접근성 속성, 공통 애니메이션 클래스와 기존 안내 문구를 검증했다.
- 웹 TypeScript 검사와 변경 소스 Prettier 검사를 통과했다. NativeProjectView 테스트를 포함한 관련 테스트 4개 파일, 16개 항목이 통과했다.
- 실제 브라우저 상호작용 검증은 수행하지 않았다.
