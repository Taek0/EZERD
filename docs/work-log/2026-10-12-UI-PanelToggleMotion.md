# 패널 토글 배치 및 모션 결과

- 2026-10-12. [계획](../planning/2026-10-12-UI-PanelToggleMotionPlan.md)
- 탐색 패널의 표시 여부를 hidden 대신 너비/투명도/visibility 전환으로 처리한다. 220ms 너비, 160ms 투명도 전환이며 중간 재열기가 가능하다.
- 내부 패널은 고정된 사용자 너비를 유지해 접는 동안 텍스트가 재배치되지 않는다. 닫히면 inert/aria-hidden 처리한다.
- 드래그 중에는 전환을 제거해 포인터에 바로 반응하며 reduced-motion에서는 애니메이션이 없다.
- navigatorControl을 별도 전달하여 탐색기 버튼은 상단 왼쪽, 속성 버튼은 오른쪽 끝, 핀 버튼은 그 왼쪽으로 배치했다.
- 속성 버튼에 공통 300ms hover/focus 툴팁을 연결했다. 현재 상태에 따라 속성 패널 열기/숨기기를 안내한다.
- 브라우저 1600px 화면: 좌측 버튼 x=20, 우측 버튼 right=1580 및 툴바 우측 경계 일치. 닫힌 패널 width=0/inert=true, 재열기 width=320 확인. 키보드 포커스로 속성 패널 숨기기 툴팁 표시 확인. OS 모션 설정은 변경하지 않았다.
- 관련 3파일 34테스트, 타입 검사, 포맷 검사, 웹 빌드 통과. 기존 Vite 청크 크기 경고 유지.
- 3002 최신 정적 자산 HTTP 200 확인. 임시 5187 검증 서버 종료. 실제 DB 변경 없음.

## 푸시 전 전체 회귀 검증 보완
- 기존 탐색기 테스트의 hidden 속성 확인을 새 애니메이션 래퍼의 inert/aria-hidden 확인으로 갱신했다. 선택 시 기존 컬럼 편집기를 열고 문서를 변경하지 않는 검증은 유지한다.
