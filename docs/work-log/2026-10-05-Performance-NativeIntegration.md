# Native 캔버스 통합 검증 및 보완

2026-10-05. 메모리 저장 어댑터에서 실제 컴포넌트를 조작해 이름 저장, 데모 undo/redo, 실패한 입력 재열기, viewer 차단, 버전 변경 후 재검토, NULL 변경, bigint 타입 변경과 명시 확인, 관계선 키보드/연결점 drag/구간 이동/자동 경로 복원을 확인했다. 1.1275 확대 상태의 연결점 이동도 저장 명령에 반영됐다.

브라우저 검증에서 성공 후 오래된 폼이 남는 문제를 수정해 해당 입력의 ACK 성공 때만 닫는다. 실패·대상 전환·unmount 후에는 다른 입력을 닫지 않는다. 포맷 편집창 wheel이 캔버스를 움직이거나 스크롤을 막지 않도록 surface 기본 방지를 편집창에서 제외했다. 잘못된 ratio 입력도 폼에서 수정 가능하도록 했다. 공통 canvas form과 순수 inline 명령 helper를 분리하여 모듈 순환 참조를 제거했다.

PNG source는 브라우저에서 렌더됐고 실제 Downloads의 native-interaction-test-2x.png(400221 bytes, 6496×1910)를 확인·보존했다. 다운로드 이벤트 대기는 도구 시간 초과가 있었으나 실제 파일 존재와 이미지 내용으로 확인했다. 파일은 artifacts/performance/2026-10-05-native-completion에 보관한다.

전체 pnpm check: 204파일2587테스트 통과, 26파일497조건부 skip, 포맷·전체 타입·서버/웹 빌드 통과. 마지막 공통 모듈 분리 후 관련 회귀5파일94테스트와 웹 타입 검증 통과. 최종 제품 전용 checkout에서 전체 검사를 다시 수행한다.

주의: 메모리 어댑터의 undo/redo와 저장 성공/실패는 실제 HTTP·NativeHistory ACK의 브라우저 검증으로 계산하지 않는다. 운영 프로젝트/DB를 수정하지 않았고 서버 저장·이력·개인 CAS는 기존 회귀 테스트 범위를 근거로 한다. 개별 조건부 DB통합497개를 실행한 것으로 주장하지 않는다. 테스트 전용 identities의 초안만 사용했다.
