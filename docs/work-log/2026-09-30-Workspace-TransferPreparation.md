# 워크스페이스 이관 및 검증 도구 준비

- workspace-transfer.mjs: 승인된 고정 ID/소유자에만 작동하는 dry run/원자적 이관/검증/재실행 도구를 구현했다. 이번 기록 시점에는 운영 이관을 아직 수행하지 않았다.
- test-workspaces.mjs: 운영 DB가 아닌 새로운 로컬 임시 DB를 생성하고 마이그레이션, API/sync/MCP/공간 권한/이관 테스트를 실행 후 해당 DB만 삭제한다.
- workspace-preview.mjs: 별도 임시 DB에 owner/viewer 계정과 샘플 설계를 준비하는 UI QA 서버다. 두 계정은 운영 계정이 아니며 서버 종료 시 해당 DB를 정리한다.
- workspace.integration.test.ts: 모든 주요 프로젝트 읽기/쓰기 경계, viewer 설계 차단/개인 상태/리뷰 허용, 멘션/알림 공간 범위, 역할 변경 후 재실행 차단, WebSocket 구독 거절/즉시 종료, 공간 보관/복원, 이관 오류 롤백/보존/중복 실행을 검증했다.
- 최신 격리 PostgreSQL 실행에서 5개 파일 38개 테스트가 통과했다. 프로젝트와 자식 테이블 잠금의 교착 가능성을 발견해 프로젝트의 최강 잠금을 먼저 잡고 자식은 스냅샷에서 읽도록 수정했다. 테스트 정리는 연결을 정상 종료한 후 강제 종료 옵션 없이 DB를 삭제하도록 보강했다.
- UI 테스트 로그인에 대한 사용자의 명시적 승인을 받았으나 현재 앱 Browser 연결이 없어 인증 후 화면 QA는 아직 완료되지 않았다. UI 단위/전송 권한 테스트와 웹 빌드는 통과했다.
