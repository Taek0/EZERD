## 한계

독립적인 디자인 목업이다. 데이터는 예시이며 상태 변경은 현재 페이지 메모리에서만 유지된다. 제품 API·DB·실제 협업 서버에 연결하거나 저장하지 않는다. 검증 결과·히스토리·DDL은 예시 시나리오이며 실제 엔진 결과가 아니다. 테이블·프로젝트 생성과 실제 파일 내보내기는 수행하지 않는다. 길이/정밀도 등 일부 필드는 입력 모양과 변경 피드백만 제공한다. 전체 기능 및 모든 입력 조합을 검증한 제품 구현으로 해석하지 않는다.

기존 분위기 비교는 실제 제품 복제가 아닌 참고용 스타일 재구성이다. 제품 코드 변경 없이 계획·상세 목업·결과 문서만 커밋한다. docs는 Prettier 제외 대상이며 제품 테스트는 재실행하지 않았다.
