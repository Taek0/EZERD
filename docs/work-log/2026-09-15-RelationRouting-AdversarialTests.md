# 관계선 라우팅 적대적 테스트 기록

## 확인한 문제

수동 굴곡점을 두 테이블 바깥쪽으로 옮겼을 때 세 연속 점이 같은 축에 있다는 이유만으로 가운데 점을 제거했다. 가운데 점이 양 끝점 사이에 있지 않은 되돌아감 경로에서도 제거되어, 반환된 조절점과 실제 폴리라인이 분리됐다.

고유한 X/Y 좌표를 갖는 장애물이 많을 때 수동 경로 탐색 비용도 빠르게 증가했다. 독립 측정에서 장애물 100개는 호출당 약 0.5초, 150개는 약 1.2초가 걸렸다.

## 추가한 검증

- 테이블 반대편의 수동 굴곡점이 실제 폴리라인 위에 남는지 확인한다.
- 굴곡점을 같은 축에서 더 멀리 이동했을 때 실제 경로가 변경되는지 확인한다.

## 결과

`pnpm exec vitest run apps/web/src/relation-routing.test.ts apps/web/src/relation-routing-adversarial.test.ts`를 실행해 테스트 파일 2개, 테스트 11개가 모두 통과했다.

추가 수동 굴곡 (300,150)의 왕복 경로도 회귀 테스트로 보존했다. 전후 직각 후보 조합과 되돌아감 검사 후 동일 grid sweep의 중복 정점 사례는 58개에서 0개로 감소했다. 직접 L자 후보를 장애물 검색보다 먼저 평가하도록 추가 최적화했다.
