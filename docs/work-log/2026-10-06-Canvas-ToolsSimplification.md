# 캔버스 도구 메뉴 정리 결과

- 상단바의 보기 선택 드롭다운과 자동 배치 버튼·더 보기 항목을 제거했다. 전체 테이블·도메인 맵 이동과 도메인 필터·필터 해제는 유지했다.
- 사이드바 도구 탭에서 카메라 저장·초기화, 테이블 복사·붙여넣기, 공유 캔버스 / 개인 화면 패널을 제거했다.
- 기존 보관 입력은 명시적으로 복구할 때만 `보관된 입력 복구` 편집기를 표시한다. 개인 화면·카메라 저장 데이터, 단축키 및 컨텍스트 메뉴 기능은 유지했다.
- 최초 화면은 기존과 동일하게 전체 테이블이며 도메인 선택 상태에서는 도메인 맵이다. 일반 진입 시 숨겨진 개인 화면 선택 상태가 저장·복원되지는 않는다. 복구 경로에서 개인 화면을 열어도 전체 테이블로 이동할 수 있다.
- 사용되지 않던 메모 폼 호출 상태와 카메라 초기화용 값을 제거했다. 상단 메모 추가는 기존 직접 생성 경로를 유지했다.
- 웹 타입 검사 통과: `node node_modules/typescript/bin/tsc -p apps/web/tsconfig.json --noEmit`.
- 관련 테스트 3개 파일, 38개 통과: NativeCanvasToolbar, NativeERDCanvas, native-clipboard-interaction. 한국어·영어의 제거 항목 부재와 도메인 필터 유지, 기존 입력 복구·단축키 동작을 확인했다.
- `pnpm format` 적용 및 `pnpm format:check`, `git diff --check` 통과. 브라우저 시각 검증은 수행하지 않았다.
