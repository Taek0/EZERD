# 편집 개선 사용 안내

작성일: 2026-09-14

## 도메인 맵
- 빈 캔버스 우클릭에서 새 도메인, 새 도메인 관계, 자동 배치를 선택한다.
- 도메인 카드 우클릭 → 도메인 직접 연결 → 목표 도메인 클릭으로 연결한다. Escape는 연결을 취소한다.
- 같은 두 도메인 사이에도 여러 관계를 만들 수 있다. 카드를 선택하면 속성 패널에서 연결 목록을 바로 확인할 수 있다.
- 연결된 도메인 강조는 관련 없는 카드와 선만 흐리게 표시한다. 강조 해제로 원래 화면을 복원한다.

## 테이블 편집
- 카드의 이름과 컬럼 셀은 더블클릭하여 편집한다. Enter 또는 포커스 이동으로 적용하고 Escape로 취소한다.
- 함께 보기에서는 물리명이 위에, 논리명이 아래에 표시된다. 좁은 카드의 컬럼 표는 내부에서 스크롤한다.
- 카드 아래 + 또는 속성 패널의 컬럼 생성 표로 추가한다. 신규 컬럼은 NOT NULL, PK는 미선택이 기본이다.
- 키 섹션에서 여러 컬럼을 체크하면 체크 순서대로 하나의 복합 UNIQUE/PK를 구성한다.
- 컬럼 우클릭 → FK 관계 연결 → 대상 테이블 클릭 → 대상 PK/UNIQUE와 양쪽 컬럼 대응 확인 → 생성한다. 대상 키가 없으면 먼저 만들어야 한다.
- 카디널리티는 양쪽 끝의 0..1, 1, 0..N, 1..N으로 지정한다. 물리 UNIQUE·NULL 제약은 자동 변경하지 않는다.
- 관계선 우클릭으로 관계를 삭제할 수 있다.

## 프로젝트 ENUM과 자동 배치
- 선택을 해제한 테이블 화면의 프로젝트 ENUM 섹션에서 이름·스키마·값 목록을 관리한다.
- 컬럼 생성 또는 컬럼 편집의 공통 ENUM 선택에서 적용한다. 이름을 변경해도 컬럼 참조는 유지되며 사용 중인 ENUM은 삭제할 수 없다.
- PostgreSQL DDL에는 ENUM 타입 정의가 테이블보다 먼저 포함된다. 이 기능은 생성 SQL을 내보내며 실제 DB 스키마를 변경하지 않는다.
- 자동 배치는 두 뷰에서 빈 공간 우클릭으로 실행한다. 테이블 화면은 현재 화면의 외부 참조를 포함하며 다른 화면의 배치와 테이블 소유권은 유지한다.
- 편집 후 상단 저장을 눌러 프로젝트에 반영한다.
