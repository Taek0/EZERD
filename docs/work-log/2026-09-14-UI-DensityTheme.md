# 공통 UI 밀도와 뉴모피즘 테마 변경 기록

작성일: 2026-09-14

요청에 맞춰 body 17→15px, 라벨 16→14px, 공통 입력·텍스트영역·선택 16→14px/행간20px으로 조정했다. 로고34px와 대시보드 제목44px는 유지했다. 툴바·경로·공지14px, 저장 메뉴13px으로 맞췄다. 진행 중/보관함의 외곽선과 버튼 inset 그림자를 제거하고 선택 상태는 은은한 배경색으로 구분했다. 프로젝트 카드 경계는 흰색70%, hover/focus-within은 옅은 회색으로 바꿨다.

공통 버튼은 회색과 밝은 청회색 배경, 부드러운 양각/음각 그림자를 적용했다. Untitled UI 원본 출처 주석은 보존하고 이후 제품 테마 override임을 별도로 명시했다. 포커스/비활성/로딩 동작을 보존했다. 삭제 확인 hover는 붉은색·흰색 글자가 유지되도록 우선순위를 명시했다.

확인 팝업 폭460→420px, 여백26→22px, 제목21→18px, 본문·버튼16→14px으로 변경했다. 버튼 높이40px는 유지했다. 드롭다운·컨텍스트 메뉴 폭248→224px, 선택 옵션 글자16→14px/행간20px과 최소높이36px으로 변경했다. 계정 팝업은430→390px, 여백24→20px이다.

검증: 실제 Vite 앱을 Chrome headless 1440×1000/390×844에서 실행했다. 모든 API를 별도 모의 응답으로 처리하여 사용자 데이터는 변경하지 않았다. 브라우저 플러그인의 Node 프로세스 종료 오류로 독립 Playwright를 사용했다. Computed style 측정 결과 body15px, 탭14px·border0·shadow none, 검색14px/높이40px, 생성 버튼14px/높이40px, 카드200×134px/white70% 경계, 확인 팝업420×189.375px·제목18px·본문14px·버튼14px/높이40px이다. 390px에서 수평 넘침이 없음을 확인했다. 대시보드와 확인 팝업 스크린샷을 시각적으로 점검했다. 검증 파일은 .cache/verification/density-{dashboard,confirm,mobile}.png와 density-metrics.json에 저장했다. 팝업 취소 동작도 통과했다. 공통 메뉴 수치는 CSS 정의이며 위 실제 측정 목록에는 포함하지 않는다.
