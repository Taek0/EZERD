# 직접 관계 조작 통합 상태

작성일: 2026-09-15

관계 레이아웃에 sourceAnchor/targetAnchor(카드 변과 비율), waypoints(최대 128개 내부 지점)를 추가했다. 기존 offset/bend 문서는 호환한다. JSONB 문서의 선택 필드 추가이므로 DB 마이그레이션은 필요하지 않다. 모델과 계약의 좌표·비율·길이 제한을 검증한다.

관계 끝점은 카드 테두리에 붙고, 내부 선분 이동은 양 끝점과 인접 직각 연결을 유지한다. 첫·마지막 선분 이동은 필요한 직각 연결을 추가한다. 카드와 부딪히는 이동은 가능한 범위로 제한한다. UI는 이동 중 미리보기만 보내고 포인터를 놓을 때 최신 문서에 변경 의도를 병합해 한 번 저장한다. 취소는 본인이 조절한 속성만 복원해 원격 반대쪽 접점 변경을 유지한다.

검증 완료: 접점·경로 계약 테스트 2개, 관계 조작/기존 경로/자동 저장 관련 테스트 30개 및 웹 타입 검사. 독립 검토에서 발견한 접점 비율의 부동소수 오차 사례는 추가 테스트에서 실패를 재현했다.

이후 보정 사항: 끝점의 접선축 좌표를 저장된 인접 waypoint와 미세 오차 범위에서 맞추도록 수정했고, Escape 포커스/전역 취소, 취소시 빈 경로 기록 제거, 선택 핸들이 까마귀발을 가리지 않는 표시를 보완했다. scripts/browser-direct-editing-smoke.mjs에 카드 타입·NULL·PK, 캔버스 새 테이블, FK 이름/대응관계, 선분·끝점 드래그 및 원자적 저장·취소·직렬화 복원을 준비했다.

최종 검증: pnpm check 통과(Prettier, 타입 검사, 단위 테스트 262개 통과, 선택 실행 DB 테스트 19개 제외, 빌드). 부동소수 접점 회귀 테스트도 통과했다. scripts/browser-direct-editing-smoke.mjs 브라우저 검증에서 직접 타입/NULL/PK 편집, 새 테이블, FK 이름/대응관계 및 원자적 생성, 선분/끝점 드래그, Escape 취소, 1회 저장과 직렬화 복원을 확인했다. 테스트의 중복 FK는 드래그 단계 전에 분리하여 대상 선을 명확하게 했다.

이전 실행을 막았던 승인 검토 서비스 오류는 재개 후 해소되었다. 기존 무관한 문서 이동과 README 변경은 커밋에서 제외한다.
