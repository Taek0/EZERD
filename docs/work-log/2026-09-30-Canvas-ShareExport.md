# 캔버스 공유 메뉴 및 PNG 점검 결과

## 변경

- 기존 고화질 PNG 버튼을 공유 아이콘으로 변경하고 프로젝트 내보내기 / 고화질 PNG 순서의 드롭다운을 연결했다.
- 내보내는 동안 중복 실행을 비활성화한다. 빈 뷰에서도 프로젝트 내보내기는 가능하며 PNG만 비활성화한다.
- 프로젝트 JSON은 자동 저장 처리 후 기존 서버 내보내기를 호출한다. 저장 대기·충돌·보관 실패가 있으면 재시도 안내를 표시한다.
- PNG 복제 시 계산된 CSS의 원본 페이지 SVG 참조를 내부 fragment로 변환한다. 관계선 마커 등 SVG 리소스가 원본 페이지를 가리킬 가능성을 제거했다.
- PNG 다운로드 링크를 DOM에 연결한 뒤 클릭하고 제거한다. 중복된 파일명 fallback도 정리했다.

## 검증

- 관련 Vitest 3개 파일, 15개 테스트 통과: Canvas, canvas-export, project-transfer. SVG 내부 참조 변환 및 외부 URL 보존 회귀 테스트 포함.
- 웹 타입 검사·프로덕션 빌드 통과. 빌드의 번들 크기 경고는 남아 있다.
- `pnpm format` 및 `pnpm format:check`, 변경 파일의 `git diff --check` 수행.
- 임시 로컬 fixture에서 실제 공유 메뉴의 두 항목과 프로젝트 내보내기 콜백 실행을 확인했다.
- PNG 생성 결과를 fixture 이미지로 표시해 한글 카드(736×676), 테이블 10개·관계 10개(6496×1852)의 내용과 관계선을 확인했다.
- 화면을 축소한 후에도 PNG 크기 6496×1852가 유지됐다.
- 브라우저 도구의 다운로드 이벤트는 시간 초과되어 OS에 저장된 파일은 확인하지 못했다. 이후 다운로드 링크 클릭을 fixture 내 이미지 표시로 대체하여 실제 PNG Blob의 디코딩과 시각 결과를 검증했다. 서버 JSON 내보내기의 전체 흐름은 실제 계정으로 검증하지 않았다.
- 임시 fixture는 제거했다. 동시에 진행 중인 문서 재분류 등 다른 변경은 이번 커밋에서 제외한다.
