# 편집 개선 구현 완료 및 최종 검증

작성일: 2026-09-14

## 완료 범위
- [x] 도메인 패널 독립 접힘, 회색 기본 카드와 큰 제목, 선택 시 연결 목록.
- [x] 빈 공간·도메인·컬럼·관계선 우클릭 메뉴, 직접 연결/Escape, 복수 관계선 분리.
- [x] 관련 도메인 강조·나머지 흐림. 필터는 설계 원본을 변경하지 않는다.
- [x] 두 뷰의 수동 관계 흐름 자동 배치. 순환·독립 카드, 최소 렌더링 크기와 이동된 캔버스 기준점을 처리한다.
- [x] 외부 참조의 소유권과 다른 화면 배치를 유지한다.
- [x] 프로젝트 공통 ENUM 생성·편집·사용 중 삭제 보호, 안정 참조와 PostgreSQL CREATE TYPE DDL.
- [x] 물리명 상단·논리명 하단, 5열 컬럼 정보, 더블클릭 편집과 Enter/Tab/blur 적용·Escape 취소.
- [x] 컬럼 생성 표, 신규 NOT NULL·PK 미선택, 카드 아래 +, 복합 UNIQUE 체크박스.
- [x] 대상 PK/UNIQUE와 순서별 컬럼 대응을 확인하는 FK 생성, 양끝 카디널리티, 까마귀발 및 관계 삭제.
- [x] 기존 저장·댓글·멘션·알림·대상 삭제 후 대화 보존 동작 유지.

## 최종 검증 결과
- pnpm check: 타입 검사, 단위 테스트 92개, 프로덕션 빌드 통과.
- pnpm test:integration: 실제 로컬 PostgreSQL HTTP 테스트 9개 통과. 일반 단위 실행에서 제외되는 9개를 별도 실행했다.
- PostgreSQL ENUM 포함 DDL 테스트 19개 및 실제 CREATE TYPE/테이블/FK/기본값 INSERT/배열/롤백 검증 통과.
- browser-domain-workflow-smoke: 최종 공유 패키지 빌드 후 재실행 통과.
- browser-table-workflow-smoke: 셀 편집·키·ENUM·FK 확인·끝점 선택·관계 삭제 통과.
- browser-editor-persistence-smoke: 최종 빌드 후 실제 앱 편집·저장·새로고침·ENUM/끝점 보존·다른 뷰 격리·390px 넘침 검사 통과.
- browser-release-smoke: 실제 앱 전체 흐름과 두 사용자 댓글·멘션·알림·삭제 대상 대화 보존 통과.
- 빌드에는 기존 대형 청크 안내가 남아 있으며 빌드 실패는 없다.

각 기능과 회귀 수정은 독립 커밋으로 기록했다. 기존 문서 분류 변경과 홈 화면 스타일은 이번 기능 커밋에 포함하지 않았다.
