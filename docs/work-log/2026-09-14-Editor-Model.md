# ENUM 및 관계 모델 확장 결과

작성일: 2026-09-14

- 프로젝트 ENUM 정의와 안정적인 컬럼 enumId 참조를 추가했다. 기존 문서의 선택 필드 부재를 그대로 지원한다.
- 이름 변경 시 참조를 유지하고 사용 중 삭제를 차단한다. 중복 이름·값, 객체 ID 충돌, UTF-8 길이를 검증한다.
- 관계 양끝 최소/최대 카디널리티와 설명을 선택 필드로 추가했다. 물리 키·NULL 제약은 자동 변경하지 않는다.
- API 저장 계약에 동일한 필드와 크기 제한을 적용했다.
- 테스트: 신규 테스트 RED 4실패를 확인한 후 구현했다. 모델·계약 6개 테스트 GREEN, 기존 관계 테스트 포함 16개 통과. 공유 패키지 빌드 통과.
