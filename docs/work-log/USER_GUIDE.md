# 첫 출시 기능 사용법

## 도메인 맵

- 도메인을 선택하면 오른쪽에서 이름·설명·색상·위치·크기를 편집한다. 아래 **연결된 도메인 관계**에 들어오고 나가는 관계가 함께 나온다.
- 도메인에서 우클릭하거나 포커스 후 Shift+F10을 누르면 상대 도메인을 고를 수 있다. 상대를 선택하고 관계 이름을 입력한 뒤 **관계 연결**을 누른다.
- 캔버스 도구줄의 **사이드바 모양 아이콘**으로 속성 패널을 표시하거나 숨긴다. 패널 왼쪽 경계를 좌우로 끌어 너비를 조절한다. 경계에 키보드 포커스를 두고 좌우 방향키(Shift로 큰 단위), Home/End도 사용할 수 있다. 표시 상태와 너비는 브라우저에 기억하며 설계 저장 상태에는 영향을 주지 않는다.
- 패널 위의 **› 도메인 관계** 제목을 누르면 화살표가 회전하면서 폼과 목록이 펼쳐지거나 접힌다. **연결된 도메인 관계** 목록도 같은 방식이다. 좁은 화면에서는 패널이 캔버스 아래에 배치된다.
- 카드 오른쪽 아래를 끌어 크기를 바꾼다. 도메인은 내용과 버튼이 겹치지 않도록 최소 240×210 크기를 유지한다. 긴 제목·설명은 카드 안에서 잘라 보여 주며 전체 내용은 속성 패널에서 편집한다.
- 도메인 열기 버튼 또는 더블클릭으로 내부 ERD로 들어간다. 돌아오면 이전 도메인 맵의 위치·배율을 유지한다. 이동은 빈 공간 드래그, 확대·축소는 버튼 또는 Ctrl/⌘+휠이다.

## 테이블 ERD

1. 도메인 내부에서 **+ 테이블**을 누른다.
2. 논리명·업무 정의와 물리명·스키마·주석을 각각 편집한다. 한쪽을 바꿔도 다른 쪽을 자동 변경하지 않는다.
3. **+ 컬럼 추가** 후 컬럼 행을 펼쳐 논리 타입·필수 여부와 DB 타입·길이·정밀도·배열·NULL·기본값을 편집한다. 화살표로 컬럼 순서를 바꾼다.
4. **+ 키 추가**에서 PK 또는 UNIQUE를 고르고 컬럼을 순서대로 추가한다. 하나의 키에 여러 컬럼을 선택하면 복합 키다.
5. **+ 테이블 관계 추가**는 먼저 논리 관계를 만든다. 실제 FK가 필요하면 관계 범위를 공통/물리로 설정하고 **물리 FK 정의**를 켠 뒤 양쪽 컬럼을 순서대로 연결한다.
6. **외부 테이블 참조**에서 다른 도메인의 원본을 배치할 수 있다. 참조에서 편집해도 원본이 바뀐다. **이 화면의 참조 제거**는 배치만 제거하고, **테이블 삭제**는 원본과 모든 배치를 삭제한다.

**모델 보기**의 함께·논리·물리는 화면 표시 방식이다. 각 객체의 **적용 범위**와는 별개다. 물리 FK 정의가 없는 관계는 물리 보기에서 숨긴다. 적용 범위 변경으로 생긴 모순이나 미완성 참조는 진단에 표시하며 값을 자동 삭제하지 않는다.

공통·논리·물리 메타데이터는 문자열 값을 갖는 JSON 객체로 편집한다. 잘못된 JSON은 필드 오류로 표시하고 마지막 유효한 값을 유지한다. 메타데이터 자체는 DDL 구문이 되지 않는다.

## 검토 대화와 멘션

- 객체를 선택하거나 빈 공간을 클릭한 다음 **검토 대화**를 연다. 새로 만든 객체에는 먼저 설계를 저장한 뒤 댓글을 연결한다.
- **댓글 등록**에서 내용을 쓰고, **＠ 멘션**으로 사이트의 사용자를 고른다. 동명이인은 내부 ID로 구분한다.
- 핀이나 대화의 위치 버튼을 누르면 해당 화면·객체로 이동한다. 답글, 해결, 다시 열기를 사용할 수 있다.
- 객체를 이동하면 핀이 따라간다. 객체나 화면이 삭제되어도 대화는 목록에 남고 대상 삭제 상태를 표시한다.
- 알림에서 멘션된 대화로 이동하면 읽음으로 표시한다. 알림은 열 때와 30초 간격으로 갱신한다. 대화 목록은 **새로고침**으로 다른 사용자의 변경을 다시 읽는다.
- 멘션한 사용자에게만 앱 내 알림을 생성하며, 자기 멘션은 알림을 만들지 않는다. 일반 답글 알림·메시지 편집/삭제·외부 알림은 현재 제공하지 않는다.

댓글·답글·알림은 설계 문서 저장과 독립이다. 오래된 설계 저장으로 다른 사용자의 대화를 덮어쓰지 않는다. username 기반이며 계정 인증·역할 권한은 없다.

## 저장과 내보내기

설계는 수동 저장이다. **저장하지 않은 변경** 표시가 있으면 저장 후 종료한다. 저장 중 계속 편집할 수 있으며 추가 편집은 다시 저장해야 한다. 다른 화면이 먼저 저장하면 충돌로 표시하고 내 편집을 유지한다. 최신 내용 다시 열기는 현재 편집을 버리는 확인을 거친다.

**PostgreSQL DDL ↓**는 지원 범위 안의 물리 구조를 SQL로 다운로드한다. 오류가 있으면 진단을 먼저 수정한다. 구체적인 타입·제약·기본값 범위는 [DDL 내보내기](./POSTGRES_EXPORT.md)에 있다.

사내 Wi-Fi 실행 방법은 [LAN 호스팅](./LAN_HOSTING.md)을 참고한다. 현재 서비스 실행 여부와 실제 다른 장치 접속 검증은 구현 상태와 별개로 확인한다.
