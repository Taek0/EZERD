# 히스토리와 ENUM 입력 동선 정리

- 히스토리 내역의 실행 취소 버튼을 제거했다. 전역 실행 취소와 삭제 복원 동작은 유지한다.
- 더보기는 내역의 글자 크기를 상속하는 박스·그림자 없는 텍스트 토글로 변경했다.
- 히스토리 필터는 공통 선택 컴포넌트와 건수 표시로 정리하고 불러온 이력 안내 문구를 제거했다.
- ENUM 편집기를 목록 위로 이동하고 추가 선택 시 생성 폼을 보이게 한 뒤 입력 포커스를 이동한다. 반복 클릭 시 작성 중인 입력은 초기화하지 않는다.
- 관련 테스트 11개를 통과했다. 전체 검증은 상단바·복구 UI 변경과 함께 수행한다.
