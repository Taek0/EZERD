# 도메인 뷰 배치와 관계 이름 충돌 개선

도메인 뷰의 테이블 묶음을 overview 도메인 카드 중심 좌표에 따라 배치한다. 각 묶음의 실제 카드 경계를 구하고 공통 배율을 계산해 묶음 사이 180px 간격을 확보한다. 묶음 내부 테이블 좌표 차이는 유지한다. 일치/누락된 도메인 위치는 결정적인 대체 위치를 사용하며 원본 도메인·테이블 좌표는 수정하지 않는다.

도메인 선택에 전체 체크박스를 추가하고 부분 선택을 표시한다. 전체 해제 시 적용 버튼이 비활성화된다.

관계 이름은 14px 글꼴의 보수적인 텍스트 경계로 카드 및 다른 이름과 충돌을 검사한다. 가까운 빈 위치에 이름을 배치하고 이동된 이름은 보조선으로 원래 관계선 중간점에 연결한다. 관계선 접점과 원본 관계 데이터는 유지한다. 이미지 내보내기는 기존 SVG getBBox 수집으로 이동한 이름 영역도 포함한다.

검증: 수직/대각선 배치, 묶음 간격, 내부 상대거리, 누락 위치, 원본 불변 및 긴 관계 이름16개의 비중첩·순서 독립성 테스트 통과. 배치는 브라우저 이미지가 아닌 좌표 계산으로 검증했다. UI에서는 전체 선택/해제와 적용 활성 상태를 확인했다. 전체 pnpm check에서 단위338개·타입·포맷·빌드 통과(DB23개는 제외).
