# 사용자명 정규화·고유성 구현

작성일: 2026-09-15

가입·이름변경·이름 로그인에서 공통 usernameSchema로 trim/소문자 정규화를 적용했다. 사용자명 단독 UNIQUE 및 DB 정규화 CHECK를 추가했다. 가입 재접속은 같은 PIN일 때만 기존 사용자 ID를 반환하고 다른 PIN에는 409를 반환한다. 변경은 조건부 ON CONFLICT로 동시 요청에서도 PIN·프로필을 덮어쓰지 않는다.

마이그레이션은 기존 이름 정규화 후 단독 고유 제약을 적용하며 중복 계정을 임의 병합하지 않는다. 실제 DB는 대소문자 정규화 후 중복 2그룹이 있어 아직 적용하지 않았다. 사용자 최종 정리 후 적용한다.

검증: 사용자 계약/문서/충돌 테스트 12개와 서버 타입 검사 통과. 임시 PostgreSQL DB에서 마이그레이션 및 HTTP API 통합 테스트 13개 통과(대소문자 가입/로그인/재접속/이름변경/다른 PIN/동시 생성 포함). 같은 실행에서 기존 autosync 테스트 2개 실패를 확인했고 별도 수정·최종 재검증 중이다. test-isolated.ts는 매 실행별 임시 DB를 생성하고 finally에서 삭제한다. 실제 데이터는 변경하지 않았다.
