# 테이블 카드 및 편집 패널 개선

작성일: 2026-09-15

Astra 담당자가 작성한 UI 코드를 주 에이전트가 적용했다. 타입의 길이·정밀도·소수 자릿수를 카드/사이드바/크기계산에 공통 표시한다. Tab/Shift+Tab으로 편집 셀을 이동하며 값을 저장한다. 카드 우클릭에서 컬럼 삭제(자체 확인), NULL/comment 개별 표시 전환을 지원하고 설정을 문서에 저장한다. 카드 헤더는 소유 도메인의 색을 따른다. 사이드바 컬럼은 드래그 정렬하며 타 테이블의 배열 위치와 키/관계 ID를 유지한다. 선택 애니메이션과 강조 스타일을 통일하고 컬럼 추가 섹션의 여백을 줄였다.

ENUM 관리에는 이름/값 검색, 값 개수·요약, 펼친 상세값과 스크롤 목록을 추가하고 생성 fieldset 윤곽을 없앴다. 기존 한 줄당 한 값 생성/편집 및 사용중 ENUM 삭제 방지는 유지한다.

타입·순서 테스트를 먼저 실패 확인 후 구현했다. 관련 단위 테스트 및 web typecheck 통과. scripts/browser-table-refinement-smoke.mjs에서 타입 숫자, 헤더 색, Tab/ShiftTab 저장, 표시 설정, 드래그 정렬, 자체 삭제 확인, 60개 ENUM 중 검색과 새 ENUM 생성을 실제 브라우저로 검증했다. 임시 fixture만 사용했으며 페이지 오류는 없었다.

최종 브라우저 검사에서 컬럼 선택 애니메이션과 길이 변경 후 카드·목록의 VARCHAR(48) 동시 표시도 확인했다.

미지정 도메인 색상도 도메인 카드와 같은 #8993a3를 테이블 헤더에 적용하도록 회귀 테스트 후 보정했다.
