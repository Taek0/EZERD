# 신규 프로젝트 네이티브 전용 생성

- 갤러리의 설계 형식 선택을 제거하고 신규 생성은 schemaVersion 2로 통일했다.
- 생성 계약은 formatVersion 생략 또는 2만 허용한다. API/MCP 및 직접 서비스 경계에서 명시적 v1 생성은 거부한다. PostgreSQL/MySQL/SQLite의 기본 DB 문맥에 맞는 빈 네이티브 문서를 저장한다.
- 기존 프로젝트 조회·v1 파일 가져오기·업그레이드는 유지했다. 기존 문서를 일괄 변환하지 않았다.
- 이전 형식 동작을 검증하는 통합 테스트는 생성 API의 과거 기본값 대신, 미편집 테스트 행만 v1으로 준비하는 전용 fixture를 사용하도록 갱신했다.
- 신규 생성 실제 REST/MCP 격리 DB 테스트 15개 통과. 관련 기존 형식 통합 테스트 107개 통과/3개 제외, 워크스페이스·갤러리 격리 DB 테스트 9개 통과.
- 통합 최종 pnpm check: 타입·포맷·빌드 성공, 단위 테스트 2762개 통과/502개 제외. 새 DB 마이그레이션은 필요하지 않으며 운영 데이터는 변경하지 않았다.
