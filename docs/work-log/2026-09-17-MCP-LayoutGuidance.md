# MCP 객체 배치 지침

서버 initialize instructions와 apply_project_changes 도구 설명에 배치 지침을 추가했다. 생성·이동 전 최신 문서를 읽고 같은 뷰의 x/y/width/height로 경계와 최소 40px 간격을 계산한다. 브라우저 스킬이나 스크린샷 대신 좌표 계산을 권장한다.

연결된 객체와 같은 업무 묶음을 가까이 두고 도메인 흐름과 PK→FK 방향을 일관되게 표현하도록 했다. 순환 관계는 묶음 배치하며 선 교차·카드 관통·긴 연결을 줄인다. 기존 배치를 불필요하게 변경하지 않고 작업 후 문서를 재조회해 같은 계산으로 확인한다.

이는 MCP 클라이언트 에이전트에 전달하는 지침이며 서버가 모든 배치를 자동 수정/거부하는 기능은 아니다. MCP 클라이언트 handshake 및 tools/list 테스트로 지침 전달을 확인했다.
