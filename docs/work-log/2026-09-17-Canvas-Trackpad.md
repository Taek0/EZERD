# 트랙패드 이동·확대 감도

일반 wheel의 두 축 이동량은 카메라 이동으로 처리한다. Ctrl/Meta wheel은 포인터 아래 좌표를 유지하면서 연속 배율로 확대/축소한다. 픽셀당 계수 0.0015, 이벤트 입력 ±40 제한, 기존 배율 0.25~2 제한을 사용한다. line/page deltaMode와 Shift 수평 이동을 지원하며 입력창 스크롤은 가로채지 않는다. 연속 이벤트는 최신 로컬 카메라를 기준으로 누적하고 공유 문서/히스토리를 수정하지 않는다.

검증: 실제 브라우저 scrollX=80, scrollY=100 입력에서 translate(-80,-100), scale(1), 페이지 scrollY=0 확인. Ctrl wheel -2에서 scale(1.003) 확인. 순수 계산 테스트에 두 축 이동·감도·포인터 기준점·한계·deltaMode·누적을 포함했다. 전체 단위 테스트 286개, 웹 타입·빌드·변경 파일 포맷 검사 통과. 브라우저는 Chromium이며 실제 Mac 트랙패드의 체감 감도는 사용자 확인 대상이다.
