# 편집 개선 후 출시 브라우저 회귀 검사

작성일: 2026-09-14

## 변경

- 기존 `scripts/browser-release-smoke.mjs`를 독립 접힘 패널과 컬럼 생성 그리드, 세로 키 선택 목록에 맞추어 갱신했다.
- 도메인 우클릭에서 관계 패널을 열고 도착 도메인을 선택한다.
- 테이블 생성 후 컬럼의 기본 NOT NULL 활성화와 PK 비활성화를 확인한다.
- 외부 테이블 참조는 선택 없는 속성 패널을 열어 추가·제거한다.
- FK 출발 컬럼과 대상 테이블을 선택한 뒤 대상 PK 및 대응 컬럼을 대화상자에서 확인하고 생성한다.
- 로컬 API와 Vite 프록시의 준비 상태를 확인한 후 브라우저 시나리오를 시작한다.

## 검증 결과

실제 Chrome의 분리된 두 사용자 세션으로 전체 시나리오가 통과했다.

- 도메인 크기 변경 시 제목·하단 버튼 충돌 없음, 사용자 지정 색상과 관계 생성.
- 패널 숨김·펼침, 테이블·컬럼·PK 작성, 논리/물리 표시 전환.
- 외부 참조 제거 후 재추가와 원본 보존, 명시적 FK 대응 확인, 문서 저장, DDL 다운로드.
- 두 사용자 멘션 알림과 읽음 처리, 답글, 해결·다시 열기.
- 카드 이동에 따른 댓글 핀 이동, 테이블 삭제 후 댓글 보존.
- 빈 공간 댓글, 대상 도메인 삭제 후 대화 보존과 도메인 맵 이동.
- 갤러리 호버와 모바일 가로 넘침 검사, 페이지 JavaScript 오류 없음.

API 재시작 시 502 응답과 개발 중 HMR로 입력이 초기화되는 일시적 실패가 있었으며, API 준비 확인과 UI 변경 종료 후 전체 검사를 다시 실행해 통과했다. 테스트가 만든 프로젝트와 두 사용자는 정확한 ID로 삭제한다. 사용자 기존 데이터는 변경하지 않는다.
