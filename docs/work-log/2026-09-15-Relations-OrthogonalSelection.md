# 관계선 자동 경로와 독립 선택

작성일: 2026-09-15

테이블 관계 렌더러를 별도 파일로 분리하고 상하좌우 접점을 선택하는 직각 경로 계산을 구현했다. 실제 카드 크기와 다른 테이블의 경계를 장애물로 사용하며 선 길이와 꺾임 수를 줄인다. 까마귀발은 테이블 밖의 마지막/첫 선분 방향에 따라 회전한다. 관계 클릭은 테이블 ID 대신 관계 ID를 선택하고 PK → FK 순서의 편집 패널을 바로 펼친다. 선 히트 영역을 stroke로 제한하고 우클릭 자동 정리를 추가했다.

테스트를 먼저 추가하고 구현했다. 독립 검토에서 수동 조절점이 직선 단순화로 소실되는 문제와 왕복 경로를 발견해 수정했다. 수동 검색의 중복 계산을 줄였다. 관계 경로 테스트 11개 및 기존 TableEditor 포함 20개 테스트 통과, web typecheck 통과. 브라우저 전용 연결 도구가 시작 오류로 두 차례 종료되어 기존 저장소의 Playwright 방식을 사용했다. 임시 로컬 fixture에서 독립 관계 선택, 테이블 미선택, 열린 PK 우선 편집 패널, 드래그와 자동 경로 복원을 확인했으며 실제 프로젝트 데이터는 변경하지 않았다.

완전히 겹치거나 다른 카드가 접점 전체를 가리는 배치에서는 완전한 회피가 불가능하므로 카드를 분리해야 한다. 경로는 테이블 장애물 회피와 꺾임 감소를 제공하며 모든 관계의 교차 수를 전역 최적화하는 기능은 아니다.
