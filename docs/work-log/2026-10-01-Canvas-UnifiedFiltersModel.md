# 공유 전체 캔버스 정규화 모델

[통합 계획](../planning/2026-10-01-Canvas-UnifiedDomainFilters.md)에 따라 공유 배치를 하나로 사용하는 규칙을 추가했다.

- `normalizeSharedTableCanvas`는 누락된 전체 테이블 배치를 보완하고 기존 공유 도메인 메모·관계선 배치를 전체 캔버스로 연결한다.
- 메모·테이블·관계 ID는 유지한다. 메모·관계선 좌표는 소속 도메인의 첫 테이블 기준으로 기존 소속 위치와 전체 위치의 차이를 반영한다.
- 기존 전체 관계선이 있으면 우선 사용하고, 여러 도메인 관계선만 있으면 도메인 ID 기준으로 결정적으로 선택한다. 반복 정규화는 같은 문서를 반환한다.
- 도메인 맵의 메모와 기존 개인 함께 보기의 메모·관계선은 변경하지 않는다. 개인 기록이 공유 데이터로 새어나가지 않는 것을 검증했다.
- `addTable`에 선택적인 생성 화면 인자를 추가했다. 도메인 필터에서 생성해도 실제 클릭한 전체 캔버스 좌표에 배치되며 소속 정보는 그대로 유지된다. 기존 3개 인자 호출은 계속 지원한다.

## 검증

`pnpm build:shared`와 모델·계약 테스트 24개 파일·176개 테스트가 통과했다. 공유 메모/관계선 좌표 이관, 기존 전체 관계선 우선, 개인 기록 비공개 유지, 입력 문서 불변성·반복 적용, 전체 좌표를 지정한 소속 테이블 생성을 확인했다.
