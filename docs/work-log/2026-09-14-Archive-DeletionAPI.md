# 보관함 프로젝트 삭제 API

작성일: 2026-09-14

DELETE /api/projects/:id는 expectedVersion을 검증하고 보관된 프로젝트만 원자적으로 삭제한다. 진행 중 프로젝트와 오래된 버전은409, 잘못된 입력은400, 없는 프로젝트는404다. 성공 응답은 {id,deleted:true}다.

기존 DB 외래 키 CASCADE로 프로젝트의 핀·답글·알림을 함께 제거하며 작성자 사용자와 다른 프로젝트는 유지한다. 실제 PostgreSQL HTTP 테스트에서 미구현404 RED를 확인한 뒤, 상태·버전 거부와 삭제·연관 데이터 정리를 GREEN으로 검증했다. 테스트가 만든 레코드만 정리했다.
