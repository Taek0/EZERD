# LAN 호스팅 설정 수정 결과

- 원인: `.env`의 `LAN_ALLOWED_CIDRS=127.0.0.1`은 CIDR 문법과 사설 IPv4 대역 검증을 통과하지 못했다.
- 현재 en0 네트워크에 맞춰 `LAN_ALLOWED_CIDRS=192.168.35.0/24`로 수정했다. 이 설정은 해당 LAN 대역의 클라이언트 접속을 허용한다.
- 빌드된 서버 설정을 `NODE_ENV=production`, `HOST=0.0.0.0`으로 로드하고 CIDR 파싱까지 성공함을 확인했다.
- 전체 서버 재시작 및 마이그레이션은 재실행하지 않았다. 사용자는 `pnpm host:serve`로 기존 빌드 결과를 실행하거나 `pnpm host:start`를 다시 실행할 수 있다.
- 네트워크가 바뀌면 허용 대역도 다시 확인해야 한다. MCP 공개 주소는 기존 로컬 주소를 유지했다.
- `.env`는 로컬 설정으로만 변경했으며 커밋에는 계획 및 작업 기록만 포함한다.
