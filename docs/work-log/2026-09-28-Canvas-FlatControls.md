# 캔버스 도구 전용 버튼 스타일 적용

- `canvas-tools.css`에 캔버스 도구 영역 전용 스타일을 추가했다.
- 커서, 손 도구, 축소/확대 및 배율 초기화 버튼의 일반 입체 버튼 배경과 그림자를 평면 스타일로 대체했다.
- 기본 상태는 투명 배경, hover는 평면 배경, 선택/누름은 옅은 파란색으로 구분하고 비활성 상태에서도 그림자가 생기지 않도록 했다.
- 도구 컨테이너의 그림자를 제거하고 기존 크기, 배치, 버튼 동작과 키보드 포커스 윤곽선을 유지했다.
- 일반 버튼 스타일은 변경하지 않았다.

## 검증

- `pnpm format` 성공. 관련 CSS 외 포맷 변경 없음.
- `pnpm format:check` 통과.
- `git diff --check` 통과.
- 공통 버튼 상태 규칙보다 전용 규칙의 우선순위가 높고 일반 버튼에는 적용되지 않음을 확인했다.
- 브라우저 시각 검증은 수행하지 않았다.
