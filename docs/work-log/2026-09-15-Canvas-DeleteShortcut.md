# 선택 카드 Delete 단축키

작성일: 2026-09-15

캔버스에서 선택한 테이블·도메인 카드에 Delete 단축키를 추가했다. 기존 자체 확인창에서 승인하면 모델 삭제 함수를 사용해 컬럼·키·관계 등 종속 데이터를 정리한다. 확인 대기 중 들어온 문서 변경은 최신 문서를 기준으로 보존한다. 입력·드롭다운·팝업 및 읽기 전용 상태, 반복 입력과 조합키는 처리하지 않는다.

검증: Canvas 테스트 5개와 웹 TypeScript 검사 통과. browser-delete-shortcut-smoke.mjs에서 테이블 삭제 취소/확인, 연결 관계 정리, 입력창 Delete 보호, 도메인 및 내부 테이블 삭제를 확인했다. 변경 파일에 Prettier 적용.
