# 핀 해결 상태 변경 시 필터 유지

작성일: 2026-09-15

원인: 공통 mutate가 PATCH 해결 상태 변경 후에도 onNavigate를 호출했다. 선택 핀이 변경되면 activeThreadId effect가 해결됨 포함과 프로젝트 전체 핀을 켰다.

수정: mutate에 이동 여부를 구분하고 해결/다시 열기 요청은 이동하지 않는다. 응답의 핀 상태만 갱신하므로 사용자가 설정한 두 필터를 유지한다. 등록·답글·명시적 위치 이동 동작은 유지한다.

검증: browser-pin-filter-smoke.mjs에서 해결 후 기본 필터로 핀이 숨겨지고 해결됨 포함/전체 핀 체크가 꺼진 채 유지됨을 확인했다. 해결됨 포함을 켠 후 다시 열어도 두 필터가 유지된다. 웹 타입 검사와 전체 Prettier 검사 통과. 브라우저 API는 테스트 fixture 응답을 사용했으며 실제 프로젝트 데이터는 변경하지 않았다. 기존 실행 서버를 사용했고 새 서버는 시작되지 않았다.
