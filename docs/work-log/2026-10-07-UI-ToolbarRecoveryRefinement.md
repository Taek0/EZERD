# 상단바·설계 확인·입력 복구 UI 정리

- 상단 더보기 메뉴는 설계 확인과 보관된 입력 복구 중심으로 정리했다. 중복된 생성·붙여넣기·관계 경로 초기화 항목 및 상단 핀 추가 버튼을 제거했다.
- 설계 확인 항목은 사이드바에서 분리해 더보기 메뉴로 여는 대화상자로 이동했다.
- 테이블·메모·전체 테이블·도메인 맵·도메인 필터·ENUM 버튼 크기를 통일했다. 캔버스 배율·도구 버튼은 기존 전용 스타일을 유지한다.
- 도메인 선택 메뉴와 선택값에 실제 도메인 색상 점을 표시한다. 공통 선택 컴포넌트에는 선택적 장식 렌더러만 추가했다.
- 입력 복구 화면에 요약·시간·항목별 공통 버튼과 닫기를 제공하고 내부 식별자와 원문은 펼쳐 확인하도록 정리했다. 긴 목록과 원문은 스크롤로 표시한다.
- 원문 보존, 복구 사본 생성, 작성자 확인, 다운로드·폐기 안전 검사는 유지한다.

## 검증

- 히스토리·ENUM 변경을 포함한 `pnpm check` 통과: 테스트 2,809개 통과(506개 조건부 건너뜀), 전체 타입·포맷 검사 및 빌드 성공.
- 기존 번들 크기 경고는 남아 있다. 브라우저에서의 수동 시각 검증은 수행하지 않았다.
- 관련 선택 컴포넌트·상단 메뉴·설계 확인·복구 테스트 25개도 통과했다.
