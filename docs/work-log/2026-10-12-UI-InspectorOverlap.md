# 탐색 클릭 및 속성 패널 배치 수정 결과

- 날짜: 2026-10-12
- [계획](../planning/2026-10-12-UI-InspectorOverlapPlan.md)
- 도메인 이름 클릭은 펼침/접힘만 수행한다. aria-expanded/aria-controls를 제공하며 별도 ↗ 열기 버튼은 유지한다.
- 도메인 관리 행이 272px 컨테이너 안에서 463px까지 늘어나는 현상을 재현했다. 내부 그리드 열의 최소 너비를 0으로 제한하고 버튼을 2열로 배치했다.
- 색상 라벨, 선택 버튼, 자동 색상 복원을 세로로 정렬했다. 수정 상태의 제목이 새 도메인 만들기로 보이는 문제도 수정했다.
- 우측 헤더 하단 및 섹션 간 여백을 확보했다. 펼친 컬럼 입력에 배경/테두리/12px 안쪽 여백을 적용하고 삭제 버튼을 분리했다. 다음 컬럼 전 10px 여백을 둔다.
- 브라우저 확인: 도메인 클릭 후 펼침 상태만 false로 바뀌고 경로는 도메인 맵 유지. 기본 너비에서 도메인 버튼 행 width/scrollWidth 모두 272px. 최소 패널에서도 234px로 일치하고 패널 자체도 clientWidth/scrollWidth 281px로 일치한다.
- 컬럼 편집의 최소 너비에서도 clientWidth/scrollWidth 230px로 일치한다. 테스트 데이터만 사용했고 실제 DB 편집은 하지 않았다.
- 관련 회귀 4파일 48테스트, 웹 타입 검사, pnpm format:check, 웹 프로덕션 빌드 통과. 기존 Vite 청크 크기 경고는 남아 있다.
- 3002의 최신 HTML/JS/CSS 응답을 확인했다. 기존 제품 서버는 최신 dist를 제공하므로 사용자 새로고침으로 반영된다. 임시 5187 검증 서버는 종료했다.
