- 캔버스 성능 계획과의 진행 순서·기준 커밋 관리 원칙을 연결하고 `docs/README.md`에 두 계획의 링크를 추가했다.
- 소스 이동·삭제·코드 리팩토링은 수행하지 않았다. `docs/EZERD.txt`, 실행 데이터·캐시·외부 자산은 수정하지 않았다.

## 검증

- 현재 소스·설정과 계획의 파일명·경로 참조를 대조했다. 목표 폴더는 아직 생성되지 않은 제안임을 명시했다.
- `pnpm format` 완료. 코드에 추가 변경은 없었다.
- `pnpm format:check`, `git diff --check` 통과. Markdown은 Prettier 제외 대상이므로 내용과 링크를 직접 확인했다.
- 문서 변경만 수행하여 단위·통합·브라우저 테스트와 빌드·성능 계측은 실행하지 않았다.
