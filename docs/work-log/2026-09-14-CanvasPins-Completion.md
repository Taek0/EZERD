# 캔버스·핀·프로젝트 피드백 완료 기록

작성일: 2026-09-14

## 반영 사항
- 테이블은 제목18px/행15px, 도메인도 글꼴을 확대했다. 테이블은 내용 기반 최소 크기를 적용해 내부 가로·세로 스크롤이 생기지 않으며 컬럼 추가 버튼과 리사이즈 손잡이를 분리했다.
- 카드 내부 우클릭 브라우저 메뉴를 차단하고 컬럼 추가·핀·PK 관계 연결 명령을 제공한다. PK/FK 행을 옅게 강조한다.
- PK에서 FK 방향으로 연결을 시작하고 포인터를 따르는 직각 점선을 표시한다. 대상 테이블에 복합 PK 순서·타입·ENUM을 보존한 컬럼을 자동 추가한다. 기본값은 기존 신규 컬럼과 같은 NOT NULL이며 이름 충돌을 구분한다.
- 테이블 관계는 직각 선만 사용한다. 표시 이름은 출발테이블.속성:도착테이블만, 경로 조절 값은 뷰별로 저장한다.
- 여러 도메인을 선택한 함께 보기를 저장할 수 있다. 해당 도메인의 원본 테이블과 집합 내부 관계만 표시한다.
- 현재 뷰 전체를 글꼴 포함2배 PNG로 내보낸다. 카드·관계·라벨을 포함하고 편집 손잡이·버튼은 제외한다. 브라우저 이미지 한도를 넘는 크기는 오류로 안내한다.
- 검색형 타입 선택과 대문자 표시, 물리/물리명 문구 제거, 도메인 복귀 버튼 정렬·개요에서 중복 버튼 제거, 도메인 열기 버튼 위치를 반영했다.
- 사이드바 토글에 열기/닫기 애니메이션과 모션 감소 처리를 적용하고 반복 클릭 시 텍스트 선택을 막았다.
- 도메인 색상은 색 영역·색조 슬라이더·HEX·팔레트가 있는 공통 팝오버다. Untitled UI 해당 색상 예제는 소스가 유료이므로 공개 React Aria로 구성했으며 유료 원본 사용으로 주장하지 않는다.
- 보관함 삭제, 오른쪽 보관/삭제 버튼, 보관 hover 빨강, 대시보드 탭·카드 윤곽을 반영했다. 확인은 전역 자체 대화상자로 통일했다.
- 검토 대화를 핀으로 변경했다. 빈 공간이 기본이고 우클릭 위치에서 작성할 수 있으며 전체 프로젝트 작성자의 핀과 답글을 스레드로 표시한다. 폰트·알림 크기도 맞췄다.

## 검증
- pnpm check: 타입 검사·단위112개·전체 빌드 통과.
- 실제 PostgreSQL HTTP 통합11개 통과: 보관 상태/버전 삭제 보호, 연관 데이터 정리, 함께 보기 핀 저장/뷰 삭제 후 대화 보존 포함.
- 테이블 브라우저 검사:9개 긴 설명 컬럼 카드에서 scrollWidth=clientWidth688, scrollHeight=clientHeight561. 검색/하이라이트/자동 FK/경로 저장 통과.
- 캔버스 브라우저 검사: 선택 도메인 집합·원본 소유권, 핀 좌표, 색상 선택, 점선 미리보기, 실제2376×944 PNG 확인.
- 실제 앱 브라우저 검사: 다른 작성자 핀과 답글, 다음 위치 핀, 보관/삭제 취소·확정·포커스 복귀 통과. 브라우저 기본 대화상자와 페이지 오류0건.
- 기존 문서 분류 변경을 제외하고 기능 단위별 커밋했다.

새 도메인이나 함께 보기 화면에 공유 핀을 남길 때는 해당 설계를 먼저 저장한다. 핀·답글은 설계 문서와 별도로 저장된다.
