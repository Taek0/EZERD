# 테이블 카드 타입 편집과 가독성 개선

- 본문 17→18px, 헤더 20→21px, 보조 라벨 13→14px로 확대하고 공유 카드 geometry의 문자 폭과 행 높이를 갱신했다.
- 타입을 공통 Button 기반 텍스트로 표시하고 클릭·Enter·Space 활성화 시 공통 SearchType을 연다.
- 카드 검색에는 돋보기를 생략한다. 선택·Escape·포커스 이탈로 편집을 종료하고 선택·취소 후에는 타입 버튼으로 키보드 포커스를 복귀한다.
- 타입 폭에 입력 여유를 추가하고 긴 타입 텍스트에 줄바꿈을 허용한다.
- 웹 타입 검사 및 TableEditor/table-geometry 테스트 18개 통과. 기존 브라우저 스크립트에 열기, 선택 종료, Escape 취소, Tab 종료 확인을 추가했다. 브라우저 실행은 부모 작업의 검증 단계에서 진행한다.
- 개발 서버는 시작하지 않았다. 기존 무관한 변경은 커밋에서 제외한다.
