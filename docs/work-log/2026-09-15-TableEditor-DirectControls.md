# 테이블 카드 직접 편집과 관계 설정 정리

작성일: 2026-09-15

카드 타입은 공통 SearchType으로 검색하여 직접 선택하며 ENUM과 배열 상태를 지원한다. NULL 허용은 체크박스로 바꾸고 PK 컬럼에서는 비활성화했다. 컨트롤 포인터·클릭·키 이벤트가 캔버스 드래그로 전달되지 않도록 처리했다.

컬럼 우클릭과 사이드바에 PK 지정·해제를 추가했다. 공통 helper는 복합 키 순서를 보존하고 PK 추가시 NOT NULL을 설정하며 마지막 멤버 해제시 빈 키를 제거한다. 기존 FK가 참조하는 PK는 동일 컬럼 순서의 다른 키가 없으면 변경을 차단하고 이유를 표시한다. 컬럼 생성시 PK 추가도 같은 helper를 사용한다.

관계 편집은 컬럼 대응 요약, 관계명과 끝점 설정을 앞에 표시하고 테이블 변경·FK 매핑·참조 동작·설명은 고급 설정으로 접었다. 도메인 캔버스 우클릭에서 해당 좌표에 새 테이블을 생성한다. 통합 뷰에서는 기존 생성 제한을 유지하며 소유 도메인 화면에서 생성하라는 이유를 메뉴에 표시한다.

검증: TypeScript 웹 타입 검사 통과. column-primary-key, TableEditor, Canvas, table-geometry 네 테스트 파일의 26개 테스트 통과. 수정 파일에 루트 Prettier 설정 적용. pnpm exec의 Windows 실행 파일 탐색 실패로 로컬 node_modules 실행 진입점을 직접 사용했다.

ForeignKeyDialog 추출 및 편집은 다른 작업 범위다. 기존 문서 이동·삭제는 이 작업에 포함하지 않는다.

최종 통합 검증: pnpm check 통과(262개 테스트 통과, 선택 실행 DB 테스트 19개 제외). 브라우저에서 카드 타입 검색 선택, NULL 변경, 컬럼 우클릭 PK 지정과 사이드바 PK 해제, 캔버스 새 테이블 생성, FK 이름 및 대응관계 설정을 확인했다.
