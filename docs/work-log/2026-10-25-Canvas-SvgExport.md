# SVG 내보내기 추가

- 공유/내보내기 메뉴에 SVG 내보내기 항목을 추가했다. 현재 뷰·필터·물리/논리 모드와 정규화된 문서를 사용한다.
- 기존 SVG 생성기를 재사용하여 UTF-8 XML과 image/svg+xml Blob으로 다운로드한다. 추가 의존성이나 서버 렌더링은 없다.
- PNG 픽셀 제한을 우회하되 빈 화면·비정상 좌표 검증, 문맥 변경 시 중단, 파일명 정리와 Blob URL 회수를 유지한다.
- 관련 5개 테스트 파일 39개 테스트 및 웹 프로덕션 빌드 통과. 기존 큰 청크 경고는 남는다. 실제 브라우저 수동 검증은 수행하지 않았다.
- SVG는 텍스트와 벡터를 보존하지만 시스템 글꼴을 사용한다. 글꼴 또는 color-mix 지원이 다른 외부 뷰어에서 표시가 달라질 수 있다. 글꼴 포함이 필요한 경우 기존 PDF 내보내기를 사용할 수 있다.
- 호스팅 재빌드·재시작 후 적용되며 DB 마이그레이션은 없다.
