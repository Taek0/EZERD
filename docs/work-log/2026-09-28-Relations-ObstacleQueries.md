# 관계 경로의 축별 장애물 구간 재사용

작성일: 2026-09-28
기준: `b889777`, `feat/performance-measurement`.

## 변경

- 관계 계산 중 raw/expanded 장애물 집합마다 수평 y·수직 x의 열린 장애물 구간을 지연 생성한다. 같은 좌표의 후보 선분은 구간 배열과 이진 검색을 재사용한다.
- 실제 장애물이나 경로 후보를 제거하지 않고 기존 부등식과 후보 순서·점수를 유지한다. 맞닿은 열린 구간은 합치지 않아 경계 접촉 의미를 보존한다.
- 8개 미만 장애물이나 음수 크기·비정상 좌표는 선형 검사로 처리한다. 인덱스는 관계 계산 한 번에 한정되며 전역/문서 간 캐시는 없다.
- 자동 후보·수동 경로의 clear 검사에 적용했다. A* fallback search와 label 충돌 처리는 기존 구현 그대로다.

## 정확성·검증

- 2,000개 고정 난수 선분과 장애물 경계, 접촉·zero-length·diagonal·비정상 좌표를 기존 선형 검사와 비교했다.
- 수정 전 routing 함수를 테스트 전용 reference로 보존했다. 40개 자동/수동/self/중첩 장면에서 points/path/label/handle 전체를 비교했다. 입력과 경로 의미를 바꾸는 근사화는 적용하지 않았다.
- 전체 `pnpm check` 및 관련 검사 결과와 고정 커밋 실측은 후속 기록한다.
- 미커밋 사전 scale 실행에서 300개 first 약222ms, warm 중앙값197ms로1초 조건과30초 프로세스 제한을 통과했다. 최종 수치는 고정 커밋으로 다시 측정한다.
