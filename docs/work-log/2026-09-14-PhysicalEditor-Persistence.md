# 물리 전용 화면 저장 보존 검증

작성일: 2026-09-14

실제 앱 회귀 스크립트를 물리 전용 표시와 comment 라벨에 맞춰 갱신했다. 비어 있지 않은 기존 논리 정의, 스키마, 테이블 주석, 메타데이터, 기본값을 포함한 테스트 문서를 저장하고 카드 편집·재저장·새로고침 후 원래 값이 유지됨을 검증했다.

논리 전용 테이블은 화면에 표시되지 않으며 자동 배치 후에도 해당 배치가 변경되지 않는다. 물리 테이블의 외부 참조와 다른 뷰 배치, ENUM 참조, 관계 양끝 정보도 보존된다.

검증: scripts/browser-editor-persistence-smoke.mjs 실제 Chrome 통과. 390px 화면 가로 넘침과 런타임 오류 없음. DDL·설계 확인·모델 보기 UI 부재 확인. 생성한 테스트 프로젝트와 사용자만 정리했다.
