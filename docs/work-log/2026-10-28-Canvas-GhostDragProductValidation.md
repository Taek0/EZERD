# 고스트 드래그 제품 브랜치 검증

- 원격 main 42a6cb5 기준으로 고스트 드래그 제품 커밋만 선별했다. 관계선 자동 정렬 사전 검증·동일 경로 저장 개선과 lab fixture/측정 도구는 제외했다.
- 장면 회귀 테스트의 lab 전용 데이터 생성기 의존성을 제거했다. 동일한 10테이블·5컬럼 데이터와 모든 검증 조건을 테스트 파일 안에서 유지한다.
- pnpm format:check 및 전체 타입 검사 통과. 전체 테스트 3,192개 통과, 환경 조건부 500개 건너뜀. 서버·웹 제품 빌드 통과.
- 첫 전체 테스트는 기존 font-cache 5초 timeout 한 건으로 실패했다. 제한/skip/제품 코드 변경 없이 전체 테스트 재실행 시 모두 통과했다.
- 기존 웹 chunk 크기 경고는 남아 있다. 실제 DB 통합 테스트는 활성화하지 않았다. 기존 lab 브라우저 검증과 수치의 범위는 전날 통합 기록을 따른다.
- 제품 PR에 없는 lab 문서 링크는 원격 lab 커밋 링크로 바꾸고 Git 제외 원시 결과는 로컬 경로 안내로 명시했다.
