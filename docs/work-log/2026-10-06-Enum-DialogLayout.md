# 네이티브 ENUM 팝업 개선

- 헤더와 검색·건수·추가 도구 줄을 정렬하고, 목록/편집 본문을 제한 높이의 스크롤 영역으로 구성했다. 하단 닫기 영역은 분리했다.
- ENUM 카드와 값 배지, 편집·삭제 폼을 현행 에셋과 일치하도록 정리했다. 읽기 전용 및 DB별 ENUM 지원 규칙과 기존 입력 복구 기능은 유지한다.
- 종료 애니메이션 160ms, reduced-motion 즉시 닫기, 타이머 정리와 포커스 복귀를 적용했다. 팝업 내부 빈 여백 클릭으로 닫히지 않게 바깥 영역 클릭만 닫기 처리한다.
- 관련 테스트, 타입·포맷 검사 및 전체 빌드 통과. 최종 pnpm check 2762개 테스트 성공/502개 제외. 브라우저 시각 검증은 수행하지 않았다.
