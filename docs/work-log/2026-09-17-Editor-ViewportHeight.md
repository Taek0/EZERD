# 편집기 하단 화면 맞춤

편집기는 100dvh 안에서 상단바를 제외한 공간을 캔버스·속성·핀 패널에 배분한다. 고정 canvas 최소 높이와 좁은 창에서 페이지를 늘리던 규칙을 별도 canvas-viewport.css로 덮어썼다. 좁은 화면에서는 핀과 속성이 배정된 하단 영역 내부에서 스크롤한다. 기존 더티 responsive-shell.css는 수정하지 않았다.

실제 App 메모리 fixture의 Chromium 브라우저 검증 결과:

- 1512×827, 두 패널 열림: 페이지 높이 827, 캔버스/속성/핀 하단 모두 827.
- 1024×640: 페이지 높이 640, 캔버스 하단 약 474, 핀 하단 640.
- 390×844: 페이지 크기 390×844, 캔버스 약 257px·속성 약 172px·핀 약 219px 높이로 화면 안에 배치.

단위 테스트 286개, 웹 타입·빌드·포맷 검사 통과. DB 테스트 20개는 제외했고 실제 DB 변경은 없다. 임시 fixture·브라우저 뷰포트·탭·5175 QA 서버는 정리한다. 실제 macOS Safari에서는 별도 확인이 필요하다.
