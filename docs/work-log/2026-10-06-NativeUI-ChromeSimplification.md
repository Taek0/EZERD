# 네이티브 상단바·사이드바 정리

- 도구 탭과 관련 메뉴를 제거했다. 필요한 카드 표시 설정은 속성 패널로 옮기고 저장 입력 복구 경로는 유지했다.
- 새 도메인 관계 생성 버튼과 실행 경로는 도메인 맵에서만 허용한다. 표/컬럼의 FK 관계와 기존 관계 편집은 유지한다.
- 목록 탭의 도메인/테이블 그룹은 기본 펼침, 도메인/테이블 관계 그룹은 기본 접힘이다.
- 반복적인 미저장 배치·미확인 요청 상태 문구는 일반 상단에서 숨기고 명시적인 복구 화면에서 확인할 수 있게 했다. 실제 오류와 저장·내보내기 보호 로직은 제거하지 않았다.
- 보관된 입력 복구는 ⋯ 내부로 이동하고 차단된 상태에서도 열 수 있다. 다시 불러오기 버튼은 제거했다.
- DB 종류·목표 DB 버전·편집 상태를 하나의 상단 메타데이터 행으로 통합했다.
- KO/EN UI, 생성 가능 범위, 목록 기본 상태, 복구 접근·미확인 요청 취소의 비동기 보호를 테스트했다. 위치가 바뀐 회귀 테스트도 새 경로로 갱신했다.
- 전체 pnpm check 통과: 2762개 테스트 성공/502개 제외, 타입·포맷·빌드 통과. 기존 번들 크기 경고는 유지된다. 브라우저 시각 검증은 수행하지 않았다.
