# 공간 초대 계정 전환과 세션 정합성 보완

- 실제 워크스페이스 QA에서 계정 메뉴에 로그아웃이 없어 다른 계정의 초대 수락으로 전환할 수 없음을 확인했다. 한국어/영어 로그아웃과 POST /sessions/logout을 추가했다.
- 서버는 요청을 인증하고 해당 사용자의 현재 토큰에 해당하는 세션만 폐기한다. 다른 로그인 세션은 유지한다. 폐기 이벤트로 해당 토큰의 WebSocket을 즉시 종료한다.
- UI는 동기화/자동 저장을 멈춘 뒤 서버 폐기와 로컬 로그인 정리를 수행한다. 사용자별 내구성 큐와 언어/화면 설정은 유지한다. 서버 폐기 실패와 저장소 정리 실패를 명확하게 표시한다.
- 임시 서버 재시작 후 시간상 만료되지 않은 캐시 토큰이 사용자 조회 401 이후 새 로그인에서도 재사용되는 문제를 발견했다. 사용자 확인 전에는 세션을 활성화하지 않고, 401/403/404 캐시는 폐기한다. 사용자 확인 정보가 없는 레거시 캐시는 PIN 로그인으로 갱신한다.
- localStorage 사용자 ID와 탭별 sessionStorage 토큰이 다른 계정을 가리킬 수 있어 세션 캐시에 인증된 userId를 함께 저장한다. 서로 일치하지 않으면 PIN 로그인으로 재발급한다. 새 사용자 로그인은 이전 미검증 세션을 재사용하지 않는다.
- 화면에서 정상 로그아웃→다른 계정 로그인→초대 수락을 검증했다. 회귀 테스트 5개와 격리 DB의 현재 세션만 폐기/다른 세션 유지/실시간 연결 종료 테스트가 통과했다.
