# 갤러리 도구 줄 및 워크스페이스 관리 개선

- 기본 프로젝트 정렬을 생성 시각 오름차순으로 바꾸고 동률은 ID로 안정적으로 정렬한다. 최근 수정순/이름순은 명시적 선택 시 사용한다. 새로운 초안과 저장된 새 프로젝트는 기본 생성순에서 기존 카드 뒤에 표시된다.
- + 버튼 대신 작은 ⋯ 메뉴에 새 프로젝트 생성/가져오기를 제공한다. 기존 가져오기 컴포넌트의 사용자 지정 트리거로 연결하고 하단 버튼은 제거했다.
- 검색 포커스의 outline/box-shadow를 제거하고 배경 변화로 표시한다. 정렬 버튼의 불필요한 여백을 줄이되 최대 레이블 폭을 예약해 위치가 흔들리지 않게 했다.
- 공간 선택 팝오버에 명시적 entering/exiting 애니메이션을 추가했다.
- 워크스페이스 관리 팝업은 고정 헤더와 스크롤 본문, 기본 정보·멤버·초대·위험 작업 구역으로 정리했다. 멤버 역할 선택 폭을 제한하여 삭제 버튼을 밀지 않게 하고 작은 화면용 배치를 추가했다.
- 생성/관리/받은 초대에 열림·닫힘 및 배경 애니메이션을 적용했다. 종료 전 160ms를 유지하며 reduced-motion에서는 즉시 닫는다. 역할 하위 선택 메뉴는 기존 공통 진입/종료 애니메이션을 사용한다.

## 검증

- `pnpm check` 통과: 포맷·전체 타입·전체 빌드, 테스트 553개 통과(40개 제외). 기존 Vite 번들 경고는 유지된다.
- 실제 컴포넌트와 가상 API 브라우저 테스트에서 First/Second 뒤 새 초안 및 Third가 추가되는 순서, 검색 focus의 outline/shadow 없음, 정렬 변경 후 검색 x=871.71875 유지, ⋯의 생성·가져오기 항목을 확인했다.
- 가져오기 메뉴에서 파일 선택기 열림 이벤트는 확인했다. 도구의 후속 파일 지정은 선택기 핸들이 만료되어 완료하지 못했으며 파일 업로드/실제 가져오기는 수행하지 않았다. 기존 파일 검증 테스트는 전체 검사에 포함된다.
- 관리 팝업에 멤버 3명과 초대 예시를 표시해 배치를 확인하고 스크린샷을 저장했다. 관리 창 종료 중 workspace-dialog-out/data-closing, 이후 제거, 공간 선택 workspace-popover-in, 생성/받은 초대 workspace-dialog-in을 확인했다.
- 운영 데이터는 변경하지 않았다. QA 파일은 제거했고 생성한 검증 서버를 종료했다.
