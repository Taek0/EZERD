# Native 편집기 원래 UI 이식 결과

2026-10-06. [계획](../planning/2026-10-06-Performance-NativeEditorUI.md)에 따라 원래 편집기의 canvas-first 구성을 Native 데이터/저장 경로 위에 이식했다.

- 상단 경로·생성·전체 테이블/도메인 맵·도메인 필터·논리/물리·공유/PNG·패널 토글.
- 오른쪽 속성/테이블/도메인/도구 탭, 패널 너비 조절, 접기/펼치기. 기존 폼은 숨김 상태로 유지하여 미저장 입력을 보존한다. camera 업데이트는 부모 프로젝트 패널을 다시 렌더하지 않는다.
- 하단 커서/손/배율/확대·축소/중앙 이동. H/V, Space·중간 버튼·손 도구 drag는 camera만 이동한다. 편집 입력과 버튼의 Space 동작은 보존한다.
- 도메인 카드의 기존 overline/상단 색상/진입 버튼과 표시 전용 복수 도메인 필터. filter는 Native scene 및 draft preview에만 적용하고 원본은 유지한다. PNG는 저장된 view를 출력한다고 안내한다.
- 생성 버튼은 검증된 Native 생성/메모/ENUM 폼으로 연결한다. v1 데이터 투영이나 저장 프로토콜 변경은 없다.

브라우저에서 손 drag(24,24→144,84),V 커서 전환,패널 접기1440px 확장,tab 키보드 이동,검색 입력 보존,패널너비390→400,도메인 필터0→10카드 복원 및 도메인 진입을 확인했다. desktop 1440×900에서 workspace 하단900,하단도구가 화면 안에 놓임을 확인했다. 모바일390px에서 가로 page overflow가 없고 패널을 아래에 배치했다. 모바일 도구 겹침을 보완했다.

전체 pnpm check 205파일2591테스트 PASS,26파일497조건부 SKIP,타입/포맷/서버·웹 build PASS. 마지막 단축키 target 보완은 제품 PR checkout 전체 검사와 브라우저에서 재확인한다. 회귀에는 toolbar 생성 폼 연결,패널 숨김 시 폼 유지,readonly 버튼,필터와 draft preview/원본 불변을 추가했다.

기존 v1 다중 선택/일괄 이동은 이번 Native UI 이식에 포함하지 않았다. 사용자 파일/DB/main은 수정하지 않았다. 실제 HTTP 저장 E2E 대신 기존 Native 저장 회귀와 읽기 전용 UI 프리뷰로 확인했다. 최종 성능/PR 반영은 별도 결과에 기록한다.
