# 캔버스 선택 도구와 도메인 표시 보완

## 변경

- 배율 왼쪽에 커서/손 도구를 추가했다. 커서는 빈 공간 드래그로 여러 카드와 메모를 선택하며, 선택한 객체를 함께 이동하거나 확인 후 삭제할 수 있다. Escape는 영역 선택을 취소한다.
- 손 도구에서는 캔버스 내부 편집을 비활성화하고 드래그로 화면만 이동한다. 도메인 뷰의 고정 배치와 읽기 전용 제한은 유지한다.
- 트랙패드 핀치 줌 계수를 0.002에서 0.003으로 높였다. 두 손가락 스크롤 이동은 유지한다.
- 일반 도메인 캔버스는 테이블 소유 도메인이 일치하는 배치만 표시한다. 과거에 남은 외부 도메인 배치도 숨기되 저장된 데이터를 일괄 삭제하지 않는다. 명시적 도메인 뷰는 선택한 도메인들의 테이블을 계속 표시한다.
- 기본 정보의 도메인 변경과 배치 정리는 별도 커밋 4ae4a87에 포함됐다.

## 검증

- `pnpm check` 통과: 포맷, 타입 검사, 테스트 342개 통과(23개 제외), 전체 빌드.
- 역방향 사각형 선택, 경계 교차, 묶음 이동의 상대 간격 및 원본 데이터 보존을 좌표 기반 테스트로 확인했다.
- 기존 번들 크기 경고는 남아 있다.
- 실제 Mac 트랙패드와 브라우저 포인터 동작은 이번 검증에서 실행하지 않았다. 실사용 감도는 사용자 피드백으로 추가 조정할 수 있다.
- 운영 데이터와 DB는 변경하지 않았다.
