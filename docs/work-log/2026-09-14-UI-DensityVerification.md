# UI 밀도 조정 최종 검증

작성일: 2026-09-14

요청한 뉴모피즘/스위스 디자인에 맞춰 전체 글꼴과 버튼·팝업 크기를 줄이고, 진행 중/보관함의 불필요한 윤곽을 없애며 프로젝트 카드 윤곽을 완화했다. 핀 형태·사이드바 글꼴·답글 입력 밀도 및 열고 닫는 애니메이션을 조정했다. 테이블 내부 글꼴은 확대하고 컬럼 편집 폼을 축소했으며 도메인 뷰는 툴바 아래 메뉴로 전환했다. 추가 요청에 따라 관계 조절점은 클릭 단계 이동 대신 자유 드래그로 바뀌었다.

실제 화면 기준 기본 본문 15px, 입력 14px, 핀 14px, 테이블 제목 20px/행 17px을 확인했다. 핀 답글 입력은 기본 28px에서 작성 시 64px로 확장된다. 도메인 뷰 하단 메뉴의 스크롤·Escape 포커스 복귀·생성·삭제 확인 취소를 검증했다. 컬럼 편집은 263×351px이며 가로 넘침 없이 이름·검색 타입·길이·NULL·설명을 수정하고 유지한다.

관계 드래그는 확대율 0.7 및 1.0에서 포인터 x/y 이동을 모델 좌표로 변환하며 뷰별 경로를 보존한다. 조절점은 카드 위의 별도 SVG에 표시되고 PNG에서는 제외된다. 일반뷰와 합성뷰의 경로 및 컬럼 편집이 독립 브라우저 fixture 새로고침 후 유지됐다. 서버 저장은 별도 실제 API 통합 검사로 검증했다.

최종 검증 결과:
- pnpm check 통과: 전체 typecheck, 115개 테스트 통과와 기본 제외된 통합 11개, production build 성공.
- 실제 서버 API 통합 11개 별도 통과(주 작업 검증).
- 테이블 및 도메인 뷰 브라우저 smoke 통과. 대형 카드의 내부 가로·세로 스크롤 없음.
- 핀/대시보드/팝업 및 동작 감소 설정 검증은 각 영역 작업 기록에 남겼다.
- 기존 Vite 번들 500kB 크기 안내만 남았다.

Untitled UI의 라이선스와 기반 컴포넌트 동작은 보존한다. 최신 요청에 따라 제품 스타일을 변경했음을 components/ui/NOTICE.md에 명시했다. 기존 README·문서 재분류·버전 문서 스크립트 변경은 이번 작업 커밋에 포함하지 않았다.
