# 기존 사용자 이름과 PIN으로 재접속

작성일: 2026-09-15

기존 등록 API가 동일한 이름과 PIN에도 UNIQUE 충돌을 반환해 접속을 거부하던 문제를 수정했다. (username, pin_hash)를 대상으로 원자적 upsert를 사용해 기존 사용자의 ID·색상·생성일·수정일을 그대로 반환한다. 새 조합은 새 사용자로 등록하고 동시에 같은 조합으로 접속해도 한 ID를 반환한다. 이름 변경시 다른 사용자의 조합과 충돌하는 경우에는 기존 409 검사를 유지한다.

데이터 초기화나 마이그레이션은 수행하지 않았다. 검증에서 생성한 테스트 사용자·프로젝트만 정리했다.

검증:
- 기존 구현에서 동일 조합 재접속이 409로 실패하는 테스트를 먼저 확인했다.
- 수정 후 서버 빌드 및 실제 DB 통합 테스트 12개 통과.
- 새 브라우저 세션에서 기존 이름·PIN 입력으로 정상 접속하고 기존 ID·색상·생성일 유지 확인.
- 기존 PIN·색상·패널 크기 및 모바일 브라우저 회귀도 통과.

초기 실행 도구의 승인 검토 시간 초과와 파일 읽기 샌드박스 오류가 있어 정확한 변경 패치를 작성하고 git apply --check로 적용 가능 여부를 확인한 뒤 실행했다. 기존 미커밋 문서 재분류는 커밋에서 제외했다.
