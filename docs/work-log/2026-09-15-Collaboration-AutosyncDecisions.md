# 자동 저장 동기화 채택 사항 반영

작성일: 2026-09-15

## 변경

- planning의 자동 저장 동기화 설계에 사용자 채택 사항을 반영했다: 변경·삭제 이력 7일, 오프라인 자동 재반영 24시간, 중복 처리 결과·삭제 표식 최소 7일, 미저장 로컬 편집 7일 및 만료 예고.
- 별도 복구함을 통합 이력의 변경·삭제·미반영 편집으로 대체하고, 삭제 미리보기와 새 ID 복원 및 현재 유효한 종속 관계 복원을 명시했다.
- 동일 사용자 권한, 서버 발급 세션, 단일 서버·PostgreSQL·WebSocket, 동시 수정 5명 이하와 전송 후 반영 1초 이내 목표를 기록했다.
- 개인 조합뷰의 공유 객체와 개인 화면 선택, 내용 편집과 배치 편집의 차이를 설명했다. 해당 배치 정책은 사용자가 추가 설명을 요청한 상태이므로 미결로 유지했다.
- 확정된 정책과 아직 필요한 구현 계약을 구분하고 완료 기준을 보강했다.

## 검증

- 설계 본문 전체의 복구함 표현을 점검해 별도 복구함을 구현하는 기존 지시를 통합 이력으로 변경했다.
- 채택된 기간·권한·규모·복원 정책이 미결 목록에 중복으로 남지 않는지 확인했다.
- git diff --check로 공백 오류가 없음을 확인했다. 문서 변경이므로 런타임 테스트는 수행하지 않았다.
- 커밋 범위는 해당 설계 문서와 이 작업 기록으로 제한했다. 기존 문서 재분류 등 미커밋 변경은 포함하지 않는다.
