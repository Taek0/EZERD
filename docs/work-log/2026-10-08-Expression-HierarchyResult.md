# 고급 인덱스·식 편집 계층화 결과

- 날짜: 2026-10-08
- 계획: [계층화 계획](../planning/2026-10-08-Expression-HierarchyPlan.md)
- `NativeAdvancedEditor.tsx`: 생성하려는 항목 선택과 선택한 항목 편집을 별도 토글로 구분했다. 손상된 고급 초안 안내에서 초기화 요구를 제거했다.
- `native-expression-tree.tsx`: 식 종류 선택을 생성하려는 식 선택으로 명명하고, 하위 식 토글에 위치와 종류를 표시했다. 기존 식 묶기는 별도 토글로 분리했다. 손상된 식 초안은 저장 불가·원문 유지로 안내한다.
- `native-editor-expression.tsx`: 비교할 컬럼·연산자와 비교할 값을 별도 fieldset으로 묶었다.
- AST 변환과 정책 판단, 저장 조건, 복구 키를 변경하지 않았다. PanelSection은 접혀도 내용을 마운트하므로 토글만으로 입력을 제거하지 않는다.
- 전용 UI 테스트에 한국어·영어 선택 계층, 하위 미완성 토큰, 비교 입력 그룹과 변환 검증을 추가했다. 공통 폼의 제출 버튼 제거에 맞추어 기존 검증은 활성 제출 버튼이 없는지 확인한다.
- 검증: 관련 UI·정책·메모 4개 파일, 59개 테스트 통과. 담당 TSX/테스트 파일만 Prettier 적용·확인. 전체 format 미실행.
- 웹 타입 검사: 실패. 수정 금지 파일 `NativePropertyEditor.tsx:287`에서 TS2367이 발생했다. 해당 파일은 수정하지 않았다.
- 실제 브라우저 상호작용 검증은 실행하지 않았다. UI 검증은 서버 렌더링 기반이며 정책·메모 테스트를 함께 실행했다.
- 실행 환경: 지정된 Node v24.18.1을 PATH에 추가했다. pnpm 실행은 샌드박스 realpath EPERM으로 실패하여 설치된 Node CLI로 Prettier·Vitest·TypeScript를 실행했다.
- 다른 작업자의 파일과 문서는 커밋에 포함하지 않는다.
