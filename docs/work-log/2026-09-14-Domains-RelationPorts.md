# 도메인 관계 끝점 배치

작성일: 2026-09-14

카드별·면별로 들어오고 나가는 모든 도메인 관계를 모아 고유한 연결점을 배분한다. 동일 도메인 쌍의 복수 관계와 반대 방향, 다른 이웃, 양방향 및 자기 관계를 처리한다. 한 면이 조밀해지면 다른 면의 여유 공간을 먼저 사용한다. 카드 경계와 곡선/라벨은 렌더링 시 계산하며 저장된 관계 객체는 변경하지 않는다.

미구현 RED 후 기하 테스트4개 GREEN: 끝점 중복, 순서 변경 안정성, 크기·위치 변경, 자기/양방향, 대상 누락,20개 관계의 끝점 분산을 검증했다. 노드와 포트 인덱스를 사용해 관계별 전체 목록 재탐색을 피했다.
