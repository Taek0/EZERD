# 비선택 메모 색상 수정 결과

- 원인: Native 캔버스 CSS 뒤에 로드되는 editor-feedback.css의 `.canvas-node.note-node`가 비선택 메모의 배경과 글자색을 덮었다. 선택 상태만 높은 선택자 우선순위로 정상 표시되었다.
- 메모 선택자를 `.native-erd-node.canvas-node.note`로 통일하여 선택 여부와 무관하게 배경색·대비 글자색·일반 상단 테두리를 유지한다.
- 밝은 색·어두운 색 각각 비선택 → 선택 → 선택 해제에서 실제 CSS 로딩 순서 기반 회귀 검사 추가. 관련 4개 테스트 파일 42개 테스트와 포맷 검사 통과.
- JSDOM의 CSS 변수 해석 한계로 검사에서 두 메모 색상 변수만 실제 값으로 치환했다. 실제 브라우저 시각 검증은 수행하지 않았다.
- 제품 변경은 CSS 규칙 하나이며 데이터 및 API 변경은 없다.
- 추가 검증: JSDOM의 묶음 선택자 우선순위 처리 차이를 피하도록 테스트에서 메모 선택자 묶음을 동등한 개별 규칙으로 분리했다. 이전 CSS에서 회귀 검사 2개 실패, 수정 CSS에서 관련 테스트 42개 통과를 확인했다.
