# 뷰 적용·핀 동작·실행 취소 완료 검증

작성일: 2026-09-14

## 변경
- 도메인 뷰에서 도메인을 선택하고 적용하면 즉시 해당 보기로 전환하고 메뉴를 닫는다.
- 핀 삭제를 자체 확인 팝업으로 제공한다. 새 답글/상태 변경이 있으면 오래된 삭제 확인을 거부하며 해당 핀·답글·알림만 제거한다.
- 핀/답글 입력은 회색 한 줄 콜아웃을 사용한다. Enter 전송, Shift+Enter 줄바꿈이며 한글 조합 중 Enter·빈 입력·중복 제출을 막는다.
- 컬럼 속성 라벨을 속성으로 변경했다. 관계 제목·테이블·카디널리티·컬럼 대응에서 PK 출발이 FK 대상보다 먼저 표시된다. 관계 추가 폼은 기존 관계 아래에 있다.
- 다른 도메인 테이블 목록은 저장 도메인 뷰에서 실제 키 관계로 연결된 외부 테이블만 표시한다. 클릭으로 이동·추가하지 않는다.
- Ctrl/Cmd+Z로 설계 편집을 되돌린다. Ctrl/Cmd+Shift+Z 또는 Ctrl+Y로 다시 실행한다. 연속 입력과 드래그를 묶고 저장 후에도 기록을 유지한다. 입력창 내부는 브라우저 기본 텍스트 실행 취소를 사용한다.

## 범위
실행 취소는 현재 프로젝트의 설계 문서 대상이다. 공유 핀·답글, 핀 삭제 및 프로젝트 자체 삭제는 포함하지 않는다. 다른 프로젝트/최신 문서를 열거나 브라우저를 재시작하면 실행 취소 기록은 초기화된다.

## 검증
- pnpm check:121개 단위 테스트, 전체 타입 검사와 빌드 통과.
- PostgreSQL HTTP 통합12개 통과. 새 답글 후 삭제 거부·답글/알림 cascade·다른 핀 보존 포함.
- browser-undo-smoke:undo/redo, 저장 중 응답 경합, 드래그1회 복구, native 입력 실행 취소, 저장/재열기 통과.
- browser-pin-editing-smoke:Enter/ShiftEnter/IME, 회색 입력, 삭제 취소/확정, 다른 핀·초안 보존 통과.
- browser-views-relations-smoke:즉시 적용, PK→FK 표시, 추가 폼 순서, 참조 목록 필터/비상호작용 통과.
- 브라우저 페이지 오류 없음. 변경을 기능별로 커밋했고 기존 문서 분류 변경은 포함하지 않았다. 기존 대형 청크 빌드 안내는 남아 있으며 빌드는 성공했다.
