# 사이드바 토글 잘림 수정

작성일: 2026-09-15

사이드바 스크롤 본문의 자동 grid 행이 낮은 화면에서 overflow:hidden인 details를 2px까지 축소하여 제목과 내용이 사라지는 현상을 재현했다. inspector-body에 grid-auto-rows: max-content를 적용하여 각 섹션의 내용 높이를 보존하고 본문에서 스크롤하도록 수정했다. 기존 접기/펼치기 애니메이션은 유지한다.

공통 Select의 max-height:256px !important는 React Aria의 가용 공간 높이 계산을 덮어쓰므로 제거하고 Popover maxHeight={256}으로 옮겼다. 이 값은 최대 높이를 유지하면서 더 작은 화면 공간에서는 자동 축소할 수 있다.

검증은 서버 데이터 변경 없이 임시 React Canvas fixture와 인앱 브라우저로 진행했다. 1280×720, 1024×600, 390×844에서 도메인/테이블 토글, 중첩 컬럼 추가 폼, 타입 검색 팝오버의 화면 경계와 스크롤을 확인했다. 수정 전 2px이었던 도메인 섹션은 수정 후 접힘 40px, 펼침 95.6px/182px로 정상 표시되었다. 좁은 화면에서는 페이지와 패널 스크롤로 마지막 삭제 버튼까지 접근했으며 최종 하단은 820px(뷰포트 844px)이었다. 타입 팝오버의 상단은 8px 이상, 하단은 각 뷰포트 안이었다. 색상 팝오버는 1024×600에서 키보드로 마지막 추천 색상에 접근할 때 내부 스크롤이 이동하고 하단 592px 안에 표시됨을 확인했다. 1280×720 및 390×844에서도 전체 색상 팝오버가 화면 안에 배치되었다.

공통 UI/inspector-state 기존 테스트 2개 파일 7개 테스트 통과, 수정한 3개 파일의 루트 Prettier 3.9.6 포맷 적용 및 git diff --check 통과. pnpm exec 실행 파일 연결이 없어 설치된 node_modules/.pnpm의 동일 버전 CLI를 직접 실행했다. 웹 typecheck는 병행 구현 중인 sync-history-labels.js 모듈 부재로 실패했으며 사이드바 변경 오류는 보고되지 않았다. 최종 통합 typecheck는 상위 작업에서 수행한다.

최종 통합에서 히스토리 요약 모듈을 포함한 전체 타입 검사·단위 테스트 230개·빌드 및 포맷 검사가 통과했다.
