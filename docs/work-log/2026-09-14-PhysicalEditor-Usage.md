# 물리 전용 편집 UI 사용 안내

작성일: 2026-09-14

- 테이블 화면은 물리명과 물리 컬럼만 표시한다. 논리/물리 선택, 적용 범위, 스키마, 테이블 주석, 사용자 메타데이터, 설계 확인 및 DDL 내보내기는 화면에서 제외한다.
- 테이블 제목과 컬럼 목록을 하나의 카드로 표시한다. 도메인 맵 복귀 버튼은 테이블 화면 상단에 있다.
- 컬럼 이름과 comment는 카드에서 더블클릭하여 편집한다. 타입은 선택 목록에서 고른다.
- 길이는 문자 타입, 정밀도는 숫자·시간 타입, 소수 자릿수는 정밀도가 설정된 숫자 타입에서 사용한다. 다른 타입에서는 해당 입력이 비활성화된다.
- 키는 컬럼을 선택한 뒤 생성한다. 관계는 출발 컬럼을 선택하고 대상 테이블과 키 대응을 확인하여 생성한다.
- 기존 문서의 논리 정보, 스키마, 테이블 주석, 기본값, 메타데이터는 저장 데이터에서 보존된다. 화면에서 제거한 항목을 일괄 삭제하거나 변환하지 않는다.
