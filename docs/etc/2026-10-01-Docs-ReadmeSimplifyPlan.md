# README 간소화 계획

- 제품 소개·핵심 기능·빠른 시작·주요 명령·코드 구조·상세 문서 링크 중심으로 줄인다.
- 배너, 실행에 필요한 버전·DB 준비 순서·접속 주소, DB 종류와 DDL의 지원 범위는 유지한다.
- 상세 권한·조작·MCP·운영 설명과 긴 작업 기록 목록은 기존 문서 링크로 안내한다.
- 진행 중인 기능 변경은 포함하지 않고 README와 이번 계획·결과만 커밋한다.
- 상대 링크·명령 대조·diff를 검증한다. Markdown은 Prettier 제외 대상이며 다른 작업의 코드 포맷은 변경하지 않는다.
