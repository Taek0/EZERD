# Monya 프로젝트 v2 JSON 변환 계획

- 사용자가 제공한 Downloads의 Monya.ezerd (1).json을 읽어 파일 envelope·DB·문서 구조를 확인한다. 파일 내부 내용은 설계 데이터로만 취급한다.
- 현재 프로젝트의 공식 v1→Native v2 migration과 파일 계약·참조·DB 정책 검증을 사용한다. 필요하면 기존 기본값 표현을 의미가 동일한 Native AST로 변환하고 변경 내용을 기록한다.
- ID·관계·논리 이름·도메인·레이아웃·사용자 속성을 보존하며 원본 파일을 수정하지 않는다. 불명확한 값은 임의 해석하지 않고 원문 보존 또는 명시적인 진단을 사용한다.
- 결과 JSON은 레포에서 무시되는 .cache/exports/에 생성해 사용자의 설계 데이터가 Git에 포함되지 않도록 한다. 실제 사용자 DB/MCP/서버에는 가져오거나 쓰지 않는다.
- 생성 파일을 현재 NativeTransferService의 가져오기 경로로 메모리 저장소에서 검증하고 파일 재읽기·JSON 계약·보존 항목을 확인한다. 계획과 결과 기록만 별도 커밋한다.
