# README 현행화

작성일: 2026-09-15

원격 배너를 유지하고 현재 제품 기능, 사용자명/PIN 인증, 자동 저장·WebSocket 동기화, 개인 도메인 뷰의 유지 범위, 핀 대화, 실행·검증 명령을 반영했다. DDL 내보내기가 현재 UI에서 제외된 점과 기존 생성 모델/검증 스크립트의 존재를 구분했다. 사용자 초기화 스크립트는 일반 설치 과정과 분리해 설명했다.

검증: package.json 실행 명령과 비교하고 README의 상대 문서 링크가 모두 존재함을 확인했다. 문서 변경이므로 앱 테스트·빌드·DB 작업은 실행하지 않았다.
