# 도메인별 참조 상세 표기 계획

- 대상: ezerd 프로젝트 `903ec4ff-2ca4-4724-8d8a-3ec98765a68b`.
- 최신 공유 version 9 / syncSequence 9와 모든 화면의 전체 배치 및 관계를 조회했다. 이전 작업 이후 변경된 사용자 배치를 기준으로 보존한다.
- 개요의 모호한 도메인 관계명 `참조` 5개를 실제 역할을 나타내는 이름으로 바꾸고, 설명에 자식 FK → 부모 PK 매핑을 열거한다.
- 실제 FK 18개에 업무상 역할, 도메인, 컬럼 매핑, 필수 여부, 1:N 의미, ON DELETE/UPDATE 동작을 기록한다. 관련 FK 컬럼의 논리 설명도 보완한다.
- 각 도메인 화면에 상세 참조 안내 메모를 추가한다. 기존 카드와 관계선에서 떨어진 화면 아래 여유 공간에 배치하고 내용이 잘리지 않는 크기를 지정한다.
- JSONB 내부 식별자와 실제 FK를 구분하며, 작성자/수행자 FK의 NO ACTION과 나머지 CASCADE 차이를 명시한다.
- 저장 후 설명 일치, 실제 스키마 속성 유지, 화면 배치 및 모델 진단을 검증하고 작업 기록을 커밋한다.
