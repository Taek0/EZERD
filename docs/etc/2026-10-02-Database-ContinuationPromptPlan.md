# DB 구현 자동 이어가기 프롬프트 정리 계획

- 사용자 요청에 따라 예약 프롬프트의 누적 커밋·검증·작업 이력을 제거하고 진행 work-log를 읽어 다음 미완료 단위를 이어가도록 줄인다.
- `worker-1-db`의 이름·주기·ACTIVE 상태·대상 채팅은 유지한다.
- 세부 구현 상태와 제약은 기존 제품 planning/work-log를 기준으로 관리하고 반복적인 상태 알림은 보내지 않는다.
- 추가 지시: 단위별 커밋 이후에도 전체 구현·필수 검증 완료까지 한 턴에서 계속한다. 사용자 수정이나 실제 종료 사유가 있는 경우만 예외로 둔다.
