# 원격 main 반영 계획

- 요청: 현재 커밋된 로컬 main을 원격 main에 반영한다.
- 제품 코드 기준점: `8a7be151db02503328befe6ace11be8164d80d99`.
- 최신 원격 기준점: `a289610ac5803af6866c560a493c4cf000aa7361`. 조회 결과 로컬 전용 67개, 원격 전용 10개 커밋이며 원격 문서 변경 8개는 로컬에도 동일 패치가 있다.
- 방법: 계획 기록을 독립 커밋하고 해당 시점의 커밋으로 격리된 worktree를 만든다. 원격의 기존 문서 기록을 보존하며 일반 merge로 이력을 통합하고, 제품 파일이 기준점과 같은지 확인한다.
- 보존: 현재 미커밋 제품 변경·새 파일·인덱스와 `docs/EZERD.txt`는 작업 범위에 포함하지 않는다. Git 기록 재작성과 force push는 하지 않는다.
- 검증: merge 결과·공백·독립 checkout의 가능한 포맷/타입/테스트/빌드 검사와 원격 HEAD를 확인한다. 실행 환경의 한계나 실패는 기록하며 이미 커밋된 제품을 임의 수정하지 않는다.
- 완료: 작업 결과를 `docs/etc/2026-10-02-Git-MainPushResult.md`에 기록하고 `HEAD:main`으로 일반 push한다. 로컬 main은 작업 중 변경이 보존되는 경우에만 fast-forward로 맞춘다.
