# 수정 코드 기반 ERD 동기화 계획

- 대상: 기존 ezerd MCP 프로젝트 `903ec4ff-2ca4-4724-8d8a-3ec98765a68b`.
- 기준: 현재 `apps/server/src/db/schema.ts`, 최신 `0012_snapshot.json`, workspace 권한·초대·감사 이력 서비스 코드. 운영 DB에 직접 접속하는 작업은 아니다.
- 초대와 감사 이력 테이블을 추가하고, 역할 ENUM 이름·키/외래키 이름·인덱스 등 기존 설계와 실제 구현 차이를 대조하여 반영한다.
- 초대의 pending 조건부 고유 인덱스는 조건 없는 UNIQUE 키로 변환하지 않고 조건과 함께 테이블 속성에 보존한다. 감사 이력의 workspace/user ID에는 코드에 없는 FK를 만들지 않는다.
- 실제 구현된 상태를 반영하도록 과거 설계 단계 메모와 권한 설명을 갱신한다. 기존 객체 ID·다른 도메인 배치는 유지한다.
- 최신 화면을 전체 조회한 뒤 새 카드 크기를 계산하고 여유 공간에 배치한다. 기존 결합 화면에도 새 테이블을 개인 MCP 변경으로 추가한다.
- 저장 후 컬럼·기본값·키·FK·ENUM을 원본과 비교하고, 카드 간 최소 40px 간격, 모델/DDL 진단을 확인한다. 작업 기록과 계획만 커밋한다.
