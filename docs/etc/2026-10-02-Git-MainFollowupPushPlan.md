# 원격 main 후속 반영 계획

- 요청: 원격 main에 아직 반영되지 않은 커밋을 push한다.
- 제품 기준점: `5b8f785016599eb6604ca0263d54bc9bcc95c08d`. 요청 시점의 로컬 전용 커밋 9개를 대상으로 한다.
- 원격 기준점: `e892fbf29a97abfb86c2bda5be497c34a2816775`. 원격 전용 이력 12개는 앞선 문서 선별 반영 및 main 통합·기록이다.
- 방법: 이전 격리 worktree를 복원해 커밋 이력을 통합하고, 제품 tree가 이번 기준점과 같은지 확인한 뒤 일반 push한다. force push와 기존 이력 재작성은 하지 않는다.
- 보존: 미커밋 변경·새 파일·인덱스·사용자 관리 `docs/EZERD.txt`를 이번 push에 포함하지 않는다. 작업 중 새로 커밋되는 제품 변경은 별도 후속 반영 대상으로 남긴다.
- 검증: 독립 checkout에서 frozen lockfile 설치·예시 환경 준비·포맷/타입/테스트/빌드를 확인하고 결과 기록을 작성한다. 최종 원격 HEAD를 조회해 실제 반영을 확인한다.
- 마무리: 원래 main이 작업 시작 후 새 커밋 없이 유지됐을 때만 안전한 fast-forward로 맞추고 격리 worktree를 보관한다.
