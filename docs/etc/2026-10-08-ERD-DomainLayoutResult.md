# 도메인 카드 배치 변경 결과

- [계획](2026-10-08-ERD-DomainLayoutPlan.md)
- ezerd overview의 5개 카드만 변경. 공유 version 79, 개인 version 15로 재조회 확인.
- 인증·프로젝트는 중앙 축, 워크스페이스는 중간 아래, 리뷰·동기화는 오른쪽 위·아래로 분기했다. 모든 카드 크기 320×240, 가로 계층 간 간격 180px.
- 전체 카드 영역은 1820×1040으로 가로형 균형을 유지한다. overview 카메라는 x=30,y=40,zoom=0.5로 설정하여 음수 좌표로 잘리는 문제를 없앴다.
- 앱의 `layoutDomainRelations` 실제 자동 경로를 사용하여 후보 배치를 비교했다. 베지어 곡선을 80개 선분으로 샘플링한 검사에서 다른 카드 관통 0건, 관계선 교차 1곳. 모든 카드 쌍 최소 40px 간격 통과.
- 도메인 관계는 현재 수동 경로를 지원하지 않으므로 실제 자동 경로를 기준으로 위치를 골랐다. 브라우저 시각 검증은 수행하지 않았다.
- 테이블·메모·도메인 관계 정의는 변경하지 않았다. 기존 UI 작업 중 파일은 커밋하지 않았다.
