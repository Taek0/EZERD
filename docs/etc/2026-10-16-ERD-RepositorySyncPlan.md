# 레포 변경 ERD 반영 계획

- 대상: TY / ezerd (903ec4ff-2ca4-4724-8d8a-3ec98765a68b).
- schema.ts와 마이그레이션 0016~0019를 기준으로 generic ENUM/프로필 조건, 개인 상태 테이블 2개 제거, sort_order 및 CHECK를 반영한다.
- 삭제 전 원본을 보존하고 연관 키·FK·인덱스·배치를 함께 정리한다. 설명 메모와 도메인 관계 설명도 현재 코드에 맞춘다.
- 기존 가로형 배치를 유지하며 변경 카드 크기와 관계선을 재조회·검증한다. 운영 DB는 변경하지 않는다.
