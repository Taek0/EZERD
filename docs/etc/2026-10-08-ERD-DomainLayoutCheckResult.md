# 도메인 개요 배치 점검 결과

- [계획](2026-10-08-ERD-DomainLayoutCheckPlan.md)
- 대상 ezerd, overview: 카드 5개, 관계 7개. MCP 두 조회 모두 성공, 다음 페이지 없음.
- 카드 크기는 모두 320×240. 모든 카드 쌍은 어느 한 축에서 최소 142.86px 이상 분리되어 있어 겹침/40px 미만 간격은 없다.
- 인증 (80,80), 공간 (542.86,-132.86), 프로젝트 (1072.86,-42.86), 리뷰 (701.29,487.24), 동기화 (1385.71,341.43).
- 상위 흐름은 인증→공간→프로젝트이지만 높이가 다르고, 프로젝트의 하위인 리뷰·동기화도 높이가 달라 계층 정렬이 불명확하다. 리뷰는 프로젝트 왼쪽 아래에 있다.
- 저장된 카메라는 x=40,y=40,zoom=0.7. 공간 카드 상단은 화면 좌표 약 -53px로 계산되어 화면 위로 잘릴 수 있다.
- 관계선은 수동 배치가 없으며 자동 경로를 사용한다. 실제 렌더링 교차 여부는 이번 좌표 점검에서 확정하지 않았다.
- 관계 설명에는 추가된 project_database_operations/native_request_cancellations의 일부 FK 설명이 아직 빠져 있다. 관계의 도메인 연결 자체는 존재한다.
- 원격 프로젝트·카메라·테이블 배치는 변경하지 않았다.
