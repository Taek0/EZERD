# 도메인 카드 배치 결과

- 기존 프로젝트 Overview의 카드 5개를 재배치했다. 공유 sequence 3.
- 인증은 왼쪽 중앙, 공간은 중간 위, 프로젝트는 중앙, 리뷰와 동기화는 오른쪽 위·아래에 배치했다.
- 인증에서 프로젝트로 향하는 직접 관계가 공간 카드를 관통하지 않도록 공간을 상단으로 분리했다.
- 기존 카드 크기 440×420과 색상·설명, 테이블 화면을 유지했다.
- 도메인 관계의 수동 경로는 현재 MCP에서 지원하지 않는다. 최초 경로 포함 요청은 원자적으로 거부됐으며 카드 위치 변경만 적용했다.
- 실제 웹의 layoutDomainRelations 함수를 사용하여 7개 Bézier 관계선을 각각 1001개 점으로 표본 검사했다. 비대상 카드 내부 통과 0건. 화면 렌더링의 픽셀 검사는 수행하지 않았다.
- 생성 스크립트의 모든 카드 최소 40px 간격 검사와 PostgreSQL diagnostics 0건 확인.
- MCP Overview 재조회: 5개 카드 좌표 모두 일치, 페이지 누락 없음.
- pnpm format 및 pnpm format:check 통과. 생성 스크립트와 가져오기 JSON 갱신.
