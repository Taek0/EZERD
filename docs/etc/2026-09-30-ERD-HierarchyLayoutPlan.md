# 도메인 설명과 계층 배치 계획

- 기존 MCP 프로젝트의 모든 화면 배치를 먼저 조회했다.
- 도메인별 역할, 소속 테이블, 다른 영역과의 연결 및 FK 예외를 설명한다.
- 전체 화면은 실제 FK를 기준으로 부모에서 자식으로 왼쪽에서 오른쪽으로 정렬한다. 도메인별로 누적된 불필요한 세로 공백을 제거한다.
- 도메인 화면은 해당 화면 내부 FK만으로 계층을 계산하고 부모를 자식 그룹의 중앙에 배치한다. 동기화 테이블들은 서로 FK가 없는 동등한 객체로 표시한다.
- 실제 카드 콘텐츠 크기와 최소 40px 간격을 유지하고 MCP 재조회로 검증한다.
- 생성 스크립트, 재가져오기 JSON, 작업 기록을 갱신한다.
