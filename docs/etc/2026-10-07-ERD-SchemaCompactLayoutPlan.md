# 코드 ERD 최신화 및 균형 배치 계획

- 기준은 현재 apps/server/src/db/schema.ts이며 기존 EZERD 프로젝트를 갱신한다.
- MCP 최신 프로젝트 및 개인 버전을 확인하고 전체 스키마 비교에 필요한 스냅샷을 보관한다.
- 기존 객체 ID와 사용자 설명을 유지하며 누락 테이블·컬럼·키·관계를 추가하고 변경된 물리 속성을 대조한다.
- 전체 뷰는 부모·자식 흐름과 도메인 묶음을 모두 드러내는 균형 잡힌 면적으로 재배치한다.
- 정확한 선 중첩뿐 아니라 가까운 평행선, 교차, 카드 관통, 라벨 충돌을 분리해 측정한다. 검증 가능한 범위와 잔여 제약을 기록한다.
- 도메인 화면도 새 컬럼에 맞게 카드 크기를 조절하고 필요 시 재배치한다.
- MCP 적용 결과를 재조회하고 로컬 산출물·검증 지표를 저장한다. docs/EZERD.txt는 수정하지 않는다.
