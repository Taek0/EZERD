# 전체 도메인 결합 화면 재배치 계획

- 대상: ezerd 프로젝트 `903ec4ff-2ca4-4724-8d8a-3ec98765a68b`의 기존 결합 화면 `119c0417-8e6e-40c1-b6c1-6acfc4356e39`.
- 최신 상태: 공유 version 7 / syncSequence 7, 개인 version 1. 결합 화면 전체 13개 카드와 관계 18개를 페이지 누락 없이 조회했다.
- 인증·프로젝트의 공통 부모 테이블을 왼쪽에 두고 종속 테이블을 오른쪽 도메인 구역으로 정렬한다. 리뷰는 스레드 → 메시지·알림 계층을 표현한다.
- 카드 콘텐츠에 필요한 크기는 유지하고 불필요한 도메인 사이 공백을 줄인다. 모든 카드 쌍은 최소 40px 간격을 확보한다.
- 개인 화면 배치와 필요한 관계 경로만 MCP `apply_personal_changes`로 변경한다. 작업 직전 개인 버전을 다시 확인한다.
- 저장 후 화면과 관계를 재조회하여 카드 겹침, 관계선의 카드 관통, 13개 테이블 및 18개 관계 유지를 검증한다.
