# 공개 문서 내부 주소 정리 계획

- 목적: 사용자가 요청한 내부 주소 변경을 공개 문서에 반영한다.
- 대상: LAN CIDR 계획·결과 문서와 워크스페이스 구현 재개 체크포인트에 남은 실제 사설 주소·대역.
- 방법: 실제 호스트와 승인 CIDR을 자리표시자로 바꾸고 실제 값은 기존 ignore 대상 `.env` 또는 비공개 운영 문서에서 관리하도록 설명한다. 명시적인 예시 주소는 유지한다.
- 범위: 서버·DB·로컬 `.env`·Git 기록·운영 이관 스크립트는 변경하지 않는다. 폰트는 사용자 결정에 따라 유지한다. `docs/EZERD.txt`와 다른 작업 변경은 보존한다.
- 검증: 문서의 실제 주소 잔존 여부와 diff 공백을 확인하고 이번 파일만 독립적으로 커밋한다.
