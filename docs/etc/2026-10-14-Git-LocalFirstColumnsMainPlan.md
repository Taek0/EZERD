# 로컬 우선 컬럼 편집 main 반영 계획

- 기존 작업은 원격 main 1923704까지 push 완료했다. 이후 새 구현은 별도로 로컬 main에만 반영한다.
- 성능 워크트리의 fbbc0d5(로컬 투영/ACK bridge), 9e80426(오프라인/권한 표시)를 선별한다. 계측 도구는 제외한다.
- 지원 범위는 큐에 보관된 컬럼 추가·이름 변경이다. 기존 자동저장 quiet window, 동일 폼의 전송 조율 및 다른 명령의 ACK 의미는 유지한다.
- 로컬 main에서 전체 검사 후 결과를 기록한다. 새 기능은 이번 요청의 선행 push와 구분하며 자동으로 원격에 push하지 않는다.
