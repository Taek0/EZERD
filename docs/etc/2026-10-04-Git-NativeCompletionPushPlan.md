# native 완료 커밋 원격 반영 계획

- 요청: 진행된 작업을 원격 main에 push한다.
- 제품 기준점: `71482ea7bcee91338dd55fd741bb24730b627b73`. 요청 시점의 로컬 main 전용 커밋은 8개이며 작업 트리는 깨끗하다.
- 원격 기준점: `041d24d7f3d447c7f84f57d191c272210a2bac11`. 원격 전용 커밋 2개는 이전 push의 포맷 교정과 결과 기록이다.
- 방법: 계획만 독립 커밋하고 별도 checkout에서 원격 이력을 일반 merge로 통합한다. 현재 제품 파일·MIT 안내·기존 자료가 유지되는지 확인하고 frozen lockfile·예시 환경으로 전체 검사 후 일반 push한다.
- 보존: 다른 브랜치와 `docs/EZERD.txt`는 변경하지 않는다. 작업 중 새 커밋이나 미커밋 변경이 생기면 별도 후속 대상으로 남긴다. force push와 기존 이력 재작성은 하지 않는다.
- 완료: 반영·검증 결과를 기록해 별도 커밋·push하고 원격 HEAD를 조회한다. 로컬 main이 계획 이후 그대로일 경우 fast-forward로 맞춘다.
