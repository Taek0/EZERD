# Test 프로젝트 구성 계획

- EZERD MCP로 새 `Test` 프로젝트를 생성한다.
- 사용자 도메인에 사용자와 사용자 주소, 결제 도메인에 결제와 환불 테이블을 만든다.
- 각 테이블에 기본 키를 설정하고 사용자 이메일에 유일 키를 설정한다.
- 사용자 주소 → 사용자, 환불 → 결제, 결제 → 사용자 외래 키를 구성한다.
- 사용자와 결제 도메인을 연결하고 결제 요청, 사용자 확인, 결제 결과 및 환불 규칙을 설명한다.
- 최신 프로젝트 버전과 동기화 순서를 기준으로 원자적으로 반영하고 재조회 및 구조 진단으로 검증한다.
- 실제 데이터베이스 DDL 실행이 아닌 EZERD 설계 문서 작성이다.
