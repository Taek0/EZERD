1. 도메인 맵 뷰
 - 아무 카드도 선택되지 않은 상태 우측탭 : 새 도메인 생성, 새 도메인 관계 생성, 연결된 관계 검색, 연결된 관계 리스트 나열 >> 전부 토글메뉴로 접힌상태 디폴트
 - 도메인 카드 기본값 회색으로, 도메인 이름 폰트 키우기
 - 캔버스 우클릭시 : 새 도메인, 도메인 카드 정렬, 새 도메인 관계(우측 탭)
 - 도메인 카드 우클릭시 : 새 도메인 관계(우측 탭), 도메인 직접 연결하기(목표 도메인 클릭하여 화살표 생성)
 - 도메인 카드 좌클릭시 : 우측탭에 상세 정보 표시 (도메인 이름, 도메인 설명, 연결된 관계, 새 관계 생성), 도메인간 관계는 다중 생성 가능, 필터링으로 연결된 도메인 골라보기

2. 테이블뷰
 - 기본적인 테이블 카드는 지금의 형태 유지
 - 기본으로 보여주는 컬럼 정보 : | PK,FK 여부 | 속성 | 타입 | null여부 | 코멘트 |
 - 테이블 관계 이름 : {출발테이블}.{속성}:{도착테이블}, 설명
 - 우측 탭 도메인 맵 뷰와 같은 토글 메뉴 적용
 - 참조 기호 추가
 - 테이블 관계 우클릭 하여 삭제 메뉴
2-1. 테이블뷰 우측탭
 - 선택 없는 상태: 토글 접힘 유지, 테이블 생성, enum 생성, 테이블 검색
 - enum 생성시: enum명, enum값 -> type에 enum명 으로 등록
 - 테이블 선택시(각 요소는 모두 토글가능)
	- 물리 특성, 논리 특성
	- 컬럼 추가 : 표 형태로 컬럼 생성, | PK 여부(기본값 X) | 속성 | 타입 | null여부(기본값 not null) | 코멘트 |
	- unique 생성 : 속성별 체크박스 세로로 나열하여 선택
	- 테이블 관계 추가 : 컬럼 선택, 대상 테이블 선택, 카디널리티 선택
2-2. 테이블 카드
 - 테이블 카드 내부에서 수정 가능한 항목 : 물리 테이블명, 논리 테이블명, 각 컬럼값
 - 논리 테이블명을 최상단, 바로 아래줄에 논리 테이블명
 - 생성된 컬럼 우측 하단 + 표시로 바로 컬럼 추가할 수 있도록 하기
 - 테이블 내부에서 값 바로 입력 허용하기
 - 컬럼 우클릭시 FK추가 메뉴, 추가 대상 테이블에 클릭하여 제약관계 생성
