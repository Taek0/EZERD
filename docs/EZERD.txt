1. 도메인 맵 뷰
 - 아무 카드도 선택되지 않은 상태 우측탭 : 새 도메인 생성, 새 도메인 관계 생성, 연결된 관계 검색, 연결된 관계 리스트 나열 >> 전부 토글메뉴로 접힌상태 디폴트
 - 도메인 카드 기본값 회색으로, 도메인 이름 폰트 키우기
 - 캔버스 우클릭시 : 새 도메인, 도메인 카드 정렬, 새 도메인 관계(우측 탭)
 - 도메인 카드 우클릭시 : 새 도메인 관계(우측 탭), 도메인 직접 연결하기(목표 도메인 클릭하여 화살표 생성)
 - 도메인 카드 좌클릭시 : 우측탭에 상세 정보 표시 (도메인 이름, 도메인 설명, 연결된 관계, 새 관계 생성), 도메인간 관계는 다중 생성 가능, 필터링으로 연결된 도메인 골라보기

2. 테이블뷰
 - 기본적인 테이블 카드는 지금의 형태 유지
 - 기본으로 보여주는 컬럼 정보 : | PK,FK 여부 | 속성 | 타입 | null여부 | 코멘트 |
 - 테이블 관계 이름 : {출발테이블}.{속성}:{도착테이블}, 설명
 - 우측 탭 도메인 맵 뷰와 같은 토글 메뉴 적용
 - 참조 기호 추가
 - 테이블 관계 우클릭 하여 삭제 메뉴
2-1. 테이블뷰 우측탭
 - 선택 없는 상태: 토글 접힘 유지, 테이블 생성, enum 생성, 테이블 검색
 - enum 생성시: enum명, enum값 -> type에 enum명 으로 등록
 - 테이블 선택시(각 요소는 모두 토글가능)
	- 물리 특성, 논리 특성
	- 컬럼 추가 : 표 형태로 컬럼 생성, | PK 여부(기본값 X) | 속성 | 타입 | null여부(기본값 not null) | 코멘트 |
	- unique 생성 : 속성별 체크박스 세로로 나열하여 선택
	- 테이블 관계 추가 : 컬럼 선택, 대상 테이블 선택, 카디널리티 선택
2-2. 테이블 카드
 - 테이블 카드 내부에서 수정 가능한 항목 : 물리 테이블명, 논리 테이블명, 각 컬럼값
 - 논리 테이블명을 최상단, 바로 아래줄에 논리 테이블명
 - 생성된 컬럼 우측 하단 + 표시로 바로 컬럼 추가할 수 있도록 하기
 - 테이블 내부에서 값 바로 입력 허용하기
 - 컬럼 우클릭시 FK추가 메뉴, 추가 대상 테이블에 클릭하여 제약관계 생성

1. 공통사항
 - 점 격자에서 점 크기를 조금 더 크게
 - PostgreSQL DDL 내보내기 일단 삭제
 - 상단의 검토대화/저장이 있는 공간 상하 너비 줄이기, 갤러리/검토대화/저장/알림 박스 폰트 및 크기 줄이기
2. 테이블 맵
 - 카드 위 테이블을 그리는 방법이 아닌 테이블 자체를 하나의 카드로 사용하는 방법
 - 스키마 항목을 제거
 - 논리 / 물리 분리 항목 제거, 물리만 사용 예정
 - 테이블 주석 제거
 - 값 설정에서 postgres 언급 제거, export 기능은 일단 사용하지 않을 예정
 - 주석 -> comment 로 변경
 - 사이드바
	- 생성된 컬럼 수정 : 적용범위 제거, 논리 컬럼명 제거, 의미타입 제거, 컬럼정의 제거, 논리필수 제거, postgresql 타입은 키보드 입력 받지 않는 선택으로 변경, 공통 enum 항목에서 '공통'제거, 길이/정밀도/소수자릿수 는 활성화 필요한 타입에만 활성화, 기본값sql식 삭제
	- 키 pk / unique : 적용범위 삭제, 키가 추가되지 않았음에도 계속해서 키 추가 버튼이 눌리는 문제
	- 테이블 관계 : 선택된 컬럼 없을때 관계 추가가 계속되는 문제, 적용범위 삭제
	- 사용자 정의 메타데이터 항목 제거
	- 설계 확인 탭 일단은 제거
 - 상단바
	- 도메인 맵으로 돌아가는 버튼 시각적으로 더 잘 보이게

 - 테이블 캔버스 우클릭 : 새 테이블
 - 테이블 카드 : 카드에서 타입,null 바로 선택 가능하게, 컬럼 우클릭시 key로 지정
 - 테이블 캔버스 사이드바 : 이미 존재하는 컬럼 클릭 -> pk 체크박스 추가, 테이블 관계 사이드바 가독성 개선작업 필요해보임. 너무 많은 데이터가 한 눈에 쌓이는 느낌.
 - PK->FK 관계 만들기 : 자동추가 되는 컬럼 이름 수정 가능하도록 레터박스(기본값은 유지), 대응관계 선택박스 추가(첨부사진 참조)
 - 까마귀발 위치 테이블 카드 주위에서 클릭하여 자유롭게 옮길 수 있는 형태로 변경
 - 테이블 관계 선은 선 자체(꼭짓점 유지한채 면)를 클릭하여 조절할 수 있게 변경

 - 테이블 카드 내부 타입 상자를 클릭하는 경우에만 텍스트박스가 보이게
 - VARCHAR 같은 긴 타입은 글자가 잘려보임, 돋보기 아이콘은 없어도 됨. 
 - 테이블 / 도메인 카드 선택 상태에서 delete 키 누르면 삭제
